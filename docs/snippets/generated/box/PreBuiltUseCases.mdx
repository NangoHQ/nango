### Files

| Function name | Description | Type |
| - | - | - |
| `files` | Sync the metadata of specified files or folder paths from Box. A file or folder ID can be provided. | [Sync](/guides/functions/syncs/sync-functions) |

### Users

| Function name | Description | Type |
| - | - | - |
| `users` | Fetches a list of users from Box. Requires an enterprise account. | [Sync](/guides/functions/syncs/sync-functions) |
