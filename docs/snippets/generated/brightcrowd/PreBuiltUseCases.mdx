### Books

| Function name | Description | Type |
| - | - | - |
| `book-analytics` | Fetches analytics for a specified list of books from Brightcrowd. | [Sync](/guides/functions/syncs/sync-functions) |
| `books` | Fetches a list of all books in an account from Brightcrowd. | [Sync](/guides/functions/syncs/sync-functions) |
| `books-by-id` | Fetches a list of specified books from Brightcrowd. | [Sync](/guides/functions/syncs/sync-functions) |
| `pages` | Fetches a list of all pages in a book from Brightcrowd. | [Sync](/guides/functions/syncs/sync-functions) |
