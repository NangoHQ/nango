### Others

| Function name | Description | Type |
| - | - | - |
| `acquire-attributes` | Take ownership of one or more attributes so this connection can write values for them. | [Tool](/guides/functions/tools) |
| `create-attributes` | Create new custom attributes (or acquire-by-template in one call) and take ownership of them. | [Tool](/guides/functions/tools) |
| `get-attribute-values` | Get the full paged value history for one specific attribute. | [Tool](/guides/functions/tools) |
| `get-correlation` | Look up the correlation (if any) between two specific attributes. | [Tool](/guides/functions/tools) |
| `get-metric-snapshot` | COMPOSITE: get a consolidated view of one metric - its recent values, this week's correlations involving it, and its recent weekly averages - in a single call. | [Tool](/guides/functions/tools) |
| `get-profile` | Get the authenticated user's basic profile and unit preferences. | [Tool](/guides/functions/tools) |
| `increment-attribute-values` | Add to (rather than overwrite) an owned numeric attribute's value for a given date, creating the day's entry if needed. | [Tool](/guides/functions/tools) |
| `list-attribute-templates` | List the attribute templates Exist supports (the catalog of trackable metrics, not the user's own tracked attributes). | [Tool](/guides/functions/tools) |
| `list-attributes-with-values` | List the user's attributes together with their recent values (up to the last 31 days) in one call. | [Tool](/guides/functions/tools) |
| `list-attributes` | List the user's attributes (metadata only, no values), including templated and custom attributes owned by any service or none. | [Tool](/guides/functions/tools) |
| `list-averages` | List weekly average values per attribute, optionally filtered by date range, group, or attribute. | [Tool](/guides/functions/tools) |
| `list-correlations` | List correlations Exist has generated in the last week, optionally filtered by attribute, strength, or confidence. | [Tool](/guides/functions/tools) |
| `list-insights` | List personalized insights Exist has generated for the user, optionally filtered by date range and priority. | [Tool](/guides/functions/tools) |
| `list-owned-attributes` | List only the attributes this connection's service currently owns (i.e. can write values for). | [Tool](/guides/functions/tools) |
| `release-attributes` | Give up ownership of one or more attributes, the closest thing to removing an attribute since the provider has no delete endpoint. | [Tool](/guides/functions/tools) |
| `track-custom-metric` | COMPOSITE: record a value for a named metric today (or a given date), automatically creating or re-acquiring the underlying attribute first if needed - the common 'log this custom thing' use case without the caller having to manage attribute lifecycle state themselves. | [Tool](/guides/functions/tools) |
| `update-attribute-values` | Write (overwrite) values for one or more owned attributes on specific dates. | [Tool](/guides/functions/tools) |
| `attribute-values` | Sync the full value history for every currently-owned (active) Exist attribute. | [Sync](/guides/functions/syncs/sync-functions) |
| `attributes` | Sync the user's attribute metadata (templated and custom, active and inactive), without values. | [Sync](/guides/functions/syncs/sync-functions) |
| `averages` | Sync weekly average values per attribute. | [Sync](/guides/functions/syncs/sync-functions) |
| `insights` | Sync the personalized insights Exist has generated for the user. | [Sync](/guides/functions/syncs/sync-functions) |
