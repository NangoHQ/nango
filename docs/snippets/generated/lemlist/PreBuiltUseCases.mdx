### Others

| Function name | Description | Type |
| - | - | - |
| `add-campaign-lead` | Add a lead (by email) to a campaign with optional profile fields and custom variables. | [Action](/guides/functions/action-functions) |
| `create-campaign` | Create a new, empty campaign (sequence and schedule are auto-generated; add leads and configure steps afterward). | [Action](/guides/functions/action-functions) |
| `enroll-lead-in-campaigns` | Enroll one lead (by email, with optional basic fields and custom variables) into a list of lemlist campaigns in a single call, returning a consolidated per-campaign success/failure result | [Action](/guides/functions/action-functions) |
| `get-campaign-stats` | Get aggregate send/open/click/reply/bounce counts for a campaign over a date range | [Action](/guides/functions/action-functions) |
| `get-lead-full-status` | Get a consolidated 'where does this lead stand' view across every campaign it is enrolled in, combining lead state/status with per-campaign engagement activity (opens/clicks/replies/bounces) in one call | [Action](/guides/functions/action-functions) |
| `get-lead` | Retrieve a single lead by email, account-wide (not campaign-scoped). | [Action](/guides/functions/action-functions) |
| `get-team-credits` | Get the team's remaining enrichment/email-finding credit balance. | [Action](/guides/functions/action-functions) |
| `get-team` | Get the current team's info (name, member user IDs, beta flags, etc.). | [Action](/guides/functions/action-functions) |
| `get-user` | Get a single team member/user's info by user ID. | [Action](/guides/functions/action-functions) |
| `list-campaign-activities` | List granular activity events (opens, clicks, replies, bounces, sends, etc.) for a campaign and/or a specific lead. | [Action](/guides/functions/action-functions) |
| `list-campaigns` | List campaigns in the lemlist team, to discover campaign IDs for lead actions. | [Action](/guides/functions/action-functions) |
| `list-unsubscribes` | List every account-wide unsubscribed/suppressed value (email, domain, phone, or LinkedIn URL). | [Action](/guides/functions/action-functions) |
| `pause-campaign` | Pause a running campaign (stops sending/sequencing for all its leads). | [Action](/guides/functions/action-functions) |
| `remove-campaign-lead` | Remove a lead from a campaign (stops it in the campaign sequence). | [Action](/guides/functions/action-functions) |
| `remove-lead-everywhere` | Remove a lead from every campaign it is currently enrolled in and unsubscribe it account-wide, for full-removal compliance requests. | [Action](/guides/functions/action-functions) |
| `resubscribe-contact` | Removes an email address, domain, phone number, or LinkedIn URL from the account-wide unsubscribe list, undoing a prior unsubscribe. | [Action](/guides/functions/action-functions) |
| `resume-campaign` | Resume or start a paused or draft campaign so it starts sequencing its leads again. | [Action](/guides/functions/action-functions) |
| `unsubscribe-contact` | Adds an email, domain, phone number, or LinkedIn URL to the account-wide unsubscribe suppression list. Idempotent: returns the existing record if the value is already unsubscribed. | [Action](/guides/functions/action-functions) |
| `update-campaign-lead` | Update a lead's fields within a campaign (partial merge). | [Action](/guides/functions/action-functions) |
| `update-campaign` | Update a campaign's fields (e.g. rename it). Partial merge: only the fields you send are changed. | [Action](/guides/functions/action-functions) |
| `verify-email` | Kick off asynchronous email-address verification (deliverability check) for a given email. | [Action](/guides/functions/action-functions) |
| `campaign-leads` | Sync every lead enrolled in every campaign | [Sync](/guides/functions/syncs/sync-functions) |
| `campaigns` | Full refresh of every lemlist campaign in the team (name, status, sequence id, creator). Note: lemlist has no campaign-deletion API, so a record flagged as deleted only means the campaign no longer appears in GET /api/campaigns (e.g. excluded by a filter the endpoint does not expose), not that it was actually destroyed. | [Sync](/guides/functions/syncs/sync-functions) |
