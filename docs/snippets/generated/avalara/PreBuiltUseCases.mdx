### Transactions

| Function name | Description | Type |
| - | - | - |
| `transactions` | List all transactions with a default backfill date of one year. | [Sync](/guides/functions/syncs/sync-functions) |

### Others

| Function name | Description | Type |
| - | - | - |
| `commit-transaction` | Marks a transaction by changing its status to Committed | [Tool](/guides/functions/tools) |
| `create-transaction` | Creates a new transaction | [Tool](/guides/functions/tools) |
| `void-transaction` | Voids the current transaction uniquely identified by the transactionCode | [Tool](/guides/functions/tools) |
