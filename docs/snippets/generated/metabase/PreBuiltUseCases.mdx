### Users

| Function name | Description | Type |
| - | - | - |
| `users` | Fetches a list of users from Metabase, including active and inactive users. | [Sync](/guides/functions/syncs/sync-functions) |

### Others

| Function name | Description | Type |
| - | - | - |
| `create-user` | Creates a user in Metabase. | [Tool](/guides/functions/tools) |
| `disable-user` | Disables a user in Metabase by id. | [Tool](/guides/functions/tools) |
| `enable-user` | Enables a disabled user. | [Tool](/guides/functions/tools) |
| `fetch-user` | Fetches details of a specific user by ID. | [Tool](/guides/functions/tools) |
| `update-user` | Updates an existing, active user in Metabase. | [Tool](/guides/functions/tools) |
