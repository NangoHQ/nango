### Others

| Function name | Description | Type |
| - | - | - |
| `add-form-questions` | Add one or more new questions/fields to an existing form. | [Tool](/guides/tools/customize-tools) |
| `add-form-webhook` | Register a new webhook URL on a form so Jotform POSTs new submissions to it | [Tool](/guides/tools/customize-tools) |
| `clone-form` | Duplicate an existing form, including its questions/structure, as a new form. | [Tool](/guides/tools/customize-tools) |
| `create-form-report` | Create a new report (e.g. a CSV export view) for a form | [Tool](/guides/tools/customize-tools) |
| `create-form-with-questions` | Create a new form, set its title, and add one or more questions/fields to it in a single call. | [Tool](/guides/tools/customize-tools) |
| `create-form` | Create a new, empty Jotform form, optionally setting its title at creation time. | [Tool](/guides/tools/customize-tools) |
| `delete-form-question` | Permanently delete a single question/field from a form. | [Tool](/guides/tools/customize-tools) |
| `delete-form-webhook` | Remove a registered webhook from a form by its index. | [Tool](/guides/tools/customize-tools) |
| `delete-form` | Delete a form. Jotform marks it DELETED rather than permanently scrubbing the record. | [Tool](/guides/tools/customize-tools) |
| `delete-report` | Permanently delete a report. | [Tool](/guides/tools/customize-tools) |
| `delete-submission` | Permanently delete a submission. | [Tool](/guides/tools/customize-tools) |
| `duplicate-form` | Clone an existing Jotform form and set the title of the new copy in one call. | [Tool](/guides/tools/customize-tools) |
| `edit-form-question` | Edit an existing question's properties (e.g. its label text) in place, without creating a duplicate. | [Tool](/guides/tools/customize-tools) |
| `get-form` | Retrieve a single form's metadata (title, status, URL, submission count, timestamps) | [Tool](/guides/tools/customize-tools) |
| `get-report` | Retrieve the configuration of a single report. | [Tool](/guides/tools/customize-tools) |
| `get-submission-with-labels` | Retrieve a submission's answers re-keyed by human-readable question label/text instead of raw numeric qid | [Tool](/guides/tools/customize-tools) |
| `get-submission` | Retrieve a single submission's recorded answers | [Tool](/guides/tools/customize-tools) |
| `get-user-usage` | Retrieve the authenticated account's current usage/quota stats (submissions, uploads, payments, API calls, and form count) for the current billing period. | [Tool](/guides/tools/customize-tools) |
| `get-user` | Retrieve the authenticated Jotform account's profile information. | [Tool](/guides/tools/customize-tools) |
| `list-form-questions` | List the questions/fields of a form, including the numeric ID (qid), type, and field name of each question. | [Tool](/guides/tools/customize-tools) |
| `list-form-reports` | List reports (e.g. CSV/grid/table exports or views) configured for a form. | [Tool](/guides/tools/customize-tools) |
| `list-form-submissions` | List submissions for a specific form. | [Tool](/guides/tools/customize-tools) |
| `list-form-webhooks` | List webhook URLs currently registered on a form. | [Tool](/guides/tools/customize-tools) |
| `list-forms` | List forms owned by the authenticated user. | [Tool](/guides/tools/customize-tools) |
| `submit-form-by-field-label` | Submit a form using human-readable field labels (resolved to question IDs via the form's questions) instead of numeric qids. | [Tool](/guides/tools/customize-tools) |
| `submit-form` | Submit a form (create a new submission) with answers for one or more of its questions. | [Tool](/guides/tools/customize-tools) |
| `update-form-title` | Renames an existing form by setting its title property | [Tool](/guides/tools/customize-tools) |
| `forms` | Sync all forms owned by the authenticated Jotform user. | [Sync](/guides/syncs/sync-functions) |
| `submissions` | Sync all submissions across all forms in the Jotform account, incrementally by creation date. | [Sync](/guides/syncs/sync-functions) |
