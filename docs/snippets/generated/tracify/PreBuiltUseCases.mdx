### Analytics KPIs

| Function name | Description | Type |
| - | - | - |
| `get-kpis-overview` | Fetches aggregated Tracify KPI overview data for a date range. | [Tool](/guides/functions/tools) |
| `get-kpis-channels` | Lists Tracify channel KPI data for a date range. | [Tool](/guides/functions/tools) |
| `get-kpis-channel` | Fetches KPI data for one Tracify channel. | [Tool](/guides/functions/tools) |
| `get-kpis-channel-breakdown` | Fetches a paginated KPI breakdown for one Tracify channel. | [Tool](/guides/functions/tools) |
| `get-kpis-channel-export` | Gets the status or result of a Tracify KPI export job. | [Tool](/guides/functions/tools) |
| `get-kpis-nvr-channel` | Fetches new-versus-returning customer KPI data for one channel. | [Tool](/guides/functions/tools) |
| `get-kpis-nvr` | Fetches new-versus-returning customer KPI data across channels. | [Tool](/guides/functions/tools) |
| `get-kpis-discount-codes` | Fetches KPI data grouped by Tracify discount code. | [Tool](/guides/functions/tools) |
| `kpis-channels` | Keeps the last 30 days of Tracify channel KPI data fresh. | [Sync](/guides/functions/syncs/sync-functions) |
| `kpis-discount-codes` | Keeps the last 30 days of Tracify discount-code KPI data fresh. | [Sync](/guides/functions/syncs/sync-functions) |
| `kpis-nvr` | Keeps the last seven days of Tracify new-versus-returning KPI data fresh. | [Sync](/guides/functions/syncs/sync-functions) |
| `kpis-overview` | Keeps the last 30 days of aggregated Tracify KPI overview data fresh. | [Sync](/guides/functions/syncs/sync-functions) |
