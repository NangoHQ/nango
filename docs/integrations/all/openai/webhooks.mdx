## How it works

1. OpenAI sends a POST request to your Nango webhook URL when one of the events you picked happens, for example `response.completed`.
2. Nango looks up the connection named by the `nangoConnectionId` query param on the webhook URL and verifies the delivery's signature against that connection's own webhook secret. OpenAI signs deliveries with [Standard Webhooks](https://www.standardwebhooks.com/), and Nango rejects deliveries signed more than 5 minutes ago.
3. Nango routes the event to that connection, using the payload's `type` field as the webhook type.

OpenAI payloads don't say which account they come from, so each connection needs its own webhook endpoint in OpenAI and its own `webhookSecret` in Nango. Deliveries without a valid signature are rejected. OpenAI payloads only carry the ID of the object that changed, so fetch it from the OpenAI API before acting on it.

## Setup

### 1. Get your Nango webhook URL

In the Nango dashboard, open your OpenAI integration and copy the **Webhook URL**. Append `?nangoConnectionId=<CONNECTION-ID>` for the connection you are registering the webhook for. URL-encode the connection ID if it contains characters like `+`, `/` or spaces.

### 2. Register the webhook in OpenAI

1. In your OpenAI project's settings, go to **Webhooks** and create an endpoint.
2. Set the URL to the URL from step 1, and pick the events to receive.
3. Copy the **Signing secret** OpenAI shows once the endpoint is created (it starts with `whsec_`). OpenAI only shows it once.

### 3. Set the webhook secret in Nango

Store the whole signing secret, including `whsec_`, as `webhookSecret` in the connection's metadata:

```bash
curl -X PATCH "https://api.nango.dev/connections/metadata" \
  -H "Authorization: Bearer <NANGO-API-KEY>" \
  -H "Content-Type: application/json" \
  -d '{
    "connection_id": "<CONNECTION-ID>",
    "provider_config_key": "<INTEGRATION-ID>",
    "metadata": { "webhookSecret": "<OPENAI-SIGNING-SECRET>" }
  }'
```

Use a Nango **Environment API key** from **Environment Settings > API Keys** with the `environment:connections:update` scope. See [Update connection metadata](/reference/backend/http-api/connections/update-metadata) for the full reference.

<Note>
The webhook secret on the integration's Settings page is not used for OpenAI. Nango only verifies against the connection's `webhookSecret`.
</Note>

## Handle the webhook

Once routed, you have two options:

- **Forward it to your app**: Nango forwards the event to your webhook URL with connection attribution. See [External webhook forwarding](/guides/triggers/webhook-forwarding).
- **Process it in a sync**: run a sync when the webhook arrives using `webhookSubscriptions` and `onWebhook`. Subscribe to event types like `response.completed`. See [Real-time syncs](/guides/syncs/realtime-syncs).

## Rollback strategy

Delete the endpoint in OpenAI, then clear `webhookSecret` from the connection's metadata.
