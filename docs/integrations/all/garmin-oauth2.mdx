## Setup guide

Garmin Connect Developer Program apps use **OAuth 2.0 with PKCE** (`S256`). Use this provider for new Garmin connections. The existing `garmin` provider remains OAuth1 for legacy connections.

1. Create / convert an app in the [Garmin developer portal](https://developerportal.garmin.com/).
2. Register the Nango callback URL on your Garmin OAuth2 app: `https://api.nango.dev/oauth/callback`.
3. Copy the OAuth2 client id and client secret into your Nango integration credentials.
4. Create a connection and complete the authorize flow.

Authorize URL: `https://connect.garmin.com/oauth2Confirm`  
Token / refresh URL: `https://diauth.garmin.com/di-oauth2-service/oauth/token`  
API proxy base: `https://apis.garmin.com`

## API gotchas

-   Garmin does not accept OAuth scopes in authorization or token requests. API sections are configured in the Garmin developer portal, and users choose permissions on the consent screen. Leave scopes blank in Nango.
