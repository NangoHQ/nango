## Access requirements
| Pre-Requisites | Status | Comment|
| - | - | - |
| Paid dev account | ✅ | API keys are created from a paid ShareFile account at [api.sharefile.com/apikeys](https://api.sharefile.com/apikeys). Key creation is not available on a trial account. |
| Paid test account | ✅ | Any paid ShareFile plan includes API access. |
| Partnership | ❌ | Not required. |
| App review | ❌ | Not required. |
| Security audit | ❌ | Not required. |


## Setup guide

1. Sign in to [api.sharefile.com/apikeys](https://api.sharefile.com/apikeys) with your ShareFile account.
2. Create an API key: enter an application name, a description, and `https://api.nango.dev/oauth/callback` as the redirect URL.
3. Copy the **Client ID** and **Client Secret** into your Nango integration.

<Tip>Need help getting started? Get help in the [community](https://nango.dev/slack).</Tip>

## API gotchas

- The user is asked for their ShareFile subdomain (the part before `.sharefile.com` in their login URL). It is used in the token URL and in the proxy base URL.
- This template targets the `sf-api.com` API control plane (accounts hosted in the US). ShareFile also returns the control plane as `apicp` in the OAuth callback and token response; it is deliberately not used to build hosts.
- Access tokens expire after 8 hours. ShareFile issues a refresh token and the refresh grant returns a new access token.
- PKCE is disabled for this provider.
