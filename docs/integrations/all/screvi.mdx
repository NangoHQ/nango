## Setup guide

### Step 1: Generating your API key

1. Sign in to [Screvi](https://app.screvi.com).
2. Open **Settings** and go to the **API** tab.
3. Select **Create API key**, give it a name and pick its scopes (`read`, or `read` and `write` if your integration needs to save or update items).
4. Copy the key. It starts with `sk_live_` and is shown only once.

### Step 2: Connecting in Nango

Paste the key into the Nango connect UI for the Screvi integration. Nango verifies it against `GET /tags` before the connection is created.

## API gotchas

- Screvi authenticates with the `X-API-Key` header, not a bearer token.
- The API is versioned in the path: the base URL is `https://api.screvi.com/api/v1`.
- Keys are scoped. A `read` key is rejected with `403` on any write endpoint, so mint the key with `write` if your integration saves articles, creates highlights or edits tags.
- Pagination uses `page` and `per_page` and reports `pagination.has_more`. `per_page` caps at 100 on most endpoints and at 50 on `/search`; a larger value is clamped rather than rejected.
- `GET /search` runs semantic as well as keyword matching, so results can legitimately contain none of the query words.
- Tags are referenced by name on write endpoints and must already exist in the account.
