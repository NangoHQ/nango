## Setup guide

<Steps>
    <Step id="request-credentials" title="Request OAuth credentials">
        Contact [interfaces@intellicure.com](mailto:interfaces@intellicure.com) to request API access and an OAuth client ID and client secret.

        Provide the callback URL shown in your Nango integration settings so Intellicure can register it for your OAuth client.
    </Step>

    <Step id="configure-integration" title="Configure the integration">
        In Nango, create an Intellicure integration and enter the client ID and client secret issued by Intellicure.
    </Step>

    <Step id="create-connection" title="Create the connection">
        Create an Intellicure connection and complete the authorization flow. Nango requests the `intellicure_api` and `offline_access` scopes and uses PKCE.
    </Step>
</Steps>

## API gotchas

- Intellicure uses the OAuth 2.0 authorization code flow with PKCE. API requests use the resulting JWT access token as a Bearer token.
- Keep the `offline_access` scope enabled so Nango can refresh access tokens.
- API endpoints are versioned under `/api/v1`. Because the Nango proxy base URL is `https://api.intellicureehr.com`, include the complete `/api/v1/...` path in proxy requests.
- API responses can contain protected health information. Follow your organization's HIPAA and security requirements when testing, storing, and logging data.
