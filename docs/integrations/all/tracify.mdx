## API gotchas

- Tracify Analytics requires the `tracify-token` header. This integration sends the Nango API key as that header.
- Analytics requests require both a `siteId` and a `presetId`. Nango stores these as connection configuration and sends the site ID as the API's `csids` query parameter.
- Data from the last 24 hours is preliminary and may change after processing. Re-request recent periods when finalized data is required.
- This provider is scoped to Tracify Analytics; its pre-built templates call only retrieval endpoints. The standard Nango proxy itself is intentionally not restricted to this route list.

## KPI endpoints and template functions

Tracify Analytics provides these eight read-only retrieval routes used by the pre-built templates. The provider config supplies authentication and the standard Nango proxy; it does not restrict the proxy to this route list.

| Tracify route | Method |
| --- | --- |
| `/analytics/api/v1/kpis/overview/` | `GET` |
| `/analytics/api/v1/kpis/channels/` | `GET` |
| `/analytics/api/v1/kpis/channels/{channel}/` | `GET` |
| `/analytics/api/v1/kpis/channels/{channel}/exports/{task_id}` | `GET` |
| `/analytics/api/v1/kpis/channels/{channel}/{breakdown_dimension}` | `GET` |
| `/analytics/api/v1/kpis/nvr_daily_breakdown/{channel}` | `GET` |
| `/analytics/api/v1/kpis/nvr_daily_breakdown` | `GET` |
| `/analytics/api/v1/kpis/discount_codes` | `GET` |

NVR requests are limited to seven days by the Tracify API. The generated **Pre-built tooling** section above is the source of truth for available Nango template functions.
