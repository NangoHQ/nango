## Setup

Create a `devin-v3` integration, then add a connection with a Devin credential beginning with `cog_`.

Nango sends the credential as a bearer token and verifies it with `GET /v3/self` before saving the connection.

## API gotchas

- Devin v3 credentials begin with `cog_`. Legacy `apk_user_` credentials belong to the v1 API and the `devin` provider.
- Organization-scoped service users can access one organization. Enterprise service users can access multiple organizations according to their assigned roles.
- API permissions come from the role assigned to the service user.
