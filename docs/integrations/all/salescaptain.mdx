# SalesCaptain

SalesCaptain provides APIs for managing contacts, conversations,
messages, appointments, and other CRM and communication data.

## Authentication

SalesCaptain uses API tokens for API authentication.

To generate an API token:

1. Log in to your SalesCaptain account.
2. Open the API settings.
3. Generate an API token.
4. Copy the generated token.
5. Use the token when creating your SalesCaptain connection in Nango.

## API documentation

For complete information about the SalesCaptain API, including
available endpoints and request/response formats, see the
[SalesCaptain API documentation](https://docs.salescaptain.com).

## Integration

Nango uses the SalesCaptain API token associated with the connection
to authenticate requests to the SalesCaptain API.
