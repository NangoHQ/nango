## API gotchas

- The current API requires `Authorization: Omnisend-API-Key <API_KEY>` on every request.
- The current API also requires `Omnisend-Version: 2026-03-15` on every request. This provider sends the header automatically.
- API keys are scoped. A key can authenticate successfully while an individual function still returns an authorization error because its scope is missing.
- Campaign send/test, automation enable/disable, event creation, deletes, and other write functions can have immediate provider-side effects. Use the minimum scopes and expose only the functions appropriate for your application.
- List endpoints use cursor pagination. The pre-built sync functions handle the documented cursor envelope for their supported collections.
- The provider verification request is `GET /api/campaigns?limit=1`; it only verifies authentication and does not create or send anything.
