## API gotchas

-   Scavio is billed in **credits**, not requests. Most endpoints cost 1 credit per call, but some
    cost more, so read the per-endpoint cost in the docs before running a large sync.
-   Endpoints live under two versions. Google search endpoints are on `/api/v2/google`; the other
    platforms are on `/api/v1/<platform>/...`. Copy the path from the endpoint's docs page rather
    than deriving it, since a few paths do not match their platform name.
-   Most endpoints are `POST` with a JSON body. Calling one with `GET` returns a 404 rather than a
    405, which reads like a missing endpoint.
-   Rate limits are per plan and returned in the response headers. A `429` means the plan limit was
    hit, not that the key is invalid.
-   The generic extract endpoint is `POST /api/v1/extract`, which is not tied to a platform. It
    takes a URL and returns Markdown, plain text or HTML, and is priced by tier rather than by the
    flat per-call cost most platform endpoints use.
