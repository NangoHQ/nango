# Connect SalesCaptain

To connect your SalesCaptain account:

1. Log in to your SalesCaptain account.
2. Navigate to **Settings → API**.
3. Generate an API token.
4. Copy the API token.
5. In Nango, create a SalesCaptain connection.
6. Enter your SalesCaptain API token.
7. Save the connection.

Nango will use this token to authenticate requests to the SalesCaptain API.

For API endpoint documentation, see [SalesCaptain API documentation](https://docs.salescaptain.com).
