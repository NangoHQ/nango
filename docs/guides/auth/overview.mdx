<a id="overview"></a>

Nango gives you one interface for API authorization and handles each provider's quirks.

- **1,300+ APIs** — From OAuth 2.0 and API keys to custom auth
- **Add APIs on demand** — Ask Nango to add any API in &lt;48h, or [contribute it yourself](/integrations/contribute-or-request-api)
- **Nango-managed OAuth apps** — Use our pre-approved OAuth apps, or bring your own
- **Pre-built UI with your branding** — Provider-specific forms, end-user guides to find API keys, and built-in validation
- **Secure credential management** — Encrypted at rest and in transit, refreshes OAuth tokens automatically, and is SOC 2 Type II certified
- **Broken credentials detection** — Get notified by Nango and easily let users reconnect

## Add to your app or agent

Every connection can be used with all Nango features, regardless of where it was created.

| Where | How it works | Setup instructions |
| --- | --- | --- |
| **In your app** | A connect button opens Nango's pre-built Connect UI. | [Follow the setup guide](/guides/auth/setup). To create your own UI, see [headless auth](/guides/auth/customize-connect-ui#build-your-own-auth-ui). |
| **From your AI agent** | The agent asks the user to authorize an integration when it needs access. | [Enable the create connection tool](/guides/agent-sessions/meta-tools#nango_create_connection) |
| **From a link you share** | Send a link by email or chat. The user opens Nango's hosted Connect UI to authorize. | [Generate and share a connect link](/guides/auth/setup#share-a-connect-link) |

## Nango-managed OAuth apps

When you set up an OAuth integration, you can register your own app or use a Nango-managed app where available.

Nango-managed OAuth apps are pre-approved and ready for production. Nango registers and maintains them so you can launch faster across multiple APIs without waiting for provider approval for each app.

Here are the tradeoffs between using a Nango-managed app and registering your own.

- **White-label OAuth** — With your own app, you control the branding users see on the consent screen. With a Nango-managed app, users see Nango's branding.
- **Scopes** — Nango-managed apps have fixed scopes. With your own app, you choose which permissions to request from the scopes the provider offers.
- **Callback URL** — Nango-managed apps use Nango's callback URL. Your own app can use a [custom callback URL](/guides/auth/setup#custom-oauth-callback-url-optional) on your domain.
- **Provider webhooks** — Receiving provider webhooks requires your own OAuth app. If you need webhooks with a Nango-managed app, reach out to support.
- **Marketplace listings** — provider marketplaces require your own app.
- **Revocation risk** — if a provider revokes a Nango-managed app, every connection using it stops working.
- **Portability** — only with your own app can you export access and refresh tokens and move off Nango without users re-authorizing.

To make registering your own app easier, Nango maintains step-by-step setup guides for most OAuth APIs in [APIs & Integrations](/integrations/overview), for example [Gmail](/api-integrations/google-mail/how-to-register-your-own-gmail-api-oauth-app).

We add more OAuth apps every week. If an API you need is missing, please contact us and we will do our best to add it.
