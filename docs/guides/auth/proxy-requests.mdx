The proxy is Nango's lowest-level way to make authenticated HTTP requests to an external API. It uses an existing connection to authenticate the request.

## When to use the proxy

Start with [Agent sessions](/guides/agent-sessions) for agent workflows, or use [Tools](/guides/tools/overview), [Triggers](/guides/triggers/overview), and [Syncs](/guides/syncs/overview) when they cover what you need.

Use the HTTP proxy when you need a raw request to a provider or need to upload or download binary files.

## How to use the proxy

Make sure you have a [configured integration](/guides/auth/setup#create-integration) and at least one connection for it.

<Tabs>
    <Tab title="Node">
        ```typescript
        try {
            const res = await nango.proxy({
                method: 'POST',
                endpoint: '/<API-ENDPOINT>',
                providerConfigKey: '<INTEGRATION-ID>',
                connectionId: '<CONNECTION-ID>',
                retries: 5, // Retries with exponential backoff (optional, default 0)
                data: {
                    colorId: 'blue'
                }
            });

            // Response was 200!
            // See https://axios-http.com/docs/res_schema
            console.log(res.data);
        } catch (error) {
            // Status of response != 200
            // See https://axios-http.com/docs/handling_errors
            console.log(error.response.data);
            console.log(error.response.status);
            console.log(error.response.headers);
        }
        ```
    </Tab>

    <Tab title="cURL">
        ```bash
        curl -X POST -H 'Content-Type: application/json' \
        -H 'Authorization: Bearer <NANGO-API-KEY>' \
        -H 'Provider-Config-Key: <INTEGRATION-ID>' \
        -H 'Connection-Id: <CONNECTION-ID>' \
        -d '{"colorId": "blue"}' \
        'https://api.nango.dev/proxy/<API-ENDPOINT>'
        ```
    </Tab>
</Tabs>
