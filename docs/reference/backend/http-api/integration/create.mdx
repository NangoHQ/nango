## Use a Nango-managed developer app

To skip registering your own app with the provider, set `credentials` to `{ "type": "NANGO_MANAGED" }`. The integration then uses Nango's [managed developer app](/guides/auth/auth-guide#nango-managed-oauth-apps) for the provider.

```json
{
  "provider": "github",
  "unique_key": "github",
  "credentials": { "type": "NANGO_MANAGED" }
}
```

This works for `OAUTH1`, `OAUTH2`, and `APP` providers that Nango has a managed app for. Other providers return a `400`. You can't combine it with `integration_config`, and you can't edit the credentials afterwards.
