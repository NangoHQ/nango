---
title: 'Get legacy integration functions config'
openapi: 'GET /scripts/config'
---

<Info>
  Requires an Environment API key with the `environment:integrations:list_functions` scope. [Learn more about API key scopes](/reference/backend/http-api/api-keys#scopes).
</Info>

<Warning>
  This is a legacy configuration endpoint for deployed syncs and deprecated actions. For new integrations, use [List functions](/reference/backend/http-api/functions/list) to discover tools, including catalog tools, and [agent sessions](/guides/agent-sessions) to expose them to agents.
</Warning>

Existing callers can continue to use:

- `GET /scripts/config?format=nango` for the legacy configuration format.
- `GET /scripts/config?format=openai` for deployed function schemas in OpenAI function-calling format.

The OpenAI format derives parameter descriptions from Markdown parameter lists in the function description and preserves array schemas. This endpoint does not include undeployed catalog tools or HTTP-triggered tools. Call available tools through the [tool-call API](/reference/backend/http-api/tools/call).
