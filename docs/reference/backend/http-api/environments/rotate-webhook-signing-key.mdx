---
title: 'Rotate the webhook signing key'
openapi: 'POST /environment/webhook-signing-key/rotate'
---

<Info>
  Requires an [Environment API key](/reference/backend/http-api/api-keys#environment-api-keys) with the `environment:webhook_signing_key:rotate` scope. It rotates the key of the environment the API key belongs to.
</Info>

Replaces the key Nango uses to [sign webhooks](/guides/platform/webhooks-from-nango#verifying-webhooks-from-nango). The new key is returned in the response, and stays readable under **Environment Settings > Webhooks > Signing key**.

To import an existing key, pass `webhook_signing_key` in the body. The value must be a UUID v4; uppercase characters are normalized to lowercase. You should generate it using a cryptographically secure random generator, such as `crypto.randomUUID()`. The security of a supplied key depends on how you generate and protect it; Nango validates its format but cannot verify its randomness.

Omit the request body or send `{}` to generate a random key.

```json
{
  "webhook_signing_key": "8a27fe09-327c-43ec-8f75-b1f212904f45"
}
```

<Warning>
  For up to 5 minutes after a rotation, webhooks are signed with either the old or the new key. Accept both until then.
</Warning>

<ResponseExample>
```json Example Response
{
  "data": {
    "webhook_signing_key": "5f1c0d2e-6a1b-4f3c-9d8e-7b6a5c4d3e2f"
  }
}
```
</ResponseExample>
