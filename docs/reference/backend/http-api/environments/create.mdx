---
title: 'Create an environment'
openapi: 'POST /environments'
---

<Info>
  Requires an [Account API key](/reference/backend/http-api/api-keys#account-api-keys) with the `account:environments:create` scope. Create one from [Account API keys](https://app.nango.dev/api-keys) in the dashboard.
</Info>

Creates a new environment. Additional environments are limited by your [pricing plan](https://www.nango.dev/pricing).

Set `is_production: true` to create a production environment. This also requires `account:environments:set_production`. The reserved name `prod` is always production and cannot be combined with `is_production: false`.

Pass `webhooks` to configure URLs, subscriptions, and an initial signing key. Supply a UUID in `webhooks.signing_key`, or omit it to generate one. See [Receive webhooks from Nango](/guides/platform/webhooks-from-nango) for delivery behavior, event types, and signature verification.

The response returns the complete environment settings, including the plaintext webhook signing key and environment `uuid`. Use the `uuid` to [create an Environment API key](/reference/backend/http-api/environments/create-api-key) or [delete the environment](/reference/backend/http-api/environments/delete). Creating an environment also creates a default full-access Environment API key, but the secret is not returned.

<RequestExample>
```bash cURL
curl --request POST \
  --url https://api.nango.dev/environments \
  --header 'Authorization: Bearer <NANGO-ACCOUNT-API-KEY>' \
  --header 'Content-Type: application/json' \
  --data '{
    "name": "staging",
    "webhooks": {
      "primary_url": "https://app.example.com/webhooks/nango",
      "on_sync_completion_always": false,
      "signing_key": "5f1c0d2e-6a1b-4f3c-9d8e-7b6a5c4d3e2f"
    }
  }'
```
</RequestExample>
