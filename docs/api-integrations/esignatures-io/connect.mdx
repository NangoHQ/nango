## Overview

To authenticate with eSignatures.io, you need:

1. **Secret Token** - the API token of your eSignatures.com account.

This guide will show you where to find it.

### Prerequisites

- An [eSignatures.com](https://esignatures.com) account. You can create a free account for testing and development.

### Step 1: Copy your Secret Token

1. Log in to your [eSignatures.com](https://esignatures.com/login) account.
2. In the top navigation, click **AI, API & Automation**.

<img src="/api-integrations/esignatures-io/open_api_page.png" alt="eSignatures.com dashboard with AI, API & Automation in the top navigation"/>

3. Next to **Your Secret token**, click **copy**.

<img src="/api-integrations/esignatures-io/copy_secret_token.png" alt="eSignatures.com AI, API & Automation page with the copy button next to Your Secret token"/>

### Step 2: Enter your Secret Token in the Connect UI

1. Open the form where you need to authenticate with eSignatures.io.
2. Paste the token you copied in Step 1 into the **Secret Token** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/esignatures-io/form.png" alt="eSignatures.io Connect UI form with the Secret Token field" style={{maxWidth: "450px" }}/>

You are now connected to eSignatures.io.
