## Overview

To authenticate with Enginemailer, you need:

1. **API Key** — an API key from your Enginemailer account.

This guide will show you how to get it.

### Prerequisites

- An Enginemailer account. If you don't have one, [sign up](https://www.enginemailer.com/account/register) for free; the Free plan includes the REST APIs.
- The Campaign API is only available on paid plans.

### Step 1: Create an API key

1. [Log in](https://portal.enginemailer.com) to Enginemailer.
2. Open the profile menu in the top right and click **Manage account**.

<img src="/api-integrations/enginemailer/open_manage_account.png" alt="Enginemailer profile menu with the Manage account option"/>

3. In the left sidebar, under **Preferences**, click **API Keys**, then click **Create API Key**.

<img src="/api-integrations/enginemailer/api_keys_page.png" alt="Enginemailer API Keys page with the Create API Key button"/>

4. The new key appears in the list. Optionally type a label for it in the **Label** column, then click the copy button next to the key.

<img src="/api-integrations/enginemailer/api_key_created.png" alt="Enginemailer API Keys list with the new key and its copy button"/>

<Note>
You can also copy the **Primary** key that comes with your account instead of creating a new one.
</Note>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Enginemailer.
2. Enter your API key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/enginemailer/form.png" alt="Enginemailer Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Enginemailer.
