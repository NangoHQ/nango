## 🚀 Quickstart

Connect to the GSC Wizard MCP server with Nango and call MCP tools in minutes. GSC Wizard MCP uses OAuth 2.1 with **dynamic client registration**, so no app registration is required.

<Steps>
    <Step id="create-integration" title="Create the integration">
        In Nango ([free signup](https://app.nango.dev)), go to **Integrations** → _Configure New Integration_ → _GSC Wizard (MCP)_.
    </Step>
    <Step id="authorize-gsc-wizard-mcp" title="Authorize GSC Wizard">
        Go to **Connections** → _Add Test Connection_ → _Authorize_, then sign in to GSC Wizard and approve the requested access. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-gsc-wizard-mcp" title="Call the GSC Wizard MCP API">
        Make your first MCP request (initialize handshake). Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
        <Tabs>
            <Tab title="cURL">

                ```bash
                curl "https://api.nango.dev/proxy/mcp" \
                  -X POST \
                  -H "Authorization: Bearer <NANGO-API-KEY>" \
                  -H "Provider-Config-Key: <INTEGRATION-ID>" \
                  -H "Connection-Id: <CONNECTION-ID>" \
                  -H "Content-Type: application/json" \
                  -d '{
                    "jsonrpc": "2.0",
                    "id": 1,
                    "method": "initialize",
                    "params": {
                        "protocolVersion": "2025-06-18",
                        "capabilities": {},
                        "clientInfo": {
                            "name": "nango-client",
                            "version": "1.0.0"
                        }
                    }
                }'
                ```

            </Tab>

            <Tab title="Node">

                Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

                ```typescript
                import { Nango } from '@nangohq/node';

                const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

                const res = await nango.post({
                    endpoint: '/mcp',
                    providerConfigKey: '<INTEGRATION-ID>',
                    connectionId: '<CONNECTION-ID>',
                    data: {
                        jsonrpc: '2.0',
                        id: 1,
                        method: 'initialize',
                        params: {
                            protocolVersion: '2025-06-18',
                            capabilities: {},
                            clientInfo: {
                                name: 'nango-client',
                                version: '1.0.0'
                            }
                        }
                    }
                });

                console.log(res.data);
                ```
            </Tab>

        </Tabs>
        ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-nango" title="Implement Nango in your app">
        Follow our [Auth implementation guide](/guides/auth/overview) to integrate Nango in your app.
    </Step>
</Steps>

## 📚 GSC Wizard (MCP) guides

Nango registers its own client with GSC Wizard's OAuth server (`tool.gscwizard.com`) automatically (dynamic client registration), so you don't need to register an app. Create the integration in Nango and sign in with a GSC Wizard account.

Things to know before connecting:

- The MCP server is `https://mcp.gscwizard.com/mcp` (Streamable HTTP). The OAuth server runs on a different host, `tool.gscwizard.com`, and binds each token to the MCP server as its resource.
- By default Nango requests the `mcp:read` and `mcp:write` scopes. Remove `mcp:write` on the integration to limit connections to the read tools; `mcp:write` adds the tools that change data, such as annotations, saved filters, sitemaps, and IndexNow submissions.
- Tool calls run as the authorizing user and see only the Search Console properties that user's GSC Wizard account can read. The user needs a GSC Wizard plan or an active trial.
- To call the REST API with an API key instead, use [GSC Wizard](/api-integrations/gsc-wizard).

Official docs: [GSC Wizard MCP server](https://www.gscwizard.com/docs/mcp-and-chatgpt.html)
