## 🚀 Quickstart

Connect to Webflow with Nango and see data flow in 2 minutes.

<Steps>
    <Step title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to [Integrations](https://app.nango.dev/dev/integrations) -> _Configure New Integration_ -> _Webflow_.
    </Step>
    <Step title="Authorize Webflow">
    Go to [Connections](https://app.nango.dev/dev/connections) -> _Add Test Connection_ -> _Authorize_, then log in to Webflow. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step title="Call the Webflow API">
    Let's make your first request to the Webflow API (list the sites in the connected Workspace). Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), [integration ID](https://app.nango.dev/dev/integrations), and [connection ID](https://app.nango.dev/dev/connections):
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/v2/sites" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/v2/sites',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>


    </Tabs>
    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the [Logs](https://app.nango.dev/dev/logs) tab in Nango to inspect requests.
    </Step>

    <Step title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.

        To obtain your own production credentials, follow the setup guide linked below.
    </Step>
</Steps>

<Note>
Webflow's Data API is versioned explicitly in the endpoint URL — use `/v2/` for production endpoints and `/beta/` for endpoints still in beta. Access tokens work across both.
</Note>

<Warning>
**Webflow Marketplace installation flow is not supported.** Nango only supports OAuth flows initiated through Nango (e.g. via the Connect UI or the [Nango Auth API](/guides/primitives/auth)), because Nango issues its own `state` parameter to match the OAuth callback back to the connection attempt that started it. A flow started from the Webflow Marketplace's "Install" button doesn't carry that state, so Nango's callback has nothing to match it against and the connection fails. If your Webflow app is listed on the Marketplace, users must connect through your Nango-powered flow, not the Marketplace install button.
</Warning>
