## Overview

To connect with GraphHopper, you need:

1. **API Key** — a GraphHopper API key.

### Prerequisites

- A GraphHopper account with a verified email address. You can [sign up](https://graphhopper.com/dashboard/signup) on the free plan, no credit card required.

### Step 1: Create an API key

1. Log in to the [GraphHopper dashboard](https://graphhopper.com/dashboard/), click **API Keys** in the sidebar, then click **Create New Key**.

<img
    src="/api-integrations/graphhopper/api_keys_page.png"
    alt="GraphHopper dashboard API Keys page with the Create New Key button highlighted"
/>

2. Enter a descriptive **Key Name** and click **Create Key**.

<img
    src="/api-integrations/graphhopper/create_api_key_form.png"
    alt="GraphHopper Create New API Key form with a key name entered and the Create Key button highlighted"
/>

3. Click the copy icon next to the new key to copy the full API key. The table only shows the start of the key.

<img
    src="/api-integrations/graphhopper/api_key_created.png"
    alt="GraphHopper API Keys list showing the new key with its copy icon highlighted"
/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with GraphHopper.
2. Enter your **API Key**.
3. Click **Connect**.

<img src="/api-integrations/graphhopper/form.png" alt="Nango Connect UI form for entering the GraphHopper API Key" style={{maxWidth: "450px" }}/>

You are now connected to GraphHopper.
