## 🚀 Quickstart

Connect to Bubble with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Bubble_.
    </Step>
    <Step id="authorize-bubble" title="Authorize Bubble">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your app hostname and API token. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-bubble-api" title="Call the Bubble API">
    Let's make your first request to the Bubble API to fetch your Live app's Swagger file. The Swagger file is disabled by default: enable it in your app under **Settings** > **API** first. Requests go to `https://<HOSTNAME>/api`, your app's Live version. To call the development version instead, set `baseUrlOverride` to `https://<HOSTNAME>/version-test/api`. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/1.1/meta/swagger.json" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/1.1/meta/swagger.json',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- Nango does not check the API token when a connection is created, so a wrong or revoked token still connects and fails on its first call.
