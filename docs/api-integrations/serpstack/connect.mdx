## Overview

To authenticate with Serpstack, you need:

1. **API Access Key** — the key assigned to your Serpstack account.

This guide will show you how to get it.

### Prerequisites

- A Serpstack account. If you don't have one, sign up for the [Free Plan](https://serpstack.com/signup/free), which includes 100 searches per month, or [log in](https://serpstack.com/login) to your existing account.

### Step 1: Copy your API access key

1. Log in to [Serpstack](https://serpstack.com/login) and open the **Dashboard** tab.
2. Under **Your API Key**, click the copy icon to copy your API access key.

<img src="/api-integrations/serpstack/dashboard_api_key.png" alt="Serpstack dashboard showing the Your API Key field with the copy icon and the Reset Key link"/>

To generate a new key, click **Reset Key**.

### Step 2: Enter your API access key in the Connect UI

1. Open the form where you need to authenticate with Serpstack.
2. Enter your API access key in the **API Access Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/serpstack/form.png" alt="Serpstack Connect UI form with the API Access Key field" style={{maxWidth: "450px" }}/>

You are now connected to Serpstack.
