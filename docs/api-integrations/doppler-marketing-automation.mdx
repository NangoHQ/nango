## 🚀 Quickstart

Connect to Doppler Marketing Automation with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Doppler Marketing Automation_.
    </Step>
    <Step id="authorize-doppler-marketing-automation" title="Authorize Doppler Marketing Automation">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your Doppler API Key and account email. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-doppler-marketing-automation-api" title="Call the Doppler Marketing Automation API">
    Let's make your first request to the Doppler API to fetch your account home. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID. Replace `<ACCOUNT-EMAIL>` with the account email stored in the connection's `accountName` connection config field:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/accounts/<ACCOUNT-EMAIL>" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/accounts/<ACCOUNT-EMAIL>',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>
