## Overview

To authenticate with CoinMarketCal, you need:

1. **API Key** — a CoinMarketCal API key.

This guide will show you how to get it.

### Prerequisites

- A CoinMarketCal developer account. The Free plan includes API access and needs no credit card; [sign up here](https://coinmarketcal.com/developer).

### Step 1: Copy your API key

1. Sign in to the [CoinMarketCal developer dashboard](https://coinmarketcal.com/developer).
2. In the left sidebar, open **API keys**. The Free plan comes with one key, created when you sign up. On a paid plan, you can click **+ New API key** to create another.
3. Click **Copy** (or **Reveal**) on the key row to get the full key, which starts with `cmc_live_`.

<img src="/api-integrations/coinmarketcal/api_keys_page_copy.png" alt="CoinMarketCal API keys page with the Copy button highlighted on the key row"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with CoinMarketCal.
2. Enter your **API Key** in the designated field.
3. Click **Connect**.

<img src="/api-integrations/coinmarketcal/form.png" alt="Nango Connect UI form for entering the CoinMarketCal API key" style={{maxWidth: "450px" }}/>

You are now connected to CoinMarketCal.
