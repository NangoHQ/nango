## Overview

To connect Billit with OAuth, your application must have [OAuth credentials issued by Billit](/api-integrations/billit-oauth/how-to-register-your-own-billit-oauth-app). You need a Billit user account with access to the company you want to connect.

## Step 1: Choose your environment

In the Nango Connect form, select the **Environment** matching the application's OAuth credentials:

- **Sandbox** — `sandbox.billit.be`, for accounts at [Billit Sandbox](https://my.sandbox.billit.be).
- **Production** — `billit.be`, for accounts at [Billit Production](https://my.billit.be).

Sandbox and production use separate accounts and OAuth credentials. If you are unsure which environment to choose, ask your application's administrator.

## Step 2: Authorize Billit

Select **Authorize**, sign in to Billit in the selected environment, and grant the application access. You will return to the application after authorization.

You do not need to enter an API key or a master account Party ID in this OAuth connection form. Those fields belong to the separate [Billit Access Point connection](/api-integrations/billit/connect).
