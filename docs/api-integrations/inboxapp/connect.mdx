## Overview

To authenticate with Inboxapp, you will need:

1. **API Token** – A token that gives access to your team's conversations, contacts and accounts through the Inboxapp API.

This guide explains how to obtain your **API Token** from Inboxapp.

### Prerequisites

- An active Inboxapp account with access to the team you want to connect

### Instructions

#### Step 1: Getting your API token

1. Log in to [Inboxapp](https://inboxapp.com) and open **Settings → API**.
2. Click **New API token**.
3. Name the token and click **Create**.
4. Copy the token and store it securely.

#### Step 2: Enter credentials in the Connect UI

Once you have your **API Token**:

1. Open the form where you need to authenticate with Inboxapp.
2. Enter your **API Token** in the API Token field.
3. Submit the form to complete authentication.

You are now connected to Inboxapp.
