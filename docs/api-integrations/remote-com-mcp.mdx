## 🚀 Quickstart

Connect to the Remote.com MCP server with Nango and call MCP tools in minutes. Remote.com MCP uses OAuth 2.0 with a **client ID metadata document**, so no app registration is required.

<Steps>
    <Step id="create-integration" title="Create the integration">
        In Nango ([free signup](https://app.nango.dev)), go to **Integrations** → _Configure New Integration_ → _Remote.com (MCP)_.
    </Step>
    <Step id="authorize-remote" title="Authorize Remote.com">
        Go to **Connections** → _Add Test Connection_ → _Authorize_, then sign in to your Remote.com account. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-remote-mcp" title="Call the Remote.com MCP server">
        Make your first MCP request (initialize handshake). Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
        <Tabs>
            <Tab title="cURL">

                ```bash
                curl "https://api.nango.dev/proxy/mcp" \
                  -X POST \
                  -H "Authorization: Bearer <NANGO-API-KEY>" \
                  -H "Provider-Config-Key: <INTEGRATION-ID>" \
                  -H "Connection-Id: <CONNECTION-ID>" \
                  -H "Content-Type: application/json" \
                  -d '{
                    "jsonrpc": "2.0",
                    "id": 1,
                    "method": "initialize",
                    "params": {
                        "protocolVersion": "2024-11-05",
                        "capabilities": {},
                        "clientInfo": {
                            "name": "nango-client",
                            "version": "1.0.0"
                        }
                    }
                  }'
                ```

            </Tab>
            <Tab title="Node">

                Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

                ```typescript
                import { Nango } from '@nangohq/node';

                const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

                const res = await nango.post({
                    endpoint: '/mcp',
                    providerConfigKey: '<INTEGRATION-ID>',
                    connectionId: '<CONNECTION-ID>',
                    data: {
                        jsonrpc: '2.0',
                        id: 1,
                        method: 'initialize',
                        params: {
                            protocolVersion: '2024-11-05',
                            capabilities: {},
                            clientInfo: {
                                name: 'nango-client',
                                version: '1.0.0'
                            }
                        }
                    }
                });

                console.log(res.data);
                ```
            </Tab>
        </Tabs>

        Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

        ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>
    <Step id="implement-nango" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## 📚 Remote.com guides

Nango identifies itself to Remote's OAuth server (`api.employ.remote.com`) with its own client ID metadata document, so you do not need to register an OAuth app: create the integration in Nango and sign in with your Remote.com account. You don't need to request scopes: the tools available depend on the user's role in Remote.

To test without a production account, Remote offers a 14-day [sandbox](https://developer.remote.com/docs/sandbox-quickstart).

Official resources: [Remote.com MCP](https://developer.remote.com/docs/introduction-to-remote-mcp)
