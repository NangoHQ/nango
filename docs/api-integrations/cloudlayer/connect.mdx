## Overview

To authenticate with cloudlayer.io, you need:

1. **API Key** — an API key of your cloudlayer.io account.

This guide will show you how to create one.

### Prerequisites

- A cloudlayer.io account. If you don't have one, [create a free account](https://beta-app.cloudlayer.io/auth/sign-up).

### Step 1: Create an API key

1. Sign in to the [cloudlayer.io dashboard](https://beta-app.cloudlayer.io).
2. Click **Settings** at the bottom of the left sidebar, then under **Developer**, click **API Keys**.

<img src="/api-integrations/cloudlayer/settings_api_keys_nav.png" alt="cloudlayer.io Settings page with API Keys under Developer"/>

3. On the **API Keys** page, click **Create API Key**. The key is created right away.

<img src="/api-integrations/cloudlayer/create_api_key_button.png" alt="cloudlayer.io API Keys page with the Create API Key button"/>

4. Click the copy icon next to the new key (it starts with `cl-`) to copy its full value.

<img src="/api-integrations/cloudlayer/api_key_created.png" alt="cloudlayer.io API Keys list with the copy icon next to the new key"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with cloudlayer.io.
2. Enter your API key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/cloudlayer/form.png" alt="cloudlayer.io Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to cloudlayer.io.
