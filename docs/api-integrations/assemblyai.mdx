## 🚀 Quickstart

Connect to AssemblyAI with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _AssemblyAI_.
    </Step>
    <Step id="authorize-assemblyai" title="Authorize AssemblyAI">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then choose your region and enter your AssemblyAI API key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-assemblyai-api" title="Call the AssemblyAI API">
    Let's make your first request to the AssemblyAI API to list your most recent transcript. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/v2/transcript?limit=1" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/v2/transcript',
            params: { limit: 1 },
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- Sync STT is served from `https://sync.assemblyai.com` (EU: `https://sync.eu.assemblyai.com`), not from the connection's base URL. Call it with `baseUrlOverride` set to that host; Nango keeps the connection's credentials and headers. See [Cloud endpoints & data residency](https://www.assemblyai.com/docs/sync-stt/endpoints-and-data-zones).
- LLM Gateway is served from `https://llm-gateway.assemblyai.com` (EU: `https://llm-gateway.eu.assemblyai.com`), with `/v1` in the endpoint path. Call it with `baseUrlOverride` set to that host; Nango keeps the connection's credentials and headers. See [LLM Gateway quickstart](https://www.assemblyai.com/docs/llm-gateway/quickstart).
- Temporary tokens are minted at `https://token.assemblyai.com/v1/token`. Call it with `baseUrlOverride` set to `https://token.assemblyai.com`; Nango keeps the connection's credentials and headers. See [Temporary tokens](https://www.assemblyai.com/docs/temporary-tokens).
