## Overview

To authenticate with 2Chat, you need:

1. **API Key** — an API key from the Developers page of your 2Chat dashboard.

This guide will show you how to create it.

### Prerequisites

- A 2Chat account. If you don't have one, [sign up](https://app.2chat.io/signup/). The 7-day free trial includes API access and needs no credit card.

### Step 1: Create an API key

1. Sign in to [2Chat](https://app.2chat.io/).
2. Click **Developers** (the `</>` icon) in the left sidebar. The **API Access** tab opens.
3. Click **New API Key** in the top right.

<img src="/api-integrations/2chat/developers_api_access.png" alt="2Chat Developers page on the API Access tab with the New API Key button" />

4. Enter a **Friendly Name** for the key, then click **Save**.

<img src="/api-integrations/2chat/new_api_key_dialog.png" alt="2Chat New API Key dialog with the Friendly Name field and the Save button" />

5. The new key appears in the API key table. Click the copy icon in its row to copy the API key.

<img src="/api-integrations/2chat/api_key_created.png" alt="2Chat API key table with the copy icon next to the new key" />

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with 2Chat.
2. Enter your API key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/2chat/form.png" alt="2Chat Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to 2Chat.
