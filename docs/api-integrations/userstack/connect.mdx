## Overview

To authenticate with Userstack, you need:

1. **API Access Key** — the access key shown on your Userstack dashboard.

This guide will show you how to get it.

### Prerequisites

- A Userstack account. The [Free plan](https://userstack.com/signup/free) includes API access with 100 lookups per month.

### Step 1: Copy your API access key

1. Sign up for a free account at [userstack.com/signup/free](https://userstack.com/signup/free), or log in at [userstack.com/login](https://userstack.com/login).
2. Open the **Dashboard**. It is the first page you see after logging in.
3. Under **Your API Key**, click the copy icon to copy your API access key.

<img src="/api-integrations/userstack/dashboard_api_key.png" alt="Userstack dashboard with the copy icon next to Your API Key"/>

**Reset Key** creates a new key and immediately invalidates the previous one, so only reset it if you also update your connection.

### Step 2: Enter your API access key in the Connect UI

1. Open the form where you need to authenticate with Userstack.
2. Paste the key you copied in Step 1 into the **API Access Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/userstack/form.png" alt="Userstack Connect UI form with the API Access Key field" style={{maxWidth: "450px" }}/>

You are now connected to Userstack.
