## Overview

To authenticate with Laylo, you need:

1. **API Key** — a key from your Laylo API Keyring.

This guide will show you how to get it.

### Prerequisites

- A Laylo account. You can [start for free](https://laylo.com/auth).

### Step 1: Create an API key

1. Sign in to [Laylo](https://laylo.com/auth).
2. Open **Settings** in the left sidebar and select the **Integrations** tab.
3. Scroll to the bottom of the page to find **API Keyring**.
4. Enter a name in the **New Key name** field so you know what the key is for, then click **Add**.

<img src="/api-integrations/laylo/api_keyring_add_key.png" alt="API Keyring section in Laylo's Integrations settings with a new key name entered and the Add button"/>

5. Click **Copy** and store the key somewhere safe. Laylo does not store the key, so this is your only chance to copy it.

<img src="/api-integrations/laylo/api_key_created.png" alt="Laylo dialog showing the new API key with the Copy button"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Laylo.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be connected.

<img src="/api-integrations/laylo/form.png" alt="Laylo Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Laylo.
