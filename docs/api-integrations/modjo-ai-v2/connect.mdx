## Overview

To connect with Modjo AI, you need an **API Key** from your Modjo AI settings. This guide shows you how to create one.

### Prerequisites

- You must have Administrator or Manager permissions in Modjo AI.

### Step 1: Generate your API key

1. Log in to [Modjo AI](https://app.modjo.ai).
2. Go to **Settings** > **Integrations**.
3. Find the **Public API** card and click **Connect**.

<img src="/api-integrations/modjo-ai/integrations.png" alt="Modjo AI integrations settings showing the Public API card"/>

4. Create a new API key.

<img src="/api-integrations/modjo-ai/create_api_key.png" alt="Modjo AI Public API settings with the option to create an API key"/>
<img src="/api-integrations/modjo-ai/generate_api_key.png" alt="Modjo AI dialog for generating a new API key"/>

5. Click **Copy** and store the key somewhere safe. Modjo AI shows it only once.

<img src="/api-integrations/modjo-ai/api_key.png" alt="Modjo AI showing the newly generated API key with a Copy button"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Modjo AI (v2).
2. Enter your **API Key**.
3. Click **Connect**.

You are now connected to Modjo AI (v2).
