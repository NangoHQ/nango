## Overview

To authenticate with ChatBotKit, you need:

1. **Token** — a ChatBotKit API token.

This guide will show you how to get it.

### Prerequisites

- A ChatBotKit account. You can sign up at [chatbotkit.com](https://chatbotkit.com/welcome).

### Step 1: Create a token

1. Sign in to [ChatBotKit](https://chatbotkit.com/signin) and open the [Tokens page](https://chatbotkit.com/tokens) under **Developer**.
2. Click **Create Token**.

<img src="/api-integrations/chatbotkit/tokens_page.png" alt="ChatBotKit Tokens page with the Create Token button"/>

3. Enter a **Name** and, optionally, a **Description**. Leave **Advanced Options** unchanged, then click **Create**.

<img src="/api-integrations/chatbotkit/create_token_form.png" alt="ChatBotKit token configuration form with the Name and Description fields and the Create button"/>

4. In the **API Token Created** dialog, copy the token. It starts with `sk-` and is shown only once, so store it right away.

<img src="/api-integrations/chatbotkit/token_created.png" alt="ChatBotKit API Token Created dialog with the button to copy the token"/>

### Step 2: Enter your token in the Connect UI

1. Open the form where you need to authenticate with ChatBotKit.
2. Enter your **Token** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/chatbotkit/form.png" alt="ChatBotKit connection form in the Nango Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to ChatBotKit.
