## Overview

To authenticate with FASHN, you need:

1. **API Key** — a FASHN API key created in the Developer API dashboard.

This guide will show you how to get it.

### Prerequisites

- A FASHN account with API credits. You must buy API credits before you can create an API key; the minimum purchase is $7.50 (100 credits).

### Step 1: Buy API credits

1. Sign in to [FASHN](https://app.fashn.ai/login).
2. Open the [Developer API page](https://app.fashn.ai/api).
3. Click **Get credits** and buy API credits. **Create new API Key** stays disabled until you have on-demand credits.

<img src="/api-integrations/fashn/api_page_get_credits.png" alt="FASHN Developer API page with the Get credits button"/>

### Step 2: Create an API key

1. On the [Developer API page](https://app.fashn.ai/api), click **Create new API Key**.
2. Copy the key right away: you can't view it again after closing the window.

### Step 3: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with FASHN.
2. In **API Key**, paste the key you copied in Step 2.
3. Submit the form. Nango checks the key with FASHN before saving the connection.

<img src="/api-integrations/fashn/form.png" alt="FASHN Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to FASHN.
