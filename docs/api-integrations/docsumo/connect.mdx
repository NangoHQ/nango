## Overview

To authenticate with Docsumo, you need:

1. **API Key** - The API key of your Docsumo account.

This guide will show you where to find it.

### Prerequisites

- A Docsumo account with API access. The [free trial](https://www.docsumo.com/free-trial) includes APIs; it starts with a short setup call with Docsumo.

### Step 1: Copy your API key

1. Log in to [Docsumo](https://app.docsumo.com).
2. Open the API settings page at [app.docsumo.com/settings/webhook-api](https://app.docsumo.com/settings/webhook-api/).
3. Click the **copy** button next to your API key to copy it to your clipboard.

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Docsumo.
2. Paste your API key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/docsumo/form.png" alt="Docsumo Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Docsumo.
