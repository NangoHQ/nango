## Overview

To authenticate with BigML, you need:

1. **API Key** — a BigML API key.
2. **Username** — the username of your BigML account.

This guide will show you how to get them.

### Prerequisites

- A BigML account. If you don't have one, [sign up](https://bigml.com/accounts/register/): the 3-day free trial needs no credit card.

### Step 1: Create an API key

1. [Sign in](https://bigml.com/accounts/login/) to BigML and click your username in the top navigation to open your account settings.

<img src="/api-integrations/bigml/open_account_settings.png" alt="BigML dashboard with the username in the top navigation highlighted"/>

2. Click **API key** in the left menu.
3. Under **Alternative Keys**, click **Create New API Key**. Keep the default list and read permissions, enter a name, and click **Create New API Key**.

<img src="/api-integrations/bigml/create_api_key_dialog.png" alt="BigML Create New API Key dialog with list and read permissions checked and the Create New API Key button highlighted"/>

4. Copy the new key from the **Alternative Keys** list.

<img src="/api-integrations/bigml/api_key_created.png" alt="BigML API key page with the new alternative key highlighted"/>

You can also use the **Master** key shown at the top of the same page.

### Step 2: Find your username

Your BigML username is shown in the top navigation, next to the **Dashboard** button.

### Step 3: Enter your credentials in the Connect UI

1. Open the form where you need to authenticate with BigML.
2. Enter your username in the **Username** field and your API key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/bigml/form.png" alt="BigML Connect UI form with the Username and API Key fields" style={{maxWidth: "450px" }}/>

You are now connected to BigML.
