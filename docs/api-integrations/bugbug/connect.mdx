## Overview

To authenticate with BugBug, you need:

1. **API Token** — the API token of your BugBug project.

This guide will show you how to find it.

### Prerequisites

- A BugBug account on the Business plan. The Public API is available on this plan, and new organizations get a 14-day trial with the features of the Business plan. If you don't have an account, [sign up](https://app.bugbug.io/sign-up/).

### Step 1: Copy your API token

Each BugBug project has its own API token, and every request made with it works on that project.

1. Sign in to [BugBug](https://app.bugbug.io/) and open your project.
2. In the left sidebar, click **Integrations**, then select the **API Token** tab.

<img src="/api-integrations/bugbug/integrations_api_token_tab.png" alt="BugBug Integrations page with the API Token tab highlighted"/>

3. Click **Copy to clipboard** next to the token. It starts with `bbp_`.

<img src="/api-integrations/bugbug/api_token_copy.png" alt="BugBug API Token tab with the Copy to clipboard button highlighted"/>

### Step 2: Enter your API token in the Connect UI

1. Open the form where you need to authenticate with BugBug.
2. Enter your token in the **API Token** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/bugbug/form.png" alt="BugBug Connect UI form with the API Token field" style={{maxWidth: "450px" }}/>

You are now connected to BugBug.
