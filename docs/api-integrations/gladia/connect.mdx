## Overview

To authenticate with Gladia, you need:

1. **API Key** — a Gladia API key that starts with `sk_gladia_`.

This guide will show you how to create one.

### Prerequisites

- A Gladia account. New accounts get a one-time credit grant to try the service; [sign up here](https://app.gladia.io/signup).

### Step 1: Create an API key

1. Sign in to [Gladia](https://app.gladia.io) and click **API keys** under **Manage** in the left sidebar.

<img src="/api-integrations/gladia/apikeys_sidebar.png" alt="Gladia dashboard with API keys highlighted in the left sidebar"/>

2. Under **Create API Key**, enter a name for the key (optional) and click **Create API Key**. There are no permissions or scopes to choose.

<Note>
Gladia also creates a default API key when you sign up. You can use it instead of creating a new one.
</Note>

<img src="/api-integrations/gladia/create_api_key.png" alt="Gladia API Keys page with a key name entered and the Create API Key button highlighted"/>

3. Find the new key in the list and click the copy icon next to it to copy the full key.

<img src="/api-integrations/gladia/copy_api_key.png" alt="Gladia API keys list with the copy icon next to the new key highlighted"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Gladia.
2. Enter your **API Key** in the designated field.
3. Click **Connect**.

<img src="/api-integrations/gladia/form.png" alt="Nango Connect UI form for entering the Gladia API key" style={{maxWidth: "450px" }}/>

You are now connected to Gladia.
