## Overview

To authenticate with Finnhub, you need:

1. **API Key** — the API key of your Finnhub account.

This guide will show you how to get it.

### Prerequisites

- A Finnhub account. The Free plan includes 60 API calls per minute; [sign up here](https://finnhub.io/register). Endpoints marked Premium need a paid plan.

### Step 1: Copy your API key

1. Sign in to [Finnhub](https://finnhub.io/login) and open your [Dashboard](https://finnhub.io/dashboard).
2. Under **API Key**, click the copy button next to the key.

<img src="/api-integrations/finnhub/dashboard_api_key.png" alt="Finnhub Dashboard with the copy button next to the API key highlighted"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Finnhub.
2. Enter your **API Key** in the designated field.
3. Click **Connect**.

<img src="/api-integrations/finnhub/form.png" alt="Nango Connect UI form for entering the Finnhub API key" style={{maxWidth: "450px" }}/>

You are now connected to Finnhub.
