## 🚀 Quickstart

Connect to the Crustdata MCP server with Nango and call MCP tools in minutes. Crustdata MCP uses OAuth 2.0 with **dynamic client registration**, so no app registration is required.

<Steps>
    <Step id="create-integration" title="Create the integration">
        In Nango ([free signup](https://app.nango.dev)), go to **Integrations** → _Configure New Integration_ → _Crustdata (MCP)_.
    </Step>
    <Step id="authorize-crustdata" title="Authorize Crustdata">
        Go to **Connections** → _Add Test Connection_ → _Authorize_, then sign in to your Crustdata account. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-crustdata-mcp" title="Call the Crustdata MCP API">
        Make your first MCP request (initialize handshake). Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
        <Tabs>
            <Tab title="cURL">

                ```bash
                curl "https://api.nango.dev/proxy/mcp" \
                  -X POST \
                  -H "Authorization: Bearer <NANGO-API-KEY>" \
                  -H "Provider-Config-Key: <INTEGRATION-ID>" \
                  -H "Connection-Id: <CONNECTION-ID>" \
                  -H "Content-Type: application/json" \
                  -d '{
                    "jsonrpc": "2.0",
                    "id": 1,
                    "method": "initialize",
                    "params": {
                        "protocolVersion": "2025-06-18",
                        "capabilities": {},
                        "clientInfo": {
                            "name": "nango-client",
                            "version": "1.0.0"
                        }
                    }
                }'
                ```

            </Tab>

            <Tab title="Node">

                Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

                ```typescript
                import { Nango } from '@nangohq/node';

                const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

                const res = await nango.post({
                    endpoint: '/mcp',
                    providerConfigKey: '<INTEGRATION-ID>',
                    connectionId: '<CONNECTION-ID>',
                    body: {
                        jsonrpc: '2.0',
                        id: 1,
                        method: 'initialize',
                        params: {
                            protocolVersion: '2025-06-18',
                            capabilities: {},
                            clientInfo: {
                                name: 'nango-client',
                                version: '1.0.0'
                            }
                        }
                    }
                });

                console.log(res.data);
                ```
            </Tab>

        </Tabs>
        ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-nango" title="Implement Nango in your app">
        Follow our [Auth implementation guide](/guides/auth/auth-guide) to integrate Nango in your app.
    </Step>
</Steps>

## 📚 Crustdata (MCP) guides

Nango uses **dynamic client registration** with Crustdata's OAuth server (`install.crustdata.com`). You don't need to register an app. Create the integration in Nango and sign in with your Crustdata account.

Official docs: [Crustdata MCP server](https://docs.crustdata.com/for-agents/mcp)

## API gotchas

- To call Crustdata's REST API directly with an API key instead, use the [Crustdata](/api-integrations/crustdata) integration.
