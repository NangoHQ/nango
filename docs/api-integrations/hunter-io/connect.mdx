## Overview

To authenticate with Hunter, you need:
1. **API Key** - A key from the API keys page of your Hunter dashboard.

This guide will walk you through finding your **API Key** within Hunter.

### Prerequisites

- An active Hunter account. API access is included in all plans, including the free plan.

### Instructions

#### Step 1: Find your Hunter API key

1. Log in to your [Hunter](https://hunter.io/) account.
2. Go to the [API keys](https://hunter.io/api-keys) page.
3. Copy an existing API key, or create a new one.

<Tip>Hunter's `test-api-key` only returns dummy responses for a few endpoints and can't be used to connect. Use a real API key from your dashboard.</Tip>

#### Step 2: Enter your API key in the Connect UI

Once you have your **API Key**:

1. Open the form where you need to authenticate with Hunter.
2. Enter your **API Key** in the field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/hunter-io/form.png" style={{maxWidth: "450px" }}/>

You are now connected to Hunter.
