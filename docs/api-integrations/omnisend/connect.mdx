## Overview

To authenticate with Omnisend, you need an API key generated in your Omnisend account.

### Prerequisites

- An Omnisend account with permission to create API keys.

### Instructions

#### Step 1: Open the API keys section

Sign in to Omnisend and open the [API keys section](https://app.omnisend.com/integrations/api-keys).

<a id="step-2-create-an-omnisend-api-key"></a>

#### Step 2: Create an Omnisend API key

Create a key with only the scopes needed by your application. Copy it when Omnisend displays it; Omnisend does not show it again after creation.

#### Step 3: Enter the API key in the Connect UI

1. Open the form where you need to authenticate with Omnisend.
2. Enter your **API Key**.
3. Submit the form. Nango verifies the credential with the read-only request `GET /api/campaigns?limit=1`.

You are now connected to Omnisend.

<Tip>Never expose the API key in browser code or commit it to source control.</Tip>
