## Overview

To connect Omnisend to Nango, you need an **API key** with only the scopes required by your application.

## Prerequisites

- An Omnisend account with access to API keys.
- Permission to create an API key with the required scopes.

## Step 1: Open Omnisend API keys

Sign in to Omnisend and open the [API keys section](https://app.omnisend.com/integrations/api-keys).

## Step 2: Create an Omnisend API key

Create a key with only the scopes needed by your application. Copy it when Omnisend displays it and store it securely; Omnisend does not show it again after creation.

<a id="step-2-create-an-omnisend-api-key"></a>

## Step 3: Enter the API key in Nango

Open the Omnisend connection form in Nango, enter the API key, and select **Connect**. Nango verifies the credential with the read-only request `GET /api/campaigns?limit=1`.

Nango automatically sends Omnisend's required headers:

```http
Authorization: Omnisend-API-Key <YOUR-API-KEY>
Omnisend-Version: 2026-03-15
```

<Tip>Never expose the API key in browser code or commit it to source control.</Tip>
