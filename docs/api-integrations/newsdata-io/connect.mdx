## Overview

To authenticate with NewsData.io, you need:

1. **API Key** - The API key of your NewsData.io account.

This guide will show you how to get it.

### Prerequisites

- A NewsData.io account. [Register here](https://newsdata.io/register) for free; no credit card is needed. Verify your email address to activate the account.

### Step 1: Copy your API key

1. Log in to [NewsData.io](https://newsdata.io/login) and click **API Key** in the left sidebar of the dashboard to open **Manage API Keys**.

<img src="/api-integrations/newsdata-io/manage_api_keys.png" alt="Manage API Keys page in the NewsData.io dashboard with the Create API Key button highlighted"/>

2. Copy the **Master Key** with the copy icon next to it. If your plan lets you create more keys, you can instead click **Create API Key** and copy the new key.

<img src="/api-integrations/newsdata-io/copy_master_key.png" alt="Copy icon next to the Master Key in the NewsData.io Manage API Keys table"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with NewsData.io.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/newsdata-io/form.png" alt="NewsData.io connection form in Nango's Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to NewsData.io.
