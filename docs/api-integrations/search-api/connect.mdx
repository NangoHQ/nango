## Overview

To authenticate with SearchApi, you need:

1. **API Key** — an API key from your SearchApi dashboard.

This guide will show you how to get it.

### Prerequisites

- A SearchApi account. You don't need a paid plan: [sign up](https://www.searchapi.io/users/sign_up) to get 100 free requests, no credit card required.

### Step 1: Create an API key

1. Sign in to [SearchApi](https://www.searchapi.io/users/sign_in).
2. In the left sidebar, open **Account** > **API keys**, or go to the [API keys page](https://www.searchapi.io/api_tokens).
3. Click **Create an API Key**, enter a name (for example, `Nango`), then click **Create Api token**. You can also use the **Default** key SearchApi creates when you sign up.
4. On the key's page, click the copy button next to **Token**.

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with SearchApi.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/search-api/form.png" alt="The SearchApi connection form in the Nango Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to SearchApi.
