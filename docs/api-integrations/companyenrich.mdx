## 🚀 Quickstart

Connect to CompanyEnrich with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _CompanyEnrich_.
    </Step>
    <Step id="authorize-companyenrich" title="Authorize CompanyEnrich">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your CompanyEnrich API key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-companyenrich-api" title="Call the CompanyEnrich API">
    Let's make your first request to the CompanyEnrich API: get your account and credit balance. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/v2/me" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/v2/me',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- CompanyEnrich's hosted MCP server is on `https://mcp.companyenrich.com` and takes the same API key: send MCP requests to `/mcp` with `baseUrlOverride` set to `https://mcp.companyenrich.com`, and Nango keeps the connection's credentials and headers. See [MCP server](https://docs.companyenrich.com/docs/mcp-server).
