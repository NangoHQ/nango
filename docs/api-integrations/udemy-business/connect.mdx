## Overview

To connect with the Udemy Business GraphQL API, you need:

1. **Client ID**: the client ID of a GraphQL API client in your Udemy Business account.
2. **Client Secret**: the client secret of the same API client.

### Prerequisites

- A Udemy Business account on the Enterprise plan. The APIs are not available on the Team plan.
- Admin access to that account.

### Step 1: Create a GraphQL API client

1. Sign in to your Udemy Business site, such as `https://<your-subdomain>.udemy.com`, as an admin.
2. Open the developer portal's API clients page at `https://<your-subdomain>.udemy.com/dev-portal/api-clients/`.
3. Create a GraphQL API client and give it the **Course** scope.
4. Copy the **Client ID** and **Client Secret**. Keep the secret somewhere safe.

### Step 2: Enter credentials in the Connect UI

1. Open the form where you need to authenticate with Udemy Business.
2. Enter your **Client ID** and **Client Secret**.
3. Submit the form, and you should be successfully authenticated.

You are now connected to Udemy Business.
