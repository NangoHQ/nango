## Overview

To authenticate with All Images AI, you need:

1. **API Key** — an All Images AI API key (personal access token).

This guide will show you how to generate one.

### Prerequisites

- An All Images AI account. If you don't have one, [sign up](https://app.all-images.ai/en/register).

### Step 1: Generate an API key

1. Sign in to [All Images AI](https://app.all-images.ai/en/login).
2. Open the [API keys page](https://app.all-images.ai/en/api-keys) (also linked as **API** in the page footer) and click **Generate an API key**.

<img src="/api-integrations/all-images-ai/api_keys_page.png" alt="All Images AI API keys page with the Generate an API key button"/>

3. Enter a name for the key and click **Confirm**.

<img src="/api-integrations/all-images-ai/name_api_key.png" alt="All Images AI dialog to name the new API key with the Confirm button"/>

4. In the new row of the API keys table, click the copy icon next to the key to copy it.

<img src="/api-integrations/all-images-ai/copy_api_key.png" alt="All Images AI API keys table with the copy icon next to the new key"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with All Images AI.
2. Enter your API key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/all-images-ai/form.png" alt="All Images AI Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to All Images AI.
