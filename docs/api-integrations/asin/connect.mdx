## Overview

To authenticate with Asin, you need:

1. **API Key** - An Asin API key.

This guide shows you how to create one.

### Prerequisites

- An Asin account. You can [sign up](https://www.asin.dev/signup) on asin.dev.

### Step 1: Create an API key

1. Sign in to [Asin](https://www.asin.dev/login) and open your dashboard.
2. Create an API key. Asin keys start with `asin_`.
3. Copy the key.

<Note>
If the key is revoked, Asin rejects requests made with it and answers HTTP 401.
</Note>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Asin.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

You are now connected to Asin.
