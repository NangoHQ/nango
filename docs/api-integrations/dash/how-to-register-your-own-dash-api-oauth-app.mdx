This guide shows you how to get the OAuth credentials (client ID & secret) for your Dash account. Each Dash account has one client ID and secret, issued when an admin turns on the REST API, so one Nango integration connects users of one Dash account.

<Steps>
  <Step title="Create a Dash account">
    If you don't have a Dash account, [start a free trial](https://www.dash.app/).
  </Step>
  <Step title="Turn on the REST API">
    Sign in to Dash as an account admin, go to **Admin** → **Integrations**, open the **REST API** tab and switch **Enable API** on. Copy the **Client ID** and **Secret key** that appear.

    <img src="/api-integrations/dash/rest_api_tab.png" alt="Dash Admin Integrations page with the REST API tab, the Enable API switch on, and the Client ID and Secret key fields"/>
  </Step>
  <Step title="Add Nango's callback URL">
    On the same page, add `https://api.nango.dev/oauth/callback` to the allowed callback URLs (or your own [custom callback URL](/guides/auth/auth-guide#custom-oauth-callback-url-optional)).
  </Step>
  <Step title="Add the scopes in Nango">
    In your Dash integration in Nango, paste the client ID and secret, and set the scopes to `offline_access` and `subdomain:<your-subdomain>`, where `<your-subdomain>` is the first part of your Dash address (`my-account` for `https://my-account.dash.app`). Dash needs the `subdomain` scope to know which account the token is for, and `offline_access` returns a refresh token.
  </Step>
  <Step title="Next">
    Follow the [_Quickstart_](/getting-started/quickstart).
  </Step>
</Steps>

<Note>Switching **Enable API** off revokes the client ID and secret along with the saved callback URLs, and switching it on again issues a new client ID and secret, which you then update in Nango.</Note>

For more details, see the [Dash API documentation](https://api-docs.dash.app/).
