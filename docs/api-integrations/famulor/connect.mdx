## Overview

To authenticate with Famulor, you will need:
1. **API Key** - A workspace API key created under **Settings → API & MCP** in Famulor.

This guide will walk you through creating your **API Key** within Famulor.

### Prerequisites:

- You must have a Famulor account with a workspace. Sign up at [app.famulor.io](https://app.famulor.io).
- The workspace plan must include **API Access**.

#### Step 1: Creating a Famulor API key

1. Log in to [Famulor](https://app.famulor.io).
2. Open **Settings → API & MCP**.
3. Create a new API key and copy it. The full key is shown only once.
4. Workspace API keys start with `fam_`.

#### Step 2: Enter credentials in the Connect UI

1. Open the form where you need to authenticate with Famulor.
2. Enter your **API Key**.
3. Submit the form.

You are now connected to Famulor.
