## 🚀 Quickstart

Connect to AppVeyor with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _AppVeyor_.
    </Step>
    <Step id="authorize-appveyor" title="Authorize AppVeyor">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your AppVeyor API key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-appveyor-api" title="Call the AppVeyor API">
    Let's make your first request to the AppVeyor API to list the roles in your account. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/roles" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/roles',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    With a user-level (v2) API key, prefix the endpoint with the account to call, for example `/account/<ACCOUNT-NAME>/roles`.

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- Nango does not check the key when a connection is created, so a wrong or revoked key still connects and fails on its first call.
