## Overview

To authenticate with Perigon, you need:

1. **API Key** — an API key from your Perigon account.

This guide will show you how to create one.

### Prerequisites

- A Perigon account with a verified email address. Unverified emails cannot access the API. If you don't have an account, [sign up](https://www.perigon.io/sign-up) and click the verification link Perigon emails you.

### Step 1: Create an API key

1. Sign in to Perigon and open **Developers** > [API keys](https://perigon.io/dev/keys).
2. Click **Create new key**.

<img src="/api-integrations/perigon/api_keys_page.png" alt="Perigon API keys page with the Create new key button"/>

3. Enter a name for the key (for example, `nango-integration`) and click **Create key**.

<img src="/api-integrations/perigon/create_api_key_dialog.png" alt="Perigon Create a new API key dialog with the Name field and Create key button"/>

4. In the key list, click the new key's token to open the **API Key Token** dialog, then copy the full token.

<img src="/api-integrations/perigon/api_key_created.png" alt="Perigon API Key Token dialog showing the full token with a copy button"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Perigon.
2. Enter your API key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/perigon/form.png" alt="Perigon Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Perigon.
