## Overview

To authenticate with Carbone, you need:

1. **API Key** - Your Carbone test or production API key.

This guide will show you how to find it.

### Prerequisites

- A [Carbone account](https://account.carbone.io/).

### Step 1: Copy your API key

1. Sign in to your [Carbone account](https://account.carbone.io/).
2. Click **API keys** in the left sidebar.
3. Click the token of the key you want to use to copy it. If Carbone asks you to confirm your password, enter it and click **Continue**.

<img src="/api-integrations/carbone/api_keys_copy_test_key.png" alt="Carbone API keys page with the Test key token highlighted"/>

<Note>
The **Test key** only generates watermarked PDFs. The **Production key** stays locked until you subscribe to a Carbone Cloud plan with **Unlock the production key**.
</Note>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Carbone.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/carbone/form.png" alt="Carbone connection form in the Nango Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to Carbone.
