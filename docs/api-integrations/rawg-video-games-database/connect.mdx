## Overview

To authenticate with RAWG Video Games Database, you need:

1. **API Key** — the key from your RAWG developer info page.

This guide will show you how to get it.

### Prerequisites

- A RAWG account. The free plan includes up to 20,000 requests per month.

### Step 1: Create your RAWG account

1. [Sign up for RAWG](https://rawg.io/signup) with your email, a username and a password.
2. If you already have an account, [log in](https://rawg.io/login) instead.

### Step 2: Get your API key

1. Open the [RAWG API page](https://rawg.io/apidocs) and click **Get API Key**.

<img src="/api-integrations/rawg-video-games-database/apidocs_get_api_key.png" alt="RAWG API page with the Get API Key button"/>

2. Fill in the developer info form: your full name, contact email, site or app URL, and a short description of how you will use the API. Then click **Submit**.

<img src="/api-integrations/rawg-video-games-database/developer_info_form.png" alt="RAWG developer info form with name, email, site URL and use-case fields"/>

3. Your API key is shown under **API Key** at the bottom of the developer info page. Click the copy icon to copy it.

<img src="/api-integrations/rawg-video-games-database/api_key_created.png" alt="RAWG developer info page showing the API Key field at the bottom"/>

### Step 3: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with RAWG Video Games Database.
2. Paste the key you copied in Step 2 into the **API Key** field.
3. Submit the form.

<img src="/api-integrations/rawg-video-games-database/form.png" alt="RAWG Video Games Database Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

If the key is wrong, Nango shows an error and the connection is not saved.
