## Overview

To authenticate with Syncore, you need:

1. **API Key** - A key that grants secure access to the Syncore API, sent via the `x-api-key` HTTP header.

This guide will walk you through getting your API key from Syncore.

### Prerequisites

- An active Syncore account.

### Instructions

#### Step 1: Getting your API key

1. Log in to the Syncore platform.
2. Go to **Settings > API**.
3. View or generate your API key, then copy it.


#### Step 2: Enter credentials in the Connect UI

Once you have your **API Key**:

1. Open the form where you need to authenticate with Syncore.
2. Enter your **API Key** in the field provided.
3. Submit the form, and you should be successfully authenticated.

You are now connected to Syncore.
