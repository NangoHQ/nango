## Overview

To connect with Together AI, you need:

1. **API Key** – A Together AI API key, sent as a Bearer token.

This guide walks you through creating one.

### Prerequisites

- A [Together AI](https://www.together.ai) account.

### Instructions

#### Step 1: Create an API key

1. Log in to Together AI and open the [Together AI settings](https://api.together.ai/settings/api-keys).
2. Create a new API key.
3. Give it a name that identifies this integration, so you can revoke it later without affecting your other keys.
4. Confirm, then copy the value. It is only shown once.

<Tip>Keep your API key secret. Anyone holding it can call the Together AI API and spend your account's credits.</Tip>

#### Step 2: Authorize in Nango

1. Open the Nango Connect form.
2. Enter your **API Key** in the field provided.
3. Submit the form, and you should be successfully authenticated.

You are now connected to Together AI.
