## 🚀 Quickstart

Connect to TD SYNNEX StreamOne Ion with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _TD SYNNEX StreamOne Ion_.
    </Step>
    <Step id="authorize-td-synnex-streamone-ion" title="Authorize TD SYNNEX StreamOne Ion">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your account ID and refresh token. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-td-synnex-streamone-ion-api" title="Call the TD SYNNEX StreamOne Ion API">
    Let's make your first request to the StreamOne Ion API to list your customers. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, connection ID, and account ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/api/v3/accounts/<ACCOUNT-ID>/customers?pageSize=1" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/api/v3/accounts/<ACCOUNT-ID>/customers',
            params: { pageSize: 1 },
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-nango" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- Nango stores the account ID as the `accountId` connection config field but adds it to no request: read it from the connection's `connection_config.accountId` and put it in the path, such as `/api/v3/accounts/<ACCOUNT-ID>/customers`.
