## Overview

To connect with GroqCloud, you need:

1. **API Key** — a GroqCloud API key.

### Prerequisites

- A GroqCloud account. You can [sign up](https://console.groq.com/login) on the free tier with Google, GitHub, SSO or email.

### Step 1: Create an API key

1. Log in to the [GroqCloud console](https://console.groq.com). In the dropdown at the top left, pick the project the key should belong to: API keys are specific to the selected project. Then click **API Keys** in the top navigation.

<img
    src="/api-integrations/groqcloud/console_api_keys_nav.png"
    alt="GroqCloud console with the organization and project dropdown at the top left and API Keys highlighted in the top navigation"
/>

2. On the [API Keys](https://console.groq.com/keys) page, click **Create API Key**.

<img
    src="/api-integrations/groqcloud/create_api_key_button.png"
    alt="GroqCloud API Keys page with the Create API Key button highlighted"
/>

3. Enter a **Display Name**, optionally choose an **Expiration**, and click **Submit**.

<img
    src="/api-integrations/groqcloud/create_api_key_dialog.png"
    alt="GroqCloud Create API Key dialog with a display name entered and the Submit button highlighted"
/>

4. Click **Copy** to copy the new key, which starts with `gsk_`. GroqCloud shows it only once.

<img
    src="/api-integrations/groqcloud/api_key_created.png"
    alt="GroqCloud dialog showing the new API key with the Copy button highlighted"
/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with GroqCloud.
2. Enter your **API Key**.
3. Click **Connect**.

<img src="/api-integrations/groqcloud/form.png" alt="Nango Connect UI form for entering the GroqCloud API Key" style={{maxWidth: "450px" }}/>

You are now connected to GroqCloud.
