## Overview

To authenticate with AbuseIPDB, you need:

1. **API Key** - An AbuseIPDB API key that lets Nango call the AbuseIPDB API on behalf of your account.

This guide will show you how to create one.

### Prerequisites

- An AbuseIPDB account. The API is free to use; you can [register](https://www.abuseipdb.com/register) for a free account.

### Step 1: Create an API key

1. Log in to [AbuseIPDB](https://www.abuseipdb.com/login) and open **My API** -> **Keys** in the account sidebar.
2. Under **Create API Key**, enter a **Key Name** (for example, `nango`) and click **Create**.

<img src="/api-integrations/abuseipdb/create_api_key.png" alt="Create API Key form on the AbuseIPDB My API Keys page"/>

3. In the **API Keys** table, click **Copy** next to the new key to copy it.

<img src="/api-integrations/abuseipdb/copy_api_key.png" alt="Copy button next to the new key in the AbuseIPDB API Keys table"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with AbuseIPDB.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/abuseipdb/form.png" alt="AbuseIPDB connection form in Nango's Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to AbuseIPDB.
