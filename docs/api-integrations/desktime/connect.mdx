## Overview

To authenticate with DeskTime, you need:

1. **API Key** — your DeskTime API key.

This guide will show you how to generate it.

### Prerequisites

- A DeskTime account. You can [sign up](https://desktime.com/register) for a 14-day free trial that includes all the features of all pricing plans, with no credit card required.

### Step 1: Generate your API key

1. Log in to [DeskTime](https://desktime.com/login).
2. Click **API** in the page footer, or go to the [API page](https://desktime.com/app/api).

<img src="/api-integrations/desktime/api_link_footer.png" alt="DeskTime page footer with the API link highlighted"/>

3. Under **Your API key**, click **Generate**. Enter your account password in the **Generate API key** dialog and click **Confirm**.

<img src="/api-integrations/desktime/generate_api_key.png" alt="DeskTime API page with the Generate button under Your API key highlighted"/>

4. Click the copy button next to your API key. You can also regenerate or deactivate the key here.

<img src="/api-integrations/desktime/copy_api_key.png" alt="DeskTime API page with the copy button next to the API key highlighted"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with DeskTime.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/desktime/form.png" alt="DeskTime connection form in the Nango Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to DeskTime.
