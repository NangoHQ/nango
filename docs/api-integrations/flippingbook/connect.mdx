## Overview

To authenticate with FlippingBook, you need:

1. **API Key** — a FlippingBook Online API key.

This guide will show you how to create it.

### Prerequisites

- A FlippingBook Online account on the Advanced, Team or Enterprise plan. API usage is only available on these plans.

### Step 1: Create an API key

1. Log in to [FlippingBook Online](https://logon.flippingbook.com).
2. Click your name in the top-right corner and select **Profile**.
3. Scroll to the **API keys** section and click **Create a new key**.

<img src="/api-integrations/flippingbook/profile_api_keys.png" alt="FlippingBook Profile page with the Create a new key button in the API keys section highlighted" />

4. Click the copy icon next to the new key to copy it. The page only shows the first part of the key, so use the copy icon rather than selecting the text.

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with FlippingBook.
2. Enter your API key in the **API Key** field.
3. Submit the form. Nango checks your key with FlippingBook, and you should be successfully authenticated.

<img src="/api-integrations/flippingbook/form.png" alt="FlippingBook Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to FlippingBook.
