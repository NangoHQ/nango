## Overview

To authenticate with Returnless, you need:

1. **API Key** — an API key from your Returnless panel.

This guide will show you how to create it.

### Prerequisites

- A Returnless account. You can [sign up for free](https://panel.returnless.com/register?language=en); a free account runs in test mode.

### Step 1: Create an API key

1. Sign in to the [Returnless panel](https://panel.returnless.com/).
2. Click **Settings** in the top menu and choose **Integrations**.

<img src="/api-integrations/returnless/settings_integrations_menu.png" alt="Returnless Settings menu with Integrations highlighted"/>

3. In the left sidebar, under **Developer**, click **API keys**, then click **Create API key**.

<img src="/api-integrations/returnless/api_keys_page.png" alt="Returnless API keys page with the Create API key button"/>

4. Enter a name for the key, for example the name of your app, and click **Create API key**.

<img src="/api-integrations/returnless/create_api_key_dialog.png" alt="Returnless Create API key dialog with the Name field"/>

5. Copy the API key from the **Copy API key** dialog. It is shown only once.

<img src="/api-integrations/returnless/api_key_created.png" alt="Returnless Copy API key dialog with the copy button highlighted"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Returnless.
2. Enter your API key in the **API Key** field.
3. Submit the form. Nango checks the key with Returnless before saving the connection.

<img src="/api-integrations/returnless/form.png" alt="Returnless Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Returnless.
