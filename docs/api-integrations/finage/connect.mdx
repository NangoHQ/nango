## Overview

To authenticate with Finage, you need:

1. **API Key** — the API key of your Finage account.

This guide will show you how to get it.

### Prerequisites

- A Finage account. [Register](https://moon.finage.co.uk/register?subscribe=API00) with your email to get started for free; Finage offers a free trial before you pick a paid plan.

### Step 1: Copy your API key

1. Sign in to the [Finage Moon dashboard](https://moon.finage.co.uk/login).
2. In the left sidebar, under **Services**, click **API**.

<img src="/api-integrations/finage/api_section_sidebar.png" alt="Finage Moon dashboard sidebar with API selected under Services"/>

3. Under **API Subscription**, click the API key field or its copy icon to copy your API key. It starts with `API_KEY`.

<img src="/api-integrations/finage/copy_api_key.png" alt="Finage API Subscription section with the masked API key field and its copy icon highlighted"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Finage.
2. Enter your API key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/finage/form.png" alt="Finage Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Finage.
