## 🚀 Quickstart

Connect to Freshservice with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Freshservice (OAuth)_.
    </Step>
    <Step id="authorize-freshservice" title="Authorize Freshservice">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, enter your Freshworks organization subdomain and Freshservice subdomain, then log in to Freshworks. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-freshservice-api" title="Call the Freshservice API">
    Let's make your first request to the Freshservice API to list tickets. This requires the `freshservice.tickets.view` scope. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/api/v2/tickets" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/api/v2/tickets',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Nango adds the access token to every request and refreshes it for you. Freshworks access tokens last 30 minutes, and refresh tokens last 365 days.

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.

        To obtain your own production credentials, follow the setup guide linked below.
    </Step>
</Steps>
