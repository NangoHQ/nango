## Overview

To authenticate with Filestack, you need:

1. **API Key** — your Filestack application's API key.

This guide will show you how to get it.

### Prerequisites

- A Filestack account. The [free plan](https://www.filestack.com/signup-free/) needs no credit card, and your API key is available as soon as you confirm your email.

### Step 1: Copy your API key

1. Log in to the [Filestack Developer Portal](https://console.filestack.com/login/). Your first application is created for you.
2. In the left sidebar, under your application's name, click the copy icon next to the masked API key.

<img src="/api-integrations/filestack/copy_api_key.png" alt="Filestack Developer Portal sidebar showing the application's masked API key and its copy icon"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Filestack.
2. Enter your API key in the **API Key** field.
3. Submit the form. The connection is saved without checking the key: if the key is wrong, the first API request returns an authentication error.

<img src="/api-integrations/filestack/form.png" alt="Filestack Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Filestack.
