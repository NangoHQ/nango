## Overview

To authenticate with Fixer, you need:

1. **API Access Key** — the API access key of your Fixer account.

This guide will show you how to get it.

### Prerequisites

- A Fixer account. [Sign up for a free account](https://fixer.io/signup/free/monthly) if you don't have one.

### Step 1: Copy your API access key

1. [Log in to Fixer](https://fixer.io/login) and open the **Dashboard**.
2. Under **Your API Key**, click the copy icon to copy your API access key. You can rotate the key with **Reset Key**.

<img src="/api-integrations/fixer/dashboard_api_key.png" alt="Fixer Dashboard with the copy icon next to Your API Key highlighted"/>

### Step 2: Enter your API access key in the Connect UI

1. Open the form where you need to authenticate with Fixer.
2. Paste the key you copied in Step 1 into the **API Access Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/fixer/form.png" alt="Fixer Connect UI form with the API Access Key field" style={{maxWidth: "450px" }}/>

You are now connected to Fixer.
