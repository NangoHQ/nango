## Overview

To authenticate with SerpApi, you need:

1. **API Key** — the private API key of your SerpApi account.

This guide will show you how to find it.

### Prerequisites

- A SerpApi account. The Free plan includes API access. If you don't have an account, [sign up](https://serpapi.com/users/sign_up).

### Step 1: Copy your private API key

1. Log in to [SerpApi](https://serpapi.com/users/sign_in).
2. In the left sidebar, under **Your Account**, click **API Key**.

<img src="/api-integrations/serpapi/api_key_sidebar_link.png" alt="SerpApi dashboard sidebar with the API Key link under Your Account"/>

3. Under **Your private API key**, click the copy button next to the key field.

<img src="/api-integrations/serpapi/copy_private_api_key.png" alt="SerpApi API Key page with the copy button next to Your private API key"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with SerpApi.
2. Enter your private API key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/serpapi/form.png" alt="SerpApi Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to SerpApi.
