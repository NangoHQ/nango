## Overview

To authenticate with Hunter, you need:

1. **API Key** — an API key from your Hunter dashboard.

This guide will show you how to get it.

### Prerequisites

- A Hunter account. The Free plan includes a free API key: [sign up](https://hunter.io/users/sign_up?from=api).

### Step 1: Copy your API key

1. Sign in to [Hunter](https://hunter.io/users/sign_in).
2. Click **API** in the left sidebar, or open the [API keys page](https://hunter.io/api-keys).

<img src="/api-integrations/hunter/dashboard_api_nav.png" alt="The API link in the Hunter dashboard sidebar"/>

3. Use an existing key, or click **New key** to generate one. You can have up to 100 keys.

<img src="/api-integrations/hunter/api_keys_new_key.png" alt="The New key button on the Hunter API keys page"/>

4. Click the copy icon next to the key to copy it.

<img src="/api-integrations/hunter/api_key_copy.png" alt="The copy icon next to an API key on the Hunter API keys page"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Hunter.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/hunter/form.png" alt="The Hunter connection form in the Nango Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to Hunter.
