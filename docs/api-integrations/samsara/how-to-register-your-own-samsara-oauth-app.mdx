This guide shows you how to create an OAuth 2.0 app in Samsara to get OAuth credentials (client ID & secret).

<Steps>
  <Step title="Create an OAuth 2.0 app">
    1. In the Samsara dashboard, go to **Settings** > **OAuth 2.0 Apps** and create a new app.
    2. Enter an app name and upload a logo (JPEG or PNG).
    3. Under **Redirect URL**, add `https://api.nango.dev/oauth/callback` (or your own [custom callback URL](/guides/auth/auth-guide#custom-oauth-callback-url-optional)).
    4. Select the scopes your integration needs. Each API endpoint lists the scopes it requires in the [API Reference](https://developers.samsara.com/reference/overview).
  </Step>
  <Step title="Add the credentials in Nango">
    Copy the app's client ID and secret into your Samsara integration in Nango. The scopes come from the app, so Nango requests none.
  </Step>
  <Step title="Next">
    Follow the [_Quickstart_](/getting-started/quickstart).
  </Step>
</Steps>

Samsara apps and tokens belong to one cloud region. Create the app in the same region (US, EU or Canada) as the dashboards you connect. For more details, see [Samsara OAuth 2.0](https://developers.samsara.com/docs/oauth-20).
