## Overview

To authenticate with the ModMed Certified FHIR API, you need:

1. **FHIR Base URL** — the practice's Certified FHIR R4 endpoint. Nango uses it as the base for all proxied API calls.

This guide will show you how to obtain your FHIR Base URL.

### Prerequisites

- A practice admin has added your developer app's Client ID to their practice.

### Step 1: Finding your FHIR Base URL

Each ModMed practice has its own Certified FHIR endpoint. Look up the practice in ModMed's [FHIR endpoint directory](https://mm-fhir-endpoint-display.prod.fhir.ema-api.com/). Endpoints follow the format `https://<practice>.<specialty>.prod.fhir.ema-api.com/fhir/r4/`.

Enter it without `https://` and without the trailing slash, e.g. `acme.mmi.prod.fhir.ema-api.com/fhir/r4`.


### Step 2: Enter your FHIR Base URL in the Connect UI

Once you have it:

1. Open the form where you need to authenticate with ModMed (FHIR).
2. Enter your **FHIR Base URL** in the designated field.
3. Submit the form, and you should be successfully authenticated.

You are now connected to ModMed (FHIR).
