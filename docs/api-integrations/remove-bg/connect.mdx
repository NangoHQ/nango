## Overview

To authenticate with remove.bg, you need:

1. **API Key** - a remove.bg API key.

This guide shows you how to get it.

### Prerequisites

- A remove.bg account. You can [sign up](https://accounts.kaleido.ai/users/sign_up) for free, including with Google. Your first 50 API calls per month are free.

<Note>
Starting December 1, 2026, background removal moves from remove.bg to Leonardo.Ai. remove.bg credentials don't carry over: Leonardo.Ai needs a new account and API key.
</Note>

### Step 1: Create an API key

1. [Sign in](https://accounts.kaleido.ai/users/sign_in) to remove.bg.
2. Click your initials in the top-right of the menu bar and choose **My Account**.

<img src="/api-integrations/remove-bg/open_my_account.png" alt="remove.bg menu bar with the account menu open and My Account highlighted"/>

3. Open the **API Keys** tab and click **+ New API Key**. You can create up to 10 API keys.

<img src="/api-integrations/remove-bg/api_keys_new_key.png" alt="remove.bg API Keys tab with the New API Key button"/>

4. Enter a **Key label**, for example `Nango`, and click **Create API Key**.

<img src="/api-integrations/remove-bg/label_api_key.png" alt="remove.bg New API Key dialog with the Key label field and the Create API Key button"/>

5. Click **Copy** next to the API key and store it safely.

<img src="/api-integrations/remove-bg/api_key_created.png" alt="remove.bg API Key dialog with the Copy button next to the new API key"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with remove.bg.
2. Enter your **API Key** in the designated field.
3. Click **Connect**. Nango checks the key with remove.bg and rejects it if it is wrong.

<img src="/api-integrations/remove-bg/form.png" alt="Nango Connect UI form for entering the remove.bg API key" style={{maxWidth: "450px" }}/>

You are now connected to remove.bg.
