## Overview

To authenticate with AgentQL, you need:

1. **API Key** — an API key from the AgentQL Dev Portal.

This guide will show you how to get it.

### Prerequisites

- An AgentQL account. [Sign up](https://dev.agentql.com/sign-up) with Google or GitHub; the free trial includes 300 API calls and needs no credit card.

### Step 1: Create an API key

1. Sign in to the [AgentQL Dev Portal](https://dev.agentql.com/sign-in) and open **API Keys**.
2. Click **+ Create a new API key**.

<img src="/api-integrations/agentql/api_keys_page.png" alt="API Keys page in the AgentQL Dev Portal with the Create a new API key button"/>

3. Copy the key with the copy button next to it. AgentQL shows it only once.
4. Optionally name the key, then click **OK**.

<img src="/api-integrations/agentql/api_key_created.png" alt="API key created successfully dialog in the AgentQL Dev Portal"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with AgentQL.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/agentql/form.png" alt="AgentQL API key form in the Nango Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to AgentQL.
