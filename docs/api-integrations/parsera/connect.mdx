## Overview

To authenticate with Parsera, you need:

1. **API Key** — the API key of your Parsera account.

This guide will show you how to get it.

### Prerequisites

- A Parsera account. API access is available on the free plan. If you don't have an account, [sign up](https://parsera.org/auth/sign-up).

### Step 1: Copy your API key

1. Log in to [Parsera](https://parsera.org/app).
2. In the left sidebar, click **API**.

<img src="/api-integrations/parsera/open_api_menu.png" alt="Parsera app sidebar with the API item highlighted"/>

3. Under **API Key**, click the copy icon to copy your key. Each account has one API key. **Refresh key** replaces it with a new one.

<img src="/api-integrations/parsera/copy_api_key.png" alt="Parsera API page with the copy icon next to the API key highlighted"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Parsera.
2. Enter your key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/parsera/form.png" alt="Parsera Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Parsera.
