## Overview

To connect with Hugging Face, you need:

1. **API Key** – A Hugging Face access token, sent as a Bearer token.

This guide walks you through creating one.

### Prerequisites

- A [Hugging Face](https://huggingface.co) account.

### Instructions

#### Step 1: Create an API key

1. Log in to Hugging Face and open the [Hugging Face account settings](https://huggingface.co/settings/tokens).
2. Create a new access token.
3. Give it a name that identifies this integration, so you can revoke it later without affecting your other keys.
4. Confirm, then copy the value. It is only shown once.

<Tip>Keep your access token secret. Anyone holding it can call the Hugging Face API and spend your account's credits.</Tip>

#### Step 2: Authorize in Nango

1. Open the Nango Connect form.
2. Enter your **API Key** in the field provided.
3. Submit the form, and you should be successfully authenticated.

You are now connected to Hugging Face.
