## Overview

To authenticate with Airtop, you need:

1. **API Key** — an API key from the Airtop Developer Portal.

This guide will show you how to get it.

### Prerequisites

- An Airtop account. You can create a free account the first time you log in to the [Airtop Developer Portal](https://portal.airtop.ai).

### Step 1: Create an API key

1. Sign in to the [Airtop Developer Portal](https://portal.airtop.ai) and open the [API Keys page](https://portal.airtop.ai/api-keys).
2. Create an API key and copy it.

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Airtop.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/airtop/form.png" alt="Airtop Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Airtop.
