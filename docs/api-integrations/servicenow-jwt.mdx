## Quickstart

<Steps>
    <Step title="Create the integration">
        In the Nango dashboard, open the **Integrations** tab, select **Configure new integration**, and choose **ServiceNow (JWT)**.
    </Step>
    <Step title="Connect your ServiceNow account">
        Open the **Connections** tab and select **Add test connection**. Enter your ServiceNow domain, client ID, client secret, key ID, private key, and user identifier. Follow the [connection guide](/api-integrations/servicenow-jwt/connect) to create these credentials.
    </Step>
    <Step title="Call the ServiceNow API">
        Send a request to the ServiceNow Table API with your Nango API key, integration ID, and connection ID:

        ```bash
        curl "https://api.nango.dev/proxy/api/now/table/incident?sysparm_limit=5" \
          -H "Authorization: Bearer <NANGO-API-KEY>" \
          -H "Provider-Config-Key: <INTEGRATION-ID>" \
          -H "Connection-Id: <CONNECTION-ID>"
        ```

        ServiceNow evaluates the request using the permissions of the configured user.
    </Step>
</Steps>
