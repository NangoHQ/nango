## Overview

To authenticate with bunny.net, you need:

1. **API Key** — your bunny.net account-level API key.

This guide will show you how to find it.

### Prerequisites

- A bunny.net account. If you don't have one, [sign up](https://dash.bunny.net/auth/register) for a free trial account.

### Step 1: Copy your API key

1. Sign in to the [bunny.net dashboard](https://dash.bunny.net/auth/login).
2. Open the account menu (your avatar at the top left) and click **API key**. You can also go straight to [Account > API key](https://dash.bunny.net/account/api-key).

<img src="/api-integrations/bunnycdn/account_menu_api_key.png" alt="bunny.net account menu with the API key item highlighted"/>

3. Click the eye icon to reveal the key, or the copy icon to copy it to your clipboard.

<img src="/api-integrations/bunnycdn/api_key_page_copy.png" alt="bunny.net Account API key page with the reveal, copy and regenerate icons"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with bunny.net.
2. Paste your key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/bunnycdn/form.png" alt="bunny.net Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to bunny.net.
