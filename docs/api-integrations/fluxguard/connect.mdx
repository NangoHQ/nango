## Overview

To authenticate with Fluxguard, you need:

1. **API Key** — an API key of your Fluxguard team.

This guide will show you how to generate one.

### Prerequisites

- A Fluxguard account. If you don't have one, [sign up](https://app.fluxguard.com/signup).

### Step 1: Generate an API key

1. Sign in to [Fluxguard](https://app.fluxguard.com).
2. Click your email in the top bar to open your account settings, then select the **Team Settings** tab.
3. Expand the **API Keys** section with the chevron on its right.

<img src="/api-integrations/fluxguard/team_settings_api_keys.png" alt="Fluxguard Team Settings tab with the API Keys section and its expand chevron"/>

4. Click **Generate new API key**.

<img src="/api-integrations/fluxguard/generate_api_key.png" alt="Expanded Fluxguard API Keys section with the Generate new API key button"/>

5. Copy the key from the **New API key** dialog, then click **Close**. Fluxguard shows the key only once; if you lose it, generate a new one.

<img src="/api-integrations/fluxguard/api_key_created.png" alt="Fluxguard New API key dialog showing the key to copy"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Fluxguard.
2. Enter your API key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/fluxguard/form.png" alt="Fluxguard Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Fluxguard.
