## Overview

To authenticate with ExchangeRate-API, you need:

1. **API Key** — the API key from your ExchangeRate-API dashboard.

This guide will show you how to get it.

### Prerequisites

- An ExchangeRate-API account. The Free plan works and needs no credit card.
- The Enriched Data and Historical Data endpoints need a Pro, Business or Volume plan.

### Step 1: Copy your API key

1. [Sign up](https://app.exchangerate-api.com/sign-up) with your email address and a password.
2. Open the confirmation link in the **Confirm Email Address** email from ExchangeRate-API. Your API key is active once your email is confirmed.
3. Sign in to the [ExchangeRate-API dashboard](https://app.exchangerate-api.com/dashboard) and copy the key shown under **API Access** -> **Your API Key**.

<img src="/api-integrations/exchangerate-api/dashboard_api_key.png" alt="ExchangeRate-API dashboard with the Your API Key field under API Access"/>

4. Optional: open **API Keys** to label the key with **Edit Label**, or click **Add New API Key** to create a separate key for this connection.

<img src="/api-integrations/exchangerate-api/manage_api_keys.png" alt="ExchangeRate-API Manage API Keys page with the Edit Label link and the Add New API Key button"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with ExchangeRate-API.
2. Paste the key you copied in Step 1 into the **API Key** field.
3. Submit the form. Nango checks the key with ExchangeRate-API and saves the connection.

<img src="/api-integrations/exchangerate-api/form.png" alt="ExchangeRate-API Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to ExchangeRate-API.
