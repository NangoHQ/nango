## Overview

To authenticate with Finlight, you need:

1. **API Key** — a key you create in the API Keys section of the finlight dashboard.

This guide will show you how to get it.

### Prerequisites

- A finlight account. You can [sign up for a free account](https://app.finlight.me) with your email or Google.

### Step 1: Create an API key

1. Sign in to the [finlight dashboard](https://app.finlight.me) and click **API Keys** in the sidebar.

<img src="/api-integrations/finlight/api_keys_nav.png" alt="finlight dashboard sidebar with API Keys highlighted" />

2. Enter a name for the key (for example, the name of your app), then click **Create API key**.

<img src="/api-integrations/finlight/create_api_key.png" alt="finlight API Key Management page with a key name entered and the Create API key button highlighted" />

3. In the new key's row, click **Copy** to copy the API key. It starts with `sk_`.

<img src="/api-integrations/finlight/copy_api_key.png" alt="finlight API Key Management page with the Copy button of the new key highlighted" />

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Finlight.
2. Enter your API key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/finlight/form.png" alt="Finlight Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Finlight.
