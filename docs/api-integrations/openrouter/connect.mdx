## Overview

To connect with OpenRouter, you need:

1. **API Key** – An OpenRouter API key, sent as a Bearer token.

This guide walks you through creating one.

### Prerequisites

- An [OpenRouter](https://openrouter.ai) account.

### Instructions

#### Step 1: Create an API key

1. Log in to [OpenRouter](https://openrouter.ai) and open [Settings -> API Keys](https://openrouter.ai/settings/keys).
2. Create a new key.
3. Give the key a name and, optionally, a credit limit. A credit limit caps how much the key can spend, which is a good safeguard for keys used by an integration.
4. Confirm, then copy the key. It starts with `sk-or-v1-` and is only shown once.

<Tip>Keep your API key secret. It can spend the credits of your OpenRouter account up to the key's limit.</Tip>

#### Step 2: Authorize in Nango

1. Open the Nango Connect form.
2. Enter your **API Key** in the field provided.
3. Submit the form, and you should be successfully authenticated.

You are now connected to OpenRouter.
