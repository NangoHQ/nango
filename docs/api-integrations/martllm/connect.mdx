## Overview

To authenticate with MartLLM, you need:

1. **API Key** - A MartLLM API key that lets Nango call the MartLLM API on behalf of your account.

This guide will show you how to get one.

### Prerequisites

- A MartLLM account. [Sign up](https://martllm.com/signup) with your email (a 6-digit code) or with Google.

### Step 1: Copy your API key

1. After you sign up, your first API key is shown at the top of the dashboard under **Your API key is ready**. Click **Copy** before you press **I've copied it**: the key is never shown again.

<img src="/api-integrations/martllm/first_key_dashboard.png" alt="Your API key is ready box with the Copy button on the MartLLM dashboard"/>

2. To create another key, open **API Keys** in the dashboard ([keys page](https://martllm.com/dashboard/keys)) and click **Create key**.

<img src="/api-integrations/martllm/api_keys_page.png" alt="Create key button on the MartLLM API Keys page"/>

3. Enter a **Name** for the key (for example, `nango`). Spend and rate limits under **More options** are optional. Click **Create key**.

<img src="/api-integrations/martllm/create_key_dialog.png" alt="Create API key dialog in MartLLM with a name entered"/>

4. In the **Copy your API key** dialog, click **Copy**, then **I've saved it**. The key starts with `ull_` and is shown only once.

<img src="/api-integrations/martllm/copy_api_key.png" alt="Copy your API key dialog in MartLLM"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with MartLLM.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/martllm/form.png" alt="MartLLM connection form in Nango's Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to MartLLM.
