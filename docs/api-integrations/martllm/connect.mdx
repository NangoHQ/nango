## Overview

To authenticate with MartLLM, you need:

1. **API Key** — a MartLLM API key.

This guide will show you how to get it.

### Prerequisites

- A MartLLM account. You can [sign up](https://martllm.com/signup) with your email or with Google.
- Credit on your account. Accounts are prepaid and start at $0; add credit from **Dashboard** -> **Credits**. See [Pricing](https://martllm.com/docs/pricing).

### Step 1: Create an API key

1. Log in to [MartLLM](https://martllm.com/dashboard). Your first key is created for you and shown at the top of the dashboard.
2. To create another key, open **Dashboard** -> **API keys** and click **Create key**.
3. Copy the key. It starts with `ull_` and is shown only once.

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with MartLLM.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

You are now connected to MartLLM.
