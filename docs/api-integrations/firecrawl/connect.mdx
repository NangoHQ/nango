## Overview

To authenticate with Firecrawl, you will need:
1. **API Key** - A key generated from the API Keys page of your Firecrawl dashboard.

This guide will walk you through finding or generating your **API Key** within Firecrawl.

### Prerequisites:

- You must have a Firecrawl account. Sign up at [firecrawl.dev](https://www.firecrawl.dev/signin?utm_source=nango&utm_medium=integration&redirect=%2Fapp%2Fapi-keys).

#### Step 1: Generating your Firecrawl API key

1. Log in to the [Firecrawl dashboard](https://www.firecrawl.dev/signin?utm_source=nango&utm_medium=integration&redirect=%2Fapp%2Fapi-keys).
2. Navigate to **API Keys**.
3. Copy an existing key, or click **Create API Key** to generate a new one.
4. New API keys start with `fc-`. Older keys in UUID format also work.

#### Step 2: Enter credentials in the Connect UI

1. Open the form where you need to authenticate with Firecrawl.
2. Enter your **API Key**.
3. Submit the form.

<img src="/api-integrations/firecrawl/form.png" style={{maxWidth: "450px" }}/>

You are now connected to Firecrawl.
