## 🚀 Quickstart

Connect to BatchData with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _BatchData_.
    </Step>
    <Step id="authorize-batchdata" title="Authorize BatchData">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your BatchData API token. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-batchdata-api" title="Call the BatchData API">
    Let's make your first request to the BatchData API: get your wallet balance. The token needs the `wallet-balance` permission. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/api/v1/wallet/balance" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/api/v1/wallet/balance',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- BatchData's MCP server is on `https://mcp.batchdata.com` and takes the same API token: send MCP requests through this connection with `baseUrlOverride` set to `https://mcp.batchdata.com`, and Nango keeps the connection's credentials and headers. See [BatchData MCP Server - Developer Integration Guide](https://help.batchdata.io/en/articles/12860581-batchdata-mcp-server-developer-integration-guide).
