## Overview

To authenticate with Addressfinder, you need:

1. **API Key** — the public key of your Addressfinder project.
2. **API Secret** — the secret paired with that key.

This guide will show you how to find them.

### Prerequisites

- An Addressfinder account. If you don't have one, [sign up for the 30-day trial](https://portal.addressfinder.net/signup/au/au_business_trial). No credit card is required.

### Step 1: Open the Keys page

Log in to the [Addressfinder Portal](https://portal.addressfinder.net) and click **Keys** in the left sidebar, under your project.

<img src="/api-integrations/addressfinder/portal_keys_menu.png" alt="Addressfinder Portal dashboard with Keys highlighted in the left sidebar"/>

### Step 2: Copy your key and secret

On the **Credentials** page, open the **API keys** tab. Your project already has a key and secret pair.

1. Copy the value in the **Key** column. This is your API key.
2. Click **Show secret**, then copy the value in the **Secret** column. This is your API secret.

<img src="/api-integrations/addressfinder/api_key_and_secret.png" alt="Addressfinder Credentials page with the Key column and the copy button for the Secret"/>

### Step 3: Enter your key and secret in the Connect UI

1. Open the form where you need to authenticate with Addressfinder.
2. Enter your key in the **API Key** field and your secret in the **API Secret** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/addressfinder/form.png" alt="Addressfinder Connect UI form with the API Key and API Secret fields" style={{maxWidth: "450px" }}/>

You are now connected to Addressfinder.
