## Overview

To authenticate with Curated, you need:

1. **Account API Key** — the API key of your Curated account.

This guide will show you how to find it.

### Prerequisites

- A Curated account. You can [sign up](https://my.curated.co/signup) for free.

### Step 1: Copy your Account API key

1. [Log in](https://my.curated.co/login) to Curated.
2. Click your account avatar in the top-right corner and select **Account**.

<img src="/api-integrations/curated/account_menu.png" alt="Curated account menu with the Account option highlighted"/>

3. On the [Account page](https://my.curated.co/account), copy the value shown under **Account API key**. This key gives access to your entire Curated account.

<img src="/api-integrations/curated/account_api_key.png" alt="Curated Account page with the Account API key field highlighted"/>

### Step 2: Enter your Account API key in the Connect UI

1. Open the form where you need to authenticate with Curated.
2. Enter your **Account API Key** in the designated field.
3. Click **Connect**.

<img src="/api-integrations/curated/form.png" alt="Nango Connect UI form for entering the Curated Account API Key" style={{maxWidth: "450px" }}/>

You are now connected to Curated.
