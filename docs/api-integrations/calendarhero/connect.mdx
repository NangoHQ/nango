## Overview

To authenticate with CalendarHero, you need:

1. **API Token** — the API token from your CalendarHero user settings.

This guide will show you how to find it.

### Prerequisites

- A CalendarHero account. If you don't have one, [sign up](https://app.calendarhero.com/register) for the free 14-day trial. No credit card is required.

### Step 1: Copy your API token

1. Sign in to [CalendarHero](https://app.calendarhero.com/).
2. Click **My Account**, then open the **API** tab of your [user settings](https://app.calendarhero.com/settings/user#API).

<img src="/api-integrations/calendarhero/user_settings_api_tab.png" alt="CalendarHero user settings with the API tab selected" />

3. Click the copy button next to the **API Token** field to copy your token.

<img src="/api-integrations/calendarhero/api_token_copy.png" alt="CalendarHero API tab with the copy button next to the API Token field" />

### Step 2: Enter your API token in the Connect UI

1. Open the form where you need to authenticate with CalendarHero.
2. Enter your API token in the **API Token** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/calendarhero/form.png" alt="CalendarHero Connect UI form with the API Token field" style={{maxWidth: "450px" }}/>

You are now connected to CalendarHero.
