## Overview

To authenticate with ClickMeeting, you need:

1. **API Key** - a ClickMeeting API key.

This guide shows you how to generate one.

### Prerequisites

- A ClickMeeting account on the Standard plan or higher. API access comes with the Standard plan, so you can't create an API key on the free trial.

### Step 1: Generate an API key

1. Sign in to your [ClickMeeting account](https://account-panel.clickmeeting.com/).
2. Hover over your profile picture in the top right corner and open **Account settings**.
3. Open the [**API** tab](https://account-panel.clickmeeting.com/account/details#api).
4. Click **Add new**, enter a name for the API key, for example `Nango`, and click **Save**.
5. Copy the API key straight away. ClickMeeting doesn't show it again after you leave or refresh the page.

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with ClickMeeting.
2. Enter your **API Key** in the designated field.
3. Click **Connect**. Nango checks the key with ClickMeeting before saving the connection.

You are now connected to ClickMeeting.
