## Overview

To authenticate with Shipday, you need:

1. **API Key** — the API key of your Shipday account, from the Shipday Dispatch dashboard.

This guide will show you how to find it.

### Prerequisites

- A Shipday account. If you don't have one, [sign up](https://dispatch.shipday.com/signUp). You can try the full platform free for 14 days with no credit card required.

### Step 1: Copy your API key

1. Sign in to the [Shipday Dispatch dashboard](https://dispatch.shipday.com/).
2. Open your account menu (your avatar, top right) and choose **Account Details**, or go straight to [Account Info](https://dispatch.shipday.com/dashboard#accountInfo).
3. On the **Account** tab, find the **Api Key** row in the **Profile** section and click **Show**. Shipday may ask for your account password first.

<img src="/api-integrations/shipday/account_info_api_key.png" alt="Shipday Account Details page with the Show button next to Api Key in the Profile section"/>

4. In the **Your api key** dialog, click **Copy** to copy the key.

<img src="/api-integrations/shipday/api_key_copy.png" alt="Shipday Your api key dialog with the Copy button"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Shipday.
2. Enter your API key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/shipday/form.png" alt="Shipday Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Shipday.
