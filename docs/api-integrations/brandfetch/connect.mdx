## Overview

To authenticate with Brandfetch, you need:

1. **API Key** — a Brandfetch API key.

This guide will show you how to get it.

### Prerequisites

- A Brandfetch developer account. You can [sign up for free](https://developers.brandfetch.com/register) without a credit card.

### Step 1: Create an API key

1. Sign in to the [Brandfetch Developer Dashboard](https://developers.brandfetch.com) and open **Keys & MCP** in the left sidebar.
2. In the **API Keys** section, click **Add API key**. You can also use the **Starter Key** created for you at signup.

<img src="/api-integrations/brandfetch/keys_page_add_api_key.png" alt="Brandfetch Keys & MCP page with the Add API key button"/>

3. Enter a name and an optional description, then click **Create**.

<img src="/api-integrations/brandfetch/create_api_key_dialog.png" alt="Brandfetch dialog to name and create a new API key"/>

4. Click the copy icon next to your new key in the **API key** column.

<img src="/api-integrations/brandfetch/copy_api_key.png" alt="Copy icon next to the new API key on the Brandfetch Keys & MCP page"/>

<Note>
Copy the key from the **API Keys** section, not the client ID or the MCP token.
</Note>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Brandfetch.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/brandfetch/form.png" alt="Nango Connect UI form for Brandfetch" style={{maxWidth: "450px" }}/>

You are now connected to Brandfetch.
