## Overview

To authenticate with Ambee, you need:

1. **API Key** — the API key of your Ambee account.

This guide will show you how to get it.

### Prerequisites

- An Ambee account. If you don't have one, sign up for free on the [Ambee API Dashboard](https://api-dashboard.getambee.com) with your Google or business account.

### Step 1: Copy your API key

1. Sign in to the [Ambee API Dashboard](https://api-dashboard.getambee.com).
2. On the dashboard home page, find the **API key** card and click **Copy**.

<img src="/api-integrations/ambee/api_key_dashboard.png" alt="Ambee API Dashboard home page with the API key card and its Copy button"/>

<Note>
You can reset the API key once every 30 days from the API Dashboard, using your registered email address.
</Note>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Ambee.
2. Enter your API key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/ambee/form.png" alt="Ambee Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Ambee.
