## 🚀 Quickstart

Connect to Mailboxlayer with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Mailboxlayer_.
    </Step>
    <Step id="authorize-mailboxlayer" title="Authorize Mailboxlayer">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your Mailboxlayer API Access Key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-mailboxlayer-api" title="Call the Mailboxlayer API">
    Let's make your first request to the Mailboxlayer API to verify an email address. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/check?email=support@apilayer.com" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/check',
            params: { email: 'support@apilayer.com' },
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>
