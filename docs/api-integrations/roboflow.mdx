## 🚀 Quickstart

Connect to Roboflow with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Roboflow_.
    </Step>
    <Step id="authorize-roboflow" title="Authorize Roboflow">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your private API key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-roboflow-api" title="Call the Roboflow API">
    Let's make your first request to the Roboflow API to get the workspace your key belongs to. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- Hosted inference (running a model or workflow on an image or video) is on `https://serverless.roboflow.com`: set `baseUrlOverride` to that host, and Nango keeps the connection's credentials and headers. See [REST API](https://docs.roboflow.com/reference/platform/rest-api).
- Dedicated Deployments are managed on `https://roboflow.cloud`: set `baseUrlOverride` to that host, and Nango keeps the connection's credentials and headers. See [REST API](https://docs.roboflow.com/reference/platform/rest-api).
- Nango sends the key in the `authorization: Bearer` header on every call. Calls that need it another way (the legacy `api_key` query parameter or `api_key` body field) can read it from the connection's credentials (`credentials.apiKey`) and pass it as the docs show.
