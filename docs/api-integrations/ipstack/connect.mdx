## Overview

To authenticate with ipstack, you need:

1. **API Access Key** — the personal API Access Key from your ipstack dashboard.

This guide will show you how to get it.

### Prerequisites

- An ipstack account. If you don't have one, [sign up for the Free plan](https://dashboard.ipstack.com/signup/free/monthly): no credit card is required.

### Step 1: Copy your API Access Key

1. [Log in](https://dashboard.ipstack.com/login) to ipstack and open the [Dashboard](https://dashboard.ipstack.com/dashboard). Your API Access Key is available there as soon as you sign up.
2. Under **Your API Key**, click the copy icon to copy your key.

<img src="/api-integrations/ipstack/dashboard_api_key.png" alt="ipstack Dashboard with the copy icon next to the API Access Key under Your API Key"/>

You can generate a new key at any time with **Reset Key**.

### Step 2: Enter your API Access Key in the Connect UI

1. Open the form where you need to authenticate with ipstack.
2. Paste the key you copied in Step 1 into the **API Access Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/ipstack/form.png" alt="ipstack connection form in the Nango Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to ipstack.
