## Overview

To authenticate with Detrack, you need:

1. **API Key** — your Detrack API key.

This guide will show you how to find it.

### Prerequisites

- A Detrack account. You can [sign up](https://app.detrack.com/signup) for a 14-day free trial with no credit card required.

### Step 1: Copy your API key

1. Sign in to the [Detrack dashboard](https://app.detrack.com/sessions/new).
2. Click **Integrations** in the left sidebar, then open the **API Key** tab.

<img src="/api-integrations/detrack/integrations_api_key_tab.png" alt="Detrack Integrations page with the API Key tab highlighted"/>

3. If no key is shown, click **Regenerate API Key** to create one. Then click the **API Key** field (copy icon) to copy your key exactly as shown, with no extra spaces.

<img src="/api-integrations/detrack/api_key_created.png" alt="Detrack API Key tab with the API Key field and its copy icon highlighted"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Detrack.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/detrack/form.png" alt="Detrack connection form in the Nango Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to Detrack.
