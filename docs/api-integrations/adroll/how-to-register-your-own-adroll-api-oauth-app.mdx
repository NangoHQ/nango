This guide shows you how to register your own app with AdRoll to obtain your OAuth credentials (client id & secret). These are required to let your users grant your app access to their AdRoll account.

<Steps>
  <Step title="Create a developer account">
    Go to the [AdRoll Developer Portal](https://developers.adroll.com/) and create a developer account.
  </Step>
  <Step title="Create a new application">
    1. Go to **My Apps** and click **Add New App**
    2. Give your application a meaningful name — users will see it on the OAuth consent page
    3. It is recommended to create separate apps for production and testing so each environment has its own redirect URI
  </Step>
  <Step title="Configure OAuth settings">
    1. In your app settings, add the Nango callback URL as a redirect URI:

    ```
    https://api.nango.dev/oauth/callback
    ```

    2. Copy your **Client ID** (consumer key) and **Client Secret** (consumer secret)
    3. In Nango, create an AdRoll integration and paste those credentials. Nango requests the `all` scope by default (AdRoll's required OAuth scope).
  </Step>
  <Step title="Next">
    Follow the [_Quickstart_](/getting-started/quickstart) to connect your first account.
  </Step>
</Steps>

For more details, see [AdRoll's OAuth documentation](https://apidocs.nextroll.com/guides/oauth.html).
