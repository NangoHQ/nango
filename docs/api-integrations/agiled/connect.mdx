## Overview

To authenticate with Agiled, you need:

1. **API Key** — an API key from your Agiled workspace.

This guide will show you how to create it.

### Prerequisites

- An Agiled account. [Sign up](https://my.agiled.ai/register) without a card: every new business starts with a free 14-day trial of the Business plan.

### Step 1: Create an API key

1. Sign in to [Agiled](https://my.agiled.app/login) and open **Settings**.
2. In the left settings menu, under **Integrations**, click **API**.

<img src="/api-integrations/agiled/settings_api_nav.png" alt="Agiled Settings page with API highlighted under Integrations in the left menu"/>

3. In the **API Keys** section, enter a **Name** that identifies where the key is used.
4. Choose a **Preset**: **Read Only** or **Full access**.
5. Click **Create key**.

<img src="/api-integrations/agiled/create_api_key.png" alt="Agiled API Keys section with a key name entered, the Read Only preset selected and the Create key button highlighted"/>

6. Click the copy button next to the token and store it safely. Agiled shows the token only once.

<img src="/api-integrations/agiled/api_key_created.png" alt="Agiled API Keys section after creating a key, with the copy button next to the new token highlighted"/>

Agiled API keys expire after 90 days. Create a new key and reconnect before then.

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Agiled.
2. Enter your API key in the **API Key** field.
3. Submit the form. Nango checks the key with Agiled before saving the connection.

<img src="/api-integrations/agiled/form.png" alt="Agiled Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Agiled.
