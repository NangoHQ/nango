## Overview

To authenticate with Tavily, you need:

1. **API Key** — a key from your Tavily dashboard.

This guide will show you how to get it.

### Prerequisites

- A Tavily account. You can sign up for free at [app.tavily.com](https://app.tavily.com).

### Step 1: Create an API key

1. Sign in to the [Tavily Platform](https://app.tavily.com). New accounts land on the **Overview** page.
2. Scroll to the **API Keys** card and click the **+** button next to the heading.

<img src="/api-integrations/tavily/api_keys_create_button.png" alt="The + button next to the API Keys heading on the Tavily Overview page"/>

3. Enter a **Key Name**, choose a **Key Type**, then click **Create**. On the free plan, **Development** is the only key type available.

<img src="/api-integrations/tavily/create_api_key_dialog.png" alt="The Create a new API key dialog in Tavily with Development selected as the key type" style={{maxWidth: "450px" }}/>

4. The new key shows up in the **API Keys** table. Click the copy icon in its row to copy the key. Keys start with `tvly-`.

<img src="/api-integrations/tavily/copy_api_key.png" alt="The copy icon next to a key in the Tavily API Keys table"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Tavily.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/tavily/form.png" alt="The Tavily connection form in the Nango Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to Tavily.
