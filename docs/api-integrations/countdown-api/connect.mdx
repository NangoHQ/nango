## Overview

To authenticate with Countdown API, you need:

1. **API Key** — the API key of your Countdown API account.

This guide will show you how to get it.

### Prerequisites

- A Countdown API account. You can [sign up](https://app.countdownapi.com/signup) for free: the free trial gives you 100 requests and no credit card is required.

### Step 1: Copy your API key

1. Log in to the [Countdown API dashboard](https://app.countdownapi.com/). You land on the **API Playground**.
2. Your **API Key** is shown at the top right of every dashboard page. Click the copy icon next to it.

<img src="/api-integrations/countdown-api/api_key_copy.png" alt="Countdown API Playground with the copy icon next to the API Key at the top right highlighted"/>

You can also find the key under **Account** -> **Plan & Payment**. Click the copy icon next to **API Key**. Each account has one API key; **Change API Key** on this page replaces it with a new one.

<img src="/api-integrations/countdown-api/account_plan_api_key.png" alt="Countdown API Account Plan & Payment page with the copy icon next to the API Key highlighted"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Countdown API.
2. Paste your key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/countdown-api/form.png" alt="Countdown API Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Countdown API.
