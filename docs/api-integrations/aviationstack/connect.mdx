## Overview

To authenticate with Aviationstack, you need:

1. **API Access Key** — the key shown in your Aviationstack dashboard.

This guide will show you how to get it.

### Prerequisites

- An Aviationstack account. You can [sign up for free](https://aviationstack.com/signup/free): the Free plan includes 100 requests per month and needs no credit card.

### Step 1: Copy your API Access Key

1. [Log in to Aviationstack](https://aviationstack.com/login) and open the **Dashboard** tab.
2. Under **Your API Key**, click the copy icon to copy your API Access Key. Each account has one key.

<img src="/api-integrations/aviationstack/dashboard_api_access_key.png" alt="Aviationstack dashboard showing the Your API Key card with the copy icon and Reset Key link"/>

To rotate the key, click **Reset Key** on the same card, then update your connection with the new key.

### Step 2: Enter your API Access Key in the Connect UI

1. Open the form where you need to authenticate with Aviationstack.
2. Paste the key you copied in Step 1 into the **API Access Key** field.
3. Submit the form. Nango checks the key with Aviationstack before saving the connection.

<img src="/api-integrations/aviationstack/form.png" alt="Aviationstack Connect UI form with the API Access Key field" style={{maxWidth: "450px" }}/>

You are now connected to Aviationstack.
