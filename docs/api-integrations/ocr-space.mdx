## 🚀 Quickstart

Connect to OCR.space with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _OCR.space_.
    </Step>
    <Step id="authorize-ocr-space" title="Authorize OCR.space">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your OCR.space API key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-ocr-space-api" title="Call the OCR.space API">
    Let's make your first request to the OCR.space API: extract the text of a sample image. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/parse/imageurl?url=https://dl.a9t9.com/ocr/solarcell.jpg" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/parse/imageurl?url=https://dl.a9t9.com/ocr/solarcell.jpg',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- Nango does not check the API key when a connection is created, so a wrong or revoked key still connects and fails on its first call.
- Nango sends the key in the `apikey` header on every call. Calls that need it another way (the `apikey` form field of `POST /parse/image` or the `apikey` query parameter of `GET /parse/imageurl`) can read it from the connection's credentials (`credentials.apiKey`) and pass it as the docs show.
