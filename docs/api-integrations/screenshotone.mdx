## 🚀 Quickstart

Connect to ScreenshotOne with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _ScreenshotOne_.
    </Step>
    <Step id="authorize-screenshotone" title="Authorize ScreenshotOne">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your ScreenshotOne access key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-screenshotone-api" title="Call the ScreenshotOne API">
    Let's make your first request to the ScreenshotOne API to get your organization's usage. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/usage" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/usage',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- Nango sends the access key in the `X-Access-Key` header on every call. Calls that need it another way (the `access_key` query parameter or POST body field, or a bearer token) can read it from the connection's credentials (`credentials.apiKey`) and pass it as the docs show.
