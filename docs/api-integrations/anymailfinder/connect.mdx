## Overview

To authenticate with Anymail Finder, you need:
1. **API key** — A key that grants Nango permission to interact with the Anymail Finder API on behalf of your account.

This guide will walk you through finding your API key in Anymail Finder.

### Prerequisites

- An Anymail Finder account. New accounts start with free credits, so no plan is needed to test the connection.

### Step 1: Find your API key

1. Log in to your [Anymail Finder](https://app.anymailfinder.com) account.
2. Go to **Settings**, then **API**, or open [app.anymailfinder.com/settings/api](https://app.anymailfinder.com/settings/api) directly.
3. Copy your **API key**. You can regenerate it from the same page if it is ever exposed.

### Step 2: Enter credentials in the Connect UI

Once you have your API key:
1. Open the form where you need to authenticate with Anymail Finder.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

You are now connected to Anymail Finder.
