## Overview

To authenticate with Amara, you need:

1. **API Key** — the personal API key from your Amara Account page.

This guide will show you how to get it.

### Prerequisites

- An Amara account. You can [sign up for free](https://amara.org/auth/sign_up/).

### Step 1: Generate your API key

1. Log in to [Amara](https://amara.org/auth/login/), click your username in the top-right, then click **Account**.
2. In the **API Access** section, click **Get an API key**.

<img src="/api-integrations/amara/account_page_api_access.png" alt="Amara Account page with the Get an API key button highlighted in the API Access section"/>

3. The key appears in the **API Key** field of the **API Access** section. Double-click the field to select the key, then copy it.

<img src="/api-integrations/amara/api_key_created.png" alt="Amara Account page showing the API Key field in the API Access section after the key was created"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Amara.
2. Enter your key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/amara/form.png" alt="Amara Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Amara.
