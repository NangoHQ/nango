## Overview

To authenticate with NeuralVerge, you need:
1. **API key** - A key that grants Nango permission to call the NeuralVerge API on your behalf.

This guide walks you through generating your API key in NeuralVerge.

### Prerequisites

- A NeuralVerge account. You can sign up at [app.neuralverge.ai](https://app.neuralverge.ai).

### Instructions

#### Step 1: Generate your API key

1. Log in to your [NeuralVerge](https://app.neuralverge.ai) account.
2. Go to **Settings** -> **API**.
3. Create a new API key, or copy an existing one. Keys start with `sk_`.
4. Store the key securely. Treat it like a password.

#### Step 2: Enter credentials in the Connect UI

Once you have your API key:
1. Open the form where you need to authenticate with NeuralVerge.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

You are now connected to NeuralVerge.
