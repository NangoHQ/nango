## Overview

To authenticate with CoinMarketCap, you need:

1. **API Key** — a CoinMarketCap API key.

This guide will show you how to get it.

### Prerequisites

- A CoinMarketCap Developer Portal account. The free Basic plan includes API access; [sign up here](https://pro.coinmarketcap.com/signup).

### Step 1: Copy your API key

1. Sign in to CoinMarketCap and open the [API dashboard](https://coinmarketcap.com/api/dashboard/).
2. In the left sidebar, click **API Keys**. The free Basic plan comes with one key, labeled **Default**.
3. Click **Show** next to the key.

<img src="/api-integrations/coinmarketcap/api_keys_page.png" alt="CoinMarketCap API Keys page with the Show button highlighted on the Default key"/>

4. In the **Show API Key** dialog, click the copy icon to copy the key.

<img src="/api-integrations/coinmarketcap/show_api_key_dialog.png" alt="CoinMarketCap Show API Key dialog with the copy icon highlighted"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with CoinMarketCap.
2. Enter your **API Key** in the designated field.
3. Click **Connect**.

<img src="/api-integrations/coinmarketcap/form.png" alt="Nango Connect UI form for entering the CoinMarketCap API key" style={{maxWidth: "450px" }}/>

You are now connected to CoinMarketCap.
