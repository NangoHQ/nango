## 🚀 Quickstart

Connect to NASA with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _NASA_.
    </Step>
    <Step id="authorize-nasa" title="Authorize NASA">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your api.nasa.gov API key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-nasa-api" title="Call the NASA API">
    Let's make your first request to the NASA API: browse near-Earth asteroids with the Asteroids NeoWs API. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/neo/rest/v1/neo/browse" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/neo/rest/v1/neo/browse',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- Nango sends the key in the `x-api-key` header on every call. Calls that need it another way (the `api_key` query parameter, or HTTP Basic auth with the key as the username and an empty password) can read it from the connection's credentials (`credentials.apiKey`) and pass it as the docs show.
