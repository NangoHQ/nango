## Overview

To authenticate with BrowserAct, you need:

1. **API Key** — a BrowserAct API key.

This guide will show you how to create it.

### Prerequisites

- A BrowserAct account. You can [start on the Free plan](https://www.browseract.com/pricing); it includes API access.

### Step 1: Create an API key

1. [Log in](https://www.browseract.com/reception) to the BrowserAct dashboard and open **API & Integrations** in the left sidebar.
2. Under **API Keys** > **Personal APIs**, click **Create New API Key**.

<img src="/api-integrations/browseract/api_integrations_page.png" alt="BrowserAct API & Integrations page with the Create New API Key button under Personal APIs"/>

3. Enter a name that says where the key will be used, choose a **CLI Action Confirmation** mode (**Confirmation Required** is the safer choice), then click **Confirm**.

<img src="/api-integrations/browseract/create_api_key_dialog.png" alt="BrowserAct API Key dialog with the name field, the CLI Action Confirmation options and the Confirm button"/>

4. The new key appears in the **Personal APIs** list. Click the copy icon in the **Actions** column to copy the API key.

<img src="/api-integrations/browseract/api_key_created.png" alt="BrowserAct Personal APIs list showing the new key with the copy icon in the Actions column"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with BrowserAct.
2. Enter your **API Key** in the designated field.
3. Click **Connect**.

<img src="/api-integrations/browseract/form.png" alt="Nango Connect UI form for entering the BrowserAct API Key" style={{maxWidth: "450px" }}/>

You are now connected to BrowserAct.
