## Overview

To authenticate with Pocket, you need:

1. **API Key** — a personal API key (`pk_<secret>`) created in Pocket's developer settings. Requests made with it read the recordings of the Pocket user who created it.

This guide will walk you through obtaining your API key from Pocket.

### Prerequisites

- A Pocket account with recordings you want to sync. Each person connects their own key; organization API keys exist separately under Organization settings for workspace-wide access.

### Step 1: Obtaining your API key

1. Log in to the [Pocket web app](https://app.heypocketai.com) and open **Settings** -> **Developer**.
2. Create a new API key. Copy the full `pk_...` secret somewhere secure until you have pasted it into Nango.

<Note>
Treat this API key as a password: never put it in source code, URLs, logs, or client-side applications. Nango stores it encrypted and only uses it server-side to call the Pocket API on your behalf.
</Note>

### Step 2: Enter your API key in the Connect UI

Once you have your API key:

1. Open the form where you need to authenticate with Pocket.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

You are now connected to Pocket.
