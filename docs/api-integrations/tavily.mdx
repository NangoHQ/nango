## 🚀 Quickstart

Connect to Tavily with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Tavily_.
    </Step>
    <Step id="authorize-tavily" title="Authorize Tavily">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your Tavily API key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-tavily-api" title="Call the Tavily API">
    Let's make your first request to the Tavily API to get your API key and account usage. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/usage" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/usage',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-nango" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- The `/search`, `/extract`, `/crawl`, `/map` and `/research` endpoints are `POST` requests with JSON bodies, and they consume [API credits](https://docs.tavily.com/documentation/api-credits).
- Development keys are limited to 100 requests per minute and production keys to 1,000. Production keys need an active paid plan or pay-as-you-go. See [Rate limits](https://docs.tavily.com/documentation/rate-limits).
- The `/usage` endpoint has a separate limit of 10 requests per 10 minutes, so avoid polling it.
- To track usage by project, add the optional `X-Project-ID` header to your requests.
