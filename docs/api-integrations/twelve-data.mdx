## 🚀 Quickstart

Connect to Twelve Data with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Twelve Data_.
    </Step>
    <Step id="authorize-twelve-data" title="Authorize Twelve Data">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your Twelve Data API key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-twelve-data-api" title="Call the Twelve Data API">
    Let's make your first request to the Twelve Data API to get your API credit usage. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/api_usage" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/api_usage',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- Nango sends the key in the `Authorization: apikey <key>` header (the `apikey` scheme, not `Bearer`), the method the docs recommend. See [Authentication](https://twelvedata.com/docs/llms/introduction.md).
- Rate limits are API credits per minute, and credits reset every minute. Only the free Basic plan also has a daily cap (800 credits). See [Pricing](https://twelvedata.com/pricing.md).
- Every response carries the `api-credits-used` and `api-credits-left` headers. See [Control over API usage](https://support.twelvedata.com/en/articles/5713553-control-over-api-usage).
- `GET /api_usage` returns your credit usage and costs 1 credit. See [API usage](https://twelvedata.com/docs/llms/advanced/api-usage.md).
- The hosted MCP server (`https://mcp.twelvedata.com/mcp`) does not accept API keys; it uses OAuth. A Nango connection with an API key only calls the REST API. See [Authentication](https://twelvedata.com/auth.md).
