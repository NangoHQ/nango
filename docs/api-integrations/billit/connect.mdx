## Overview

To connect the Billit Access Point API in Nango, provide:

1. **Environment** — The Billit sandbox or production API host.
2. **Master Account Party ID** — The Registration ID of your Billit master account.
3. **API Key** — An API key belonging to a user with access to the master account.

### Prerequisites

- A Billit Access Point master account.
- A user with access to the master account.

### Step 1: Choose your environment

Billit keeps sandbox and production completely separate:

- **Sandbox** — `api.sandbox.billit.be`
- **Production** — `api.billit.be`

Create a [sandbox account](https://my.sandbox.billit.be/Account/Register) for testing. Credentials created in one environment do not work in the other.

### Step 2: Get your API key

1. Sign in to [Billit Sandbox](https://my.sandbox.billit.be) or [Billit Production](https://my.billit.be), matching the environment selected above.
2. Open **My profile** using the profile icon in the top-right corner, then find the **API** section.
3. Copy the API key for a user with access to the master account.

<img src="/api-integrations/billit/api-key.png" alt="Billit My profile page showing the masked API key in the API section" style={{maxWidth: "700px" }} />

The screenshot above is from Billit's [Access Point authentication guide](https://docs.accesspoint.billit.eu/docs/authentication).

Keep the API key secret. If it is exposed, renew it in Billit and update the Nango connection.

### Step 3: Find your master account Party ID

1. In MyBillit, select your **master account** company.
2. Open **My company**.
3. Copy the number between `/Manage/` and `/CompanyEdit` in the browser address bar. For example, in `https://my.sandbox.billit.be/Manage/123456/CompanyEdit`, the Party ID is `123456`. Use your own account's value, not this example.

<img src="/api-integrations/billit/party-id.png" alt="Billit My company page with the Party ID highlighted in the browser address bar" style={{maxWidth: "700px" }} />

This is the master account's Registration ID, sent as the **Party ID** in API request headers. The screenshot above is from Billit's [Party ID guide](https://docs.billit.be/docs/partyid-and-key).

<Warning>
Use the master account Registration ID, not the Registration ID of an entity or subaccount referenced in an API path. Billit requires the master account Party ID for every production API call and for KYC identification calls in both environments.
</Warning>

### Step 4: Connect Billit in Nango

1. Open the Nango Connect form.
2. Select the **Environment** matching your credentials.
3. Enter the **Master Account Party ID**.
4. Enter the **API Key**.
5. Submit the form.

<img src="/api-integrations/billit/form.png" alt="Nango Connect UI form with Environment, Master Account Party ID, and API Key fields for Billit" style={{maxWidth: "450px" }}/>

Nango verifies the connection by listing the entities linked to the master account.
