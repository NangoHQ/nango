## 🚀 Quickstart

Connect to Kintone (API Token) with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Kintone (API Token)_.
    </Step>
    <Step id="authorize-kintone-api-key" title="Authorize Kintone">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your Kintone subdomain, region and API token. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-kintone-api-key-api" title="Call the Kintone API">
    Let's make your first request to the Kintone API to list the REST APIs of your Kintone environment. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/k/v1/apis.json" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/k/v1/apis.json',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- Nango does not check the key when a connection is created, so a wrong or revoked key still connects and fails on its first call.
- To reach apps beyond those the API tokens cover, use the `kintone` integration, which connects with OAuth 2.0.
