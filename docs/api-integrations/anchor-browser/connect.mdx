## Overview

To authenticate with Anchor Browser, you need:

1. **API Key** — an API key from your Anchor dashboard.

This guide will show you how to get it.

### Prerequisites

- An Anchor Browser account. You can sign up for free at [app.anchorbrowser.io](https://app.anchorbrowser.io).

### Step 1: Create an API key

1. Sign in to the [Anchor dashboard](https://app.anchorbrowser.io).
2. In the left sidebar, under **Developer Tools**, click **API Keys**.

<img src="/api-integrations/anchor-browser/sidebar_api_keys.png" alt="Anchor dashboard sidebar with API Keys under Developer Tools"/>

3. Click **Create key** in the top-right corner, enter a name for the key, then click **Create key**.

<img src="/api-integrations/anchor-browser/create_api_key_dialog.png" alt="Create key dialog asking for a key name"/>

4. In the keys table, click the copy icon in the **Key** column next to your new key to copy it.

<img src="/api-integrations/anchor-browser/api_key_created.png" alt="API keys table with the copy icon next to the new key"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Anchor Browser.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/anchor-browser/form.png" alt="Anchor Browser Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Anchor Browser.
