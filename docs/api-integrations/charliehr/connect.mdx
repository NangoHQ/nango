## Overview

To authenticate with CharlieHR, you need:

1. **Client ID** and **Client Secret** — your CharlieHR API credentials.

This guide will show you how to get them.

### Prerequisites

- A CharlieHR admin account.

### Step 1: Get your API credentials

1. Log in to CharlieHR with your admin account.
2. From your dashboard, open the **Integrations** tab and go to **API Keys**.
3. Generate a new set of keys, then copy the **Client ID** and **Client Secret**.

<Note>
CharlieHR only shows your keys once, when you generate them. Save them somewhere secure before leaving the page.
</Note>


<img src="/api-integrations/charliehr/generate_api_key.png"/>


### Step 2: Enter your credentials in the Connect UI

1. Open the form where you need to authenticate with CharlieHR.
2. Enter your **Client ID** and **Client Secret** in the designated fields.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/charliehr/form.png" style={{maxWidth: "450px" }}/>

You are now connected to CharlieHR.
