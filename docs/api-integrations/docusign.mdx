## 🚀 Quickstart

Connect to DocuSign with Nango and see data flow in 2 minutes.

<Note>
Testing with a DocuSign developer account? Use the [DocuSign (Sandbox)](/api-integrations/docusign-sandbox) integration instead.
</Note>

<Steps>
    <Step title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to [Integrations](https://app.nango.dev/dev/integrations) -> _Configure New Integration_ -> _DocuSign_.

    DocuSign has no Nango-managed OAuth app. Follow the [setup guide](/api-integrations/docusign/how-to-register-your-own-docusign-oauth-app) to register your own and enter its integration key and secret.
    </Step>
    <Step title="Authorize DocuSign">
    Go to [Connections](https://app.nango.dev/dev/connections) -> _Add Test Connection_ -> _Authorize_, then log in to DocuSign. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step title="Call the DocuSign API">
    Let's make your first request to the DocuSign API to fetch the account. Nango saves the user's `accountId` and `baseUri` in the connection config. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), [integration ID](https://app.nango.dev/dev/integrations), [connection ID](https://app.nango.dev/dev/connections) and those two values:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/restapi/v2.1/accounts/<ACCOUNT-ID>" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>" \
              -H "Base-Url-Override: <BASE-URI>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/restapi/v2.1/accounts/<ACCOUNT-ID>',
            baseUrlOverride: '<BASE-URI>',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Production accounts live on regional hosts (such as `na2.docusign.net`), so send requests to the connection's `baseUri`.

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the [Logs](https://app.nango.dev/dev/logs) tab in Nango to inspect requests.
    </Step>

    <Step title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>
