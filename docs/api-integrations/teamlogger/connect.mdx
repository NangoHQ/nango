## Overview

To authenticate with TeamLogger, you need:
1. **API Key** — A key that grants Nango access to the TeamLogger API on your behalf.

This guide will walk you through generating your API key.

### Prerequisites

- A TeamLogger company account with administrator access.

### Step 1: Generate your API key

1. Log in to your TeamLogger account as an administrator.
2. Go to your account **Settings**.
3. Open the **Integrations** (or **API**) section.
4. Generate (or copy) your account's API key.

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with TeamLogger.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

You are now connected to TeamLogger.
