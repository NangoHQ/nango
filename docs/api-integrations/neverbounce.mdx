## 🚀 Quickstart

Connect to NeverBounce with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _NeverBounce_.
    </Step>
    <Step id="authorize-neverbounce" title="Authorize NeverBounce">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your NeverBounce API key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-neverbounce-api" title="Call the NeverBounce API">
    Let's make your first request to the NeverBounce API to get your account's credits and job counts. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/v4/account/info" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/v4/account/info',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    NeverBounce returns errors with a 200 status code, so check the `status` property of the response: `success` means the request worked, and `auth_failure` means the API key was not accepted ([error handling](https://developers.neverbounce.com/v4.0/reference/error-handling)).

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- Nango sends the key as the `key` query parameter on every call. Calls that need it in the request body (an `application/x-www-form-urlencoded` or `application/json` POST) can read it from the connection's credentials (`credentials.apiKey`) and pass it as the NeverBounce docs show.
