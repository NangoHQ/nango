## Overview

To authenticate with Olostep, you need:

1. **API Key** — an API key from the Olostep dashboard.

This guide will show you how to get it.

### Prerequisites

- An Olostep account. You can [sign up](https://www.olostep.com/auth/) for free, with no credit card required.

### Step 1: Create an API key

1. Sign in to [Olostep](https://www.olostep.com/auth/), click **Developer** in the dashboard sidebar to open the [API Keys page](https://www.olostep.com/dashboard/api-keys), then click **Create**.

<img src="/api-integrations/olostep/api_keys_page.png" alt="Olostep API Keys page with the Create button"/>

2. Enter a name for the key (for example, `nango-integration`) and click **Create**.

<img src="/api-integrations/olostep/create_key_dialog.png" alt="Olostep dialog to name a new API key"/>

3. Copy the API key from the **API Key created successfully!** dialog, then click **Done**.

<img src="/api-integrations/olostep/api_key_created.png" alt="Olostep dialog showing the new API key with a copy button"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Olostep.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/olostep/form.png" alt="Olostep Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Olostep.
