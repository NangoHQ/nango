## 🚀 Quickstart

Connect to DaData.ru with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _DaData.ru_.
    </Step>
    <Step id="authorize-dadata-ru" title="Authorize DaData.ru">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your DaData API key and secret key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-dadata-ru-api" title="Call the DaData.ru API">
    Let's make your first request to the DaData.ru API (get your account balance). Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/v2/profile/balance" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/v2/profile/balance',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- Suggestions API calls go to `suggestions.dadata.ru`: set `baseUrlOverride` to `https://suggestions.dadata.ru/suggestions/api` (endpoint e.g. `/4_1/rs/suggest/address`), and Nango keeps the connection's credentials and headers. See [API: подсказки по адресам](https://dadata.ru/api/suggest/address/).
- Clean (standardization) API calls go to `cleaner.dadata.ru`: set `baseUrlOverride` to `https://cleaner.dadata.ru/api` (endpoint e.g. `/v1/clean/address`), and Nango keeps the connection's credentials and headers. See [API: стандартизация адресов](https://dadata.ru/api/clean/address/).
