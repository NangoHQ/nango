## Overview

To authenticate with API-Sports, you need:

1. **API Key** — the API key of your API-Sports account, shown on the **My Access** page of the dashboard.

This guide will show you how to find it.

### Prerequisites

- An [API-Sports](https://dashboard.api-football.com/register) account. The free plan works and needs no credit card.

### Step 1: Copy your API key

1. Sign in to the [API-Sports dashboard](https://dashboard.api-football.com/login).
2. Open your user profile panel and click **My Access**.

<img src="/api-integrations/api-sports/user_menu_my_access.png" alt="API-Sports dashboard profile panel with the My Access entry highlighted"/>

3. Hover over the field next to **API-KEY** to reveal your key, then copy it. Your account has one key; **Reset my API-KEY** replaces it with a new one.

<img src="/api-integrations/api-sports/my_access_api_key.png" alt="API-Sports My Access page with the API-KEY field highlighted"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with API-Sports.
2. Paste the key you copied in Step 1 into the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/api-sports/form.png" alt="API-Sports Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to API-Sports.
