## 🚀 Quickstart

Connect to Pushinator with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Pushinator_.
    </Step>
    <Step id="authorize-pushinator" title="Authorize Pushinator">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your Pushinator API token. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-pushinator-api" title="Call the Pushinator API">
    Let's make your first request to the Pushinator API to send a notification to one of your channels. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, connection ID, and channel UUID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl -X POST "https://api.nango.dev/proxy/api/v2/notifications/send" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>" \
              -H "Content-Type: application/json" \
              -d '{"channel_id": "<CHANNEL-UUID>", "content": "Hello from Nango"}'
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.post({
            endpoint: '/api/v2/notifications/send',
            data: {
                channel_id: '<CHANNEL-UUID>',
                content: 'Hello from Nango'
            },
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- Nango does not check the API key when a connection is created, so a wrong or revoked key still connects and fails on its first call.
