## 🚀 Quickstart

Connect to Databricks with Nango and see data flow in 2 minutes.

<Steps>
    <Step title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to the **Integrations** tab -> _Configure New Integration_ -> _Databricks Account (OAuth)_. Enter the Client ID and Client Secret of your Databricks app connection (see the setup guide below).
    </Step>
    <Step title="Authorize Databricks">
    Go to the **Connections** tab -> _Add Test Connection_. Pick the account console host for your cloud (`accounts.cloud.databricks.com` for AWS, `accounts.gcp.databricks.com` for GCP, `accounts.azuredatabricks.net` for Azure), enter your Databricks account ID (in the account console, click the down arrow next to your username in the upper right corner), then click _Authorize_ and log in to Databricks as an account admin. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step title="Call the Databricks API">
    Let's make your first request to the Databricks account API (list account users). Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID (from the **Integrations** tab), connection ID (from the **Connections** tab), and your Databricks account ID (stored on the connection as the `accountId` connection config field):
    <Tabs>
        <Tab title="cURL">
            ```bash
            curl "https://api.nango.dev/proxy/2.0/accounts/<ACCOUNT-ID>/scim/v2/Users?count=1" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```
        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/2.0/accounts/<ACCOUNT-ID>/scim/v2/Users',
            params: { count: 1 },
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });
        console.log(JSON.stringify(res.data, null, 2));
        ```
        </Tab>

    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step title="Implement Nango in your app">
        Follow our [Auth implementation guide](/guides/primitives/auth) to integrate Nango in your app.

        To obtain your own credentials, follow the setup guide linked below.
    </Step>
</Steps>
