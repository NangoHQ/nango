## Overview

To authenticate with IP2Location.io, you need:

1. **API Key** — your IP2Location.io API key.

This guide will show you how to get it.

### Prerequisites

- An IP2Location.io account. You can [sign up for free](https://www.ip2location.io/sign-up); the free plan includes an API key.

### Step 1: Copy your API key

1. [Log in](https://www.ip2location.io/log-in) to IP2Location.io. If the Quick Start Guide appears, click **Skip Quickstart**.
2. On the **Dashboard**, the **API Key** card at the top shows your key. Click the copy icon next to **API Key** to copy it.

<img src="/api-integrations/ip2location-io/dashboard_api_key.png" alt="IP2Location.io Dashboard with the API Key card and its copy icon"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with IP2Location.io.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/ip2location-io/form.png" alt="IP2Location.io connection form in the Nango Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to IP2Location.io.
