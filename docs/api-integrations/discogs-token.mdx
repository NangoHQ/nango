## 🚀 Quickstart

Connect to Discogs with a personal access token through Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to [Integrations](https://app.nango.dev/dev/integrations) -> _Configure New Integration_ -> _Discogs (Personal Access Token)_.
    </Step>
    <Step id="authorize-discogs-token" title="Authorize Discogs">
    Go to [Connections](https://app.nango.dev/dev/connections) -> _Add Test Connection_ -> _Discogs (Personal Access Token)_ -> enter your personal access token and click _Authorize_. See the [connect guide](/api-integrations/discogs-token/connect) for how to generate a token.
    </Step>
    <Step id="call-discogs-api" title="Call the Discogs API">
    Let's make your first request to the Discogs API (fetch the authenticated user's identity). Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), [integration ID](https://app.nango.dev/dev/integrations), and [connection ID](https://app.nango.dev/dev/connections):
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/oauth/identity" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/oauth/identity',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>

    </Tabs>
    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connection/get).

    ✅ You're connected! Check the [Logs](https://app.nango.dev/dev/logs) tab in Nango to inspect requests.
    </Step>

    <Step id="implement-nango" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.

        To let your users connect their own accounts, follow the connect guide linked below.
    </Step>
</Steps>

## API gotchas

- Discogs **requires a unique `User-Agent` header** on every API request. Nango sets one automatically for proxy requests.
- Personal access tokens are sent as `Authorization: Discogs token=<token>`.
- Personal access tokens are tied to a single Discogs user account and are best suited for scripts or single-user integrations. For multi-user integrations, use [Discogs OAuth](/api-integrations/discogs) instead.
- Discogs rate limits authenticated requests to 60 per minute per user. Check the `X-Discogs-Ratelimit-Remaining` response header.
