## 🚀 Quickstart

Connect to DocsBot AI with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _DocsBot AI_.
    </Step>
    <Step id="authorize-docsbot-ai" title="Authorize DocsBot AI">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your DocsBot API key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-docsbot-ai-api" title="Call the DocsBot AI API">
    Let's make your first request to the DocsBot Admin API to list the teams your user has a role in. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/teams" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/teams',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- The Chat APIs (chat agent, conversations, questions) are served from `https://api.docsbot.ai`, not the `https://docsbot.ai/api` base URL. Call them with `baseUrlOverride` set to `https://api.docsbot.ai`; Nango keeps the connection's API key. See [Authentication](https://docsbot.ai/documentation/developer/authentication).
