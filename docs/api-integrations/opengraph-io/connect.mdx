## Overview

To authenticate with OpenGraph.io, you need:

1. **App ID** — the API key of your OpenGraph.io account.

This guide will show you how to get it.

### Prerequisites

- An OpenGraph.io account. [Sign up here](https://dashboard.opengraph.io/register); the Free plan includes 100 API credits per month.

### Step 1: Copy your App ID

1. Log in to the [OpenGraph.io dashboard](https://dashboard.opengraph.io). New accounts go through a short onboarding with one test request before the dashboard opens.
2. In the sidebar, under **API**, click **API Keys**. Click **Create API Key**, or copy the App ID of the existing **defaultKey**.

<img src="/api-integrations/opengraph-io/api_keys_page.png" alt="OpenGraph.io API Keys page with the Create API Key button highlighted"/>

3. In the **API Key Created** dialog, click **Copy**, then **Done**. This key is your App ID.

<img src="/api-integrations/opengraph-io/api_key_created.png" alt="OpenGraph.io API Key Created dialog with the Copy button highlighted"/>

### Step 2: Enter your App ID in the Connect UI

1. Open the form where you need to authenticate with OpenGraph.io.
2. Enter your **App ID** in the designated field.
3. Click **Connect**.

<img src="/api-integrations/opengraph-io/form.png" alt="Nango Connect UI form for entering the OpenGraph.io App ID" style={{maxWidth: "450px" }}/>

You are now connected to OpenGraph.io.
