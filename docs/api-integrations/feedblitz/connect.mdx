## Overview

To authenticate with FeedBlitz, you need:

1. **API Key** — a FeedBlitz API key.

This guide will show you how to get it.

### Prerequisites

- A premium (paid or trial) FeedBlitz publisher account. New accounts can start a free 30-day trial from [feedblitz.com/pricing](https://www.feedblitz.com/pricing/).

### Step 1: Get your API key

1. Log in to your FeedBlitz account at [app.feedblitz.com](https://app.feedblitz.com/f/).
2. Open **My Account** | **API Keys** in the left sidebar, or go to [feedblitz.com/f?pl_api](https://www.feedblitz.com/f?pl_api).
3. Generate a new key and copy it. API keys are case sensitive.

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with FeedBlitz.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/feedblitz/form.png" alt="FeedBlitz connection form in the Nango Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to FeedBlitz.
