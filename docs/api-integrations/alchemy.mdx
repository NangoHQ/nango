## 🚀 Quickstart

Connect to Alchemy with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Alchemy_.
    </Step>
    <Step id="authorize-alchemy" title="Authorize Alchemy">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your Alchemy API key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-alchemy-api" title="Call the Alchemy API">
    Let's make your first request to the Alchemy API to get the current ETH price. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/prices/v1/tokens/by-symbol?symbols=ETH" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/prices/v1/tokens/by-symbol',
            params: { symbols: 'ETH' },
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- Chain APIs (JSON-RPC and NFT API) are served from per-network hosts such as `https://eth-mainnet.g.alchemy.com`, not from `https://api.g.alchemy.com`. Call them with `baseUrlOverride` set to the network host; Nango keeps the connection's credentials and headers. See [Chain API supported chains](https://www.alchemy.com/docs/reference/node-supported-chains).
