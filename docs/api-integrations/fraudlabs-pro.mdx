## 🚀 Quickstart

Connect to FraudLabs Pro with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _FraudLabs Pro_.
    </Step>
    <Step id="authorize-fraudlabs-pro" title="Authorize FraudLabs Pro">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your FraudLabs Pro API key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-fraudlabs-pro-api" title="Call the FraudLabs Pro API">
    Let's make your first request to the FraudLabs Pro API: screen an order placed from the IP address `8.8.8.8`. Nango adds your FraudLabs Pro key to the request body. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl -X POST "https://api.nango.dev/proxy/v2/order/screen" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>" \
              -H "Content-Type: application/json" \
              -d '{"ip": "8.8.8.8", "format": "json"}'
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.post({
            endpoint: '/v2/order/screen',
            data: { ip: '8.8.8.8', format: 'json' },
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- Nango does not check the API key when a connection is created, so a wrong or revoked key still connects and fails on its first call.
- Nango sends the key as the `key` query parameter on every call, and adds it as the `key` field of the JSON or form body on POST calls such as `/v2/order/screen`. Calls that send a raw string body can read it from the connection's credentials (`credentials.apiKey`) and add the `key` field as the docs show.
