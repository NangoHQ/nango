## Overview

To authenticate with Gender API, you need:

1. **API Key** - A Gender API key that lets Nango call the Gender API on behalf of your account.

This guide will show you how to create one.

### Prerequisites

- A Gender API account. Every account includes 100 lookups a month, no credit card needed. You can [create one here](https://gender-api.com/en/account); click the activation link in the email Gender API sends you before you log in.

### Step 1: Create an API key

1. Log in to [Gender API](https://gender-api.com/en/account/login) and, in the left sidebar under **API**, click **API Keys**.
2. Click **Create New Key**.

<img src="/api-integrations/gender-api/api_keys_page.png" alt="API Keys page in the Gender API account area with the Create New Key button"/>

3. Click **Copy** in the green notice to copy the new key right away: it is shown only once. You can optionally give the key a label, such as `nango`.

<img src="/api-integrations/gender-api/api_key_created.png" alt="Newly generated Gender API key with the Copy button"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Gender API.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/gender-api/form.png" alt="Gender API connection form in Nango's Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to Gender API.
