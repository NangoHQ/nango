This guide shows you how to create an API key in ShareFile to obtain your OAuth credentials (client ID & secret). These are required to let your users grant your app access to their ShareFile account.

<Info>
  API keys can only be created from a paid ShareFile account. Trial accounts cannot create them.
</Info>

## Create your OAuth App
<Steps>
  <Step title="Sign in to the ShareFile API key page">
    Go to [api.sharefile.com/apikeys](https://api.sharefile.com/apikeys) and sign in with your ShareFile account.
  </Step>
  <Step title="Create an API key">
    1. Click **Create API Key**.
    2. Enter an **Application Name** and a **Description**.
    3. Under **Redirect URL**, add `https://api.nango.dev/oauth/callback`.
    4. Save the key.
  </Step>
  <Step title="Obtain your OAuth credentials">
    ShareFile shows the key's **Client ID** and **Client Secret**. Save these credentials securely as you'll need them when configuring your integration in Nango.
  </Step>
  <Step title="Start building your integration">
    Follow the [_Quickstart_](/getting-started/quickstart) to build your integration.
  </Step>
</Steps>

## OAuth Scopes

ShareFile has no scope list. Access follows the permissions of the user who authorizes; the token response reports them as flags such as `access_files_folders` and `modify_files_folders`. See the [ShareFile OAuth 2.0 guide](https://api.sharefile.com/gettingstarted/oauth2) for details.
