## Overview

To authenticate with MailboxValidator, you need:

1. **API Key** — the API key of your MailboxValidator API plan.

This guide will show you how to get it.

### Prerequisites

- A MailboxValidator account with an API plan. You can [sign up for the free API plan](https://www.mailboxvalidator.com/plans), which gives you up to 300 validations every 30 days.

### Step 1: Copy your API key

1. Log in to [MailboxValidator](https://www.mailboxvalidator.com/login) and open the [Dashboard](https://www.mailboxvalidator.com/dashboard).
2. In the **API Plan** section, copy the value next to **API Key**. Each account has one API key.

<img src="/api-integrations/mailboxvalidator/dashboard_api_key.png" alt="MailboxValidator dashboard with the API key in the API Plan section"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with MailboxValidator.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/mailboxvalidator/form.png" alt="MailboxValidator connection form in the Nango Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to MailboxValidator.
