## Overview

To authenticate with Basin, you need an **API Key**.

Basin has two types of API keys:
- **Account API Key** - scoped to your entire account, provides access to all forms and projects.
- **Form API Key** - scoped to a single form, mainly meant for Zapier-style integrations.

Use the Account API Key unless you specifically only need access to one form.

### Prerequisites:

- A Basin account on the Growth, Pro, or Agency plan (API access isn't available on other plans).

### Instructions:

#### Step 1: Finding your API Key
1. Log in to your account and navigate to the **Account API Key** page: [https://usebasin.com/app/api_settings](https://usebasin.com/app/api_settings).

<img src="/api-integrations/basin/api_key.png"/>

2. For a Form API Key instead: open the form's dashboard, navigate to the form and go to **Integrations** -> **API**.

<img src="/api-integrations/basin/form_api_key.png"/>


3. Copy the key.

#### Step 2: Enter your API Key in the Connect UI
1. Open the form where you need to authenticate with Basin.
2. Enter your **API Key**.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/basin/form.png" style={{maxWidth: "450px" }}/>

You are now connected to Basin.
