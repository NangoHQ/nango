## Overview

To authenticate with Better Proposals, you need:

1. **API Key** — the API key of your Better Proposals account.

This guide will show you how to generate it.

### Prerequisites

- A Better Proposals account. If you don't have one, [sign up](https://betterproposals.io/signup). After the free trial, the API is only available on the Premium or Enterprise plan.

### Step 1: Generate your API key

1. Log in to [Better Proposals](https://betterproposals.io/2/login/).
2. Go to **Settings** > **Integrations** > **API** ([direct link](https://betterproposals.io/2/integrations/api/)).
3. Click **Generate API Key**.

<img src="/api-integrations/better-proposals/generate_api_key.png" alt="Better Proposals Integrations settings with the API page open and the Generate API Key button highlighted"/>

4. Copy the key shown in the **API Key** field.

<img src="/api-integrations/better-proposals/api_key_created.png" alt="Better Proposals API page showing the API Key field and the Regenerate API Key button"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Better Proposals.
2. Enter your key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/better-proposals/form.png" alt="Better Proposals Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Better Proposals.
