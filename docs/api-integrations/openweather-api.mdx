## 🚀 Quickstart

Connect to OpenWeather API with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _OpenWeather API_.
    </Step>
    <Step id="authorize-openweather-api" title="Authorize OpenWeather API">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then pick your API host and enter your API key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-openweather-api" title="Call the OpenWeather API">
    Let's make your first request to the OpenWeather API to get the current weather for a location. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/data/2.5/weather?lat=44.34&lon=10.99" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/data/2.5/weather',
            params: { lat: '44.34', lon: '10.99' },
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- Historical weather and accumulated parameter calls go to `history.openweathermap.org`. Set `baseUrlOverride` to `https://history.openweathermap.org`; Nango keeps the connection's API key. See [Historical weather API](https://openweathermap.org/api/history)
- Weather Maps 2.0 tiles come from `maps.openweathermap.org`. Set `baseUrlOverride` to `https://maps.openweathermap.org`; Nango keeps the connection's API key. See [Weather maps 2.0](https://openweathermap.org/api/weather-map-2)
- Bulk downloads come from `bulk.openweathermap.org`. Set `baseUrlOverride` to `https://bulk.openweathermap.org`; Nango keeps the connection's API key. See [Bulk Download](https://openweathermap.org/api/bulk)
