## Overview

To authenticate with Breeze, you need:

1. **API Token** — the API token from your Breeze personal settings.

This guide will show you where to find it.

### Prerequisites

- A Breeze account. If you don't have one, [sign up](https://www.breeze.pm/signup): you can use Breeze free for 14 days, with no credit card required.

### Step 1: Copy your API token

1. Sign in to [Breeze](https://app.breeze.pm/signin).
2. Open your [personal settings](https://app.breeze.pm/profile) and click the **Integrations** tab.

<img src="/api-integrations/breeze/profile_integrations_tab.png" alt="Breeze personal settings with the Integrations tab selected"/>

3. Under **API token**, click **Copy** to copy your token.

<img src="/api-integrations/breeze/copy_api_token.png" alt="Breeze Integrations tab with the Copy button next to the API token field"/>

### Step 2: Enter your API token in the Connect UI

1. Open the form where you need to authenticate with Breeze.
2. Enter your API token in the **API Token** field. Breeze needs no password with the token, so the form does not ask for one.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/breeze/form.png" alt="Breeze Connect UI form with the API Token field" style={{maxWidth: "450px" }}/>

You are now connected to Breeze.
