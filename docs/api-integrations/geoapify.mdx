## 🚀 Quickstart

Connect to Geoapify with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Geoapify_.
    </Step>
    <Step id="authorize-geoapify" title="Authorize Geoapify">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then choose your region and enter your Geoapify API key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-geoapify-api" title="Call the Geoapify API">
    Let's make your first request to the Geoapify API to geocode an address. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/v1/geocode/search?text=Berlin%2C%20Germany&limit=1&format=json" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/v1/geocode/search',
            params: { text: 'Berlin, Germany', limit: '1', format: 'json' },
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- When the `region` connection config field is `api.geoapify.com`, set `baseUrlOverride` to `https://maps.geoapify.com` for Map Tiles and Static Maps; on `api-eu.geoapify.com` the region host serves them too. The connection keeps its API key. See [Maps, Geocoding & Routing APIs and GDPR](https://www.geoapify.com/maps-geocoding-routing-apis-gdpr-compliant-application/).
