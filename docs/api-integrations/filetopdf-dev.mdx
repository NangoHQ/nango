## 🚀 Quickstart

Connect to FileToPDF.dev with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _FileToPDF.dev_.
    </Step>
    <Step id="authorize-filetopdf-dev" title="Authorize FileToPDF.dev">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your FileToPDF.dev API key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-filetopdf-dev-api" title="Call the FileToPDF.dev API">
    Let's make your first request to the FileToPDF.dev API to convert a Markdown string to a PDF. The request uses one conversion credit, and the `Accept: application/json` header returns the PDF base64-encoded in a JSON response. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl -X POST "https://api.nango.dev/proxy/markdown" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>" \
              -H "Content-Type: application/json" \
              -H "Accept: application/json" \
              -d '{"markdown": "# Hello from Nango"}'
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.post({
            endpoint: '/markdown',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>',
            headers: { Accept: 'application/json' },
            data: { markdown: '# Hello from Nango' }
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- Nango does not check the key when a connection is created, so a wrong or revoked key still connects and fails on its first call.
