## Overview

To authenticate with currencyapi, you need:

1. **API Key** — a live or sandbox API key from your currencyapi account.

This guide will show you how to get it.

### Prerequisites

- A currencyapi account. [Sign up](https://app.currencyapi.com/register) if you don't have one: the Free plan includes API access and needs no credit card.
- Sandbox keys, whose requests do not count against your quota, are only available on the Pro plan and above.

### Step 1: Copy your API key

1. Sign in to [currencyapi](https://app.currencyapi.com/).
2. In the left sidebar, open [API keys](https://app.currencyapi.com/api-keys). A live key named **Default Key** is created with your account. Your key is also shown on the **Dashboard**.
3. Click **Copy to clipboard** next to the key you want to use, either a live key or, on Pro and above, a sandbox key.

<img src="/api-integrations/currencyapi/api_keys_page.png" alt="currencyapi API keys page with the Copy to clipboard button next to the Default Key highlighted"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with currencyapi.
2. Paste your key in the **API Key** field. Keys start with `cur_`.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/currencyapi/form.png" alt="currencyapi Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to currencyapi.
