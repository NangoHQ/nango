## 🚀 Quickstart

Connect to Omny Studio with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Omny Studio_.
    </Step>
    <Step id="authorize-omny-studio" title="Authorize Omny Studio">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your API key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-omny-studio-api" title="Call the Omny Studio API">
    Let's make your first request to the Omny Studio API (list programs, one page). Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/v1/programs?pageSize=10" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/v1/programs',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>',
            params: { pageSize: 10 }
        });

        console.log(res.data);
        ```
        </Tab>

    </Tabs>
    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## 📝 API gotchas

- The Management API has two versions, `v0` and `v1`; v1 is recommended for new work and is the only one with the download analytics and reporting endpoints. Put the version in the path (`/v1/programs`).
- Rate limits are applied organization-wide across all API keys. The limit is shown on the API keys settings page in Omny Studio; a `429` carries a `Retry-After` header.
- An API key can be scoped to the organization, a network or a single program, with per-area permissions. Calls outside the key's scope answer `403`.
