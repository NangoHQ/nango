## Overview

To authenticate with Linkup, you need:

1. **API Key** - A key that lets Nango call the Linkup API on behalf of your organization.

This guide will show you how to create one.

### Prerequisites

- A Linkup account. You can [create one for free](https://app.linkup.so/sign-up).

### Step 1: Create an API key

1. Sign in to the [Linkup app](https://app.linkup.so/sign-in).
2. Click **API keys** in the left sidebar, then click the **+** button next to your team (for example, **Team - default**).

<img src="/api-integrations/linkup/api_keys_page.png" alt="Linkup API keys page with the + button next to Team - default"/>

3. Enter a **Name** and a **Description** for the key, then click **Submit**.

<img src="/api-integrations/linkup/create_api_key_dialog.png" alt="Linkup Create API key dialog with Name and Description fields"/>

4. In the **API key created** dialog, click the copy button next to the key, then click **Done**.

<img src="/api-integrations/linkup/api_key_created.png" alt="Linkup API key created dialog with the copy button next to the key"/>

<Note>
The key is shown only once. Store it somewhere safe before you close the dialog.
</Note>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Linkup.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/linkup/form.png" alt="Nango Connect UI form for Linkup with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Linkup.
