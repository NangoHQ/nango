## Overview

To authenticate with Clearout, you need:

1. **API Token** — a Clearout API token.

This guide will show you how to create one.

### Prerequisites

- A Clearout account. You can [sign up](https://app.clearout.io/register) for free; any plan works, including the free tier.

### Step 1: Create an API token

1. Sign in to your [Clearout dashboard](https://app.clearout.io/login).
2. Click **Developer** in the top navigation, open the [API](https://app.clearout.io/developer/api/list) tab and click **+ Create API Token**.

<img src="/api-integrations/clearout/api_tokens_page.png" alt="Clearout Developer page with the API tab open and the Create API Token button"/>

3. Enter a name for the token, optionally a description, and click **Create**.

<img src="/api-integrations/clearout/create_api_token_dialog.png" alt="Clearout Create API Token dialog with the Name field and the Create button"/>

4. Click **Copy** to copy the new token.

<img src="/api-integrations/clearout/api_token_created.png" alt="Clearout dialog confirming the API token was created, with the Copy button"/>

All your tokens are listed in the **API** tab.

### Step 2: Enter your API token in the Connect UI

1. Open the form where you need to authenticate with Clearout.
2. Enter your **API Token** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/clearout/form.png" alt="Nango Connect UI form for Clearout with the API Token field" style={{maxWidth: "450px" }}/>

You are now connected to Clearout.
