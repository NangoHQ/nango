## Overview

To authenticate with Claid.ai, you need:

1. **API Key** — an API key from your Claid account.

This guide will show you how to create one.

### Prerequisites

- A Claid account. The free trial includes 50 API credits. If you don't have an account, [sign up](https://claid.ai/login).

### Step 1: Create an API key

1. Sign in to [Claid](https://claid.ai/login).
2. In the left sidebar, open **Integrations** -> **API Keys**, then click **Create API key**.

<img src="/api-integrations/claid-ai/api_keys_page.png" alt="Claid API Keys page with the Create API key button highlighted"/>

3. Enter a name for the key, turn on the **Access permissions** your integration needs (for example `storage` and `image_editing`), then click **Generate**.

<img src="/api-integrations/claid-ai/create_api_key_dialog.png" alt="Claid Create API key dialog with a key name and the storage and image_editing permissions turned on"/>

4. In the **Your new API key** dialog, click **Copy** to copy the key, then click **Close**.

<img src="/api-integrations/claid-ai/api_key_created.png" alt="Claid Your new API key dialog with the Copy and Download buttons"/>

<Note>Claid shows the key only once, when you create it. Copy it before you close the dialog.</Note>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Claid.ai.
2. Paste your API key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/claid-ai/form.png" alt="Claid.ai Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Claid.ai.
