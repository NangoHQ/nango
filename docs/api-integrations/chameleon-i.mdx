## Quickstart

Connect to Chameleon-I, a UK-based recruitment CRM and ATS, with Nango and make requests in minutes. Chameleon-I uses a static API key generated in your workspace.

<Steps>
    <Step title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to [Integrations](https://app.nango.dev/dev/integrations) → _Configure New Integration_ → _Chameleon-I_.
    </Step>
    <Step title="Authorize Chameleon-I">
    Go to [Connections](https://app.nango.dev/dev/connections) → _Add Test Connection_ → _Authorize_, then enter a Chameleon-I API key. Later, your users can do the same directly from your app.
    </Step>
    <Step title="Call the Chameleon-I API">
    Make a request to search candidates. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), [integration ID](https://app.nango.dev/dev/integrations), and [connection ID](https://app.nango.dev/dev/connections):
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/api/v1/candidate/search" \
              -H "Authorization: Bearer <NANGO-SECRET-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ secretKey: '<NANGO-SECRET-KEY>' });

        const res = await nango.get({
            endpoint: '/api/v1/candidate/search',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    ✅ You're connected! Check the [Logs](https://app.nango.dev/dev/logs) tab in Nango to inspect requests.

    </Step>

    <Step title="Implement Nango in your app">
        Follow our [Auth implementation guide](/guides/primitives/auth) to integrate Nango in your app.

        To obtain your Chameleon-I API key, follow the setup guide below.
    </Step>
</Steps>

## Access requirements

To connect to Chameleon-I through Nango, you need:

- A Chameleon-I workspace account (create a [free trial](https://www.chameleoni.com/register))
- Administrator access to generate API keys
- Valid API key with appropriate permissions for your use case

<Tip>API key access can be configured with different permission levels depending on your integration scope.</Tip>

## Setup guide

Follow the [Chameleon-I connection setup guide](/api-integrations/chameleon-i/connect) to:
1. Generate an API key in your Chameleon-I workspace
2. Copy the API key
3. Authorize your connection in Nango

## API endpoints

Chameleon-I provides 36+ REST endpoints for managing recruitment data including:

- Candidate management (`/api/v1/candidate/*`)
- Requirement management (`/api/v1/requirement/*`)
- Search and query operations
- Activity tracking
- Integration webhooks

See the [official Jentic API docs](https://jentic.com/apis/chameleoni.com/chameleoni) for complete endpoint documentation.

## API gotchas

- **Pagination:** Cursor-based pagination with 50 items per page default
- **Authentication:** Uses `API-KEY` header (not `Authorization` header)
- **Rate limiting:** Enforced by Chameleon-I; implement exponential backoff for reliable integrations
- **Base URL:** All requests go to `https://api.chameleoni.com`
