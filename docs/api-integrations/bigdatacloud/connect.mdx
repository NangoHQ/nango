## Overview

To authenticate with BigDataCloud, you need:

1. **API Key** — the key BigDataCloud creates for your account.

This guide will show you how to get it.

### Prerequisites

- A BigDataCloud account. If you don't have one, [sign up](https://www.bigdatacloud.com/signup): every API package includes a free tier and no credit card is required. An API key is created for you automatically.

### Step 1: Copy your API key

1. [Log in](https://www.bigdatacloud.com/login) to BigDataCloud and open your account dashboard.
2. Click **Credentials** in the left sidebar.

<img src="/api-integrations/bigdatacloud/account_credentials_nav.png" alt="BigDataCloud account dashboard with Credentials highlighted in the left sidebar"/>

3. On the **API Keys** page, click **Copy key** to copy your API key.

<img src="/api-integrations/bigdatacloud/copy_api_key.png" alt="BigDataCloud API Keys page with the Copy key button highlighted"/>

A new key shows as **Pending** while it propagates across BigDataCloud's network, which typically completes within 10 minutes. Wait until it is active before connecting.

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with BigDataCloud.
2. Enter your API key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/bigdatacloud/form.png" alt="BigDataCloud Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to BigDataCloud.
