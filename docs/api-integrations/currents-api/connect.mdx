## Overview

To authenticate with Currents API, you need:

1. **API Key** — the API key from your Currents profile dashboard.

This guide will show you how to get it.

### Prerequisites

- A Currents API account. [Sign up for free](https://currentsapi.services/en/register) if you don't have one, then open the link in the confirmation email: your API key is locked until your email is verified.

### Step 1: Copy your API key

1. Log in and open your [profile dashboard](https://currentsapi.services/en/profile).
2. In the **API Keys** section, click **Copy** next to your **Primary** key.

<img src="/api-integrations/currents-api/copy_api_key.png" alt="Currents profile dashboard with the Copy button next to the Primary API key highlighted"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Currents API.
2. Enter your key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/currents-api/form.png" alt="Currents API Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Currents API.
