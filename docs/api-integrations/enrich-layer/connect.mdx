## Overview

To authenticate with Enrich Layer, you need:

1. **API Key** — the API key from your Enrich Layer dashboard.

This guide will show you how to find it.

### Prerequisites

- An Enrich Layer account. If you don't have one, [create a free account](https://enrichlayer.com/auth/register).

### Step 1: Copy your API key

1. Sign in to [Enrich Layer](https://enrichlayer.com/auth/login). The dashboard opens on the **API Key** page (**Enrich Layer API** > **API Key**).
2. The **Bearer Token (API Key)** table lists your API key, labelled **default**. To use a separate key, click **Generate more API keys**.

<img src="/api-integrations/enrich-layer/api_key_page.png" alt="Enrich Layer API Key page with the Bearer Token (API Key) table and the Generate more API keys button" />

3. Click the token in the **Bearer Token (API Key)** table to copy your API key.

<img src="/api-integrations/enrich-layer/copy_api_key.png" alt="Enrich Layer Bearer Token (API Key) table with the token value to click to copy it" />

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Enrich Layer.
2. Enter your API key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/enrich-layer/form.png" alt="Enrich Layer Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Enrich Layer.
