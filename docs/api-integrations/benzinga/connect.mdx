## Overview

To authenticate with Benzinga, you need:

1. **API Key** — the API key of your Benzinga APIs account.

This guide will show you how to get it.

### Prerequisites

- A Benzinga APIs account. [Register](https://www.benzinga.com/apis/licensing/register) if you don't have one.

### Step 1: Copy your API key

1. Log in to the Benzinga APIs dashboard and open the **API Keys** tab of your profile.

<img src="/api-integrations/benzinga/api_keys_tab.png" alt="Benzinga APIs dashboard with the API Keys tab highlighted"/>

2. Your API key is listed with the status **Active**. Click the copy button next to it to copy the key.

<img src="/api-integrations/benzinga/copy_api_key.png" alt="Benzinga API Keys list with the copy button highlighted next to the active key"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Benzinga.
2. Paste the key you copied in Step 1 into the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/benzinga/form.png" alt="Benzinga Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Benzinga.
