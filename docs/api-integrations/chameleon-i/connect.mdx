## Step 1: Generate an API key

1. Log in to your [Chameleon-I workspace](https://www.chameleoni.com/)
2. Go to **Settings** → **API Settings** (or similar admin section)
3. Click **Generate API Key** or **Create New API Key**
4. Copy the generated API key — you'll need this in the next step

<Tip>
If you don't have a Chameleon-I account, start with a [free trial](https://www.chameleoni.com/register) (14-30 days).
</Tip>

## Step 2: Authorize in Nango

1. In Nango, go to [Connections](https://app.nango.dev/dev/connections)
2. Click **Add Test Connection**
3. Select **Chameleon-I** as the provider
4. Paste your API key in the **API Key** field
5. Click **Connect**

✅ You're done! Your Chameleon-I connection is now authorized and ready to use.
