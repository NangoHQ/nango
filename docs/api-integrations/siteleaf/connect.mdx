## Overview

To authenticate with Siteleaf, you need:

1. **API Key** - the API key of your Siteleaf account.
2. **API Secret** - the API secret issued together with the API key.

This guide will show you where to find both.

### Prerequisites

- A Siteleaf account. If you don't have one, [sign up](https://manage.siteleaf.com/signup) for free: API access is included on the free Developer plan.

### Step 1: Open the API tab of your account

1. Log in to [Siteleaf](https://manage.siteleaf.com/login).
2. Open [My account](https://manage.siteleaf.com/account).
3. Click the **API** tab.

<img src="/api-integrations/siteleaf/account_api_tab.png" alt="Siteleaf My account page with the API tab highlighted"/>

### Step 2: Copy your API Key and API Secret

Copy the **API Key** and the **API Secret**. Siteleaf creates both with your account, so there is nothing to generate.

<Warning>**Regenerate keys** replaces both the API Key and the API Secret.</Warning>

<img src="/api-integrations/siteleaf/api_key_and_secret.png" alt="Siteleaf API tab with the API Key and API Secret fields highlighted"/>

### Step 3: Enter your credentials in the Connect UI

1. Open the form where you need to authenticate with Siteleaf.
2. Enter the **API Key** value in the **API Key** field.
3. Enter the **API Secret** value in the **API Secret** field.
4. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/siteleaf/form.png" alt="Siteleaf Connect UI form with the API Key and API Secret fields" style={{maxWidth: "450px" }}/>

You are now connected to Siteleaf.
