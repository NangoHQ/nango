# Overview

To authenticate with Publora, you will need:
1. **API Key** - A key that grants access to every social account connected to your Publora workspace.

This guide will walk you through creating your **API Key** within Publora.

### Prerequisites:

- A Publora account. The free Starter plan includes API access, 15 posts a month and three connected social accounts, and does not ask for a card.
- At least one social account connected in Publora. The API publishes to accounts connected there; it cannot connect them for you.

### Instructions:

#### Step 1: Creating your API key

1. Sign in at [app.publora.com](https://app.publora.com)
2. Go to [Settings → API keys](https://app.publora.com/dashboard/api)
3. Press **Generate API key**
4. Copy the key and store it securely. It starts with `sk_`

<Note>The key belongs to the workspace, so it can publish to every social account connected in it.</Note>

<Warning>Be careful with this API key: anyone holding it can publish to your connected social accounts.</Warning>

#### Step 2: Enter credentials in the Connect UI

Once you have your **API Key**:

1. Open the form where you need to authenticate with Publora.
2. Enter your **API Key** in its respective field.
3. Submit the form, and you should be successfully authenticated.

You are now connected to Publora.
