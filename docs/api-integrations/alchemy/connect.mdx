## Overview

To authenticate with Alchemy, you need:

1. **API Key** — the API key of an Alchemy app.

This guide will show you how to get it.

### Prerequisites

- An Alchemy account. You can [sign up for free](https://dashboard.alchemy.com/signup).

### Step 1: Copy your app API key

1. Sign in to the [Alchemy Dashboard](https://dashboard.alchemy.com/) and open **Apps** in the left sidebar.
2. Select your app. New accounts already have one. To make another, click **Create new app**, enter a name, pick chains and services, then click **Create App**.

<img src="/api-integrations/alchemy/apps_list.png" alt="Apps page in the Alchemy Dashboard with an app listed and the Create new app button"/>

3. On the app's details page, click **Copy** next to **API Key** in the top-right corner.

<img src="/api-integrations/alchemy/app_api_key.png" alt="Alchemy app details page with the Copy button next to the API Key"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Alchemy.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/alchemy/form.png" alt="Alchemy connection form in the Nango Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to Alchemy.
