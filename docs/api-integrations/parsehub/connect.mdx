## Overview

To authenticate with ParseHub, you need:

1. **API Key** — the API key of your ParseHub account.

This guide will show you how to get it.

### Prerequisites

- A ParseHub account. [Sign up](https://www.parsehub.com/register) if you don't have one.

### Step 1: Copy your API key

1. Log in to [ParseHub](https://www.parsehub.com/login) and open your [account page](https://www.parsehub.com/account) (**Dashboard** -> **Account**).
2. On the **Account Settings** tab, copy the value shown next to **My API key**. Each account has one API key, so there is nothing to create.

<img src="/api-integrations/parsehub/account_api_key.png" alt="ParseHub Account Settings tab with the My API key field highlighted"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with ParseHub.
2. Enter your key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/parsehub/form.png" alt="ParseHub Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to ParseHub.
