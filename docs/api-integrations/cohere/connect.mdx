## Overview

To authenticate with Cohere, you need:

1. **API Key** — a trial or production API key from your Cohere dashboard.

This guide will show you how to get it.

### Prerequisites

- A Cohere account. Every new account gets a free, rate-limited trial key: [sign up](https://dashboard.cohere.com/welcome/register).

### Step 1: Create an API key

1. Sign in to the [Cohere dashboard](https://dashboard.cohere.com/welcome/login). If you just signed up, confirm your email address first.
2. In the sidebar under **Platform**, click **API Keys**.

<img src="/api-integrations/cohere/dashboard_api_keys_nav.png" alt="The API Keys link in the Cohere dashboard sidebar"/>

3. Cohere creates a trial key named `default` when you sign up. To make a separate key, click **New Trial key** in the **Trial keys** section, enter a name, and click **Generate Trial key**.

<img src="/api-integrations/cohere/new_trial_key.png" alt="The New Trial key button in the Trial keys section of the Cohere API Keys page"/>

4. Copy the key with the copy button, then click **Close**.

<img src="/api-integrations/cohere/trial_key_created.png" alt="The New Trial key dialog with the copy button next to the new key"/>

<Note>
Trial keys are free but rate limited, and Cohere does not permit them for production or commercial use. For a production key, an organization Owner clicks **Get your Production key** and completes the Go to Production application. See [Going live](https://docs.cohere.com/docs/going-live).
</Note>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Cohere.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/cohere/form.png" alt="The Cohere connection form in the Nango Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to Cohere.
