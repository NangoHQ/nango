## Overview

To authenticate with Caly, you need:

1. **API Key** - a Caly API key.

This guide shows you how to create one.

### Prerequisites

- A Caly account. If you don't have one, [sign up](https://trycaly.com). API keys are available on every plan, including Free.

### Step 1: Find your API key

1. Log in to [Caly](https://app.trycaly.com).
2. Go to **Settings** > **Developer** > **API keys**.
3. Click **Add**, give the key a name, and choose when it expires.
4. Click **Save**, then copy the key. Caly only shows it once, so copy it before you close the dialog.

<img src="/api-integrations/caly/api_keys.png" alt="Caly API keys page with the Create an API key dialog"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Caly.
2. Enter your key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/caly/form.png" alt="Nango Connect UI form with the Caly API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Caly.
