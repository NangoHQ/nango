## Overview

To authenticate with Veille, you need:

1. **API Key** — an API key from your Veille dashboard.

This guide will show you how to get it.

### Prerequisites

- A Veille account. [Sign up](https://app.veille.io/register) if you don't have one.

### Step 1: Create an API key

1. Log in to the [Veille dashboard](https://app.veille.io). In the left sidebar, under **API**, click **API keys**.

<img src="/api-integrations/veille/api_keys_nav.png" alt="Veille sidebar with API keys highlighted under API"/>

2. On the **API keys** page, click **New API key**. Your account also comes with a **Default API Key** that you can copy from this page instead.

<img src="/api-integrations/veille/new_api_key.png" alt="Veille API keys page with the New API key button highlighted"/>

3. Enter a unique **Name** and pick a **Category** on the **API key options** tab. **Expires** and **Request limits** are optional. Click **Create API key**.

<img src="/api-integrations/veille/create_api_key_dialog.png" alt="Veille New API key dialog with a name and category entered and the Create API key button highlighted"/>

4. In the **API key created** window, click **Copy** to copy the key, then click **Accept and continue**.

<img src="/api-integrations/veille/api_key_created.png" alt="Veille API key created window with the copy button highlighted"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Veille.
2. Enter your key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/veille/form.png" alt="Veille Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Veille.
