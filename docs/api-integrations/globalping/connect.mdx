## Overview

To authenticate with Globalping, you need:

1. **API Token** — a Globalping API token.

This guide will show you how to get it.

### Prerequisites

- A Globalping account. You can create one on the [Globalping Dashboard](https://dash.globalping.io/) by signing in with GitHub.

### Step 1: Generate an API token

1. Sign in to the [Globalping Dashboard](https://dash.globalping.io/) with GitHub.
2. In the left sidebar, click **Tokens**.

<img src="/api-integrations/globalping/dashboard_tokens_nav.png" alt="Tokens page in the left sidebar of the Globalping Dashboard"/>

3. Click **Generate new token**, enter a name for the token and choose an expiration. Leave **Origins** empty, then click **Generate token**.

<img src="/api-integrations/globalping/generate_token_dialog.png" alt="Generate new token dialog with a token name, expiration and empty Origins field"/>

4. Click **Copy** to copy the token and store it securely.

<img src="/api-integrations/globalping/token_created.png" alt="New Globalping API token with the Copy button"/>

### Step 2: Enter your API token in the Connect UI

1. Open the form where you need to authenticate with Globalping.
2. Enter your **API Token** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/globalping/form.png" alt="Globalping connection form in the Nango Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to Globalping.
