## Overview

To authenticate with Evenium, you need:

1. **API Key** — the access token from your Evenium profile.

This guide will show you how to get it.

### Prerequisites

- An Evenium organizer account, on [evenium.net](https://evenium.net/ng/create-event) or an Evenium Facility account on evenium.com.

### Step 1: Copy your API key

1. Sign in to Evenium.
2. Click your name in the top bar, then choose **API Key**. You can also open the API key panel directly: [evenium.net](https://evenium.net/ng/person/home/index.jsf?open=profile-apikey) or [evenium.com (Facility account)](https://evenium.com/ng/member/myAccount/myAccount.jsf?open=apikey).

<img src="/api-integrations/evenium/profile_menu_api_key.png" alt="Evenium profile menu with the API Key option highlighted"/>

3. Copy the access token shown in the **API Key** panel. Do not click **Revoke it** unless you want to replace the key with a new one.

<img src="/api-integrations/evenium/api_key_shown.png" alt="Evenium API Key panel showing the access token field and the Revoke it button"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Evenium.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/evenium/form.png" alt="Evenium connection form in the Nango Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to Evenium.
