## 🚀 Quickstart

Connect to Pinata with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Pinata_.
    </Step>
    <Step id="authorize-pinata" title="Authorize Pinata">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your Pinata API key JWT. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-pinata-api" title="Call the Pinata API">
    Let's make your first request to the Pinata API to test your API key. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/data/testAuthentication" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/data/testAuthentication',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- Pinata's file upload API is on `https://uploads.pinata.cloud`. Calls to it set `baseUrlOverride` to `https://uploads.pinata.cloud`; Nango keeps the connection's credentials and headers. See [Get Upload Limits](https://docs.pinata.cloud/api-reference/endpoint/get-upload-limits).
- Pinata's agents management API is on `https://agents.pinata.cloud`. Calls to it set `baseUrlOverride` to `https://agents.pinata.cloud`; Nango keeps the connection's credentials and headers. See [HTTP API](https://docs.pinata.cloud/agents/api).
