## Quickstart

[Arcmira](https://arcmira.com) searches indexed YouTube and podcast transcripts. Use the Nango proxy to find a spoken passage and link readers to that moment in the original recording.

<Steps>
    <Step title="Create the integration" id="create-integration">
        In Nango, open the **Integrations** tab, select **Configure New Integration**, and choose **Arcmira**.
    </Step>
    <Step title="Connect Arcmira" id="connect-arcmira">
        Open the **Connections** tab and select **Add Test Connection**. Enter your [Arcmira API key](/api-integrations/arcmira/connect).

        Nango verifies the key with `GET /v1/me`, which returns account context without consuming usage credits.
    </Step>
    <Step title="Call the Arcmira API" id="call-arcmira-api">
        Use a Nango [Environment API key](/reference/backend/http-api/api-keys#scopes) with the `environment:proxy` scope. Supply the integration ID and connection ID from the previous steps:

        ```bash
        curl "https://api.nango.dev/proxy/v1/search?q=GPU%20demand&limit=3" \
          -H "Authorization: Bearer <NANGO-API-KEY>" \
          -H "Provider-Config-Key: <INTEGRATION-ID>" \
          -H "Connection-Id: <CONNECTION-ID>"
        ```

        For each match in `chunks`, use `text` for the passage, `start_seconds` for its timestamp when present, and `watch_url` for its source. Nango supplies the Arcmira bearer key.
    </Step>
    <Step title="Implement Nango in your app" id="implement-nango">
        Follow the [Auth implementation guide](/guides/auth/auth-guide) to let users connect their Arcmira accounts.
    </Step>
</Steps>

## API gotchas

- Access follows the connected key's scopes and account plan. Inspect `GET /v1/me` before relying on write or commercial research access.
- A paid read uses credits from your plan, then your on-demand budget. Connection verification does not retrieve transcripts or run research queries.
- `GET /v1/me` remains available when account usage is exhausted, so a successful connection does not imply that every research request can run.
