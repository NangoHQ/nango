## Overview

To authenticate with Ollama, you need:

1. **API Key** — an Ollama API key.

This guide will show you how to create one.

### Prerequisites

- An Ollama account. [Sign up](https://ollama.com/signup) if you don't have one.

### Step 1: Create an Ollama API key

1. Sign in to [ollama.com](https://ollama.com) and open the [Keys](https://ollama.com/settings/keys) page in your settings.
2. On the **API keys** tab, click **Create API key**.

<img src="/api-integrations/ollama/api_keys_page.png" alt="Ollama Keys page with the Create API key button"/>

3. Enter a name for the key and click **Create**.

<img src="/api-integrations/ollama/create_api_key_dialog.png" alt="Create API key dialog with a name field and the Create button"/>

4. Copy the key from the **Save your API key** dialog. Ollama shows it only once, so store it somewhere safe.

<img src="/api-integrations/ollama/api_key_created.png" alt="Save your API key dialog showing the new key with a copy button"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Ollama.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/ollama/form.png" alt="Ollama Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Ollama.
