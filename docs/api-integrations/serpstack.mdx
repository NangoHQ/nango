## 🚀 Quickstart

Connect to Serpstack with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Serpstack_.
    </Step>
    <Step id="authorize-serpstack" title="Authorize Serpstack">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your Serpstack API access key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-serpstack-api" title="Call the Serpstack API">
    Let's make your first request to the Serpstack API to look up a location for geo-specific searches. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/locations?query=united&limit=1" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/locations',
            params: { query: 'united', limit: '1' },
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- Nango sends the key as the `access_key` query parameter on every call to `https://api.serpstack.com`. Calls that need it another way, such as the `apikey` header on the APILayer gateway (`api.apilayer.net`), can read it from the connection's credentials (`credentials.apiKey`) and pass it as the docs show.
