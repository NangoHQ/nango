## Overview

To authenticate with TextRazor, you need:

1. **API Key** — the API key of your TextRazor account.

This guide will show you how to get it.

### Prerequisites

- A TextRazor account. You can [sign up](https://www.textrazor.com/signup) for free; the free plan includes API access. Verify your email address with the link TextRazor sends before you log in.

### Step 1: Copy your API key

1. [Log in](https://www.textrazor.com/login) and open the [TextRazor Console](https://www.textrazor.com/console). It opens on the **Home** tab.
2. Copy the value under **API Key**. Each account has one key, created automatically, so there is nothing to create.

<img src="/api-integrations/textrazor/console_api_key.png" alt="TextRazor Console Home tab with the API key under the API Key heading"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with TextRazor.
2. Paste the key you copied in Step 1 into the **API Key** field.
3. Submit the form. Nango checks the key with TextRazor, and you should be successfully authenticated.

<img src="/api-integrations/textrazor/form.png" alt="TextRazor Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to TextRazor.
