## 🚀 Quickstart

Connect to Gender API with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Gender API_.
    </Step>
    <Step id="authorize-gender-api" title="Authorize Gender API">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your Gender API key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-gender-api-api" title="Call the Gender API">
    Let's make your first request to the Gender API to get your account's usage statistics. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/v2/statistic" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/v2/statistic',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- The Gender API MCP server is served from `https://mcp.gender-api.com`, not from `https://gender-api.com`. Call it with `baseUrlOverride` set to that host; Nango keeps the connection's credentials and headers. See [Hosted MCP Server](https://gender-api.com/en/app-integrations/mcp-server).
- Nango sends the key as a bearer token in the `Authorization` header on every call. Calls to the legacy API v1 take it as the `key` query parameter instead (for example `GET /get-stats?key=<key>`): read it from the connection's credentials (`credentials.apiKey`) and add that parameter yourself. See [Statistic](https://gender-api.com/en/api-docs/v2/statistic).
