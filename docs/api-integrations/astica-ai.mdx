## 🚀 Quickstart

Connect to Astica AI with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Astica AI_.
    </Step>
    <Step id="authorize-astica-ai" title="Authorize Astica AI">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your astica API key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-astica-ai-api" title="Call the Astica AI API">
    Let's make your first request to the astica Voice API to list your voice clones. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl -X POST "https://api.nango.dev/proxy/voice_clone_list" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>" \
              -H "Content-Type: application/json" \
              -d '{}'
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.post({
            endpoint: '/voice_clone_list',
            data: {},
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- Vision API calls go to `vision.astica.ai` (for example `POST /describe`): set `baseUrlOverride` to `https://vision.astica.ai`, and Nango keeps the connection's credentials and headers. See [Vision AI - REST API Documentation](https://astica.ai/vision/documentation/).
- Listen (speech to text) API calls go to `listen.astica.ai` (for example `POST /transcribe`): set `baseUrlOverride` to `https://listen.astica.ai`, and Nango keeps the connection's credentials and headers. See [asticaListen - Hearing AI Documentation](https://astica.ai/hearing/documentation/).
- NLP API calls go to `nlp.astica.ai` (for example `POST /generate`): set `baseUrlOverride` to `https://nlp.astica.ai`, and Nango keeps the connection's credentials and headers. See [Natural Language Processing - NLP AI - Documentation](https://astica.ai/nlp/documentation/).
- Design (image generation) API calls go to `design.astica.ai` (for example `POST /generate_image`): set `baseUrlOverride` to `https://design.astica.ai`, and Nango keeps the connection's credentials and headers. See [Realistic Image Generation - REST API Documentation](https://astica.ai/design/documentation/).
- Nango sends the key in the `x-api-key` header on every call. Calls that take the key as the `tkn` field (the vision, listen, nlp and design hosts, and the voice multipart and WebSocket calls) can read it from the connection's credentials (`credentials.apiKey`) and pass it as `tkn` in the body, as the docs show.
