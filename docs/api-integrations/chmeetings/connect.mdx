## Overview

To authenticate with ChMeetings, you need:

1. **API Key** — your account's API key from the **API Integration** card in your ChMeetings settings.

This guide will show you how to get it.

### Prerequisites

- A ChMeetings account. If you don't have one, [sign up](https://app.chmeetings.com/Account/Register?lang=en).

### Step 1: Get your API key

1. Log in to [ChMeetings](https://app.chmeetings.com/).
2. In the left menu, expand **Settings** and click **Integrations**.

<img src="/api-integrations/chmeetings/settings_integrations_menu.png" alt="ChMeetings left menu with Settings expanded and Integrations highlighted" />

3. In the **API Integration** card, click **Get API**.

<img src="/api-integrations/chmeetings/get_api_button.png" alt="ChMeetings Integrations page with the Get API button in the API Integration card" />

4. Your API key appears in the card. Copy it with the copy icon next to the **API Key** field.

<img src="/api-integrations/chmeetings/api_key_created.png" alt="ChMeetings API Integration card showing the API Key field and its copy icon" />

<Note>Clicking **Change Key** replaces your API key and disables every app that uses the current one.</Note>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with ChMeetings.
2. Enter your API key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/chmeetings/form.png" alt="ChMeetings Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to ChMeetings.
