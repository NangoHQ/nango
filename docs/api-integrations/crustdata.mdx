## 🚀 Quickstart

Connect to Crustdata with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Crustdata_.
    </Step>
    <Step id="authorize-crustdata" title="Authorize Crustdata">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your Crustdata API key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-crustdata-api" title="Call the Crustdata API">
    Let's make your first request to the Crustdata API to get your account's credit balance. This call is free. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/account/credits" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/account/credits',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Nango sends your API key and the `x-api-version: 2025-11-01` header on every request.

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- Nango pins the API version with `x-api-version: 2025-11-01`. Crustdata returns `400` without this header.
- Most endpoints use `POST` with a JSON body, even for searches and lookups.
- Most calls spend credits. The account endpoints, such as `/account/credits` and `/account/endpoints`, are free. Use `/account/endpoints` to see which endpoints your plan includes.
- Rate limits are per API key and per endpoint, from 5 to 300 requests per minute. On a `429`, Nango waits for the `x-ratelimit-reset` interval before retrying.
