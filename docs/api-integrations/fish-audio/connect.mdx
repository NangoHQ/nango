## Overview

To authenticate with Fish Audio, you need:

1. **API Key** — a Fish Audio API key.

This guide will show you how to get it.

### Prerequisites

- A Fish Audio account. You can sign up on the [Fish Audio Get Started page](https://fish.audio/app/developers/get-started/) and verify your email.

### Step 1: Create an API key

1. Sign in to Fish Audio and open **Developer** > [Get Started](https://fish.audio/app/developers/get-started/).
2. Under **Get your API key**, click **Create API key**. The key is created in one click.

<img src="/api-integrations/fish-audio/get_started_create_api_key.png" alt="Fish Audio Developer Get Started page with the Create API key button under Get your API key"/>

3. Click the copy button next to the new key and store it securely. The key is shown only once.

<img src="/api-integrations/fish-audio/api_key_created.png" alt="Fish Audio Get Started page showing the new API key with the copy button"/>

You can rename or manage your keys later under **Administration** > [API Keys](https://fish.audio/app/api-keys/).

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Fish Audio.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/fish-audio/form.png" alt="Fish Audio connection form in the Nango Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to Fish Audio.
