Famulor ([famulor.io](https://www.famulor.io)) is a platform for AI voice assistants that answer and place phone calls and reply on messaging channels. The REST API manages assistants, calls, transcripts, campaigns, contacts, and knowledge bases.

## 🚀 Quickstart

Connect to Famulor with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to [Integrations](https://app.nango.dev/dev/integrations) -> _Configure New Integration_ -> _Famulor_.
    </Step>
    <Step id="authorize-famulor" title="Authorize Famulor">
    Go to [Connections](https://app.nango.dev/dev/connections) -> _Add Test Connection_ -> _Famulor_ -> enter your API key and click _Authorize_. See the [connect guide](/api-integrations/famulor/connect) for how to create a key.
    </Step>
    <Step id="call-famulor-api" title="Call the Famulor API">
    Let's make your first request to the Famulor API (list your assistants). Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), [integration ID](https://app.nango.dev/dev/integrations), and [connection ID](https://app.nango.dev/dev/connections):
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/api/v1/assistants?limit=10" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/api/v1/assistants',
            params: { limit: 10 },
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>

    </Tabs>
    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the [Logs](https://app.nango.dev/dev/logs) tab in Nango to inspect requests.
    </Step>

    <Step id="implement-nango" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.

        To obtain your own production credentials, follow the connect guide linked below.
    </Step>
</Steps>

## API gotchas

- REST requests require **API Access** on the workspace plan. Without it, requests return `403 api_access_required`.
- Responses use a `{ "data": ..., "meta": ... }` envelope. List endpoints paginate with `limit` (max 200) and `offset`.
- Keys created in the dashboard carry every scope. Create a narrower key with `POST /api/v1/api-keys` and an explicit `scopes` array.
- When a request is rate-limited (`429`), retry after the delay in the `Retry-After` header.
- For user-facing apps that act on behalf of a signed-in user, use the [Famulor (MCP)](/api-integrations/famulor-mcp) integration or OAuth 2.0 instead of a shared key.
