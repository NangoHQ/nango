## 🚀 Quickstart

Connect to Agility CMS with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Agility CMS_.
    </Step>
    <Step id="authorize-agility-cms" title="Authorize Agility CMS">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then select your region and enter your instance GUID and Personal Access Token. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-agility-cms-api" title="Call the Agility CMS API">
    Let's make your first request to the Agility CMS Management API to get the current user. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/api/v1/users/me" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/api/v1/users/me',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- Nango stores the instance GUID in the `instanceGuid` connection config field but adds it to no request. Read it from the connection's `connection_config` and put it in the path of instance-level endpoints, for example `/api/v1/instance/<instanceGuid>/locales`.
