## Overview

To authenticate with Sendspark, you need:

1. **API Key** — the API Key of your Sendspark workspace.
2. **API Secret** — the API Secret generated for your user next to that API Key.

This guide will show you how to generate them in Sendspark.

### Prerequisites

- A Sendspark account on a plan with API access. Sendspark includes API access from the Growth plan upwards.

### Step 1: Generate your API Key and API Secret

1. Log in to Sendspark and open **API Credentials** from your account menu, or go directly to [sendspark.com/settings/api-credentials](https://sendspark.com/settings/api-credentials).
2. Click **GENERATE KEYS**. Your **API Key** appears on screen; copy it.
3. Click the **Key** icon next to your API Key.
4. Click **Generate New Secret Key** and copy your **API Secret**.

<Tip>Sendspark shows the API Secret only once. Store it securely; if you lose it, generate a new one.</Tip>

### Step 2: Enter your credentials in the Connect UI

1. Open the form where you need to authenticate with Sendspark.
2. Enter your **API Key** in the **API Key** field and your **API Secret** in the **API Secret** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/sendspark/form.png" alt="Sendspark Connect UI form with the API Key and API Secret fields" style={{maxWidth: "450px" }}/>

You are now connected to Sendspark.
