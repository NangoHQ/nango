## Overview

To authenticate with Polygon, you need:

1. **API Key** — an API key from your Massive account. [Polygon.io is now called Massive](https://massive.com/blog/polygon-is-now-massive), and existing Polygon.io keys remain valid.

This guide will show you how to get it.

### Prerequisites

- A Massive account. [Sign up](https://massive.com/dashboard/signup) if you don't have one; a free Basic account is enough to start.

### Step 1: Create an API key

1. [Log in](https://massive.com/dashboard/login) to Massive and click **Keys** in the dashboard sidebar.
2. Click **New key**. The key is created right away and its details page opens.

<img src="/api-integrations/polygon/keys_page_new_key.png" alt="Massive dashboard Keys page with the New key button highlighted"/>

3. Optionally, click **Update** next to **Name**, enter a name that says where the key will be used, and click **Save**.
4. Click **Copy** next to **API Key** to copy the key.

<img src="/api-integrations/polygon/api_key_created.png" alt="Massive API key details page with the Copy button next to the API Key highlighted"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Polygon.
2. Paste the key you copied in Step 1 into the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/polygon/form.png" alt="Polygon Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Polygon.
