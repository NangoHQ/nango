## Overview

To connect AssemblyAI, you need an **API Key** from your AssemblyAI dashboard and the **API Hostname** for your chosen region.

### Prerequisites

- An AssemblyAI account. Sign up with AssemblyAI if you do not have one.

### Step 1: Find your API key

1. Sign in to your AssemblyAI dashboard.
2. Copy your API key.

### Step 2: Choose your API region

| Region       | API Hostname            |
| ------------ | ----------------------- |
| US (default) | `api.assemblyai.com`    |
| EU           | `api.eu.assemblyai.com` |

Select the region you want this connection to use.

### Step 3: Enter your details in the Connect UI

1. Open the form where you need to authenticate with AssemblyAI.
2. Enter your **API Key** as it appears in the dashboard. Do not add a `Bearer` prefix.
3. Confirm the **API Hostname**. The form selects `api.assemblyai.com` by default; choose `api.eu.assemblyai.com` for the EU.
4. Submit the form.

<img src="/api-integrations/assemblyai/form.png" alt="Nango Connect UI form for entering an AssemblyAI API key and API hostname" style={{maxWidth: "450px" }}/>

You are now connected to AssemblyAI.
