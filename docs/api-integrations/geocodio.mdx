## 🚀 Quickstart

Connect to Geocodio with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Geocodio_.
    </Step>
    <Step id="authorize-geocodio" title="Authorize Geocodio">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then choose your region and enter your Geocodio API key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-geocodio-api" title="Call the Geocodio API">
    Let's make your first request to the Geocodio API to geocode an address. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/v2.1/geocode?q=1109+N+Highland+St%2C+Arlington+VA&limit=1" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/v2.1/geocode',
            params: { q: '1109 N Highland St, Arlington VA', limit: '1' },
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- Nango sends the key in the `Authorization: Bearer` header on every call. Calls that need it as the `api_key` query parameter can read it from the connection's credentials (`credentials.apiKey`) and pass it as the Geocodio docs show.
