## Overview

To authenticate with Bouncer, you need:
1. **API Key** - A key generated from the API page of your Bouncer dashboard.

This guide will walk you through generating your **API Key** within Bouncer.

### Prerequisites

- An active Bouncer account.

### Instructions

#### Step 1: Generate your Bouncer API key

1. Log in to your [Bouncer](https://app.usebouncer.com/login) account.
2. Click **API** in the left-side menu.
3. Click **Generate API Key**.
4. Copy the key.

#### Step 2: Enter your API key in the Connect UI

Once you have your **API Key**:

1. Open the form where you need to authenticate with Bouncer.
2. Enter your **API Key** in the field.
3. Submit the form, and you should be successfully authenticated.

You are now connected to Bouncer.
