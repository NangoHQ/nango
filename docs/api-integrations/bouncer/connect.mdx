## Overview

To authenticate with Bouncer, you need:

1. **API Key** — an API key from your Bouncer account.

This guide will show you how to get it.

### Prerequisites

- A Bouncer account. New accounts get 100 free credits: [sign up](https://app.usebouncer.com/signup).

### Step 1: Generate an API key

1. Sign in to [Bouncer](https://app.usebouncer.com/login).
2. Click **API** in the left-side menu.
3. Under **API Keys**, click **Generate API Key**. Bouncer creates the key right away.
4. Click the copy icon next to the key to copy it.

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Bouncer.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/bouncer/form.png" alt="The Bouncer connection form in the Nango Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to Bouncer.
