## Overview

To authenticate with DeepSeek, you need:

1. **API Key** — a DeepSeek API key.

This guide will show you how to get it.

### Prerequisites

- A DeepSeek platform account. You can [sign up](https://platform.deepseek.com/sign_up) on the DeepSeek platform.
- An account balance. DeepSeek deducts API usage from your topped-up or granted balance. See [Models & Pricing](https://api-docs.deepseek.com/quick_start/pricing).

### Step 1: Create an API key

1. Log in to the [DeepSeek platform](https://platform.deepseek.com/).
2. Open the [API keys](https://platform.deepseek.com/api_keys) page.
3. Create a new API key and copy it.
4. If your account has no balance, top it up on the **Top up** page.

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with DeepSeek.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/deepseek/form.png" alt="DeepSeek connection form in the Nango Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to DeepSeek.
