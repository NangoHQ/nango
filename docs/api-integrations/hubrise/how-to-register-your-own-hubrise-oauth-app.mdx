This guide shows you how to create an OAuth 2.0 client in HubRise to get OAuth credentials (client ID & secret).

<Steps>
  <Step title="Create an OAuth 2.0 client">
    1. Log in to the [HubRise back office](https://manager.hubrise.com) (create a free test account if needed).
    2. Go to **SETTINGS** > **DEVELOPER** and click **Create an OAuth 2.0 client**.
    3. Enter a name for your client, usually your app name, and click **Create**.
    4. Download the client secret JSON: it holds the `client_id` and `client_secret`.
  </Step>
  <Step title="Add the credentials in Nango">
    Paste the client ID and secret into your HubRise integration in Nango, and add the scopes your app needs (see [OAuth scopes](https://www.hubrise.com/developers/api/authentication)). Write a scope as in HubRise, for example `location[orders.write,customer_list.read,catalog.read]`.
  </Step>
  <Step title="Next">
    Follow the [_Quickstart_](/getting-started/quickstart).
  </Step>
</Steps>

HubRise access tokens do not expire, so there is no refresh. Nango stores the `account_id`, `location_id`, `catalog_id` and `customer_list_id` returned with the token in the connection config. For more details, see [HubRise API authentication](https://www.hubrise.com/developers/api/authentication).
