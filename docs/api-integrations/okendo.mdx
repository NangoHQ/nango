## 🚀 Quickstart

Connect to Okendo with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Okendo_.
    </Step>
    <Step id="authorize-okendo" title="Authorize Okendo">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your User ID and API Key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-okendo-api" title="Call the Okendo API">
    Let's make your first request to the Okendo API to list your published reviews. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/reviews" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/reviews',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- Nango sends `okendo-api-version: 2025-02-01` on every call. To use another API version, pass `version` under `integrations_config_defaults.<INTEGRATION-ID>.connection_config` when creating a Connect session; this automated field does not appear in the Connect UI. When it is unset, `2025-02-01` applies.
