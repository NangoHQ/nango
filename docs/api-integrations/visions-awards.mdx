## 🚀 Quickstart

Connect to Visions Awards with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Visions Awards_.
    </Step>
    <Step id="authorize-visions-awards" title="Authorize Visions Awards">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your Visions Awards API client ID and client secret. Nango exchanges them for an access token and gets a new one when it expires. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-visions-awards-api" title="Call the Visions Awards API">
    Let's make your first request to the Visions Awards API to list the sales orders waiting for a proof decision (status `F`). Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/api/jobs?status=F" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/api/jobs',
            params: { status: 'F' },
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- A job is identified by its sales order number, and some endpoints also take the secondary work order key after a comma in the same path segment (`/api/jobs/{id},{key2}`).
