## Overview

To authenticate with Financial Modeling Prep, you need:

1. **API Key** — the API key from your Financial Modeling Prep dashboard.

This guide will show you how to get it.

### Prerequisites

- A Financial Modeling Prep account. [Sign up](https://site.financialmodelingprep.com/register) for free; no card is required. The free plan allows 250 API calls per day; paid plans allow more.

### Step 1: Copy your API key

1. Sign in to [Financial Modeling Prep](https://site.financialmodelingprep.com/login).
2. Click **Dashboard** in the top-right corner, or go to the [dashboard](https://site.financialmodelingprep.com/developer/docs/dashboard) directly.

<img src="/api-integrations/financial-modeling-prep/open_dashboard.png" alt="Financial Modeling Prep page header with the Dashboard button in the top-right corner highlighted"/>

3. In the **API Key** section, click the copy button next to your key.

<img src="/api-integrations/financial-modeling-prep/copy_api_key.png" alt="Financial Modeling Prep dashboard with the copy button in the API Key section highlighted"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Financial Modeling Prep.
2. Enter your API key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/financial-modeling-prep/form.png" alt="Financial Modeling Prep Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Financial Modeling Prep.
