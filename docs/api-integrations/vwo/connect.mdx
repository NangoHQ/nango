## Overview

To authenticate with Wingify (VWO), you need:

1. **API Token** — a Wingify API token.

This guide will show you how to get it.

### Prerequisites

- A Wingify account on the Enterprise plan. API access is only available on this plan.

### Step 1: Generate an API token

1. Sign in to Wingify and open the [API tokens page](https://app.wingify.com/#/developers/tokens).
2. Click **Add another API token**, then select the permission level your integration needs. See [Roles and Permissions in Wingify](https://help.wingify.com/hc/en-us/articles/58759151167769) for what each level allows.

<img src="/api-integrations/vwo/create_api_key.png"/>

3. Copy the token.

### Step 2: Enter your API token in the Connect UI

1. Open the form where you need to authenticate with Wingify (VWO).
2. Enter your **API Token** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/vwo/form.png" style={{maxWidth: "450px" }}/>

You are now connected to Wingify (VWO).
