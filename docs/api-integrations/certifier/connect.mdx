## Overview

To authenticate with Certifier, you need:

1. **Access Token** — a Certifier access token for your workspace.

This guide will show you how to generate it.

### Prerequisites

- A Certifier account. The API is included in the free Starter plan; see [Certifier pricing](https://certifier.io/pricing) to sign up.

### Step 1: Generate an access token

1. [Log in](https://app.certifier.io) to the Certifier dashboard and go to **Settings** -> **Developers** -> **Access Tokens** ([Access Tokens page](https://app.certifier.io/settings/workspace/developers/access-tokens)).
2. Click **Generate Access Token**.

<img src="/api-integrations/certifier/access_tokens_page.png" alt="Certifier Access Tokens settings page with the Generate Access Token button highlighted"/>

3. Enter a descriptive name in the **Access Token Name** field, then click **Continue**.

<img src="/api-integrations/certifier/generate_access_token_dialog.png" alt="Certifier Generate Access Token dialog with a token name entered and the Continue button highlighted"/>

4. In the **Your Access Token** dialog, click **Copy Token** and store the token somewhere safe. Certifier will not show it again.

<img src="/api-integrations/certifier/access_token_created.png" alt="Certifier Your Access Token dialog with the Copy Token button highlighted"/>

### Step 2: Enter your access token in the Connect UI

1. Open the form where you need to authenticate with Certifier.
2. Enter your **Access Token** in the designated field.
3. Click **Connect**.

<img src="/api-integrations/certifier/form.png" alt="Nango Connect UI form for entering the Certifier Access Token" style={{maxWidth: "450px" }}/>

You are now connected to Certifier.
