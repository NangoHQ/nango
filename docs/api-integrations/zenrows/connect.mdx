## Overview

To authenticate with Zenrows, you need:

1. **API Key** - A Zenrows API key that lets Nango call the Zenrows API on behalf of your account.

This guide will show you how to create one.

### Prerequisites

- A Zenrows account. Every new account starts on the Free plan, no credit card required; you can [sign up here](https://app.zenrows.com/register?p=free).

### Step 1: Create an API key

1. Log in to [Zenrows](https://app.zenrows.com/login) and go to [**Settings** -> **API Keys**](https://app.zenrows.com/settings/api-keys).
2. Click **Add key**.

<img src="/api-integrations/zenrows/api_keys_page.png" alt="Add key button on the Zenrows API Keys settings page"/>

3. Enter a name for the key (for example, `nango`) and click **Create key**.

<img src="/api-integrations/zenrows/create_api_key_dialog.png" alt="Create API key dialog with a key name and the Create key button"/>

4. Copy the key from the **Copy your new key** dialog, then click **Done**. The key is shown in full only once.

<img src="/api-integrations/zenrows/copy_new_api_key.png" alt="Copy your new key dialog showing the new Zenrows API key"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Zenrows.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/zenrows/form.png" alt="Zenrows connection form in Nango's Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to Zenrows.
