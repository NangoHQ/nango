## Overview

To authenticate with MxToolbox, you need:

1. **API Key** — your MxToolbox API key.

This guide will show you how to get it.

### Prerequisites

- An MxToolbox account. [Create a free account](https://mxtoolbox.com/public/registration.aspx?ReturnUrl=/api/api-reference) to receive your API key. Paid plans unlock higher request quotas, network lookups, and full monitor access.

### Step 1: Copy your API key

1. Log in to [MxToolbox](https://mxtoolbox.com).
2. Click your email address in the top right corner to open the account menu, then click **Settings**.
3. Open the **API** tab, or go straight to the [API page](https://mxtoolbox.com/user/api).

<img src="/api-integrations/mxtoolbox/open_account_menu.png" alt="MxToolbox settings with the account menu in the top right corner and the API tab"/>

4. Copy the API key from the field at the top of the page. MxToolbox creates the key for you, so there is nothing to generate.

<img src="/api-integrations/mxtoolbox/copy_api_key.png" alt="MxToolbox API page with the API key field above the daily API usage"/>

If your key is ever exposed, click **Revoke API Key** on the same page to replace it.

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with MxToolbox.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/mxtoolbox/form.png" alt="MxToolbox connection form in the Nango Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to MxToolbox.
