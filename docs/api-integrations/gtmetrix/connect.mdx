## Overview

To connect with GTmetrix, you need:

1. **API Key** — your GTmetrix API key.

### Prerequisites

- A GTmetrix account. You can [sign up](https://gtmetrix.com/) for free, no credit card required.

### Step 1: Generate your API key

1. Log in to GTmetrix and open the [Account](https://gtmetrix.com/dashboard/account#us-api) page.
2. Under **API Usage**, click **Generate API Key**.

<img
    src="/api-integrations/gtmetrix/generate_api_key.png"
    alt="GTmetrix Account page with the Generate API Key button highlighted under API Usage"
/>

3. Your API key appears under **API Usage**. Click **Copy to clipboard** to copy it.

<img
    src="/api-integrations/gtmetrix/api_key_created.png"
    alt="GTmetrix Account page showing the API key under API Usage with the Copy to clipboard button highlighted"
/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with GTmetrix.
2. Enter your **API Key**. There is no password field: GTmetrix authenticates with the API key alone.
3. Click **Connect**. Nango checks the key with GTmetrix before saving the connection.

<img src="/api-integrations/gtmetrix/form.png" alt="Nango Connect UI form for entering the GTmetrix API Key" style={{maxWidth: "450px" }}/>

You are now connected to GTmetrix.
