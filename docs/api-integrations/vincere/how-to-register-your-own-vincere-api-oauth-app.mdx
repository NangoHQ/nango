This guide shows you how to obtain your own Vincere OAuth credentials. These are required to let your users grant your app access to their Vincere account.

<Steps>
  <Step title="Confirm partner access">
    Vincere does not offer self-service OAuth app registration. Your integration must be on Vincere's approved partner list before credentials are issued.
  </Step>
  <Step title="Request your credentials">
    Vincere has no developer portal. Both the **Client ID** and the tenant **API Key** are issued by hand, through a single request to the [Vincere Support Team](https://help.vincere.io/en/articles/6959443-contact-vincere-support-and-book-training).

    Include in your request:
    - **Integration name** — how your app is identified to Vincere.
    - **Callback URL** — `https://api.nango.dev/oauth/callback`.
    - **Subdomain** — the tenant you are enabling, for example `mycompany` for `https://mycompany.vincere.io`.

    Vincere replies with a **Client ID** for the integration itself, and an **API Key** scoped to that one subdomain. The Client ID stays the same across customers; the API Key does not — each customer requests their own by following the [Vincere connect guide](/api-integrations/vincere/connect).
  </Step>
  <Step title="Configure the integration in Nango">
    Enter the **Client ID** in your Nango integration settings. Vincere's token endpoint does not use a client secret, so any placeholder value can be used for the client secret field. Your users supply their own **Subdomain** and **API Key** when they connect.
  </Step>
  <Step title="Next">
    Follow the [_Quickstart_](/getting-started/quickstart) to connect your first account.
  </Step>
</Steps>

For more details, see the [Vincere API documentation](https://api.vincere.io/).
