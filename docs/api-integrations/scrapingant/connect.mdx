## Overview

To authenticate with ScrapingAnt, you need:

1. **API Token** — the API token of your ScrapingAnt account.

This guide will show you how to find it.

### Prerequisites

- A ScrapingAnt account. The free plan includes API access: [sign up](https://app.scrapingant.com/signup).

### Step 1: Copy your API token

1. Sign in to [ScrapingAnt](https://app.scrapingant.com/login). You land on the **Dashboard**.
2. In the **Web Scraping API** card, click the copy icon next to the **API token** field.

<img src="/api-integrations/scrapingant/dashboard_api_token.png" alt="The API token field in the Web Scraping API card of the ScrapingAnt dashboard, with the copy icon highlighted"/>

You can also copy the same token from **Account security** on the [Profile](https://app.scrapingant.com/profile) page. Each account has one token. **Regenerate token** replaces it and stops the old token from working.

<img src="/api-integrations/scrapingant/profile_api_token.png" alt="The API token field under Account security on the ScrapingAnt Profile page, with the copy icon highlighted"/>

### Step 2: Enter your API token in the Connect UI

1. Open the form where you need to authenticate with ScrapingAnt.
2. Enter your **API Token** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/scrapingant/form.png" alt="The ScrapingAnt connection form in the Nango Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to ScrapingAnt.
