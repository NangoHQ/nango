## Overview

To authenticate with Bika.ai, you need:

1. **API Token** — a personal API token from your Bika.ai account settings.

This guide will show you how to create it.

### Prerequisites

- A Bika.ai account. If you don't have one, [sign up](https://bika.ai). The free plan includes API access.

### Step 1: Create an API token

1. Sign in to [Bika.ai](https://bika.ai).
2. Click your avatar in the lower-left corner, then select **My settings**.

<img src="/api-integrations/bika-ai/open_my_settings.png" alt="Bika.ai avatar menu with the My settings option" />

3. Under **Account**, open the **Developer** tab.
4. Under **Create token**, choose an **Expiration**, then click **Create**.

<img src="/api-integrations/bika-ai/developer_create_token.png" alt="Bika.ai Developer tab with the Expiration selector and the Create button" />

5. Your new token appears under **My tokens**. Click the **Copy** button next to it to copy the full token.

<img src="/api-integrations/bika-ai/copy_api_token.png" alt="Bika.ai My tokens list with the Copy button next to a token" />

### Step 2: Enter your API token in the Connect UI

1. Open the form where you need to authenticate with Bika.ai.
2. Enter your API token in the **API Token** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/bika-ai/form.png" alt="Bika.ai Connect UI form with the API Token field" style={{maxWidth: "450px" }}/>

You are now connected to Bika.ai.
