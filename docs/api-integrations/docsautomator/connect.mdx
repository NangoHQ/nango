## Overview

To authenticate with DocsAutomator, you need:

1. **API Key** — the API key of your DocsAutomator workspace.

This guide will show you where to find it.

### Prerequisites

- A DocsAutomator account. You can [sign up](https://app.docsautomator.co/signup) for free, with no credit card.

### Step 1: Copy your API key

1. Log in to [DocsAutomator](https://app.docsautomator.co/login).
2. In the left sidebar, click **Settings**.

<img src="/api-integrations/docsautomator/open_settings.png" alt="DocsAutomator sidebar with the Settings item highlighted"/>

3. Open the **API key** tab, or go to [app.docsautomator.co/settings/workspace/api](https://app.docsautomator.co/settings/workspace/api).
4. Click the eye icon next to the masked field to show your API key, then copy it.

<img src="/api-integrations/docsautomator/api_key_page.png" alt="DocsAutomator API key tab with the eye icon highlighted"/>

The API key is scoped to the workspace you are in.

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with DocsAutomator.
2. Paste your API key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/docsautomator/form.png" alt="DocsAutomator Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to DocsAutomator.
