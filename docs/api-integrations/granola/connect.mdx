## Overview

To authenticate with Granola, you will need:
1. **API Key** – Your Granola API key for authentication.

This guide will walk you through generating your **API key** in Granola.

### Prerequisites

- You must be on Granola's **Business** or **Enterprise** plan (API access is not available on the Free plan). Any workspace member on a Business plan can create an API key; on Enterprise, workspace admins control which access scopes members can use.

### Instructions

#### Step 1: Generating your Granola API key

1. Open the [Granola](https://granola.ai/) desktop app.
2. Navigate to **Settings** → **Connectors** → **API keys** (or **Workspace API keys**).
3. Click **Create new key** and choose the note access scopes the key should include (your own notes, workspace public notes, or both).
4. Click **Generate API Key** and store it securely.

#### Step 2: Enter credentials in the Connect UI

Once you have your **API Key**:
1. Open the form where you need to authenticate with Granola.
2. Enter your **API Key** in the respective field.
3. Submit the form, and you should be successfully authenticated.

You are now connected to Granola.
