## Overview

To authenticate with Adrapid, you need:

1. **API Token** — the API token from your Adrapid account page.

This guide will show you how to find it.

### Prerequisites

- An Adrapid account with API access. Adrapid's [pricing page](https://adrapid.com/pricing) lists the REST API under the Enterprise plan.

### Step 1: Copy your API token

1. Sign in to [Adrapid](https://app.adrapid.com).
2. Click your user name in the top right of the app to open the [account page](https://app.adrapid.com/account).

<img src="/api-integrations/adrapid/open_account_page.png" alt="Adrapid app with the user name in the top right highlighted"/>

3. In the **API Token** section, click the copy button next to the **Token** field. The refresh button beside it rotates the token.

<img src="/api-integrations/adrapid/copy_api_token.png" alt="Adrapid account page with the copy button in the API Token section highlighted"/>

### Step 2: Enter your API token in the Connect UI

1. Open the form where you need to authenticate with Adrapid.
2. Enter your API token in the **API Token** field.
3. Submit the form. Nango checks the token with Adrapid before saving the connection.

<img src="/api-integrations/adrapid/form.png" alt="Adrapid Connect UI form with the API Token field" style={{maxWidth: "450px" }}/>

You are now connected to Adrapid.
