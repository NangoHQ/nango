## 🚀 Quickstart

Connect to Short.io with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Short.io_.
    </Step>
    <Step id="authorize-short-io" title="Authorize Short.io">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your Short.io private API key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-short-io-api" title="Call the Short.io API">
    Let's make your first request to the Short.io API to list your domains. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/api/domains" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/api/domains',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-nango" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- Set `baseUrlOverride` to `https://statistics.short.io` for the Statistics API (`/statistics/...`); the connection keeps its API key. See [the Statistics API reference](https://developers.short.io/reference/getdomaindomainid).
