## 🚀 Quickstart

Connect to Short.io with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Short.io_.
    </Step>
    <Step id="authorize-short-io" title="Authorize Short.io">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your Short.io private API key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-short-io-api" title="Call the Short.io API">
    Let's make your first request to the Short.io API to list your domains. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/domains" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/domains',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-nango" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- Nango sends the key as-is in the `Authorization` header, with no `Bearer` prefix. See [How to use the Short.io API](https://docs.short.io/articles/api-reference/Technical%20questions/how-to-use-the-short.io-api).
- Nango's base URL for Short.io is `https://api.short.io/api`, which covers the endpoints the [API reference](https://developers.short.io/reference) lists under `/api`, such as `GET /api/domains` (call it as `/domains`). Most other endpoints, such as `POST /links`, sit at the root of `https://api.short.io`. To call them, set the `Base-Url-Override` header (or `baseUrlOverride` in the Node SDK) to `https://api.short.io`.
- The Statistics API is served from a different host, `https://statistics.short.io/statistics`, so it isn't reachable through the default base URL. See [the Statistics API reference](https://developers.short.io/reference/getdomaindomainid).
- Public keys can only create links. Use a private key for everything else. See [How to use the Short.io API](https://docs.short.io/articles/api-reference/Technical%20questions/how-to-use-the-short.io-api).
- The API allows 5 to 50 requests per second depending on the endpoint, 5 requests in 10 seconds for bulk create, and 60 requests per minute for statistics. Requests over the limit get a `429`; retry them later. See [API limits](https://docs.short.io/articles/api-reference/Technical%20questions/what-are-the-api-limits-on-short.io-orperformance).
