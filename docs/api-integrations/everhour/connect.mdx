## Overview

To authenticate with Everhour, you need:

1. **API Token** — the personal API token of your Everhour user.

This guide will show you how to find it.

### Prerequisites

- An [Everhour](https://everhour.com) account. Each user has one token, and it has the same permissions as that user's role.

### Step 1: Copy your API token

1. Sign in to [Everhour](https://app.everhour.com).
2. Click **Settings** in the left sidebar, then open the [**My Profile**](https://app.everhour.com/#/account/profile) tab.

<img src="/api-integrations/everhour/profile_settings_page.png" alt="Everhour Settings page with the My Profile tab open"/>

3. Scroll down to the **Application Access** section and copy the value of the **API Token** field. Only click **Reset Token** if you want to replace the token.

<img src="/api-integrations/everhour/api_token_field.png" alt="Everhour Application Access section with the API Token field and the Reset Token link"/>

### Step 2: Enter your API token in the Connect UI

1. Open the form where you need to authenticate with Everhour.
2. Paste the token you copied in Step 1 into the **API Token** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/everhour/form.png" alt="Everhour Connect UI form with the API Token field" style={{maxWidth: "450px" }}/>

You are now connected to Everhour.
