## 🚀 Quickstart

Connect to AltTextLab with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _AltTextLab_.
    </Step>
    <Step id="authorize-alttextlab" title="Authorize AltTextLab">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your AltTextLab API key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-alttextlab-api" title="Call the AltTextLab API">
    Let's make your first request to the AltTextLab API to generate alt text for a public image. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl -X POST "https://api.nango.dev/proxy/api/v1/alt-text/generate" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>" \
              -H "Content-Type: application/json" \
              -d '{"imageUrl": "https://raw.githubusercontent.com/NangoHQ/nango/master/docs/images/readme/overview.png"}'
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.post({
            endpoint: '/api/v1/alt-text/generate',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>',
            data: {
                imageUrl: 'https://raw.githubusercontent.com/NangoHQ/nango/master/docs/images/readme/overview.png'
            }
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>
