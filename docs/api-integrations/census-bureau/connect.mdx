## Overview

To authenticate with the Census Bureau, you need:

1. **API Key** — a Census Data API key.

This guide will show you how to get it. The key is free.

### Step 1: Requesting your API key

1. Open the [Census Data API key request page](https://api.census.gov/data/key_signup.html).
2. Enter your organization name and your email address. The email address must end in `.com`, `.net`, `.org`, `.gov` or `.edu`.
3. Check **I agree to the terms of service** and click **Request Key**.

<img src="/api-integrations/census-bureau/request_api_key.png" alt="Census Data API key request form with the Request Key button highlighted"/>

4. Open the email you receive from the Census Bureau. It contains your API key and a link to activate it.
5. Click the activation link. A success page confirms that your key has been activated.

<img src="/api-integrations/census-bureau/key_activated.png" alt="Census success page confirming that the API key has been activated"/>

6. Copy the API key from the email.

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with the Census Bureau.
2. Paste the key you copied in Step 1 into the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/census-bureau/form.png" alt="Census Bureau Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to the Census Bureau.
