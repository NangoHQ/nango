## Overview

To authenticate with JustCall, you need:

1. **API Key** - The API key of your JustCall account.
2. **API Secret** - The API secret shown next to the API key.

This guide will show you where to find both.

### Prerequisites

- A JustCall account. If you don't have one, [sign up](https://justcall.io/signup).
- The **Account Owner** or **Admin** role: only they can see the API key and secret.
- A plan with API access: JustCall's developer docs say API access is available starting from the Team plan.

### Step 1: Copy your API key and API secret

1. Log in to [JustCall](https://app.justcall.io/login).
2. Click your profile icon, then click **APIs and Webhooks** ([direct link](https://app.justcall.io/app/developersApiCredentials)).
3. In the **API Credentials** section, click the copy button next to the **API Key**.
4. Click the eye icon next to the **API Secret** to reveal it, then click its copy button.

### Step 2: Enter your credentials in the Connect UI

1. Open the form where you need to authenticate with JustCall.
2. Paste your API key in the **API Key** field.
3. Paste your API secret in the **API Secret** field.
4. Submit the form, and you should be successfully authenticated.

You are now connected to JustCall.
