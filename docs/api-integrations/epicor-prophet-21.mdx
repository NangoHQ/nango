## 🚀 Quickstart

Connect to Epicor Prophet 21 with Nango and see data flow in 2 minutes.

<Note>
Each Prophet 21 customer runs its own P21 server, so every connection specifies the hostname of that server, plus the username and password of the P21 user the integration acts as.
</Note>

<Steps>
    <Step title="Create the integration" id="create-integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Epicor Prophet 21_.
    </Step>
    <Step title="Authorize Epicor Prophet 21" id="authorize-epicor-prophet-21">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your P21 server hostname, username, and password. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step title="Call the Epicor Prophet 21 API" id="call-epicor-prophet-21-api">
    Let's make your first request to the P21 API to read one supplier through the OData API. The P21 user needs access to the `supplier` table (see [the connect guide](/api-integrations/epicor-prophet-21/connect#step-2-set-up-a-p21-api-user)). Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/odataservice/odata/table/supplier?\$top=1" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/odataservice/odata/table/supplier',
            params: { $top: '1' },
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step title="Implement Nango in your app" id="implement-in-app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>
