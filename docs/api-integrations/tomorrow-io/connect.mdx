## Overview

To authenticate with Tomorrow.io, you need:

1. **API Key** — a Tomorrow.io API key.

This guide will show you how to get it.

### Prerequisites

- A Tomorrow.io account. The free plan includes API access; you can [sign up here](https://app.tomorrow.io/signup).

### Step 1: Copy your API key

1. Sign in to the [Tomorrow.io app](https://app.tomorrow.io/signin).
2. In the left sidebar, click **Keys** to open the [API Management page](https://app.tomorrow.io/development/keys).
3. In the keys table, find your key (the default one is named **My API Key**) and click the copy icon next to it.

<img src="/api-integrations/tomorrow-io/keys_page_copy_api_key.png" alt="Tomorrow.io API Management page with the copy icon next to My API Key highlighted"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Tomorrow.io.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/tomorrow-io/form.png" alt="Tomorrow.io Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Tomorrow.io.
