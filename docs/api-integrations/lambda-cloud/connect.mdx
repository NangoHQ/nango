## Overview

To connect with Lambda Cloud, you need:

1. **API Key** – A Lambda Cloud API key, sent as a Bearer token.

This guide walks you through generating one.

### Prerequisites

- A [Lambda Cloud](https://lambda.ai) account.

### Instructions

#### Step 1: Generate an API key

1. Log in to the Lambda Cloud dashboard and open the [API keys page](https://cloud.lambda.ai/api-keys).
2. Generate a new API key and give it a name.
3. Copy the key and store it securely. It is only shown once.

<Tip>Keep your API key secret. It can launch and terminate billable instances on your Lambda Cloud account.</Tip>

#### Step 2: Authorize in Nango

1. Open the Nango Connect form.
2. Enter your **API Key** in the field provided.
3. Submit the form, and you should be successfully authenticated.

You are now connected to Lambda Cloud.
