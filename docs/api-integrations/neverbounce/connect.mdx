## Overview

To authenticate with NeverBounce, you need:

1. **API Key** — the API key of a NeverBounce Custom Integration app.

This guide will show you how to get it.

### Prerequisites

- A NeverBounce account. You can [sign up for free](https://app.neverbounce.com/register).
- A verified email address: click the link in NeverBounce's welcome email, otherwise API features stay locked.

### Step 1: Create a Custom Integration app

1. Log in to your [NeverBounce account](https://app.neverbounce.com/login).
2. Click **API** in the left sidebar to open the **Integrations** page.
3. Under **Code**, click **Create New** on the **Custom Integration** card. The app is created and its overview page opens.

<img src="/api-integrations/neverbounce/api_apps_custom_integration.png" alt="NeverBounce Integrations page with the Create New button on the Custom Integration card"/>

4. Optional: click the pencil icon next to the app name to rename it, then click **Save**.

### Step 2: Copy your API key

1. On the app's **API Key Setup** tab, under **Your API Key**, click **Copy**.

<img src="/api-integrations/neverbounce/custom_integration_api_key.png" alt="NeverBounce Custom Integration app overview with the Copy button next to Your API Key"/>

To rotate the key later, click **Reset** in the same section.

### Step 3: Enter your credentials in the Connect UI

1. Open the form where you need to authenticate with NeverBounce.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/neverbounce/form.png" alt="NeverBounce connection form in the Nango Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to NeverBounce.
