## 🚀 Quickstart

Connect to Bugsnag with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Bugsnag_.
    </Step>
    <Step id="authorize-bugsnag" title="Authorize Bugsnag">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your API host and personal auth token. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-bugsnag-api" title="Call the Bugsnag API">
    Let's make your first request to the Bugsnag Data Access API to list your organizations. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/user/organizations" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/user/organizations',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- Nango sends `x-version: 2` on every call. To use another API version, pass `version` under `integrations_config_defaults.<INTEGRATION-ID>.connection_config` when creating a Connect session. This field isn't shown in the Connect UI. When it is unset, `2` applies.
