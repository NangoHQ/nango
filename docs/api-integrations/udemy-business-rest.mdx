## 🚀 Quickstart

Connect to Udemy Business (REST) with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Udemy Business (REST)_.
    </Step>
    <Step id="authorize-udemy-business-rest" title="Authorize Udemy Business (REST)">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your Udemy Business subdomain, your account ID, and the Client ID and Client Secret of a REST API client. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-udemy-business-rest-api" title="Call the Udemy Business REST API">
    Let's make your first request to the Udemy Business REST API to list courses. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, connection ID, and Udemy Business account ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/api-2.0/organizations/<ACCOUNT-ID>/courses/list/?page_size=10" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/api-2.0/organizations/<ACCOUNT-ID>/courses/list/?page_size=10',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Nango sends the client ID and secret with HTTP Basic authentication on every request.

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- Every REST path includes your account ID, such as `/api-2.0/organizations/<ACCOUNT-ID>/courses/list/`. It's saved in the connection config as `organization_id`.
- The REST API uses a separate API client from the GraphQL API. For the GraphQL API, use the [Udemy Business](/api-integrations/udemy-business) integration.
- Udemy refreshes its Reporting API data at most three times a day.
- The Udemy Business APIs are available on the Enterprise plan.
