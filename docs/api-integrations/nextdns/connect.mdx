## Overview

To authenticate with NextDNS, you need:

1. **API Key** — the API key of your NextDNS account.

This guide will show you how to get it.

### Prerequisites

- A NextDNS account. If you don't have one, [sign up](https://my.nextdns.io/signup). The API is available on the Free plan.

### Step 1: Generate your API key

1. Sign in to [NextDNS](https://my.nextdns.io/login). Click your email address in the top-right corner, then click **Account**.

<img src="/api-integrations/nextdns/open_account_menu.png" alt="NextDNS dashboard with the account menu open and the Account item highlighted"/>

2. On the **Account** page, scroll to the **API** section at the bottom and click **Generate API key**.

<img src="/api-integrations/nextdns/generate_api_key.png" alt="NextDNS Account page with the Generate API key button in the API section"/>

3. Copy the API key with the copy button.

<img src="/api-integrations/nextdns/copy_api_key.png" alt="NextDNS Account page showing the generated API key and its copy button"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with NextDNS.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/nextdns/form.png" alt="NextDNS Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to NextDNS.
