This guide shows you how to register a Webflow app and obtain your OAuth credentials (client ID & secret). These are required to let your users grant your app access to their Webflow site data.

## Registering a Webflow app

<Steps>
  <Step title="Open the Webflow Dashboard">
    Log in to Webflow and go to your Dashboard, then select the Workspace you want to register the app under. You need Admin permissions on that Workspace — only Workspace admins can create apps, view client secrets, and modify app settings. It's recommended to use a dedicated development Workspace to keep apps separate from production sites.
  </Step>
  <Step title="Start the app registration">
    From the Workspace **Settings** menu, go to **Apps & Integrations** > **App Development**, then click **Create an App**.
  </Step>
  <Step title="Add app details">
    Enter the app's Name, Description (140 characters max), Icon, and a valid HTTPS Homepage URL.
  </Step>
  <Step title="Configure the Data Client capability">
    Click **Continue**, then under App Capabilities select **Data Client** — this is what enables OAuth access to site data via the Webflow Data API. In the OAuth configuration:
    - Set the Redirect URL to `https://api.nango.dev/oauth/callback`.
    - Select the scopes your integration needs. For the full list, see [Webflow's OAuth scopes documentation](https://docs.developers.webflow.com/data/reference/scopes).

    Click **Create app** to finish registration.
  </Step>
  <Step title="Copy your credentials">
    On the app's page, copy the **Client ID** and **Client Secret** — you'll enter these when configuring your integration in Nango.
  </Step>
</Steps>

<Note>
New apps are only available to users in your app's own Workspace. External users can't install it until it's approved and published in the Webflow Marketplace — see [Register an App](https://docs.developers.webflow.com/docs/register-an-app) for testing with external users before submission.
</Note>

You're now ready to integrate Webflow with Nango. For more details, see the [Webflow API documentation](https://docs.developers.webflow.com/data/reference/rest-introduction).
