## Overview

To authenticate with Dovetail, you need:

1. **API Key** — a Dovetail personal API key.

This guide will show you how to get it.

### Prerequisites

- A Dovetail account. You can [start a free 30-day trial](https://dovetail.com/pricing/) of Dovetail One Gold.

### Step 1: Create a personal API key

1. Sign in to Dovetail and go to [Settings → Account](https://dovetail.com/settings/user/account).
2. Find **Personal API keys** and click **Create key**.

<img src="/api-integrations/dovetail/personal_api_keys_create.png" alt="Dovetail Settings Account page with the Create key button under Personal API keys"/>

3. Enter a label, choose how long the key lasts under **Expires after**, and choose an **Access level** (for example **Read only**). Then click **Create**.

<img src="/api-integrations/dovetail/create_personal_api_key_dialog.png" alt="Dovetail Create personal API key dialog with a label, the Expires after option and the Read only access level"/>

4. Copy the key straight away. It is shown only once.

<img src="/api-integrations/dovetail/personal_api_key_created.png" alt="Dovetail Save your API key dialog with the copy button next to the new key"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Dovetail.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/dovetail/form.png" alt="Dovetail connection form in the Nango Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to Dovetail.
