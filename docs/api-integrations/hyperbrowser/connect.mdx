## Overview

To authenticate with Hyperbrowser, you need:

1. **API Key** — an API key from your Hyperbrowser settings.

This guide will show you how to get it.

### Prerequisites

- A Hyperbrowser account. You can sign up for free at [app.hyperbrowser.ai](https://app.hyperbrowser.ai/signup).

### Step 1: Create an API key

1. Sign in to the [Hyperbrowser dashboard](https://app.hyperbrowser.ai).
2. In the left sidebar, click **Settings**, then open the **API Keys** tab.
3. Click **Generate key**.

<img src="/api-integrations/hyperbrowser/api_keys_settings.png" alt="Hyperbrowser API Keys settings tab with the Generate key button"/>

4. Enter a name for the key. Leave **Restrict key access** off so the key can use every API feature, then click **Create key**.

<img src="/api-integrations/hyperbrowser/create_api_key_dialog.png" alt="Add a new API key dialog with the key name field and Create key button"/>

5. Click the copy icon to copy your API key. It starts with `hb_` and is shown only once, so store it somewhere safe.

<img src="/api-integrations/hyperbrowser/api_key_created.png" alt="Save your API key dialog with the copy button next to the new key"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Hyperbrowser.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/hyperbrowser/form.png" alt="Hyperbrowser Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Hyperbrowser.
