## Overview

To authenticate with College Football Data, you need:

1. **API Key** — your College Football Data API key.

This guide will show you how to get it.

### Prerequisites

- An email address. You request a free API key with a short form and it is sent to your inbox; no account is needed. Higher limits are available through the [API tiers](https://collegefootballdata.com/api-tiers).

### Step 1: Request your API key

1. Open the [CFBD API Keys](https://collegefootballdata.com/key) page.
2. Enter your email address in the **Email Address** field and choose your **Primary use**.
3. Click **Submit**.

<img src="/api-integrations/college-football-data/request_api_key_form.png" alt="College Football Data API key request form with the Email Address and Primary use fields and the Submit button"/>

4. Open the **CFBD API Key Request** email sent to your inbox and copy the API key under **Your API key has been generated:**. The email can take a few minutes to arrive.

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with College Football Data.
2. Enter your API key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/college-football-data/form.png" alt="College Football Data Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to College Football Data.
