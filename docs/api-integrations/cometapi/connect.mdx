## Overview

To authenticate with CometAPI, you need:

1. **API Key** — a CometAPI API key.

This guide will show you how to get it.

### Prerequisites

- A CometAPI account. You can [sign up for free](https://www.cometapi.com/console/login) with Google, GitHub or your email.

### Step 1: Create an API key

1. Sign in to the [CometAPI console](https://www.cometapi.com/console/login).
2. In the sidebar, open **API Keys**, then click **Create API Key**.

<img src="/api-integrations/cometapi/api_keys_page.png" alt="API Keys page in the CometAPI console with the Create API Key button"/>

3. Enter a name for the key. Keep **Unlimited Quota** on, or turn it off to set a spending cap, then click **Create**.

<img src="/api-integrations/cometapi/create_key_dialog.png" alt="Create a Key dialog in the CometAPI console with the Name field and Unlimited Quota toggle"/>

4. Click **Copy** to copy the new key. CometAPI shows it only once.

<img src="/api-integrations/cometapi/api_key_created.png" alt="API Key Created dialog in the CometAPI console with the Copy button"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with CometAPI.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/cometapi/form.png" alt="CometAPI connection form in the Nango Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to CometAPI.
