## Overview

To authenticate with Demio, you need:

1. **API Key** - the API key of your Demio account.
2. **API Secret** - the API secret of your Demio account.

This guide will show you where to find both.

### Prerequisites

- A Demio account. If you don't have one, start a free trial at [my.demio.com/trial](https://my.demio.com/trial) (no credit card required).
- You must be the account Owner: only account owners have access to the Account Settings, where the API details are.

### Step 1: Open the API tab in Settings

1. Log in to [Demio](https://my.demio.com/login) as the account Owner.
2. Click your name in the top right, then click **Settings**.
3. Open the **API** tab.

<img src="/api-integrations/demio/settings_api_tab.png" alt="Demio Settings page with the API tab highlighted"/>

### Step 2: Copy your API Key and API Secret

In the **API Details** section, copy the **API Key** and the **API Secret**. Demio creates both with your account, so there is nothing to generate.

<img src="/api-integrations/demio/api_key_and_secret.png" alt="Demio API Details section with the API Key and API Secret fields highlighted"/>

### Step 3: Enter your credentials in the Connect UI

1. Open the form where you need to authenticate with Demio.
2. Enter the **API Key** value in the **API Key** field.
3. Enter the **API Secret** value in the **API Secret** field.
4. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/demio/form.png" alt="Demio Connect UI form with the API Key and API Secret fields" style={{maxWidth: "450px" }}/>

You are now connected to Demio.
