## Overview

To authenticate with Holiday API, you need:

1. **API Key** — the API key shown in your Holiday API dashboard.

This guide will show you how to get it.

### Prerequisites

- A Holiday API account. [Sign up](https://holidayapi.com/signup) for free: the free Developer plan includes 10,000 requests a month for last year's data, for non-commercial use. Paid plans add commercial use and every year.

### Step 1: Copy your API key

1. Sign in to Holiday API and open your [dashboard](https://holidayapi.com/dashboard).
2. Under **My Account** > **API Key**, click **Copy**.

<img src="/api-integrations/holiday-api/dashboard_api_key_copy.png" alt="Holiday API dashboard showing the API Key section of My Account with its Copy button"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Holiday API.
2. Paste the key you copied in Step 1 into the **API Key** field.
3. Submit the form. Nango checks the key with Holiday API and rejects it if it is invalid.
