## Overview

To authenticate with Holiday API, you will need:
1. **API Key** - Your Holiday API key.

This guide will help you find your Holiday API key.

### Prerequisites:

- You must have a Holiday API account. [Sign up here](https://holidayapi.com/signup) if you don't have one.

### Instructions:

#### Step 1: Copy your API key

1. Log in to your [Holiday API dashboard](https://holidayapi.com/login).
2. In the **My Account** section of the dashboard, click **Copy** next to your API key.

<Tip>You can create additional API keys in the **My Account** section of your dashboard. Using a dedicated API key for Nango lets you revoke it without affecting your other integrations.</Tip>

#### Step 2: Enter credentials in the Connect UI

Once you have your **API Key**:
1. Open the form where you need to authenticate with Holiday API.
2. Enter your API key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/holiday-api/form.png" style={{maxWidth: "450px" }}/>

You are now connected to Holiday API.
