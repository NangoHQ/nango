## Overview

To authenticate with Agenty, you need:

1. **API Key** — an API key from your Agenty account.

This guide will show you how to get it.

### Prerequisites

- An Agenty account. [Sign up](https://cloud.agenty.com/signup) if you don't have one.

### Step 1: Create an API key

1. Log in to [Agenty](https://cloud.agenty.com/). In the left sidebar, open **Settings** and click **API Keys**.

<img src="/api-integrations/agenty/settings_api_keys_menu.png" alt="Agenty sidebar with Settings open and API Keys highlighted"/>

2. On the **API Keys** page, click **Create API Key**. If an **Upgrade to Premium** popup appears, close it and click **Create API Key** again.

<img src="/api-integrations/agenty/create_api_key_button.png" alt="Agenty API Keys page with the Create API Key button highlighted"/>

3. Enter a **Key Name** and click **Create**.

<img src="/api-integrations/agenty/create_api_key_dialog.png" alt="Agenty Create API Key dialog with a key name entered and the Create button highlighted"/>

4. Click the copy button next to your new key to copy the full API key.

<img src="/api-integrations/agenty/api_key_created.png" alt="Agenty API Keys page showing the new key with its copy button highlighted"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Agenty.
2. Enter your key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/agenty/form.png" alt="Agenty Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Agenty.
