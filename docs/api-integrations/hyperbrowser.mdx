## 🚀 Quickstart

Connect to Hyperbrowser with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Hyperbrowser_.
    </Step>
    <Step id="authorize-hyperbrowser" title="Authorize Hyperbrowser">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your Hyperbrowser API key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-hyperbrowser-api" title="Call the Hyperbrowser API">
    Let's make your first request to the Hyperbrowser API to list your browser sessions. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/api/sessions" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/api/sessions',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- Hyperbrowser's hosted MCP server is on the fixed host `https://mcp.hyperbrowser.ai` (path `/mcp`), and takes the same API key. Send MCP calls through this connection with `baseUrlOverride` set to `https://mcp.hyperbrowser.ai`. See [Model Context Protocol](https://hyperbrowser.ai/docs/integrations/model-context-protocol).
- Nango sends the key in the `x-api-key` header on every call. Calls that need it another way (`Authorization: Bearer` on the MCP server) can read it from the connection's credentials (`credentials.apiKey`) and pass it as the docs show.
