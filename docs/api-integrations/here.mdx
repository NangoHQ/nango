## 🚀 Quickstart

Connect to HERE with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _HERE_.
    </Step>
    <Step id="authorize-here" title="Authorize HERE">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your HERE API key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-here-api" title="Call the HERE API">
    Let's make your first request to the HERE Geocoding & Search API: geocode `Berlin`. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/v1/geocode?q=Berlin&limit=1" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/v1/geocode',
            params: { q: 'Berlin', limit: '1' },
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- Geocoding & Search endpoints other than `/v1/geocode` are on their own hosts, such as `https://discover.search.hereapi.com` for `/v1/discover`. Calls to them set `baseUrlOverride` to that host; Nango keeps the connection's API key. See [Construct a request to HERE Geocoding & Search API v7](https://docs.here.com/geocoding-and-search/docs/request-constructing).
