## 🚀 Quickstart

Connect to the Braze MCP server with Nango and call MCP tools in minutes. Braze MCP uses OAuth 2.0 with **dynamic client registration**, so no app registration is required.

<Steps>
    <Step id="create-integration" title="Create the integration">
        In Nango ([free signup](https://app.nango.dev)), go to **Integrations** → _Configure New Integration_ → _Braze (MCP)_.
    </Step>
    <Step id="authorize-braze-mcp" title="Authorize Braze">
        Go to **Connections** → _Add Test Connection_ → _Authorize_, choose your region, then log in to your Braze account. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-braze-mcp" title="Call the Braze MCP API">
        Make your first MCP request (initialize handshake). Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
        <Tabs>
            <Tab title="cURL">

                ```bash
                curl "https://api.nango.dev/proxy/mcp" \
                  -X POST \
                  -H "Authorization: Bearer <NANGO-API-KEY>" \
                  -H "Provider-Config-Key: <INTEGRATION-ID>" \
                  -H "Connection-Id: <CONNECTION-ID>" \
                  -H "Content-Type: application/json" \
                  -d '{
                    "jsonrpc": "2.0",
                    "id": 1,
                    "method": "initialize",
                    "params": {
                        "protocolVersion": "2024-11-05",
                        "capabilities": {},
                        "clientInfo": {
                            "name": "nango-client",
                            "version": "1.0.0"
                        }
                    }
                }'
                ```

            </Tab>

            <Tab title="Node">

                Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

                ```typescript
                import { Nango } from '@nangohq/node';

                const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

                const res = await nango.post({
                    endpoint: '/mcp',
                    providerConfigKey: '<INTEGRATION-ID>',
                    connectionId: '<CONNECTION-ID>',
                    body: {
                        jsonrpc: '2.0',
                        id: 1,
                        method: 'initialize',
                        params: {
                            protocolVersion: '2024-11-05',
                            capabilities: {},
                            clientInfo: {
                                name: 'nango-client',
                                version: '1.0.0'
                            }
                        }
                    }
                });

                console.log(res.data);
                ```
            </Tab>

        </Tabs>
        ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-nango" title="Implement Nango in your app">
        Follow our [Auth implementation guide](/guides/auth/auth-guide) to integrate Nango in your app.
    </Step>
</Steps>

## 📚 Braze (MCP) guides

Nango uses **dynamic client registration** with Braze's MCP OAuth server, so you do not register an MCP application. Before your users can connect, check the following in Braze:

- **Paid account:** the Braze MCP server is not available on free trial accounts.
- **Admin approval:** a company admin must turn on MCP OAuth access and approve Nango's redirect URI (`https://api.nango.dev/oauth/callback`, or your own [custom callback URL](/guides/auth/auth-guide#custom-oauth-callback-url-optional)) in **Settings** → **Admin Settings** → **External Connections**.
- **Permissions:** the user needs the **Use MCP Server** permission. The MCP tools act with the user's own dashboard permissions, so a user scoped to a team rather than a whole workspace may not be able to use every tool.
- **No IP allowlisting:** companies that use dashboard IP allowlisting cannot use the Braze MCP server.

In the integration's settings in Nango, add the scopes Braze's MCP server asks for: `mcp:tools`, `mcp:resources` and `mcp:operator`. What the agent can do is the intersection of the granted scopes and the user's own dashboard permissions: it can never do more than the user can.

When they connect, users choose Braze's US endpoint (`mcp.braze.com`) or EU endpoint (`mcp.braze.eu`). Braze recommends the EU endpoint for EU customers; non-EU customers can use either. See [How do I link my account?](/api-integrations/braze-mcp/connect).

Official resources: [Braze MCP server setup](https://www.braze.com/docs/user_guide/brazeai/mcp_server/setup)
