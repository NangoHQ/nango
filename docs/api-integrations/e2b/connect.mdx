## Overview

To authenticate with E2B, you need:

1. **API Key** — an API key for your E2B project.

This guide will show you how to create it.

### Prerequisites

- An E2B account. If you don't have one, [sign up](https://console.e2b.dev/sign-up). The free Hobby plan includes API access and needs no credit card.

### Step 1: Create an API key

1. Sign in to the [E2B console](https://console.e2b.dev/sign-in) and select the project you want to connect.
2. In the left sidebar, under **Configure**, click **API keys**.

<img src="/api-integrations/e2b/open_api_keys.png" alt="E2B console sidebar with API keys selected under Configure" />

3. Click **Create a key**.

<img src="/api-integrations/e2b/create_api_key.png" alt="E2B API Keys page with the Create a key button" />

4. Enter a name for the key, then click **Create**.
5. Click **Copy** to copy the API key. E2B shows it only once.

<img src="/api-integrations/e2b/copy_api_key.png" alt="E2B key created dialog with the Copy button" />

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with E2B.
2. Enter your API key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/e2b/form.png" alt="E2B Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to E2B.
