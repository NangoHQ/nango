## Overview

To authenticate with Omny Studio, you will need:

1. **API Key** – A key that grants access to the Omny Studio Management API for your organization, network or program.

This guide explains how to obtain your **API Key** from Omny Studio.

### Prerequisites

- An active Omny Studio account
- The **Manage API Keys** permission on that account

### Instructions

#### Step 1: Getting your API key

1. Log in to Omny Studio and open **Organization Settings** -> [API keys](https://omnystudio.com/settings/apikeys).
2. Click **Create API key**.
3. Give the key a name and choose its scope (the whole organization, a network or a single program) and its permissions. Grant only what the integration needs; read access to content and analytics is enough for reporting.
4. Click **Create**. Copy the key now: Omny Studio shows it only once.

#### Step 2: Enter credentials in the Connect UI

Once you have your **API Key**:

1. Open the form where you need to authenticate with Omny Studio.
2. Enter your **API Key** in the API Key field.
3. Submit the form to complete authentication.

You are now connected to Omny Studio.
