## Overview

To authenticate with Featherless, you need:

1. **API Key** — a Featherless API key.

This guide will show you how to get it.

### Prerequisites

- A Featherless account. You can sign up at [featherless.ai/register](https://featherless.ai/register).

### Step 1: Create an API key

1. Sign in at [featherless.ai/login](https://featherless.ai/login), then select **API Keys** in the left sidebar of your account, or go to [featherless.ai/account/api-keys](https://featherless.ai/account/api-keys).

<img src="/api-integrations/featherless/account_api_keys_nav.png" alt="Featherless account page with API Keys in the left sidebar"/>

2. Click **New API Key**, enter a name, then click **Create**.

<img src="/api-integrations/featherless/create_api_key_dialog.png" alt="Create new API key dialog in Featherless with the Name field and the Create button"/>

3. Copy the API key and click **Done**. The key is shown only once.

<img src="/api-integrations/featherless/api_key_created.png" alt="Featherless dialog showing the new API key with the copy button"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Featherless.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/featherless/form.png" alt="Featherless connection form in the Nango Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to Featherless.
