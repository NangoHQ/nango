## 🚀 Quickstart

Connect to Supabase with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Supabase (OAuth)_. Paste the client ID and secret of your Supabase OAuth app. You don't need to add scopes: Supabase grants the scopes chosen on the OAuth app.
    </Step>
    <Step id="authorize-supabase" title="Authorize Supabase">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then log in to Supabase and choose the organization to connect. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-supabase-api" title="Call the Supabase Management API">
    Let's make your first request to the Supabase Management API (list the organizations the connection can access, which needs the **Organizations** read scope). Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/v1/organizations" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/v1/organizations',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [Auth implementation guide](/guides/auth/auth-guide) to integrate Nango in your app.

        To obtain your own credentials, follow the setup guide linked below.
    </Step>
</Steps>

## API gotchas

- Scopes are chosen on the OAuth app in Supabase, not per connection. If you change them, existing connections keep their old scopes until the user authorizes again.
- The Management API allows 120 requests per minute per endpoint, and for OAuth apps the limit is shared by everyone calling through the app. When you set `retries` on a proxy call, Nango waits until `X-RateLimit-Reset` (seconds) has passed before retrying a `429`.
