## Overview

To authenticate with Listclean, you need:

1. **API Token** — an API token from your Listclean dashboard.

This guide will show you how to create one.

### Prerequisites

- A Listclean account. New accounts get 25 free verification credits, no credit card required. If you don't have an account, [sign up](https://app.listclean.xyz/signup).

### Step 1: Create an API token

1. Sign in to the [Listclean dashboard](https://app.listclean.xyz).
2. In the left sidebar, expand **API** and click **API Key**.

<img src="/api-integrations/listclean/api_key_nav.png" alt="Listclean dashboard with the API section in the left sidebar"/>

3. Under **Create API token**, enter a token label (for example, `nango-integration`) and click **Create token**.

<img src="/api-integrations/listclean/create_api_token.png" alt="Listclean API access page with the token label field and the Create token button"/>

4. Under **New token created**, click the copy icon to copy the token. It is shown only once.

<img src="/api-integrations/listclean/api_token_created.png" alt="Listclean API access page showing the new API token to copy"/>

### Step 2: Enter your API token in the Connect UI

1. Open the form where you need to authenticate with Listclean.
2. Enter your API token in the **API Token** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/listclean/form.png" alt="Listclean Connect UI form with the API Token field" style={{maxWidth: "450px" }}/>

You are now connected to Listclean.
