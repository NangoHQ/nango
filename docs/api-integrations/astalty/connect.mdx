## Overview

To authenticate with Astalty, you need:

1. **API Key** — a key created in Astalty's API Dashboard.

### Prerequisites

- An Astalty account on the Premium plan, which includes API access.
- You're the Account Owner, or an Admin with the **Can manage API keys and webhooks** permission.

### Step 1: Create an API key

1. Log in to [Astalty](https://app.astalty.com.au), open **Settings**, and select **API Dashboard**.

<img src="/api-integrations/astalty/api_dashboard.png" alt="Astalty Settings menu with API Dashboard at the bottom of the list" />

2. Select **Manage Keys**, then **Create API Key**.

<img src="/api-integrations/astalty/manage_keys.png" alt="Astalty Manage Keys page with the Create API Key button" />

3. Enter a **Name** for the key and choose an **Access Level**: **Full Access** to read, create, update, and delete data, or **Read Only** to read data only. Then select **Create**.

<img src="/api-integrations/astalty/create_key.png" alt="Astalty Create API Key dialog with the Name field and the Full Access and Read Only access levels" />

4. Select **Copy to clipboard** to copy the key.

<img src="/api-integrations/astalty/copy_key.png" alt="Astalty API Key Created dialog with the key hidden and the Copy to clipboard button" />

<Note>
Astalty shows the key only once. If you close the dialog without copying it, delete the key and create a new one.
</Note>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Astalty.
2. Enter your **API Key**.
3. Click **Connect**.

<img src="/api-integrations/astalty/form.png" alt="Nango Connect UI form for entering the Astalty API Key" style={{maxWidth: "450px" }}/>

You are now connected to Astalty.
