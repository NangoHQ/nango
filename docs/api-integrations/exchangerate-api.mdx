## 🚀 Quickstart

Connect to ExchangeRate-API with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _ExchangeRate-API_.
    </Step>
    <Step id="authorize-exchangerate-api" title="Authorize ExchangeRate-API">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your ExchangeRate-API API key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-exchangerate-api-api" title="Call the ExchangeRate-API API">
    Let's make your first request to the ExchangeRate-API API: get the latest exchange rates from USD. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/v6/latest/USD" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/v6/latest/USD',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- The keyless open access API is on `https://open.er-api.com`. Calls to it set `baseUrlOverride` to `https://open.er-api.com`; Nango keeps the connection's credentials and headers. See [ExchangeRate-API - Open Access, No Key Required](https://www.exchangerate-api.com/docs/free).
- Nango sends the key in the `Authorization` header on every call, so endpoints leave the key out of the path (`/v6/latest/USD`). Calls that need the key in the URL path (`/v6/<KEY>/latest/USD`) can read it from the connection's credentials (`credentials.apiKey`) and put it in the path as the docs show.
