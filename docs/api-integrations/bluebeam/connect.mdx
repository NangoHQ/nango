## Overview

To authenticate with Bluebeam, you need:

1. **API Host** — the Bluebeam API host for the region your account is in.

This guide will show you how to find it.

### Prerequisites

- A Bluebeam account with access to Bluebeam Studio.

### Step 1: Find your API host

Your API host depends on the region your Bluebeam account was created in. This is the same region you select when signing in to Bluebeam.

| Region | API Host |
| - | - |
| United States | `api.bluebeam.com` |
| United Kingdom | `api.bluebeamstudio.co.uk` |
| Australia | `api.bluebeamstudio.com.au` |
| Germany | `api.bluebeamstudio.de` |
| Sweden | `api.bluebeamstudio.se` |

<Tip>
If you're not sure which region your account is in, check the address of the Bluebeam sign-in page you use, or ask your Bluebeam administrator.
</Tip>

### Step 2: Enter your API host in the Connect UI

1. Open the form where you need to authenticate with Bluebeam.
2. Select your **API Host** from the list.
3. Click **Connect**. You'll be redirected to Bluebeam.

<img src="/api-integrations/bluebeam/form.png" alt="Nango Connect UI form with the Bluebeam API Host dropdown" style={{ maxWidth: '450px' }} />

You are now connected to Bluebeam.
