## 🚀 Quickstart

Connect to BeyondTrust Privileged Remote Access with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _BeyondTrust Privileged Remote Access_.
    </Step>
    <Step id="authorize-beyondtrust-pra" title="Authorize BeyondTrust Privileged Remote Access">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your site hostname, OAuth Client ID and OAuth Client Secret. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-beyondtrust-pra-api" title="Call the BeyondTrust Privileged Remote Access API">
    Let's make your first request to the BeyondTrust Privileged Remote Access Command API to check the health of your site. The API account needs Command API access. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/command?action=check_health" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/command',
            params: { action: 'check_health' },
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Nango exchanges your OAuth Client ID and OAuth Client Secret for an access token from your site and refreshes it for you.

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>
