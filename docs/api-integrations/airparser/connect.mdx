## Overview

To authenticate with Airparser, you need:

1. **API Key** - The API key of your Airparser account.

This guide will show you how to find it.

### Prerequisites

- An Airparser account. You can [sign up](https://app.airparser.com/signup) for the free plan, no credit card required.

### Step 1: Copy your API key

1. Log in to [Airparser](https://app.airparser.com) and open **Account and Settings** -> **Account & API** ([direct link](https://app.airparser.com/account)).

<img src="/api-integrations/airparser/account_api_nav.png" alt="The Account & API page in Airparser's Account and Settings"/>

2. In the **Account Information** section, click the copy icon next to the **API key** field.

<img src="/api-integrations/airparser/copy_api_key.png" alt="The copy icon next to the API key field on the Airparser Account & API page"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Airparser.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/airparser/form.png" alt="The Airparser connection form in Nango's Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to Airparser.
