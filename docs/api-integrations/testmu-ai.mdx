## 🚀 Quickstart

Connect to TestMu AI with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _TestMu AI_.
    </Step>
    <Step id="authorize-testmu-ai" title="Authorize TestMu AI">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then select your data center region and enter your Username and Access Key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-testmu-ai-api" title="Call the TestMu AI API">
    Let's make your first request to the TestMu AI API (get your organization's concurrency). Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/automation/api/v1/org/concurrency" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/automation/api/v1/org/concurrency',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- The User Management API is served from `https://auth.lambdatest.com` (EU: `https://eu-auth.lambdatest.com`), not from the connection's base URL. Call it with `baseUrlOverride` set to the host for the connection's `region`; Nango keeps the connection's credentials and headers. See [Get all Groups](https://www.testmuai.com/support/api-doc/user-management/groups/get-all-groups/).
- The Test Manager API is served from `https://test-manager-api.lambdatest.com` (EU: `https://eu-test-manager-api.lambdatest.com`). Call it with `baseUrlOverride` set to the host for the connection's `region`; Nango keeps the connection's credentials and headers. See [Get All Projects](https://www.testmuai.com/support/api-doc/test-manager/projects/get-all-projects/).
- The App Automation API (real devices) is served from `https://mobile-api.lambdatest.com` and `https://manual-api.lambdatest.com` (EU: `https://eu-mobile-api.lambdatest.com` and `https://eu-manual-api.lambdatest.com`). Call them with `baseUrlOverride` set to that host; Nango keeps the connection's credentials and headers. See [Fetch all uploaded applications](https://www.testmuai.com/support/api-doc/app-automation-api-real-devices/application-appium/fetch-all-uploaded-applications-server-1/).
