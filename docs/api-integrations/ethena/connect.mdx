## Overview

To authenticate with Ethena, you need:

1. **Username** — the username that goes with your Ethena API key.
2. **API Key** — the API key Ethena provisions for your company.

This guide will show you how to get these credentials from Ethena.

### Prerequisites

- An Ethena account with API access. Ethena does not offer self-service API keys: [contact Ethena](https://www.goethena.com/platform/contact-us/) or your sales representative to get access.

### Step 1: Get your API credentials

1. Contact your Ethena sales representative and ask for API access.
2. Your representative provisions an API key and shares it with you.
3. Ethena's API docs do not say what the username is, so ask your representative for the username to use with the API key as well.

### Step 2: Enter your credentials in the Connect UI

1. Open the form where you need to authenticate with Ethena.
2. Enter your username in the **Username** field.
3. Enter your API key in the **API Key** field.
4. Submit the form, and you should be successfully authenticated.

You are now connected to Ethena.
