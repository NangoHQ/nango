## 🚀 Quickstart

Connect to Crawlbase with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Crawlbase_.
    </Step>
    <Step id="authorize-crawlbase" title="Authorize Crawlbase">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your Crawlbase token. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-crawlbase-api" title="Call the Crawlbase API">
    Let's make your first request to the Crawlbase API to count the pages in your Cloud Storage. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/storage/total_count" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/storage/total_count',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- Calls to the hosted MCP server set `baseUrlOverride` to `https://mcp.crawlbase.com` (endpoint `/mcp`); Nango keeps the connection's `token` query parameter. See [MCP Server](https://crawlbase.com/docs/ai-mcp).
