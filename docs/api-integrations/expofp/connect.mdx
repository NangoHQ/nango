## Overview

To authenticate with ExpoFP, you need:

1. **API Token** — the API token from your ExpoFP profile.

This guide will show you where to find it.

### Prerequisites

- An ExpoFP account ([sign up](https://app.expofp.com/signup)).

### Step 1: Copy your API token

1. Log in to ExpoFP at [app.expofp.com/login](https://app.expofp.com/login).
2. In the left sidebar, open **My account** -> **Profile** ([app.expofp.com/profile](https://app.expofp.com/profile/)).
3. Click **show** next to **API Token**.

<img src="/api-integrations/expofp/profile_api_token_show.png" alt="ExpoFP Profile page with the show link next to API Token"/>

4. Copy the token with the copy button next to the field.

<img src="/api-integrations/expofp/api_token_copy.png" alt="ExpoFP Profile page with the API Token revealed and the copy button highlighted"/>

### Step 2: Enter your API token in the Connect UI

1. Open the form where you need to authenticate with ExpoFP.
2. Paste the token into the **API Token** field.
3. Submit the form.

<img src="/api-integrations/expofp/form.png" alt="ExpoFP Connect UI form with the API Token field" style={{maxWidth: "450px" }}/>

You are now connected to ExpoFP.
