## Overview

To authenticate with Codemagic, you need:

1. **API Token** — the personal API token of your Codemagic account.

This guide will show you how to get it.

### Prerequisites

- A Codemagic account. [Sign up](https://codemagic.io/signup) if you don't have one.

### Step 1: Copy your API token

1. Log in to [Codemagic](https://codemagic.io/login).
2. Click **Account settings** at the bottom of the left sidebar.
3. Under **API token**, click **Show**.

<img src="/api-integrations/codemagic/account_settings_api_token.png" alt="Codemagic Account settings page with the Show button highlighted under API token"/>

4. Copy the revealed token with the copy button next to it.

<img src="/api-integrations/codemagic/api_token_revealed.png" alt="Codemagic API token section with the token revealed and the copy button highlighted"/>

<Note>The token is personal: what it can do depends on your role in each Codemagic team. To rotate it, click **Revoke**, then **Show** to generate a new one.</Note>

### Step 2: Enter your API token in the Connect UI

1. Open the form where you need to authenticate with Codemagic.
2. Paste your token in the **API Token** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/codemagic/form.png" alt="Codemagic Connect UI form with the API Token field" style={{maxWidth: "450px" }}/>

You are now connected to Codemagic.
