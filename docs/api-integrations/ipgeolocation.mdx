## 🚀 Quickstart

Connect to IPGeolocation.io with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _IPGeolocation.io_.
    </Step>
    <Step id="authorize-ipgeolocation" title="Authorize IPGeolocation.io">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your IPGeolocation.io API key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-ipgeolocation-api" title="Call the IPGeolocation.io API">
    Let's make your first request to the IPGeolocation.io API to look up the country and city of an IP address. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/v3/ipgeo?ip=8.8.8.8&fields=location.country_name,location.city" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/v3/ipgeo',
            params: { ip: '8.8.8.8', fields: 'location.country_name,location.city' },
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>
