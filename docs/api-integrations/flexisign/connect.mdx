## Overview

To authenticate with FlexiSign, you need:

1. **API Key** - a FlexiSign API key.

This guide will show you how to get it.

### Prerequisites

- A FlexiSign account. You can [sign up](https://flexisign.io/app/signup) for free: API access is included from the free plan.

### Step 1: Generate an API key

1. Sign in to [FlexiSign](https://flexisign.io/app/login), click **Integrations** in the top navigation and open [FlexiSign API](https://flexisign.io/app/integrations/flexisignapi).
2. Under **Your API Key**, click **Generate new API key**.

<img src="/api-integrations/flexisign/generate_api_key.png" alt="FlexiSign API page with the Generate new API key button"/>

3. In the **Access Code** panel, tick **View** for **Templates**, and for **Documents** if you need to read documents, then click **Save**.

<img src="/api-integrations/flexisign/api_key_access.png" alt="FlexiSign Access Code panel with View ticked for Documents and Templates"/>

4. Click **Copy** next to the API key field.

<img src="/api-integrations/flexisign/api_key_created.png" alt="FlexiSign API page with the Copy button next to the API key"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with FlexiSign.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/flexisign/form.png" alt="FlexiSign connection form in the Nango Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to FlexiSign.
