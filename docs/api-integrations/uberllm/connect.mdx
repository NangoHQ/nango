## Overview

To authenticate with UberLLM, you need:

1. **API Key** — an UberLLM API key.

This guide will show you how to get it.

### Prerequisites

- An UberLLM account. You can [sign up](https://uberllm.dev/signup) with your email or with Google.
- Credit on your account. Accounts are prepaid and start at $0; add credit from **Dashboard** -> **Credits**. See [Pricing](https://uberllm.dev/docs/pricing).

### Step 1: Create an API key

1. Log in to [UberLLM](https://uberllm.dev/dashboard). Your first key is created for you and shown at the top of the dashboard.
2. To create another key, open **Dashboard** -> **API keys** and click **Create key**.
3. Copy the key. It starts with `ull_` and is shown only once.

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with UberLLM.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

You are now connected to UberLLM.
