## Overview

To authenticate with HERE, you need:

1. **API Key** — an API key for an app on the HERE platform.

This guide will show you how to get it.

### Prerequisites

- A HERE platform account. If your company has no HERE platform organization yet, you can [get started for free](https://www.here.com/get-started/pricing).

### Step 1: Register an app

Skip this step if you already have an app you want to use.

1. Sign in to the [HERE platform](https://platform.here.com).
2. Select **Access Manager** from the launcher.
3. On the **Apps** tab, click **Register new app** and enter the required information.
4. Click **Register**.

### Step 2: Create an API key

1. In **Access Manager**, on the **Apps** tab, select your app.
2. On the **Credentials** tab, select **API Keys**, then click **Create API key**. An app can have at most two API keys.
3. Copy the API key.

If the **Credentials** tab is missing or greyed out, you may not have manager permissions for the app. Ask the app's manager to create the key.

### Step 3: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with HERE.
2. Paste the key you copied in Step 2 into the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

You are now connected to HERE.
