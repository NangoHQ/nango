## Overview

To authenticate with PredictLeads, you need:

1. **API Key** - the **Authentication key** of your PredictLeads API subscription.
2. **API Token** - the **Authentication token** of your PredictLeads API subscription.

This guide will show you where to find both.

### Prerequisites

- A PredictLeads account. If you don't have one, [sign up](https://predictleads.com/sign_up) and confirm your email address: the free plan includes up to 100 API calls per month.

### Step 1: Copy your API key and API token

1. Sign in to [PredictLeads](https://predictleads.com/sign_in).
2. In the sidebar, click **Subscription Plans**.

<img src="/api-integrations/predictleads/open_subscription_plans.png" alt="PredictLeads dashboard sidebar with Subscription Plans selected"/>

3. In the **API Subscriptions** section, click **Copy** next to **Authentication key**. This is your API key.
4. Click **Copy** next to **Authentication token**. This is your API token. Do not click **Regenerate**, which replaces the token.

<img src="/api-integrations/predictleads/copy_api_key_and_token.png" alt="PredictLeads API Subscriptions section with the Authentication key and Authentication token rows and their Copy buttons"/>

### Step 2: Enter your credentials in the Connect UI

1. Open the form where you need to authenticate with PredictLeads.
2. Paste the **Authentication key** in the **API Key** field.
3. Paste the **Authentication token** in the **API Token** field.
4. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/predictleads/form.png" alt="PredictLeads Connect UI form with the API Key and API Token fields" style={{maxWidth: "450px" }}/>

You are now connected to PredictLeads.
