## 🚀 Quickstart

Connect to Apiframe with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Apiframe_.
    </Step>
    <Step id="authorize-apiframe" title="Authorize Apiframe">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your Apiframe API key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-apiframe-api" title="Call the Apiframe API">
    Let's make your first request to the Apiframe API to get the authenticated user, team and API key. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/v2/me" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/v2/me',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- The Apiframe MCP server is served from `https://mcp.apiframe.ai`, not from `https://api.apiframe.ai`. Call it with `baseUrlOverride` set to that host; Nango keeps the connection's credentials and headers. See [MCP Server](https://apiframe.ai/docs/mcp).
