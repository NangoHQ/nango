## Overview

To authenticate with BoxHero, you need:

1. **API Token** — an API token generated in your BoxHero team's settings.

This guide will show you how to generate it.

### Prerequisites

- A BoxHero account. If you don't have one, [sign up](https://app.boxhero.io).
- Each API token is bound to a single team, so generate it in the team you want to connect.

### Step 1: Generate an API token

1. Sign in to the [BoxHero web app](https://app.boxhero.io) and open the team you want to connect.
2. In the left menu, expand **Settings** and click **Integrations**.

<img src="/api-integrations/boxhero/settings_integrations_menu.png" alt="BoxHero left menu with Settings expanded and Integrations highlighted" />

3. In the **API Token** section, click **Generate**.

<img src="/api-integrations/boxhero/generate_api_token.png" alt="BoxHero Integrations settings page with the Generate button in the API Token section" />

4. Click the copy button next to the token to copy it.

<img src="/api-integrations/boxhero/copy_api_token.png" alt="BoxHero API Token section with the copy button next to the generated token" />

### Step 2: Enter your API token in the Connect UI

1. Open the form where you need to authenticate with BoxHero.
2. Enter your API token in the **API Token** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/boxhero/form.png" alt="BoxHero Connect UI form with the API Token field" style={{maxWidth: "450px" }}/>

You are now connected to BoxHero.
