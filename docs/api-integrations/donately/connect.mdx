## Overview

To authenticate with Donately, you need:

1. **API Token** — your Donately personal access token.

This guide will show you where to find it.

### Prerequisites

- A Donately account. [Sign up](https://admin.donately.com/sign-up) if you don't have one.

### Step 1: Copy your API token

1. [Sign in](https://admin.donately.com/sign-in) to the Donately dashboard.
2. In the left sidebar, expand **Integrations** and click **API & MCP**.
3. Click the **Your API token lives in your profile** card. This opens **User Settings** -> **API Access**.

<img src="/api-integrations/donately/api_mcp_page.png" alt="Donately API & MCP page with the Your API token lives in your profile card highlighted"/>

4. Under **Personal access token**, click **Copy** to copy your API token.

<img src="/api-integrations/donately/copy_api_token.png" alt="Donately User Settings API Access tab with the Copy button next to the personal access token highlighted"/>

### Step 2: Enter your API token in the Connect UI

1. Open the form where you need to authenticate with Donately.
2. Paste your API token into the **API Token** field.
3. Click **Connect**. Nango checks the token with Donately before saving the connection.

<img src="/api-integrations/donately/form.png" alt="Nango Connect UI form for entering the Donately API Token" style={{maxWidth: "450px" }}/>

You are now connected to Donately.
