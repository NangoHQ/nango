## 🚀 Quickstart

Connect to Inboxapp (MCP) with Nango and start calling tools in minutes. Inboxapp MCP uses OAuth 2.0 with dynamic client registration, meaning no app registration is required.

<Steps>
    <Step title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to [Integrations](https://app.nango.dev/dev/integrations) -> _Configure New Integration_ -> _Inboxapp (MCP)_.
    </Step>
    <Step title="Authorize Inboxapp">
    Go to [Connections](https://app.nango.dev/dev/connections) -> _Add Test Connection_ -> _Authorize_, then log in to Inboxapp, pick the team to connect and approve access. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step title="Call an Inboxapp MCP tool">
    Make your first MCP request to Inboxapp (list threads). Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), [integration ID](https://app.nango.dev/dev/integrations), and [connection ID](https://app.nango.dev/dev/connections):
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/mcp" \
              -X POST \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>" \
              -H "Content-Type: application/json" \
              -d '{
                "jsonrpc": "2.0",
                "id": 1,
                "method": "tools/call",
                "params": {
                    "name": "threads_list",
                    "arguments": {
                        "limit": 10
                    }
                }
            }'
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.post({
            endpoint: '/mcp',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>',
            data: {
                jsonrpc: '2.0',
                id: 1,
                method: 'tools/call',
                params: {
                    name: 'threads_list',
                    arguments: { limit: 10 }
                }
            }
        });

        console.log(res.data);
        ```
        </Tab>

    </Tabs>
    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the [Logs](https://app.nango.dev/dev/logs) tab in Nango to inspect requests.
    </Step>

   <Step title="Implement Nango in your app">
        Follow our [Auth implementation guide](/guides/primitives/auth) to integrate Nango in your app.
    </Step>
</Steps>

## 📚 Inboxapp (MCP) Integration Guides

Nango uses **dynamic client registration** with Inboxapp's OAuth server. You do not need to register an MCP application, just create the integration in Nango and authorize with your Inboxapp account.

Official docs: [Inboxapp MCP server](https://docs.inboxapp.com/v2/mcp-server)

## 🚨 API gotchas

- Each connection is authorized for one team, chosen on the consent screen.
- Sending, editing or unsending a message reaches a real person from the user's own account.
- MCP calls count toward the same [rate limits](https://docs.inboxapp.com/v2/reference/rate-limits) as the REST API.
