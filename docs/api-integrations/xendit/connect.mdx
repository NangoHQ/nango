## Overview

To authenticate with the Xendit API via Nango, you will need:
1. **Secret API Key** – Your Xendit secret API key from the Xendit Dashboard.

This guide walks you through finding your API key and connecting your account.

### Prerequisites

- A Xendit account. [Sign up here](https://dashboard.xendit.co/register) if you don't have one.

### Instructions

#### Step 1: Finding your API key

1. Sign in to the [Xendit Dashboard](https://dashboard.xendit.co).
2. Navigate to **Settings** > **API Keys**.
3. Click **Generate Secret Key** to create a new API key.
4. Copy the generated secret API key and store it securely. The key is only shown once.

<Note>
Xendit provides separate API keys for test and live environments. Use a **test** key during development — requests made with test keys do not interact with banking networks and incur no charges.
</Note>

#### Step 2: Enter credentials in the Connect UI

Once you have your **Secret API Key**:

1. Open the form where you need to authenticate with Xendit.
2. Enter your **Secret API Key** in the field provided.
3. Submit the form, and you should be successfully authenticated.

You are now connected to Xendit.
