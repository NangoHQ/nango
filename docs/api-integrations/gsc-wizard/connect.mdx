## Overview

To connect with GSC Wizard, you need:

1. **API Key**: a GSC Wizard API key, which starts with `gscw_live_`.

### Prerequisites

- A GSC Wizard account with a plan or an active trial ([sign up](https://www.gscwizard.com/)) and at least one Google Search Console property connected.

### Step 1: Create an API key

1. Log in to [GSC Wizard](https://tool.gscwizard.com) and open the [API keys](https://tool.gscwizard.com/account/api-keys) page of your account.
2. Under **Create a key**, enter a **Name** so you can recognize the key later.
3. Pick a **Scope**: **Read only** to query data and run reports, or **Read & write** to also let the connection add, edit, or delete things such as annotations, saved filters, and sitemaps.
4. Click **Create key**, then click **Copy**. GSC Wizard shows the full key only once.

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with GSC Wizard.
2. Enter your **API Key**.
3. Click **Connect**.

You are now connected to GSC Wizard. The connection sees the same Search Console properties as the account that created the key. You can revoke the key on the same page at any time.
