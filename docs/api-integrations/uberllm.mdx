## 🚀 Quickstart

Connect to UberLLM with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _UberLLM_.
    </Step>
    <Step id="authorize-uberllm" title="Authorize UberLLM">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your UberLLM API key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-uberllm-api" title="Call the UberLLM API">
    Let's make your first request to the UberLLM API to get your account balance. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/v1/balance" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/v1/balance',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- UberLLM is OpenAI-compatible: send chat requests to `POST /v1/chat/completions` through the proxy with a model id in `vendor/model` form, such as `deepseek/deepseek-v4.1-flash`.
- `GET /v1/models` lists chat models only and needs no key. Add `?type=image`, `?type=video`, `?type=music` or `?type=all` to list the other models the same key can call. Media requests are described in the [media guide](https://uberllm.dev/docs/media).
- Nango checks the key with `GET /v1/balance` when a connection is created. It returns `balance_usd`, `held_usd` and `available_usd`, so you can also use it to warn a user before their credit runs out.
- Accounts are prepaid and start at $0, so requests need credit on the account.
