## Overview

To authenticate with IPGeolocation.io, you need:

1. **API Key** — your IPGeolocation.io API key.

This guide will show you how to get it.

### Prerequisites

- An IPGeolocation.io account. The free Developer plan includes API access; [sign up](https://app.ipgeolocation.io/signup) to get one. An API key is created along with your account.

### Step 1: Copy your API key

1. [Sign in](https://app.ipgeolocation.io/login) to the IPGeolocation.io dashboard.
2. On the **Dashboard** page, find the **API Keys** section below **Current API Plan**.
3. Click the **Copy API key** icon next to your key. The key is masked; click the eye icon to show it in full.

<img src="/api-integrations/ipgeolocation/dashboard_api_keys.png" alt="IPGeolocation.io dashboard with the Copy API key icon in the API Keys section"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with IPGeolocation.io.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/ipgeolocation/form.png" alt="IPGeolocation.io connection form in the Nango Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to IPGeolocation.io.
