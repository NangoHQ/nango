## 🚀 Quickstart

Connect to the Attentive MCP server with Nango and call MCP tools in minutes. Attentive MCP uses OAuth 2.0 with **dynamic client registration**, so no app registration is required.

<Steps>
    <Step id="create-integration" title="Create the integration">
        In Nango ([free signup](https://app.nango.dev)), go to **Integrations** → _Configure New Integration_ → _Attentive (MCP)_.
    </Step>
    <Step id="authorize-attentive" title="Authorize Attentive">
        Go to **Connections** → _Add Test Connection_ → _Authorize_, then log in to your Attentive account. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-attentive-mcp" title="Call the Attentive MCP API">
        Make your first MCP request (initialize handshake). Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
        <Tabs>
            <Tab title="cURL">

                ```bash
                curl "https://api.nango.dev/proxy/mcp?readOnly=false" \
                  -X POST \
                  -H "Authorization: Bearer <NANGO-API-KEY>" \
                  -H "Provider-Config-Key: <INTEGRATION-ID>" \
                  -H "Connection-Id: <CONNECTION-ID>" \
                  -H "Content-Type: application/json" \
                  -d '{
                    "jsonrpc": "2.0",
                    "id": 1,
                    "method": "initialize",
                    "params": {
                        "protocolVersion": "2024-11-05",
                        "capabilities": {},
                        "clientInfo": {
                            "name": "nango-client",
                            "version": "1.0.0"
                        }
                    }
                }'
                ```

            </Tab>

            <Tab title="Node">

                Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

                ```typescript
                import { Nango } from '@nangohq/node';

                const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

                const res = await nango.post({
                    endpoint: '/mcp?readOnly=false',
                    providerConfigKey: '<INTEGRATION-ID>',
                    connectionId: '<CONNECTION-ID>',
                    body: {
                        jsonrpc: '2.0',
                        id: 1,
                        method: 'initialize',
                        params: {
                            protocolVersion: '2024-11-05',
                            capabilities: {},
                            clientInfo: {
                                name: 'nango-client',
                                version: '1.0.0'
                            }
                        }
                    }
                });

                console.log(res.data);
                ```
            </Tab>

        </Tabs>
        ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-nango" title="Implement Nango in your app">
        Follow our [Auth implementation guide](/guides/auth/auth-guide) to integrate Nango in your app.
    </Step>
</Steps>

## 📚 Attentive (MCP) guides

Nango uses **dynamic client registration** with Attentive's MCP OAuth server. You do not need to register an MCP application — just create the integration in Nango and authorize with your Attentive account.

Official resources: [Attentive MCP server](https://docs.attentive.com/docs/mcp)

## API gotchas

- Attentive's MCP server is read-only unless the MCP URL includes `readOnly=false`. Nango adds it for agent sessions, so agents get Attentive's write tools as well. For your own proxy calls, use `/mcp` without the parameter to stay read-only.
- Tools mirror the connected user's Attentive permissions: if the user can't do something in the Attentive UI, the MCP server won't do it either.
- The Attentive MCP server is in beta.
