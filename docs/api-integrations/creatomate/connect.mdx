## Overview

To authenticate with Creatomate, you need:

1. **API Key** — the API key of the Creatomate project you want to connect.

This guide will show you how to get it.

### Prerequisites

- A Creatomate account. You can [sign up](https://creatomate.com/sign-in) for free; no credit card is needed.

### Step 1: Copy your project API key

Each project in your Creatomate account has its own API key, so copy the key of the project you want to connect.

1. Sign in to [Creatomate](https://creatomate.com/sign-in).
2. In the top-left of the dashboard, click the project name and choose **Project Settings**.

<img src="/api-integrations/creatomate/open_project_settings.png" alt="Creatomate dashboard with the project menu open and Project Settings highlighted"/>

3. In the **Project Settings** dialog, open the **API** tab.
4. Click the copy button next to **API Key**.

<img src="/api-integrations/creatomate/copy_api_key.png" alt="Creatomate Project Settings dialog on the API tab with the copy button next to API Key highlighted"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Creatomate.
2. Paste your key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/creatomate/form.png" alt="Creatomate Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Creatomate.
