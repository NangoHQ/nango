## Overview

To authenticate with Ayrshare, you need:

1. **API Key** — the API key of your Primary Profile, from the API Key page of your Ayrshare dashboard.

This guide will show you how to find it.

### Prerequisites

- An Ayrshare account. If you don't have one, [sign up](https://app.ayrshare.com/). All plans include API access. The Launch plan has a 28-day free trial; Premium, Business and Enterprise are billed at signup.

### Step 1: Copy your API key

1. Sign in to [Ayrshare](https://app.ayrshare.com/).
2. If you use User Profiles, switch to your **Primary Profile** from the **User Profiles** page. A Profile Key does not work in place of the API key.
3. Open the **API Key** page from the left navigation panel.
4. Copy the **API Key**.

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Ayrshare.
2. Enter your API key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/ayrshare/form.png" alt="Ayrshare Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Ayrshare.
