## Overview

To authenticate with Browse AI, you need:

1. **API Key** — a Browse AI API key.

This guide will show you how to create it.

### Prerequisites

- A Browse AI account. You can [sign up](https://dashboard.browse.ai/signup) for free; the API is available on all plans.

### Step 1: Create an API key

1. [Log in](https://dashboard.browse.ai/login) to the Browse AI dashboard and open the **API** tab ([API keys page](https://dashboard.browse.ai/api)).
2. Click **Create API key**.

<img src="/api-integrations/browseai/api_keys_page.png" alt="Browse AI API tab with the Create API key button highlighted"/>

3. Enter a descriptive name in the **API Key Name** field, then click the confirm button next to it.

<img src="/api-integrations/browseai/name_api_key.png" alt="Browse AI API Key Name field with a name entered and the confirm button highlighted"/>

4. The new key appears in the API keys table. Click the copy button in the **Secret API Key** column to copy the full key, then store it somewhere safe.

<img src="/api-integrations/browseai/api_key_created.png" alt="Browse AI API keys table showing the new key with the copy button in the Secret API Key column highlighted"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Browse AI.
2. Enter your **API Key** in the designated field.
3. Click **Connect**.

<img src="/api-integrations/browseai/form.png" alt="Nango Connect UI form for entering the Browse AI API Key" style={{maxWidth: "450px" }}/>

You are now connected to Browse AI.
