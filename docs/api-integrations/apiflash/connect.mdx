## Overview

To authenticate with ApiFlash, you need:

1. **Access Key** — an ApiFlash access key.

This guide will show you how to get it.

### Prerequisites

- An ApiFlash account. The free plan includes 100 screenshots per month and doesn't need a credit card. [Sign up here](https://apiflash.com/register).

### Step 1: Get your access key

1. Log in to [ApiFlash](https://apiflash.com/login).
2. In the dashboard sidebar, click **Access keys**.
3. Copy an existing access key, or click **New access key** to create one.

<img src="/api-integrations/apiflash/access_keys_page.png" alt="ApiFlash Access keys page with the New access key button"/>

4. If you're creating a new key, confirm by clicking **Create**, then copy the new key from the list.

<img src="/api-integrations/apiflash/confirm_new_access_key.png" alt="ApiFlash dialog to confirm creating a new access key"/>

### Step 2: Enter your access key in the Connect UI

1. Open the form where you need to authenticate with ApiFlash.
2. Enter your **Access Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/apiflash/form.png" alt="Nango Connect UI form for ApiFlash with the Access Key field" style={{maxWidth: "450px" }}/>

You are now connected to ApiFlash.
