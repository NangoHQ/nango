## Overview

To authenticate with Documint, you need:

1. **API Key** — an API key from your Documint account.

This guide will show you how to create one.

### Prerequisites

- A Documint account. You can [sign up](https://app.documint.me/auth/sign-up) and try Documint free for 14 days with the Silver plan.

### Step 1: Create an API key

1. Log in to [Documint](https://app.documint.me/auth/login).
2. Click the **Settings** gear icon at the bottom of the left-hand panel.

<img src="/api-integrations/documint/open_settings.png" alt="Documint left-hand panel with the Settings gear icon highlighted"/>

3. In Settings, open **API keys** from the left-hand panel and click **New API key**.

<img src="/api-integrations/documint/api_keys_page.png" alt="Documint API keys page with the New API key button highlighted"/>

4. Give your key a name and click **Create**.

<img src="/api-integrations/documint/create_api_key_dialog.png" alt="Documint Create API Key dialog with a key name entered and the Create button highlighted"/>

5. Copy your API key. Documint shows it only once, so store it somewhere safe.

<img src="/api-integrations/documint/api_key_created.png" alt="Documint dialog showing the new API key with the copy button highlighted"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Documint.
2. Paste your API key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/documint/form.png" alt="Documint Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Documint.
