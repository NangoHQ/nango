## Overview

To authenticate with Aimtell, you need:

1. **API Key** — your Aimtell account API key.

This guide will show you how to get it.

### Prerequisites

- An Aimtell account. API access is included on every plan, and you can start with the [14-day free trial](https://aimtell.com/signup).

### Step 1: Generate your API key

1. Log in to the [Aimtell dashboard](https://dashboard.aimtell.com). If the setup wizard opens, add your site to continue to the dashboard.
2. In the left navigation, under **Manage Account**, click **API Keys**.

<img src="/api-integrations/aimtell/api_keys_nav.png" alt="API Keys link under Manage Account in the Aimtell dashboard navigation"/>

3. If you don't have an API key yet, click **click here** in "No API Key set, please click here to add one".

<img src="/api-integrations/aimtell/generate_api_key.png" alt="Generating an API key on the Aimtell API Key page"/>

4. Copy the key shown after **Your API Key is:**.

<img src="/api-integrations/aimtell/copy_api_key.png" alt="The Aimtell API Key page showing the account API key"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Aimtell.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/aimtell/form.png" alt="Aimtell connection form in the Nango Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to Aimtell.
