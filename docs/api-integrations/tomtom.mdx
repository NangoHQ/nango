## 🚀 Quickstart

Connect to TomTom with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _TomTom_.
    </Step>
    <Step id="authorize-tomtom" title="Authorize TomTom">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your API key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-tomtom-api" title="Call the TomTom API">
    Let's make your first request to the TomTom Search API to list the POI categories. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/search/2/poiCategories.json" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/search/2/poiCategories.json',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- Detailed South Korea data is on `kr-api.tomtom.com`. Calls to it set `baseUrlOverride` to `https://kr-api.tomtom.com`; Nango keeps the connection's credentials. See [Region-specific content](https://docs.tomtom.com/platform/documentation/api-best-practices/region-specific-content.md).
- Nango sends the key as the `key` query parameter on every call. Orbis-based services (routing, traffic incident details, places) also accept it in a `TomTom-Api-Key` header: read it from the connection's credentials (`credentials.apiKey`) and set that header yourself.
