## Overview

To authenticate with Cody, you need:

1. **API Key** — an API key from your Cody account settings.

This guide will show you how to create it.

### Prerequisites

- A Cody account. If you don't have one, [sign up](https://getcody.ai/auth/signup).

### Step 1: Create an API key

1. Sign in to [Cody](https://getcody.ai/auth/login).
2. Click **Account** in the top navigation, then **API Keys** in the left menu. You can also open the [API Keys page](https://getcody.ai/settings/api) directly.
3. Click **Create API Key**.

<img src="/api-integrations/cody/api_keys_page.png" alt="Cody API Keys page under Account with the Create API Key button" />

4. Enter a name for the key, then click **Create**.

<img src="/api-integrations/cody/create_api_key_dialog.png" alt="Cody Create API Key dialog with the key name field and the Create button" />

5. Click **Copy Key** and store the key somewhere safe. Cody won't show it again.

<img src="/api-integrations/cody/api_key_created.png" alt="Cody dialog showing the new API key with the Copy Key button" />

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Cody.
2. Enter your key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/cody/form.png" alt="Cody Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Cody.
