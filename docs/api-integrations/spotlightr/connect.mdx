## Overview

To authenticate with Spotlightr, you need:

1. **API Key** — the API key of your Spotlightr account.

This guide will show you how to find it.

### Prerequisites

- A Spotlightr account. If you don't have one, [sign up](https://projects.spotlightr.com/auth/register) for the two-week free trial; no credit card is needed.

### Step 1: Copy your API key

1. Log in to the [Spotlightr app](https://projects.spotlightr.com).
2. Click the **Settings** (gear) icon in the left sidebar to open **Application Settings**, then click the **Integrations** tab.

<img src="/api-integrations/spotlightr/settings_integrations_tab.png" alt="Spotlightr Application Settings with the Integrations tab highlighted"/>

3. Your API key is shown in the **API Key** field at the top of the **Integrations** section. Click the copy button next to it.

<img src="/api-integrations/spotlightr/copy_api_key.png" alt="Spotlightr Integrations tab with the copy button next to the API Key field highlighted"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Spotlightr.
2. Paste your key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/spotlightr/form.png" alt="Spotlightr Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Spotlightr.
