## Overview

To authenticate with CurrencyScoop, you need:

1. **API Key** — the API key of your CurrencyBeacon account (CurrencyScoop is now CurrencyBeacon).

This guide will show you how to get it.

### Prerequisites

- A CurrencyBeacon account. If you don't have one, [register](https://currencybeacon.com/register) for free: the free plan includes 5,000 API requests a month and needs no credit card.

### Step 1: Copy your API key

1. [Log in](https://currencybeacon.com/login) to CurrencyBeacon. You land on your [account dashboard](https://currencybeacon.com/account/dashboard) (**Account** > **Home**).
2. In the **API key** section, click **Copy** next to the **API Key** field. Your account has one API key, created for you automatically.

<img src="/api-integrations/currencyscoop/dashboard_api_key_copy.png" alt="CurrencyBeacon account dashboard with the Copy button next to the API Key field in the API key section"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with CurrencyScoop.
2. Enter your API key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/currencyscoop/form.png" alt="CurrencyScoop Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to CurrencyScoop.
