## Overview

To authenticate with Anakin, you need:

1. **API Key** — A key that grants Nango permission to call Anakin's API on your behalf.

This guide will walk you through finding this within Anakin.

### Prerequisites

- An account with Anakin. The free tier requires no credit card and includes 300 credits.

### Step 1: Finding your API key

1. Log in to the [Anakin dashboard](https://anakin.io/account), or [create an account](https://anakin.io/signup) if you do not have one yet.
2. Open **Account** and select the **Developer** tab.
3. Copy an existing key, or click **Create New API Key**, give it a name, and confirm with **Create API Key**.

Your key starts with `ask_` followed by 64 hexadecimal characters. Treat it like a password: it
carries your full account credit balance, and Anakin displays a newly created key **only once** —
copy it before closing the dialog. If you lose it, delete the key and create a new one.

### Step 2: Enter credentials in the Connect UI

Once you have your **API Key**:

1. Open the form where you need to authenticate with Anakin.
2. Enter your **API Key** in its respective field.
3. Submit the form, and you should be successfully authenticated.

You are now connected to Anakin.
