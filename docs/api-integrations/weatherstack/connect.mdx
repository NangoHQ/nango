## Overview

To authenticate with Weatherstack, you need:

1. **API Access Key** — the API Access Key from your Weatherstack dashboard.

This guide will show you how to get it.

### Prerequisites

- A Weatherstack account. [Sign up](https://weatherstack.com/signup/free) if you don't have one: the Free plan includes 100 API calls a month.

### Step 1: Copy your API Access Key

1. Log in to [Weatherstack](https://weatherstack.com/login) and open your [dashboard](https://weatherstack.com/dashboard).
2. In the **Your API Key** field, click the copy icon to copy your API Access Key. Use **Reset Key** on the same card if you need to rotate it.

<img src="/api-integrations/weatherstack/dashboard_api_key.png" alt="Weatherstack dashboard with the copy icon of the Your API Key field highlighted"/>

### Step 2: Enter your API Access Key in the Connect UI

1. Open the form where you need to authenticate with Weatherstack.
2. Enter your key in the **API Access Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/weatherstack/form.png" alt="Weatherstack Connect UI form with the API Access Key field" style={{maxWidth: "450px" }}/>

You are now connected to Weatherstack.
