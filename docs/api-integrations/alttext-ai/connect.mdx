## Overview

To authenticate with AltText.ai, you need:

1. **API Key** — an AltText.ai API key. A site key or a full-access key both work.

This guide will show you how to create one.

### Prerequisites

- An AltText.ai account. Every new account starts with 25 free credits, no credit card required. If you don't have an account, [sign up](https://alttext.ai/users/sign-up).

### Step 1: Create an API key

1. Sign in to [AltText.ai](https://alttext.ai/users/sign-in).
2. Open **Integrations** > **API Keys** ([direct link](https://alttext.ai/account/api_keys)) and click **New API Key**.

<img src="/api-integrations/alttext-ai/api_keys_page.png" alt="AltText.ai API Keys tab with the New API Key button"/>

3. Enter a name for the key. Keep **Site key** selected for a key that generates alt text, or pick **Full access** for a key that can also manage other keys. Then click **Create Key**.

<img src="/api-integrations/alttext-ai/new_api_key_form.png" alt="AltText.ai New API Key form with the key name and the Site key and Full access options"/>

4. On the **API Keys** list, click the key's masked token to copy it. The token starts with `atai_`.

<img src="/api-integrations/alttext-ai/api_key_created.png" alt="AltText.ai API Keys list showing the new key and its masked token to copy"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with AltText.ai.
2. Enter your API key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/alttext-ai/form.png" alt="AltText.ai Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to AltText.ai.
