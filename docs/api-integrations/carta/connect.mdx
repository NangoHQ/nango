## Overview

To authenticate with Carta, you need:

1. **Login Host** and **API Host** — the Carta environment your account is in.
2. A Carta login with access to the companies, firms, or portfolios you want to share.

This guide shows you how to pick the environment.

### Step 1: Select your Carta environment

Most accounts are in production, which is the default. Pick Playground only if you were given a Carta Playground account for testing. The two hosts must match:

| Environment | Login Host | API Host |
| - | - | - |
| Production | `login.app.carta.com` | `api.carta.com` |
| Playground | `login.playground.carta.team` | `api.playground.carta.team` |

### Step 2: Log in to Carta

Click **Connect**, log in to Carta, and approve the requested access.

<Note>Carta only shows data your login can already see in Carta.</Note>
