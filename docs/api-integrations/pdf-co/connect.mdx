## Overview

To authenticate with PDF.co, you need:

1. **API Key** - your PDF.co API key.

This guide shows you how to get it.

### Prerequisites

- A PDF.co account. You can [sign up](https://app.pdf.co/signup) for a free trial with no credit card.

### Step 1: Copy your API key

1. Sign in to the [PDF.co dashboard](https://app.pdf.co/).
2. On the **Home** page, find the **Your API Key** card and click **Copy Key**.

<img src="/api-integrations/pdf-co/copy_api_key.png" alt="PDF.co dashboard home page with the Copy Key button on the Your API Key card"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with PDF.co.
2. Enter your **API Key** in the designated field.
3. Click **Connect**. Nango checks the key with PDF.co and rejects it if it is wrong.

<img src="/api-integrations/pdf-co/form.png" alt="Nango Connect UI form for entering the PDF.co API key" style={{maxWidth: "450px" }}/>

You are now connected to PDF.co.
