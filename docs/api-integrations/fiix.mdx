## 🚀 Quickstart

Connect to Fiix with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Fiix_.
    </Step>
    <Step id="authorize-fiix" title="Authorize Fiix">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your subdomain, App Key, Access Key, and Secret Key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-fiix-api" title="Call the Fiix API">
    Let's make your first request to the Fiix API to list your accounts. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl -X POST "https://api.nango.dev/proxy/api/" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>" \
              -H "Content-Type: application/json" \
              -d '{"_maCn": "FindRequest", "clientVersion": {"major": 2, "minor": 8, "patch": 1}, "className": "Account", "fields": "id, strCode, strDescription"}'
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.post({
            endpoint: '/api/',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>',
            data: {
                _maCn: 'FindRequest',
                clientVersion: { major: 2, minor: 8, patch: 1 },
                className: 'Account',
                fields: 'id, strCode, strDescription'
            }
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Nango adds your keys to the request URL and signs every request for you.

    <Note>
    Fiix returns errors with a `200` status. Check the response for an `error` object to know if a request failed.
    </Note>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>
