## Overview

To authenticate with Appointo, you need:

1. **API Token** — an API token from the Integrations page of your Appointo dashboard.

This guide will show you how to generate it.

### Prerequisites

- An Appointo account on a paid plan. Appointo API access is not available on free plans.

### Step 1: Generate an API token

1. Sign in to the [Appointo dashboard](https://dashboard.appointo.me/).
2. Click **Integrations** in the left sidebar.
3. On the **API Token** card, click **Generate Token**.

<img src="/api-integrations/appointo/integrations_api_token.png" alt="Appointo Integrations page with the Generate Token button on the API Token card" />

4. Copy the generated token.

### Step 2: Enter your API token in the Connect UI

1. Open the form where you need to authenticate with Appointo.
2. Enter your API token in the **API Token** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/appointo/form.png" alt="Appointo Connect UI form with the API Token field" style={{maxWidth: "450px" }}/>

You are now connected to Appointo.
