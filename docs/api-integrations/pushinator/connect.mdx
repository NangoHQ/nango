## Overview

To authenticate with Pushinator, you need:

1. **API Token** — a Pushinator API token.

This guide will show you how to create it.

### Prerequisites

- A Pushinator account. The Free plan can create API tokens. If you don't have an account, [sign up](https://console.pushinator.com/sign-up).

### Step 1: Create an API token

1. Sign in to the [Pushinator Console](https://console.pushinator.com). If you land on an upgrade page after signing up, skip it.
2. Click **API Tokens** in the left sidebar, then click **Create API token**.

<img src="/api-integrations/pushinator/api_tokens_page.png" alt="Pushinator Console API Tokens page with the Create API token button"/>

3. In the **Here's your API token** dialog, click **Copy**, then click **Okay**. The token is shown only once; if you lose it, create a new one.

<img src="/api-integrations/pushinator/api_token_created.png" alt="Pushinator dialog showing the new API token with the Copy button"/>

New tokens are named **Untitled API Token**. To rename one, open the actions menu in its row and choose **Rename token**.

### Step 2: Enter your API token in the Connect UI

1. Open the form where you need to authenticate with Pushinator.
2. Enter your API token in the **API Token** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/pushinator/form.png" alt="Pushinator Connect UI form with the API Token field" style={{maxWidth: "450px" }}/>

You are now connected to Pushinator.
