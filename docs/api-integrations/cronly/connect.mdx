## Overview

To authenticate with Cronly, you need:

1. **API Key** — a Cronly API token.

This guide will show you how to get it.

### Prerequisites

- A Cronly account. API access is included on the free plan; [register](https://cronly.app/register) if you don't have one.

### Step 1: Generate an API token

1. Sign in to [Cronly](https://cronly.app/login).
2. In the sidebar under **Integrations**, click **API keys**, then click **Generate new token**.

<img src="/api-integrations/cronly/api_keys_page.png" alt="Cronly API keys page with the Generate new token button"/>

3. Enter a name for the token and click **Generate token**.

<img src="/api-integrations/cronly/generate_token_form.png" alt="Cronly Generate new token form with the Name field and the Generate token button"/>

4. Copy the new token with the clipboard button in the green banner, including its numeric `ID|` prefix. Cronly shows it only once.

<img src="/api-integrations/cronly/token_created.png" alt="Cronly banner confirming the token was created, with the button to copy it"/>

### Step 2: Enter your API token in the Connect UI

1. Open the form where you need to authenticate with Cronly.
2. Enter your API token in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/cronly/form.png" alt="Cronly Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Cronly.
