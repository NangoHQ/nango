## Overview

To authenticate with BugHerd, you need:

1. **API Key** — the API key from your BugHerd organization settings.

This guide will show you where to find it.

### Prerequisites

- A BugHerd account. If you don't have one, [sign up](https://www.bugherd.com/users/registrations/new).

### Step 1: Open your organization settings

1. Log in to [BugHerd](https://www.bugherd.com/users/sign_in).
2. Click your organization name in the top-left breadcrumb, then choose **Settings**.

<img src="/api-integrations/bugherd/open_org_settings.png" alt="BugHerd organization menu with the Settings option highlighted"/>

### Step 2: Copy your API key

1. Stay on the **General** tab and scroll to the **Authentication Token** section.
2. Click **Copy** to copy your API key.

<img src="/api-integrations/bugherd/copy_api_key.png" alt="BugHerd General settings with the Copy button in the Authentication Token section"/>

### Step 3: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with BugHerd.
2. Paste your API key into the **API Key** field. BugHerd's password is always the letter `x`, so Nango fills it in and the form does not ask for one.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/bugherd/form.png" alt="BugHerd Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to BugHerd.
