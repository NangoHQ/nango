## 🚀 Quickstart

Connect to Carbone with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Carbone_.
    </Step>
    <Step id="authorize-carbone" title="Authorize Carbone">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your Carbone API key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-carbone-api" title="Call the Carbone API">
    Let's make your first request to the Carbone API to list your templates. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/templates?limit=1" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/templates',
            params: { limit: '1' },
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- Nango sends the `carbone-version: 5` header on every request, because Carbone recommends specifying an API version.
- The test API key only generates watermarked PDFs. Other formats need the production key, which requires a Carbone Cloud subscription.
- `GET /render/{renderId}` and `GET /status` don't require authentication; every other endpoint does.
- Carbone returns HTTP 429 when too many requests are sent in parallel.
