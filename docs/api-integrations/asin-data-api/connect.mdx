## Overview

To authenticate with ASIN Data API, you need:

1. **API Key** - the API key of your ASIN Data API account.

This guide will show you how to find it.

### Prerequisites

- An ASIN Data API account. If you don't have one, [sign up for free](https://app.asindataapi.com/signup) and click the verification link in the email ASIN Data API sends you.

### Step 1: Copy your API key

Each ASIN Data API account has one API key, created automatically.

1. Log in to the [ASIN Data API dashboard](https://app.asindataapi.com/login). You land on the **API Playground**.
2. Your API key is shown next to **API Key** at the top of the page. Click the copy icon next to it.

<img src="/api-integrations/asin-data-api/api_key_playground.png" alt="ASIN Data API Playground with the API Key field and its copy icon at the top of the page"/>

You can also find the key under **Account** -> **Plan & Payment**. Click the copy icon next to **API Key**.

<img src="/api-integrations/asin-data-api/account_api_key.png" alt="ASIN Data API Plan & Payment page with the API Key field and its copy icon"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with ASIN Data API.
2. Enter your API key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/asin-data-api/form.png" alt="ASIN Data API Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to ASIN Data API.
