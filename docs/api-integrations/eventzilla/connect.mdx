## Overview

To authenticate with Eventzilla, you need:

1. **API key** — a key generated under API credentials in your Eventzilla settings.

This guide will show you how to generate it.

### Prerequisites

- An [Eventzilla](https://www.eventzilla.net) account.

### Step 1: Generate an API key

1. Sign in to [Eventzilla](https://app.eventzilla.net/us/login).
2. Open **Settings**, then go to **For Developers** > **API credentials** and click **Generate new key**.

<img src="/api-integrations/eventzilla/api_credentials_page.png" alt="Eventzilla API Credentials page with the Generate new key button"/>

3. Enter a friendly name for the key (for example, `Nango`) and click **Create key**.

<img src="/api-integrations/eventzilla/create_key_dialog.png" alt="Eventzilla dialog with the friendly name field and the Create key button"/>

4. In the **Copy your API key now** dialog, click **Copy**. Eventzilla shows the full key only in this dialog.

<img src="/api-integrations/eventzilla/copy_api_key.png" alt="Eventzilla Copy your API key now dialog with the Copy button"/>

5. Tick **I've saved this key**, then click **Done**.

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Eventzilla.
2. Paste the key you copied in Step 1 into the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/eventzilla/form.png" alt="Eventzilla Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Eventzilla.
