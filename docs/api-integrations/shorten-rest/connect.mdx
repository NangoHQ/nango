## Overview

To authenticate with Shorten.REST, you need:

1. **API Key** — an API key from your Shorten.REST account.

This guide will show you how to find it.

### Prerequisites

- A Shorten.REST account. If you don't have one, [sign up](https://dash.shorten.rest/).

### Step 1: Copy your API key

1. Sign in to [Shorten.REST Dash](https://dash.shorten.rest/) and click **API Keys** under **Settings** in the left sidebar. Shorten.REST creates an API key for you when you sign up, so the **API key management** table already lists one.

<img src="/api-integrations/shorten-rest/api_keys_page.png" alt="Shorten.REST API Keys page with the Create key button highlighted"/>

2. Click **Copy** next to the key you want to use.

<img src="/api-integrations/shorten-rest/copy_api_key.png" alt="Shorten.REST API key management table with the Copy button highlighted"/>

An account can have up to 2 API keys. To add a second one, click **Create key**.

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Shorten.REST.
2. Enter your API key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/shorten-rest/form.png" alt="Shorten.REST Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Shorten.REST.
