## 🚀 Quickstart

Connect to Court Rules with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Court Rules_.
    </Step>
    <Step id="authorize-court-rules" title="Authorize Court Rules">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your Court Rules API key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-court-rules-api" title="Call the Court Rules API">
    Let's make your first request to the Court Rules API to list the statewide rulebooks for California. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/api/v1/rulebooks?jurisdiction=CA&scope=statewide" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/api/v1/rulebooks',
            params: { jurisdiction: 'CA', scope: 'statewide' },
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- Enforcement data is served only by the MCP server at `https://mcp.courtrules.app/mcp`, which takes the same API key. Calls to it set `baseUrlOverride` to `https://mcp.courtrules.app`; Nango keeps the connection's credentials and headers. See [Overview](https://docs.courtrules.app/api-reference/overview.md).
