## Overview

To authenticate with Twelve Data, you need:

1. **API Key** — the API key from your Twelve Data dashboard.

This guide will show you how to get it.

### Prerequisites

- A Twelve Data account. The Basic plan is free and needs no credit card: [sign up](https://twelvedata.com/register).

### Step 1: Copy your API key

1. Sign in to [Twelve Data](https://twelvedata.com/login).
2. Click **API keys** in the dashboard sidebar, or open the [API keys page](https://twelvedata.com/account/api-keys).

<img src="/api-integrations/twelve-data/dashboard_api_keys_nav.png" alt="The API keys item in the Twelve Data dashboard sidebar" />

3. Twelve Data creates one key for your account, listed as **Secret key**. Click **Reveal** to show the token, or click the copy button next to it to copy the key.

<img src="/api-integrations/twelve-data/api_key_copy.png" alt="The Secret key row on the Twelve Data API keys page" />

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Twelve Data.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/twelve-data/form.png" alt="The Twelve Data connection form in the Nango Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to Twelve Data.
