## Overview

To authenticate with JigsawStack, you need:

1. **Secret Key** — a secret API key from your JigsawStack dashboard.

This guide will show you how to get it.

### Prerequisites

- A JigsawStack account. You can sign up for free at the [JigsawStack dashboard](https://jigsawstack.com/dashboard).

### Step 1: Create a secret API key

1. Log in to the [JigsawStack dashboard](https://jigsawstack.com/dashboard) and open the **Keys** tab.

<img src="/api-integrations/jigsawstack/dashboard_keys_tab.png" alt="JigsawStack dashboard with the Keys tab highlighted" />

2. On the **API Keys** page, click **+ Create new key**.

<img src="/api-integrations/jigsawstack/create_new_key.png" alt="JigsawStack API Keys page with the Create new key button highlighted" />

3. Enter a name for the key, keep the **Secret** type selected and click **Generate API Key**. A secret key can access all APIs.

<img src="/api-integrations/jigsawstack/generate_api_key_dialog.png" alt="JigsawStack new key dialog with the Secret type selected and the Generate API Key button highlighted" />

4. Copy the secret key and store it securely. It is shown only once.

<img src="/api-integrations/jigsawstack/copy_secret_key.png" alt="JigsawStack secret key dialog with the copy button highlighted" />

### Step 2: Enter your secret key in the Connect UI

1. Open the form where you need to authenticate with JigsawStack.
2. Enter your **Secret Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/jigsawstack/form.png" alt="JigsawStack Connect UI form with the Secret Key field" style={{maxWidth: "450px" }}/>

You are now connected to JigsawStack.
