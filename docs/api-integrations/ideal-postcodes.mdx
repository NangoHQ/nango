## 🚀 Quickstart

Connect to Ideal Postcodes with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Ideal Postcodes_.
    </Step>
    <Step id="authorize-ideal-postcodes" title="Authorize Ideal Postcodes">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your API key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-ideal-postcodes-api" title="Call the Ideal Postcodes API">
    Let's make your first request to the Ideal Postcodes API to get address suggestions for "10 downing". Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/v1/autocomplete/addresses?query=10%20downing&limit=1" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/v1/autocomplete/addresses',
            params: { query: '10 downing', limit: '1' },
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- Nango sends the key as `Authorization: Bearer <key>` on every call. Calls that need it another way, such as the `api_key` query parameter, can read it from the connection's credentials (`credentials.apiKey`) and pass it as the docs show.
- Ideal Postcodes' MCP server takes the same key: send MCP requests to `/mcp` through this connection.
