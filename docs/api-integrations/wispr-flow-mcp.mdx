## 🚀 Quickstart

Connect to the Wispr Flow MCP server with Nango and call MCP tools in minutes. Wispr Flow MCP uses OAuth 2.0 with **dynamic client registration**, so no app registration is required.

<Steps>
    <Step id="create-integration" title="Create the integration">
        In Nango ([free signup](https://app.nango.dev)), go to **Integrations** → _Configure New Integration_ → _Wispr Flow (MCP)_.
    </Step>
    <Step id="authorize-wispr-flow-mcp" title="Authorize Wispr Flow">
        Go to **Connections** → _Add Test Connection_ → _Authorize_, then sign in to your Wispr Flow account. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-wispr-flow-mcp" title="Call the Wispr Flow MCP API">
        Make your first MCP request (initialize handshake). Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
        <Tabs>
            <Tab title="cURL">

                ```bash
                curl "https://api.nango.dev/proxy/connect/mcp" \
                  -X POST \
                  -H "Authorization: Bearer <NANGO-API-KEY>" \
                  -H "Provider-Config-Key: <INTEGRATION-ID>" \
                  -H "Connection-Id: <CONNECTION-ID>" \
                  -H "Content-Type: application/json" \
                  -d '{
                    "jsonrpc": "2.0",
                    "id": 1,
                    "method": "initialize",
                    "params": {
                        "protocolVersion": "2024-11-05",
                        "capabilities": {},
                        "clientInfo": {
                            "name": "nango-client",
                            "version": "1.0.0"
                        }
                    }
                }'
                ```

            </Tab>

            <Tab title="Node">

                Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

                ```typescript
                import { Nango } from '@nangohq/node';

                const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

                const res = await nango.post({
                    endpoint: '/connect/mcp',
                    providerConfigKey: '<INTEGRATION-ID>',
                    connectionId: '<CONNECTION-ID>',
                    body: {
                        jsonrpc: '2.0',
                        id: 1,
                        method: 'initialize',
                        params: {
                            protocolVersion: '2024-11-05',
                            capabilities: {},
                            clientInfo: {
                                name: 'nango-client',
                                version: '1.0.0'
                            }
                        }
                    }
                });

                console.log(res.data);
                ```
            </Tab>

        </Tabs>
        ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-nango" title="Implement Nango in your app">
        Follow our [Auth implementation guide](/guides/auth/auth-guide) to integrate Nango in your app.
    </Step>
</Steps>

## 📚 Wispr Flow (MCP) guides

Nango registers a client with Wispr Flow's OAuth server automatically (dynamic client registration), so you do not need to register an MCP application — just create the integration in Nango and authorize with your Wispr Flow account. Nango requests the `openid` and `offline_access` scopes Wispr Flow's MCP server asks for, which returns a refresh token; access tokens are short-lived, so Nango refreshes them for you.

Things to know before connecting:

- The Wispr Flow account needs Notetaker and MCP access. MCP access is on by default, but an organization admin can turn it off, and it is not available on HIPAA (BAA) accounts.
- Authorization is account-wide: tools can read all of the user's Notetaker meetings, calendar events and notes, including existing content.
- Wispr Flow describes access as read-only: tools cannot create, edit, share or delete content, and cannot read dictation history or Notetaker chat history.
- If a tool call returns "Too many requests", wait about a minute before retrying.

Official resources: [Connect an MCP client to Wispr Flow](https://docs.wisprflow.ai/articles/9551372685-connect-an-mcp-client-to-wispr-flow-remote-mcp-server)
