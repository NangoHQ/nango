## Overview

To authenticate with Discogs (Personal Access Token), you will need:
1. **Personal Access Token** - A token that grants Nango permission to interact with the Discogs API on your behalf.

This guide will walk you through generating your **Personal Access Token** within Discogs.

### Prerequisites:

- You must have a Discogs account. Sign up for free at [discogs.com](https://www.discogs.com/).

#### Step 1: Generating your Personal Access Token

1. Log in to your [Discogs](https://www.discogs.com/) account.
2. Go to **Settings** -> [**Developers**](https://www.discogs.com/settings/developers).
3. Click **Generate new token** (skip this if you already have one).
4. Copy the generated **Personal Access Token**.

<Tip>You can revoke or regenerate your token at any time from the same page. Regenerating a token invalidates the previous one.</Tip>

#### Step 2: Enter credentials in the Connect UI

1. Open the form where you need to authenticate with Discogs (Personal Access Token).
2. Enter your **Personal Access Token**.
3. Submit the form.

You are now connected to Discogs (Personal Access Token).
