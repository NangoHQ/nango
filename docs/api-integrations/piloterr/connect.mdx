## Overview

To authenticate with Piloterr, you need:

1. **API Key** — an API key from your Piloterr workspace.

This guide will show you how to create one.

### Prerequisites

- A Piloterr account. If you don't have one, [sign up](https://app.piloterr.com/register); the free trial includes API access with no credit card.

### Step 1: Create an API key

1. Sign in to [Piloterr](https://app.piloterr.com) and click **API** in the sidebar to open the **API keys** tab.
2. Click **New API key**.

<img src="/api-integrations/piloterr/api_keys_page.png" alt="Piloterr API keys tab with the New API key button"/>

3. Enter a **Name** (for example, `nango-integration`) and pick a **Category** (for example, `development`). You can also set an expiry date, and request limits in the **Request limits** tab.
4. Click **Create API key**.

<img src="/api-integrations/piloterr/create_api_key_dialog.png" alt="Piloterr API key dialog with the Name and Category fields and the Create API key button"/>

5. In the **API key created** dialog, click **Copy** to copy the key, then click **Accept and continue**. The key is shown only once.

<img src="/api-integrations/piloterr/api_key_created.png" alt="Piloterr API key created dialog with the Copy button"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Piloterr.
2. Enter your API key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/piloterr/form.png" alt="Piloterr Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Piloterr.
