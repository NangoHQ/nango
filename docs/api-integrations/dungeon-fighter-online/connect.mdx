## Overview

To authenticate with Dungeon Fighter Online, you need:

1. **API Key** — the API key of an application you register on Neople Developers.

This guide will show you how to get it.

### Prerequisites

- A Facebook, Google or Naver account to sign in to [Neople Developers](https://developers.neople.co.kr/main). The site is in Korean.

### Step 1: Register an application and copy your API key

1. Go to [Neople Developers](https://developers.neople.co.kr/main) and click **로그인** (Login). Sign in with your Facebook, Google or Naver account. On your first sign-in, accept the terms of service and the privacy consent.
2. Open **마이페이지** (My Page). The **애플리케이션 목록** (Application list) opens. Click **등록** (Register).

<img src="/api-integrations/dungeon-fighter-online/app_list_register.png" alt="Neople Developers Application list (애플리케이션 목록) with the Register (등록) button" />

3. Select **던전앤파이터** (Dungeon Fighter) as the game, enter an application name using only letters and numbers, and a description. Click **등록** (Register), then **확인** (OK).

<img src="/api-integrations/dungeon-fighter-online/register_application_form.png" alt="Neople Developers application registration form with the Dungeon Fighter (던전앤파이터) game selected and the Register (등록) button" />

4. The new application appears in the Application list. Copy the key from its **API Key** column. You can also find it later under **설정** (Settings).

<img src="/api-integrations/dungeon-fighter-online/api_key_created.png" alt="Neople Developers Application list showing the new application and its API Key column" />

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Dungeon Fighter Online.
2. Enter your API key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/dungeon-fighter-online/form.png" alt="Dungeon Fighter Online Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Dungeon Fighter Online.
