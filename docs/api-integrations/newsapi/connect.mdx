## Overview

To authenticate with NewsAPI, you need:

1. **API Key** — the API key of your NewsAPI account.

This guide will show you how to get it.

### Prerequisites

- A NewsAPI account. [Register here](https://newsapi.org/register); the free Developer plan is for development and testing only, and production use needs a paid plan.

### Step 1: Copy your API key

1. Log in at [newsapi.org/login](https://newsapi.org/login) and open your [Account](https://newsapi.org/account) page.
2. Copy the key in the **API key** field.

<img src="/api-integrations/newsapi/account_api_key.png" alt="NewsAPI Account page with the API key field highlighted"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with NewsAPI.
2. Enter your **API Key** in the designated field.
3. Click **Connect**.

<img src="/api-integrations/newsapi/form.png" alt="Nango Connect UI form for entering the NewsAPI API key" style={{maxWidth: "450px" }}/>

You are now connected to NewsAPI.
