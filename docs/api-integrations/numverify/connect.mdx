## Overview

To authenticate with Numverify, you need:

1. **API Access Key** — the personal key assigned to your Numverify account.

This guide will show you how to get it.

### Prerequisites

- A Numverify account. If you don't have one, sign up for the [Free Plan](https://numverify.com/signup/free/monthly), which includes 100 API requests per month, or [log in](https://numverify.com/login) to your existing account.

### Step 1: Copy your API Access Key

1. Open your [Numverify dashboard](https://numverify.com/dashboard).
2. Under **Your API Key**, click the copy icon to copy your API Access Key.

<img src="/api-integrations/numverify/dashboard_api_key.png" alt="Numverify dashboard showing the Your API Key field with the copy icon and the Reset Key link"/>

To generate a new key, click **Reset Key**.

### Step 2: Enter your API Access Key in the Connect UI

1. Open the form where you need to authenticate with Numverify.
2. Enter your API Access Key in the **API Access Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/numverify/form.png" alt="Numverify Connect UI form with the API Access Key field" style={{maxWidth: "450px" }}/>

You are now connected to Numverify.
