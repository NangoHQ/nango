## Overview

To authenticate with HydraDB, you need:
1. **API Key** — A key that grants Nango permission to interact with the HydraDB API on your behalf.

This guide will walk you through obtaining your API key from HydraDB.

### Prerequisites

- A HydraDB account ([hydradb.com](https://hydradb.com)).

### Step 1: Obtain your API key

1. Sign in to the [HydraDB dashboard](https://dashboard.hydradb.com).
2. Open the **API keys** section.
3. Create a new key, or copy an existing one.

<img src="/api-integrations/hydradb/api_key.png"/>

### Step 2: Enter credentials in the Connect UI

Once you have your API key:
1. Open the form where you need to authenticate with HydraDB.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/hydradb/form.png" style={{maxWidth: "450px" }}/>


You are now connected to HydraDB.
