## Overview

To authenticate with HydraDB, you will need an **API key** that grants Nango
permission to call the HydraDB API on your behalf. This guide explains how to
obtain it.

### Prerequisites

- A HydraDB account ([hydradb.com](https://hydradb.com)).

### Instructions

#### Step 1: Find your API key

1. Sign in to the HydraDB dashboard.
2. Open the API keys section.
3. Create a key, or copy an existing one.

#### Step 2: Enter it in Nango

When adding a HydraDB connection in Nango, paste the API key into the **API Key**
field.

You are now connected to HydraDB.
