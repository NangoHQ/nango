## Overview

To authenticate with Supadata, you need:

1. **API Key** — an API key of your Supadata organization.

This guide will show you how to create one.

### Prerequisites

- A Supadata account. The Free plan includes API access. If you don't have an account, [sign up](https://dash.supadata.ai?plan=free).

### Step 1: Create an API key

1. Sign in to the [Supadata dashboard](https://dash.supadata.ai).
2. In the sidebar, open **API Keys** and click **Create API Key**.

<img src="/api-integrations/supadata/api_keys_page.png" alt="Supadata dashboard API Keys page with the Create API Key button"/>

3. Enter a description (for example, `nango-integration`), keep **Never expires** or pick an expiry date, and click **Create**.

<img src="/api-integrations/supadata/create_api_key_dialog.png" alt="Supadata Create API Key dialog with the description and expiry fields"/>

4. Copy the API key before you click **Got it**. It is shown only once.

<img src="/api-integrations/supadata/api_key_created.png" alt="Supadata API key created dialog showing the new key to copy"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Supadata.
2. Enter your API key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/supadata/form.png" alt="Supadata Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Supadata.
