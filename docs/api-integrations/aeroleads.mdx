## 🚀 Quickstart

Connect to AeroLeads with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _AeroLeads_.
    </Step>
    <Step id="authorize-aeroleads" title="Authorize AeroLeads">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your AeroLeads API key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-aeroleads-api" title="Call the AeroLeads API">
    Let's make your first request to the AeroLeads API: get the details of a LinkedIn profile. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, connection ID, and a LinkedIn profile URL:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl -G "https://api.nango.dev/proxy/get_linkedin_details" \
              --data-urlencode "linkedin_url=<LINKEDIN-PROFILE-URL>" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/get_linkedin_details',
            params: { linkedin_url: '<LINKEDIN-PROFILE-URL>' },
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

- Nango does not check the API key when a connection is created, so a wrong or revoked key still connects and fails on its first call.
