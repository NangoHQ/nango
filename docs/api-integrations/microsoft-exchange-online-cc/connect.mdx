## Overview

To authenticate with Microsoft Exchange Online Admin (Client Credentials), you need:

1. **Tenant ID** — the ID of the Microsoft Entra tenant where your app is registered.
2. **Client ID** — the ID Microsoft Entra ID assigns to your app.
3. **Client Secret** — a secret that lets your app call the Exchange Online Admin API without a signed-in user.

This guide will show you how to get them.

### Prerequisites

- An Exchange Online subscription.
- A Microsoft Entra role that can register apps and assign roles, such as **Privileged Role Administrator**, and an admin who can grant tenant-wide consent.

### Step 1: Register an app in Microsoft Entra ID

1. Sign in to the [Microsoft Entra admin center](https://entra.microsoft.com) and open **App registrations**.
<img src="/integrations/all/microsoft-business-central/app_registration.png" />
2. Select **New registration**.
<img src="/integrations/all/microsoft-business-central/new_registration.png" />
3. Enter a name for your app, select **Accounts in this organizational directory only**, and select **Register**.
<img src="/integrations/all/sharepoint-online-oauth2-cc/register_new_app.png" />
4. On the app's **Overview** page, copy the **Application (client) ID** and the **Directory (tenant) ID**. These are your **Client ID** and **Tenant ID**.
<img src="/integrations/all/sharepoint-online-oauth2-cc/client_id.png" />

### Step 2: Add the Exchange API permission

1. In your app, go to **API permissions** > **Add a permission** > **APIs my organization uses**.
2. Search for **Office 365 Exchange Online** and select it.
3. Select **Application permissions**, expand **Exchange**, select `Exchange.ManageAsAppV2`, then select **Add permissions**.
4. Select **Grant admin consent for [your tenant]**.

### Step 3: Give the app an Exchange role

The API permission lets your app get a token; an Exchange role decides what it can manage. Without one, requests return `403 Forbidden`.

1. In the [Microsoft Entra admin center](https://entra.microsoft.com), go to **Roles & admins**.
2. Select a role that covers your integration, such as **Exchange Administrator**, then **Add assignments**, and assign it to your app.

### Step 4: Create a client secret

1. In your app, go to **Certificates & secrets** > **New client secret**.
2. Enter a description and an expiry, then select **Add**.
<img src="/integrations/all/sharepoint-online-oauth2-cc/client_secret.png" />
3. Copy the secret's **Value**. This is your **Client Secret**.
<img src="/integrations/all/sharepoint-online-oauth2-cc/gen_client_secret.png" />

<Note>
Microsoft only shows the secret value once. Save it somewhere secure before leaving the page. When the secret expires, create a new one and update it in Nango.
</Note>

### Step 5: Enter your credentials in the Connect UI

1. Open the form where you need to authenticate with Microsoft Exchange Online Admin (Client Credentials).
2. Enter your **Tenant ID**, **Client ID**, and **Client Secret** in the designated fields.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/microsoft-exchange-online-cc/form.png" alt="Nango Connect UI form for entering the Microsoft Exchange Online tenant ID, client ID and client secret" style={{maxWidth: "450px" }}/>

You are now connected to Microsoft Exchange Online Admin (Client Credentials).
