## Overview

To authenticate with 0CodeKit, you need:

1. **API Key** - your 0CodeKit API key.

This guide shows you where to find it.

### Prerequisites

- A 0CodeKit account. The free plan includes API access; [sign up here](https://my.0codekit.com/en/auth/register).

### Step 1: Copy your API key

1. Sign in to [0CodeKit](https://my.0codekit.com/en/auth/login) and click **Dashboard** in the top navigation.
2. Scroll down to the **API Key** card. 0CodeKit creates your key when you sign up.
3. Click the copy icon next to **Your API Key**. Click the eye icon first if you want to see the key.

<img src="/api-integrations/0codekit/account_api_key_copy.png" alt="0CodeKit dashboard with the API Key card and the copy button next to Your API Key"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with 0CodeKit.
2. Enter your **API Key** in the designated field.
3. Submit the form. Nango checks the key with 0CodeKit and rejects it if it is wrong.

<img src="/api-integrations/0codekit/form.png" alt="Nango Connect UI form for entering the 0CodeKit API key" style={{maxWidth: "450px" }}/>

You are now connected to 0CodeKit.
