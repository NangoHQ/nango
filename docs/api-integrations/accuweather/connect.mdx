## Overview

To connect with AccuWeather, you need:

1. **API Key** — the API key of your AccuWeather developer app.

This guide will show you how to get it.

### Prerequisites

- An AccuWeather developer account with an active subscription. You can [sign up](https://developer.accuweather.com/signin) for free and start a 14-day free trial, with no credit card required.

### Step 1: Activate a subscription

1. Sign in to the [AccuWeather developer portal](https://developer.accuweather.com/signin).
2. Click **Subscriptions & Keys** in the top navigation. On your first visit, fill in the **Complete Your Profile** form and click **Continue**.
3. Click **Activate Free Trial** to start the 14-day trial. If you already have a paid plan, skip this step.

<img
    src="/api-integrations/accuweather/activate_free_trial.png"
    alt="AccuWeather Subscriptions & Keys page with the Activate Free Trial button highlighted"
/>

### Step 2: Copy your API key

1. On the **Subscriptions & Keys** page, find your app under **My Subscriptions**. AccuWeather creates an app with an API key for your subscription.
2. Click the copy icon next to the masked API key.

<img
    src="/api-integrations/accuweather/copy_api_key.png"
    alt="AccuWeather subscription showing an app's masked API key with the copy icon highlighted"
/>

### Step 3: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with AccuWeather.
2. Enter your **API Key** in the designated field.
3. Click **Connect**.

<img src="/api-integrations/accuweather/form.png" alt="Nango Connect UI form for entering the AccuWeather API Key" style={{maxWidth: "450px" }}/>

You are now connected to AccuWeather.
