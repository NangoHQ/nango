## Overview

To authenticate with Klazify, you need:

1. **API Key** - your Klazify API key.

This guide shows you how to find it.

### Prerequisites

- A Klazify account. All plans include a 7-day free trial. [Sign up here](https://www.klazify.com/register) with your email or Google account.

### Step 1: Copy your API key

1. Sign in to [Klazify](https://www.klazify.com/login).
2. In the top bar, click **Docs** to open the [API documentation](https://www.klazify.com/api-docs).
3. Under **Your API Key**, click **Copy Key**.

<img src="/api-integrations/klazify/api_key_copy.png" alt="Klazify API documentation page with the Your API Key box and the Copy Key button"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Klazify.
2. Enter your **API Key** in the designated field.
3. Click **Connect**. Nango checks the key with Klazify and rejects it if it is wrong.

<img src="/api-integrations/klazify/form.png" alt="Nango Connect UI form for entering the Klazify API key" style={{maxWidth: "450px" }}/>

You are now connected to Klazify.
