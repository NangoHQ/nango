## Overview

To authenticate with Bolt IoT, you need:

1. **API Key** — your Bolt Cloud API key.

This guide will show you how to get it.

### Prerequisites

- A Bolt Cloud account. You can sign up at [cloud.boltiot.com](https://cloud.boltiot.com/register/). The API is free to use.

### Step 1: Copy your API key

1. Sign in to [Bolt Cloud](https://cloud.boltiot.com). New accounts must first verify their email through the link Bolt sends.
2. Click **API** in the left sidebar.
3. Under **Generate Key**, make sure API access is set to **Enable**.

<img src="/api-integrations/bolt-iot/api_tab.png" alt="Bolt Cloud API Credentials page with the API tab selected and API access set to Enable"/>

4. Click the eye icon to show your API key, then click the copy icon next to it to copy the key.

<img src="/api-integrations/bolt-iot/copy_api_key.png" alt="Bolt Cloud Generate Key section with the copy icon next to the API key"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Bolt IoT.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/bolt-iot/form.png" alt="Bolt IoT connection form in the Nango Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to Bolt IoT.
