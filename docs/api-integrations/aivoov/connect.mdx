## Overview

To authenticate with AiVOOV, you need:

1. **API Key** — the API key from your AiVOOV profile.

This guide will show you how to find it.

### Prerequisites

- An AiVOOV account. If you don't have one, [sign up](https://aivoov.com/signup).
- A plan that includes API access. The API is a premium feature available only with selected plans; see [AiVOOV pricing](https://aivoov.com/pricing).
- A Characters Credit balance on your account, which the API needs.

### Step 1: Copy your API key

1. [Log in](https://aivoov.com/signin) to your AiVOOV account.
2. Open your [Profile page](https://aivoov.com/user/my_profile).
3. Go to the **API** section and copy your API key.

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with AiVOOV.
2. Enter your API key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/aivoov/form.png" alt="AiVOOV Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to AiVOOV.
