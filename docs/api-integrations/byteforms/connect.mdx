## Overview

To authenticate with Byteforms, you need:

1. **API Key** — a key you generate on your Byteforms profile.

This guide will show you how to generate one.

### Prerequisites

- A Byteforms account. If you don't have one, [sign up](https://forms.bytesuite.io/register); API access is part of the free plan.

### Step 1: Generate an API key

1. Sign in to [Byteforms](https://forms.bytesuite.io/login).
2. Open the user menu, click **Profile**, then select the **Account** tab.
3. Under **API Key**, click **Generate a new API Key**.
4. Enter a name for the key (for example, `nango-integration`) and click **Generate API Key**.

<img src="/api-integrations/byteforms/generate_api_key_dialog.png" alt="Byteforms Generate API Key dialog with the key name field"/>

5. In the **Here's your API Key** dialog, click **Copy API Key**. Byteforms shows the key only once, so store it somewhere safe.

<img src="/api-integrations/byteforms/api_key_created.png" alt="Byteforms dialog showing the new API key with the Copy API Key button"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Byteforms.
2. Paste your key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/byteforms/form.png" alt="Byteforms Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Byteforms.
