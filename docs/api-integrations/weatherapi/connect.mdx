## Overview

To authenticate with WeatherAPI.com, you need:

1. **API Key** — the API key from your WeatherAPI.com dashboard.

This guide will show you how to get it.

### Prerequisites

- A WeatherAPI.com account. [Sign up](https://www.weatherapi.com/signup) if you don't have one: the free plan includes 100,000 calls a month and needs no credit card.

### Step 1: Copy your API key

1. Log in to WeatherAPI.com and open your [dashboard](https://www.weatherapi.com/my/).
2. Scroll to the **API keys** section. Use the existing key, or enter a name for a new key and click **Add API key**.

<img src="/api-integrations/weatherapi/add_api_key.png" alt="WeatherAPI.com dashboard API keys section with the key name field and the Add API key button highlighted"/>

3. Click **Copy** next to the key in the **API keys** table.

<img src="/api-integrations/weatherapi/copy_api_key.png" alt="WeatherAPI.com API keys table with the Copy button of the new key highlighted"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with WeatherAPI.com.
2. Enter your key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/weatherapi/form.png" alt="WeatherAPI.com Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to WeatherAPI.com.
