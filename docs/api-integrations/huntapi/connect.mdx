## Overview

To authenticate with HuntAPI, you need:

1. **API Key** - A HuntAPI API key.

This guide shows you how to create one.

### Prerequisites

- A HuntAPI account. You can [sign up](https://app.huntapi.com/register) from the HuntAPI dashboard.

### Step 1: Create an API key

1. Sign in to the [HuntAPI dashboard](https://app.huntapi.com/) and click **API Keys** in the sidebar.
2. Click **New API Key**.
3. Enter a **Name** and pick a **Category**. You can also set an expiry date, and request limits on the **Request limits** tab. Then click **Create API Key**.
4. Click **Copy** to copy the key. HuntAPI shows it only once.

<Note>
If the key expires, is deactivated, or reaches its request limits, HuntAPI rejects requests made with it.
</Note>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with HuntAPI.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

You are now connected to HuntAPI.
