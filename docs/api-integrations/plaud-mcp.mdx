## Quickstart

Connect to the Plaud MCP server with Nango and call MCP tools in minutes. Plaud MCP uses OAuth 2.0 with **dynamic client registration**, so no app registration is required.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Plaud (MCP)_.
    </Step>
    <Step id="authorize-plaud" title="Authorize Plaud">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then log in to Plaud and approve access. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-plaud-mcp-tool" title="Call a Plaud MCP tool">
    Make your first MCP request (initialize handshake). Replace the placeholders below with your Nango API key, integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/mcp" \
              -X POST \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>" \
              -H "Content-Type: application/json" \
              -d '{
                "jsonrpc": "2.0",
                "id": 1,
                "method": "initialize",
                "params": {
                    "protocolVersion": "2024-11-05",
                    "capabilities": {},
                    "clientInfo": {
                        "name": "nango-client",
                        "version": "1.0.0"
                    }
                }
            }'
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ secretKey: '<NANGO-API-KEY>' });

        const res = await nango.post({
            endpoint: '/mcp',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>',
            body: {
                jsonrpc: '2.0',
                id: 1,
                method: 'initialize',
                params: {
                    protocolVersion: '2024-11-05',
                    capabilities: {},
                    clientInfo: {
                        name: 'nango-client',
                        version: '1.0.0'
                    }
                }
            }
        });

        console.log(res.data);
        ```
        </Tab>

    </Tabs>
    You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-nango" title="Implement Nango in your app">
        Follow our [Auth implementation guide](/guides/primitives/auth) to integrate Nango in your app.
    </Step>
</Steps>

## Plaud (MCP) guides

Nango uses **dynamic client registration** with Plaud's MCP OAuth server. You do not need to register an MCP application.

Available MCP tools include `get_current_user`, `list_files`, `get_file`, `get_note`, and `get_transcript` — covering recordings, AI-generated notes, and full transcripts with speaker labels.

To call Plaud's underlying REST API directly instead, see the [Plaud integration](/api-integrations/plaud).

Official resources: [Plaud MCP documentation](https://docs.plaud.ai/plaud-mcp-cli/mcp)
