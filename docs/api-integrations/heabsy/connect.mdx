## Overview

To authenticate with Heabsy, you need:

1. **API Key** — a key from the Heabsy Platform console.

This guide will show you how to get it.

### Prerequisites

- A Heabsy Platform account. You can [sign up here](https://platform.heabsy.com/quickstart) with Google, GitHub or email.

### Step 1: Create an API key

1. Sign in to the [Heabsy Platform console](https://platform.heabsy.com).
2. In the left sidebar, click **API keys**, then click **Create key**.

<img src="/api-integrations/heabsy/api_keys_page.png" alt="API keys page in the Heabsy Platform console with the Create key button"/>

3. Enter a name for the key. Optionally restrict its models, rate limits, budget or expiry, then click **Create key**.

<img src="/api-integrations/heabsy/create_key_dialog.png" alt="Create key dialog in the Heabsy Platform console with a key name entered"/>

4. In the **Save your key now** dialog, click **Copy**, then click **I saved the key**. The key is shown only once.

<img src="/api-integrations/heabsy/key_created.png" alt="Save your key now dialog with the Copy button"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Heabsy.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/heabsy/form.png" alt="Heabsy connection form in the Nango Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to Heabsy.
