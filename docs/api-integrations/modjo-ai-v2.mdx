## 🚀 Quickstart

Connect to Modjo AI (v2) with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Modjo AI (v2)_.
    </Step>
    <Step id="authorize-modjo-ai" title="Authorize Modjo AI">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your Modjo AI API key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-modjo-ai-api" title="Call the Modjo AI API">
    Let's make your first request to the Modjo AI v2 API to list users. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/users?page=1&size=10" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/users',
            params: { page: 1, size: 10 },
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Paths are relative to `https://api.modjo.ai/v2`. Modjo allows 100 requests per minute per workspace. On a `429`, Nango waits for the `X-RateLimit-Reset` interval before retrying.

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.

        To obtain your own API key, follow the setup guide linked below.
    </Step>
</Steps>
