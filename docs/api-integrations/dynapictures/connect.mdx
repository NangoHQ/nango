## Overview

To authenticate with DynaPictures, you need:

1. **API Key** — the API key of your DynaPictures account.

This guide will show you how to find it.

### Prerequisites

- A DynaPictures account. There is a free plan. If you don't have an account, [sign up](https://dynapictures.com/b/p/register).

### Step 1: Copy your API key

1. Sign in to [DynaPictures](https://dynapictures.com/app/).
2. Click the profile icon in the top-right corner, then choose **Account**.

<img src="/api-integrations/dynapictures/open_account_menu.png" alt="DynaPictures profile menu with the Account option"/>

3. On the **Account Settings** page, find the **API Key** section and click **Copy**.

<img src="/api-integrations/dynapictures/copy_api_key.png" alt="DynaPictures Account Settings page with the Copy button in the API Key section"/>

<Note>Each DynaPictures account has one API key, and it carries the full access of your user. It can't be limited to particular workspaces or actions.</Note>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with DynaPictures.
2. Paste your API key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/dynapictures/form.png" alt="DynaPictures Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to DynaPictures.
