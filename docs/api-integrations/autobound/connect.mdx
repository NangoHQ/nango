## Overview

To authenticate with Autobound, you need:

1. **API Key** — an Autobound Signal API key.

This guide will show you how to get it.

### Prerequisites

- An Autobound Signal API account. You can [sign up for free](https://signalapi.autobound.ai/signup); new accounts get 1,000 free credits with no credit card.

### Step 1: Create an API key

1. Sign in to the [Autobound Signal API portal](https://signalapi.autobound.ai/login). In the left sidebar under **Account**, click **API Keys**.

<img src="/api-integrations/autobound/open_api_keys.png" alt="Autobound Signal API portal with API Keys selected in the left sidebar"/>

2. On the **API Keys** page, click **Create Key**.

<img src="/api-integrations/autobound/create_key_button.png" alt="Autobound API Keys page with the Create Key button in the top-right corner"/>

3. Enter a name for the key, then click **Create**.

<img src="/api-integrations/autobound/name_new_key.png" alt="Create New API Key form in Autobound with a key name entered and the Create button"/>

4. Under **Save Your API Key**, click the copy button to copy the key, then click **Done**. The key is shown only once, so store it somewhere safe.

<img src="/api-integrations/autobound/copy_api_key.png" alt="Save Your API Key panel in Autobound with the copy button next to the new key"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Autobound.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/autobound/form.png" alt="Autobound connection form in the Nango Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to Autobound.
