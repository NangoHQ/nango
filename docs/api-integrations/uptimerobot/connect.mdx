## Overview

To authenticate with UptimeRobot, you need:

1. **API Key** - your UptimeRobot Main API key.

This guide shows you how to create it.

### Prerequisites

- An UptimeRobot account. You can [sign up](https://dashboard.uptimerobot.com/sign-up) for free; API access is included on the Free plan.

### Step 1: Create your Main API key

1. Log in to the [UptimeRobot dashboard](https://dashboard.uptimerobot.com/login).
2. Click **Integrations & API** in the left sidebar.
3. Choose the **API** tab.
4. Under **Main API keys**, click **Create** next to **Main API key**.

<img src="/api-integrations/uptimerobot/integrations_api_main_key.png" alt="UptimeRobot Integrations page with the API tab selected and the Create button next to Main API key"/>

5. Click the copy button next to the new key to copy it to your clipboard.

<img src="/api-integrations/uptimerobot/main_api_key_created.png" alt="UptimeRobot Main API key created, with the copy button next to the masked key"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with UptimeRobot.
2. Enter your **API Key** in the designated field.
3. Click **Connect**. Nango checks the key with UptimeRobot and rejects it if it is wrong.

<img src="/api-integrations/uptimerobot/form.png" alt="Nango Connect UI form for entering the UptimeRobot API key" style={{maxWidth: "450px" }}/>

You are now connected to UptimeRobot.
