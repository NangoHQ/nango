## Overview

To authenticate with Financial Data, you need:

1. **API Key** — the API key shown on your Financial Data dashboard.

This guide will show you how to get it.

### Prerequisites

- A [Financial Data](https://financialdata.net/sign-up) account with a subscription. The Free plan covers the endpoints labelled **Free subscription** in the [API documentation](https://financialdata.net/documentation).

### Step 1: Copy your API key

1. Sign in at [financialdata.net/sign-in](https://financialdata.net/sign-in). You land on the **Dashboard**.
2. If **Subscription Name** says **Not subscribed**, click **Manage Subscription**, choose a plan (click **Get Started** on the Free plan), and complete the checkout.
3. Back on the **Dashboard**, copy the value next to **API Key**. Each account has one API key.

<img src="/api-integrations/financial-data/dashboard_api_key.png" alt="Financial Data dashboard showing the subscription and the API Key field"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Financial Data.
2. Paste the key you copied in Step 1 into the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/financial-data/form.png" alt="Financial Data Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Financial Data.
