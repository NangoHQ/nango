## Overview

To authenticate with beaconcha.in, you need:

1. **API Key** — a beaconcha.in API key.

This guide will show you how to create one.

### Prerequisites

- A [beaconcha.in account](https://beaconcha.in/register) with a 30-day free trial or a paid API plan. API endpoints require an API key, and only free trial and paid users have API access.

### Step 1: Start a free trial or choose a plan

1. Sign in to [beaconcha.in](https://beaconcha.in/login) and, in the sidebar, open **API** -> [API Key Management](https://beaconcha.in/api/key-management).
2. Click **Upgrade Plan**, then click **Start Free Trial** on the API pricing page, or choose a paid plan. The trial does not renew on its own: API access ends after 30 days unless you upgrade. Without an active trial or plan, beaconcha.in rejects API requests made with your key, so the connection fails.

<img src="/api-integrations/beaconcha-in/start_free_trial.png" alt="beaconcha.in API pricing page with the Start Free Trial button"/>

### Step 2: Create an API key

1. On the [API Key Management](https://beaconcha.in/api/key-management) page, under **Create New API Key**, enter a name for the key and click **Generate key**.

<img src="/api-integrations/beaconcha-in/create_api_key.png" alt="beaconcha.in API Key Management page with the key name field and the Generate key button"/>

2. Click **Copy API Key** to copy the new key right away. It is only shown once.

<img src="/api-integrations/beaconcha-in/copy_api_key.png" alt="beaconcha.in dialog confirming the API key was created, with the Copy API Key button"/>

### Step 3: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with beaconcha.in.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/beaconcha-in/form.png" alt="Nango Connect UI form for beaconcha.in with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to beaconcha.in.
