## Overview

To authenticate with Callingly, you need:

1. **API Key** — a Callingly API key.

This guide will show you how to get it.

### Prerequisites

- A Callingly account. You can [start a 14-day free trial](https://callingly.com/register), no credit card required, if you don't have one.

### Step 1: Create an API key

1. Log in to [Callingly](https://callingly.com/login) and go to **Settings** -> **API Keys**, under **Advanced**.
2. Click **Add API Key** in the top right.

<img src="/api-integrations/callingly/api_keys_page.png" alt="Callingly API Keys settings page with the Add API Key button"/>

3. Give the API key a name (it is only for your own reference) and click **Save**.

<img src="/api-integrations/callingly/new_api_key_dialog.png" alt="Callingly New API Key panel with the Name field and the Save button"/>

4. Copy the API key and store it somewhere safe. You can't view it again after you close the panel.

<img src="/api-integrations/callingly/api_key_created.png" alt="Callingly New API Key panel showing the created API key, with the key hidden"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Callingly.
2. Enter your API key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/callingly/form.png" alt="Callingly Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Callingly.
