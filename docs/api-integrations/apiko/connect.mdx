## Step 1: Create an API key

1. Sign in to APIKO and open **API Keys** in the console.
2. Create a key and copy it. See the [APIKO quickstart](https://apiko.app/docs/quickstart) for the console instructions.

## Step 2: Authorize the connection

1. Open the Nango Connect UI for APIKO.
2. Paste the key into the **API Key** field and authorize the connection.

Nango verifies the key by listing models available to the APIKO account.
