## Overview

To authenticate with Amplemarket, you will need:

1. **API Key** - A key that is used to identify your Amplemarket account.

This guide will walk you through finding this key within Amplemarket.

### Prerequisites:

- You must have a registered Amplemarket account.

### Instructions:

#### Step 1: Finding Your API Key

1. **Log in** to your Amplemarket dashboard.
2. Go to **Settings** -> **API** to open the API Integrations page.
3. Click **+ New API Key**, then give it a name and submit the form to generate the key.

<img src="/api-integrations/amplemarket/created_api_key.webp"/>


4. Copy the **API Key**.

<img src="/api-integrations/amplemarket/generate_api_key.webp"/>



#### Step 2: Enter API Key in the Connect UI

Once you have your **API Key**:

1. Open the form where you need to authenticate with Amplemarket.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/amplemarket/form.png" style={{maxWidth: "450px" }}/>

You are now connected to Amplemarket.
