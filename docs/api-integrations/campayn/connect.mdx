## Overview

To authenticate with Campayn, you need:

1. **API Key** - A key that lets Nango call the Campayn API on behalf of your account.

This guide will show you how to find it.

### Prerequisites

- A Campayn account.

### Step 1: Copy your API key

1. Log in to your [Campayn account](https://campayn.com/login).
2. Open **Settings**, then go to **Account**.
3. Click **Show your campayn API key** to reveal the key, then copy it.

<Note>
If you regenerate your API key in the Campayn **Account** section, the old key stops working. Update your connection with the new key.
</Note>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Campayn.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/campayn/form.png" alt="Campayn Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Campayn.
