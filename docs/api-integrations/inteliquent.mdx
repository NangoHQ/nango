## Quickstart

Connect to Inteliquent with Nango and see data flow in 2 minutes.

<Steps>
    <Step title="Create the integration" id="create-integration">
    In Nango ([free signup](https://app.nango.dev)), go to [Integrations](https://app.nango.dev/dev/integrations) -> _Configure New Integration_ -> _Inteliquent_.
    </Step>
    <Step title="Authorize Inteliquent" id="authorize-inteliquent">
    Go to [Connections](https://app.nango.dev/dev/connections) -> _Add Test Connection_ -> _Authorize_, then enter your Inteliquent API Key and API Secret and pick the production or sandbox environment. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step title="Call the Inteliquent API" id="call-inteliquent-api">
    Let's make your first request to the Inteliquent Services API (look up telephone number details). The Services API is JSON-over-POST; Nango injects the required `privateKey` body field from the connection's API Key. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), [integration ID](https://app.nango.dev/dev/integrations), and [connection ID](https://app.nango.dev/dev/connections):
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl -X POST "https://api.nango.dev/proxy/Services/2.0.0/tnDetail" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>" \
              -H "Content-Type: application/json" \
              -d '{"tnSearchList":{"tnSearchItem":[{"tnMask":"xxxxxxxxxx"}]},"pageSort":{"size":10}}'
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.post({
            endpoint: '/Services/2.0.0/tnDetail',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>',
            data: {
                tnSearchList: { tnSearchItem: [{ tnMask: 'xxxxxxxxxx' }] },
                pageSort: { size: 10 }
            }
        });

        console.log(res.data);
        ```
        </Tab>

    </Tabs>
    Or fetch credentials with the [Node SDK](/reference/sdks/node#get-a-connection-with-credentials) or [API](/reference/api/connection/get).

    You're connected! Check the [Logs](https://app.nango.dev/dev/logs) tab in Nango to inspect requests.
    </Step>

    <Step title="Implement Nango in your app" id="implement-nango">
        Follow our [Auth implementation guide](/guides/primitives/auth) to integrate Nango in your app.

        To obtain your own production credentials, follow the connect guide linked below.
    </Step>
</Steps>

## 💡 API gotchas

- The proxy base URL is the environment host (`https://services.inteliquent.com` or `https://services-sandbox.inteliquent.com`). Include the Services API version in each endpoint path (for example `/Services/2.0.0/tnDetail`).
- Every Services API request is a JSON `POST` that must include `privateKey`; Nango injects it from the connection's API Key.
