## Overview

To authenticate with API Ninjas, you need:

1. **API Key** — the API key of your API Ninjas account.

This guide will show you how to get it.

### Prerequisites

- An API Ninjas account. You can [create one for free](https://api-ninjas.com/register) with no credit card.

### Step 1: Copy your API key

1. Sign in to [API Ninjas](https://api-ninjas.com/signin). You land on your [profile page](https://api-ninjas.com/profile).
2. In the left sidebar under **Develop**, click **API keys**.

<img src="/api-integrations/api-ninjas/api_keys_menu.png" alt="API keys item under Develop in the API Ninjas sidebar"/>

3. Under **Your API key**, click **Copy**. Each account has one API key, and it works with every API Ninjas API.

<img src="/api-integrations/api-ninjas/copy_api_key.png" alt="Copy button next to your API key in API Ninjas"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with API Ninjas.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/api-ninjas/form.png" alt="API Ninjas connection form in the Nango Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to API Ninjas.
