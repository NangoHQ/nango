## Overview

To authenticate with Geokeo, you need:

1. **API Key** - the API key from your Geokeo dashboard.

This guide will show you how to find it.

### Prerequisites

- A Geokeo account. [Sign up](https://geokeo.com/signup.php) if you don't have one: no credit card is needed, and the free plan includes 2,500 API requests per day.

### Step 1: Copy your API key

1. [Log in to Geokeo](https://geokeo.com/login.php). You land on the **Dashboard**.
2. Open the **Api Keys** tab.
3. Click the copy button next to your API key.

<img src="/api-integrations/geokeo/api_keys_copy.png" alt="Geokeo dashboard Api Keys tab with the copy button next to the API key highlighted"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Geokeo.
2. Paste the API key from Step 1 into the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/geokeo/form.png" alt="Geokeo Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Geokeo.
