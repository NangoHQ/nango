## 🚀 Quickstart

Connect to Udemy Business with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Udemy Business_.
    </Step>
    <Step id="authorize-udemy-business" title="Authorize Udemy Business">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter the Client ID and Client Secret of a GraphQL API client from your Udemy Business account. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-udemy-business-api" title="Call the Udemy Business API">
    Let's make your first request to the Udemy Business GraphQL API to search the course catalog. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/api/2024-01/graphql" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>" \
              -H "Content-Type: application/json" \
              -d '{"query": "query { courseSearch(query: \"public speaking\", context: {triggerType: RECOMMENDATION}, pageSize: 5, page: 0) { count results { trackingId course { id title } } } }"}'
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.post({
            endpoint: '/api/2024-01/graphql',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>',
            data: {
                query: 'query { courseSearch(query: "public speaking", context: {triggerType: RECOMMENDATION}, pageSize: 5, page: 0) { count results { trackingId course { id title } } } }'
            }
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Nango exchanges the client ID and secret for an access token with the OAuth client credentials grant, and refreshes it for you.

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- The API version is part of the path: `/api/2024-01/graphql`.
- The token is requested with `scope=course:read`, which the integration sets for you. Without a scope, Udemy still issues a token, but one that carries no scope.
- The Udemy Business APIs are available on the Enterprise plan.
- Udemy Business also has a REST API, with its own API client and HTTP Basic authentication. Use the [Udemy Business (REST)](/api-integrations/udemy-business-rest) integration for it.
