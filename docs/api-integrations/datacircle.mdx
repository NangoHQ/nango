## Quickstart

Connect to Datacircle with Nango and see data flow in 2 minutes.

<Steps>
    <Step title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Datacircle_.
    </Step>
    <Step title="Authorize Datacircle">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your Datacircle API key. See the [connect guide](/api-integrations/datacircle/connect) for where to find it. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step title="Call the Datacircle API">
    Let's make your first request to the Datacircle API (read the account's balance, which costs nothing). Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), the integration ID (on the **Integrations** tab), and the connection ID (on the **Connections** tab):
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/balance/" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/balance/',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>

    </Tabs>
    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step title="Implement Nango in your app">
        Follow our [Auth implementation guide](/guides/auth/auth-guide) to integrate Nango in your app.

        To obtain your own production credentials, follow the connect guide linked below.
    </Step>
</Steps>

## API gotchas

- Provider calls (`POST /v1/profiles/enrich`, `GET /linkedin/profile`) need an `X-Data-Provider` header (`up2data` or `harvestapi`). Send it through the proxy as `Nango-Proxy-X-Data-Provider`.
- Each provider call is paid from the account's prepaid balance at the provider's own price; with an empty balance, the API answers `402`. `GET /balance/` and `GET /files/` are free.
