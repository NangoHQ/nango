## Overview

To authenticate with FinalScout, you need:

1. **API Key** — your FinalScout API key.

This guide will show you how to find it.

### Prerequisites

- A FinalScout account. You can [sign up](https://finalscout.com/account/signup) for free. FinalScout makes API access available to select plans.

### Step 1: Copy your API key

1. Sign in to [FinalScout](https://finalscout.com/account/signin).
2. Click **APIs** in the left sidebar to open the [API settings page](https://finalscout.com/app/api/settings).

<img src="/api-integrations/finalscout/open_apis_menu.png" alt="FinalScout dashboard with the APIs item in the left sidebar"/>

3. In the **API Key** section, click the copy icon next to the key to copy your API key.

<img src="/api-integrations/finalscout/copy_api_key.png" alt="FinalScout API settings page with the copy icon in the API Key section"/>

If you set an IP whitelist on the same page, FinalScout rejects requests from IP addresses that are not on it.

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with FinalScout.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/finalscout/form.png" alt="Nango Connect UI form for FinalScout with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to FinalScout.
