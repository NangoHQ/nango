## 🚀 Quickstart

Connect to Microsoft Graph with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Microsoft (Admin - Certificate)_. Enter your app's client ID, paste the private key (`private_key.pem`) in the **Client secret** field and the certificate (`certificate.pem`) in the **Certificate** field, and set the scopes to `https://graph.microsoft.com/.default`. See [how to register your own app](/api-integrations/microsoft-admin-cert/how-to-register-your-own-microsoft-admin-certificate-app).
    </Step>
    <Step id="authorize-microsoft" title="Authorize Microsoft">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, enter the tenant ID, then sign in as an administrator of that tenant and accept the permissions. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-microsoft-api" title="Call the Microsoft Graph API">
    Let's make your first request to the Microsoft Graph API to read the connected organization (the app needs the `Organization.Read.All` or `Directory.Read.All` application permission). Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/v1.0/organization" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/v1.0/organization',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [Auth implementation guide](/guides/auth/auth-guide) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- This is the same admin-consent flow as [Microsoft Admin](/integrations/all/microsoft-admin), but Nango proves the app's identity with a JWT signed by your certificate's private key instead of a client secret. Use it when your organization does not allow client secrets.
- Only an administrator of the tenant can authorize the connection, since admin consent grants the app's permissions for the whole organization.
- The app only gets **Application permissions**. Use the `https://graph.microsoft.com/.default` scope, which requests every application permission granted to the app; `.default` can't be combined with other scopes.
- When the certificate expires or you replace it, upload the new certificate in Microsoft Entra and update both the private key and the certificate in the Nango integration.
