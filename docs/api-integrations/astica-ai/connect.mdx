## Overview

To authenticate with Astica AI, you need:

1. **API Key** — an API key generated in your astica account.

This guide will show you how to get it.

### Prerequisites

- An [astica account](https://astica.ai/register/). Registration is free.

### Step 1: Generate an API key

1. Sign in to [astica](https://astica.ai/login/).
2. Open the [API Keys page](https://astica.ai/api-keys/) (**Quick Access** > **Generate API Keys**, or **API Keys** in the account menu).
3. Generate an API key and copy it.

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Astica AI.
2. Paste the key you copied in Step 1 into the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/astica-ai/form.png" alt="Astica AI Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Astica AI.
