## 🚀 Quickstart

Connect to DocuPost with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _DocuPost_.
    </Step>
    <Step id="authorize-docupost" title="Authorize DocuPost">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your DocuPost API token. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-docupost-api" title="Call the DocuPost API">
    Let's make your first request to the DocuPost API: send a letter. This mails a real letter and deducts its cost from your DocuPost balance; cancel it in DocuPost within one hour and the amount is refunded automatically. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl -X POST "https://api.nango.dev/proxy/1.1/wf/sendletter?to_name=John%20Doe&to_address1=123%20Test%20Ln&to_city=Los%20Angeles&to_state=CA&to_zip=90210&from_name=Sender%20Corp&from_address1=123%20Test%20Rd&from_city=Los%20Angeles&from_state=CA&from_zip=90210&pdf=https://www.w3.org/WAI/ER/tests/xhtml/testfiles/resources/pdf/dummy.pdf" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.post({
            endpoint: '/1.1/wf/sendletter',
            params: {
                to_name: 'John Doe',
                to_address1: '123 Test Ln',
                to_city: 'Los Angeles',
                to_state: 'CA',
                to_zip: '90210',
                from_name: 'Sender Corp',
                from_address1: '123 Test Rd',
                from_city: 'Los Angeles',
                from_state: 'CA',
                from_zip: '90210',
                pdf: 'https://www.w3.org/WAI/ER/tests/xhtml/testfiles/resources/pdf/dummy.pdf'
            },
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- Nango does not check the API token when a connection is created, so a wrong or revoked token still connects and fails on its first call.
