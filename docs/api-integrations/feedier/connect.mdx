## Overview

To authenticate with Feedier, you need:

1. **Private Key** — the private API key of your Feedier workspace.

This guide will show you how to get it.

### Prerequisites

- A Feedier account. You can [sign up](https://bx.feedier.com/register) for a free trial.

### Step 1: Copy your private key

1. Log in to [Feedier](https://bx.feedier.com/login).
2. Click your avatar in the top-right corner, then under **Advanced**, click **Advanced settings**.

<img src="/api-integrations/feedier/feedier_user_menu_advanced_settings.png" alt="Feedier user menu open in the top-right corner with Advanced settings highlighted" />

3. In the **API** section, click the copy button next to the **Private key** field. Use the private key, not the public key.

<img src="/api-integrations/feedier/feedier_api_private_key.png" alt="Feedier Advanced settings page with the API section showing the endpoint URL, public key and private key" />

### Step 2: Enter your private key in the Connect UI

1. Open the form where you need to authenticate with Feedier.
2. Enter your private key in the **Private Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/feedier/form.png" alt="Feedier Connect UI form with the Private Key field" style={{maxWidth: "450px" }}/>

You are now connected to Feedier.
