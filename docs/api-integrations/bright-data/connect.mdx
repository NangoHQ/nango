## Overview

To authenticate with Bright Data, you need:

1. **API Key** — an API key from your Bright Data account.

This guide will show you how to get it.

### Prerequisites

- A Bright Data account. [Sign up](https://brightdata.com/?hs_signup=1) if you don't have one.
- An admin user on the account. Only admins can create API keys.

### Step 1: Create an API key

1. Sign in to Bright Data and open [Account settings](https://brightdata.com/cp/setting/users). If you don't see the API key section, switch to an admin account.
2. Click **Add API key** in the top right of the API key section.
3. Set the **User**, **Permissions** and **Expiration date** (or choose **Unlimited**), then click **Save**.
4. Copy the key and store it securely. Bright Data shows it only once.

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Bright Data.
2. Enter your key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/bright-data/form.png" alt="Bright Data Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Bright Data.
