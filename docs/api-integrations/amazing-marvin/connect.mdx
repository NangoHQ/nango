## Overview

To authenticate with Amazing Marvin, you need:

1. **API Token** — the limited-access API token from your Marvin API credentials.

This guide will show you how to get it.

### Prerequisites

- An Amazing Marvin account. New accounts start with a 14-day trial, no credit card required. [Sign up here](https://app.amazingmarvin.com/?signup).

### Step 1: Copy your API token

1. Sign in to the [Amazing Marvin web app](https://app.amazingmarvin.com/).
2. Open [https://app.amazingmarvin.com/pre?api](https://app.amazingmarvin.com/pre?api). The **Your Marvin API credentials** dialog opens.
3. Click the copy icon next to **API Token**. Use the API token, not the **Full-Access Token**.

<img src="/api-integrations/amazing-marvin/api_credentials_copy_token.png" alt="Your Marvin API credentials dialog with the copy icon next to API Token highlighted"/>

To rotate an exposed token, use the API strategy settings in Marvin.

### Step 2: Enter your API token in the Connect UI

1. Open the form where you need to authenticate with Amazing Marvin.
2. Enter your token in the **API Token** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/amazing-marvin/form.png" alt="Amazing Marvin Connect UI form with the API Token field" style={{maxWidth: "450px" }}/>

You are now connected to Amazing Marvin.
