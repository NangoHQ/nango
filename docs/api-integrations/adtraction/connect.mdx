## Overview

To authenticate with Adtraction, you need:

1. **API Key** — an API key from your Adtraction partner or advertiser account.

This guide will show you how to create it.

### Prerequisites

- An Adtraction account. Partner accounts are free: [sign up as a partner](https://adtraction.com/partner-sign-up/). Advertiser accounts are set up with Adtraction's team through the form on [adtraction.com](https://adtraction.com/).

Partner keys work with the partner endpoints and advertiser keys with the advertiser endpoints. Both are created the same way.

### Step 1: Create an API key

1. Sign in to [Adtraction](https://adtraction.com/login).
2. Click your account at the bottom of the left menu, then click **Settings**.
3. Open the **API** tab. Your account's API key is listed in the **API keys** table, but its value is masked.

<img src="/api-integrations/adtraction/settings_api_tab.png" alt="Adtraction Settings page with the API tab open and an existing key in the API keys table"/>

4. If you don't have the key's value, open the **⋮** menu on that key, click **Remove API key** and confirm.
5. Click **Create API key**, then click **Create API key** again in the dialog.

<img src="/api-integrations/adtraction/create_api_key.png" alt="Adtraction API tab with the Create API key button highlighted"/>

6. Click **Copy API key** and store the key safely. It is only shown once.

<img src="/api-integrations/adtraction/api_key_created.png" alt="Adtraction Create API key dialog with the Copy API key button highlighted"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Adtraction.
2. Enter your API key in the **API Key** field.
3. Submit the form. Nango checks the key with Adtraction before saving the connection.

<img src="/api-integrations/adtraction/form.png" alt="Adtraction Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Adtraction.
