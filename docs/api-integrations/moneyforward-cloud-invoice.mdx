## 🚀 Quickstart

Connect to Money Forward Cloud Invoice with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Money Forward Cloud Invoice_. Paste the client ID and secret of your Money Forward app.
    </Step>
    <Step id="authorize-moneyforward-cloud-invoice" title="Authorize Money Forward Cloud Invoice">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then log in to Money Forward Cloud and allow access. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-moneyforward-cloud-invoice-api" title="Call the Money Forward Cloud Invoice API">
    Let's make your first request to the Money Forward Cloud Invoice API to read the connected business's office details. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/api/v3/office" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/api/v3/office',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [Auth implementation guide](/guides/auth/overview) to integrate Nango in your app.
    </Step>
</Steps>
