## Overview

To authenticate with Extracta.ai, you need:

1. **API Key** — an API key of your Extracta.ai account.

This guide will show you how to create one.

### Prerequisites

- An Extracta.ai account. If you don't have one, [sign up](https://app.extracta.ai/register).

### Step 1: Create an API key

1. Sign in to the [Extracta.ai dashboard](https://app.extracta.ai) and click **API** in the left sidebar.

<img src="/api-integrations/extracta-ai/dashboard_api_nav.png" alt="Extracta.ai dashboard with API in the left sidebar"/>

2. Under **API Keys**, click **Create new API key**. Optionally enter a name for the key, then click **Create key**.

<img src="/api-integrations/extracta-ai/create_api_key.png" alt="Extracta.ai API page with the Create new API key button"/>

3. Click **Copy** in the **Copy your new API key now** panel. After you dismiss the panel, the key is only shown masked.

<img src="/api-integrations/extracta-ai/api_key_created.png" alt="Extracta.ai panel with the Copy button for the new API key"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Extracta.ai.
2. Enter your API key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/extracta-ai/form.png" alt="Extracta.ai Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Extracta.ai.
