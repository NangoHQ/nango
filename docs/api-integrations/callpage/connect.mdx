## Overview

To authenticate with CallPage, you need:

1. **API Key** — a CallPage API key.

This guide will show you how to get it.

### Prerequisites

- A CallPage account. You can [start a 14-day free trial](https://app.callpage.io/register) if you don't have one.

### Step 1: Create an API key

1. Sign in to the [CallPage dashboard](https://app.callpage.io).
2. In the sidebar, click **Settings**, open the **API settings** tab, then click **Create new API key**.

<img src="/api-integrations/callpage/api_settings_page.png" alt="CallPage API settings tab with the Create new API key button"/>

3. In the **Add API Key** dialog, tick **Global API key** (or select the specific widgets and numbers the key can access), enter a description, then click **Save Api Key**.

<img src="/api-integrations/callpage/add_api_key_dialog.png" alt="CallPage Add API Key dialog with the Global API key checkbox, the Description field and the Save Api Key button"/>

4. In the API keys table, click the copy icon next to the masked key to copy your API key.

<img src="/api-integrations/callpage/copy_api_key.png" alt="CallPage API keys table with the copy icon next to the masked API key"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with CallPage.
2. Enter your API key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/callpage/form.png" alt="CallPage Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to CallPage.
