## 🚀 Quickstart

Connect to Hookdeck with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Hookdeck_.
    </Step>
    <Step id="authorize-hookdeck" title="Authorize Hookdeck">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your Hookdeck project API key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-hookdeck-api" title="Call the Hookdeck API">
    Let's make your first request to the Hookdeck API: list the sources of your project. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/2026-09-01/sources?limit=1" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/2026-09-01/sources',
            params: { limit: '1' },
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- Hookdeck's Publish API is on `https://hkdk.events`. Calls to it set `baseUrlOverride` to `https://hkdk.events`; Nango keeps the connection's credentials and headers. See [REST API Reference](https://hookdeck.com/docs/api).
- Nango sends the key as `Authorization: Bearer <key>` on every call. Hookdeck also accepts it as `Authorization: Basic` with the key as the username and an empty password; calls that need that can read the key from the connection's credentials (`credentials.apiKey`) and pass it as the docs show.
