## Overview

To authenticate with eSputnik, you need:

1. **API key** - an API key created in your eSputnik account.

This guide will show you how to create one.

### Prerequisites

- An [eSputnik](https://esputnik.com) account. You can [create one](https://yespo.io/registration) with a starter package to test the API.

### Step 1: Create an API key

1. Log in to your eSputnik account.
2. Click your account name in the top-right corner, then choose **Settings**.

<img src="/api-integrations/esputnik/open_settings.png" alt="eSputnik account menu in the top-right corner with Settings highlighted"/>

3. In the **Settings** sidebar, click **API**, then click **New key**.

<img src="/api-integrations/esputnik/api_keys_new_key.png" alt="eSputnik Settings API page with the New key button"/>

4. In **Description**, enter a name for the key, such as the name of your app.
5. In the access rights dropdown, select **Full access to API**, then click **Save**.

<img src="/api-integrations/esputnik/add_key_form.png" alt="eSputnik new API key form with a description and Full access to API selected"/>

6. In the API keys list, click the masked key number of your new key to copy it to your clipboard.

<img src="/api-integrations/esputnik/copy_api_key.png" alt="eSputnik API keys list with the masked key number to click to copy the key"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with eSputnik.
2. Paste the key you copied in Step 1 into the **API key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/esputnik/form.png" alt="eSputnik Connect UI form with the API key field" style={{maxWidth: "450px" }}/>

You are now connected to eSputnik.
