## Overview

To authenticate with Nanonets, you need:

1. **API Key** - An API key from your Nanonets account.

This guide will show you how to create one.

### Prerequisites

- A Nanonets account. If you don't have one, [sign up](https://accounts.nanonets.com/signup).

### Step 1: Create an API key

1. Log in to [Nanonets](https://app.nanonets.com).
2. In the left panel, click **Account info**, then **Api keys**.

<img src="/api-integrations/nanonets/account_info_api_keys.png" alt="Nanonets left panel with Account info expanded and Api keys selected"/>

3. On the API keys page, click **Add a New Key**.

<img src="/api-integrations/nanonets/add_new_key.png" alt="Nanonets API keys page with the Add a New Key button"/>

4. The new key appears in the list. Click **Copy Key** next to it to copy it.

<img src="/api-integrations/nanonets/copy_api_key.png" alt="Nanonets API keys list with the Copy Key button next to the new key"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Nanonets.
2. Paste your API key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/nanonets/form.png" alt="Nanonets Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Nanonets.
