## Overview

To authenticate with OpenCage, you need:

1. **API Key** - Your OpenCage geocoding API key.

This guide will show you how to find it.

### Prerequisites

- An OpenCage account. You can [sign up](https://opencagedata.com/users/sign_up) for a free trial without a credit card.

### Step 1: Copy your API key

1. Log in to [OpenCage](https://opencagedata.com/users/sign_in) and open your [dashboard](https://opencagedata.com/dashboard).
2. Open the **Geocoding API** tab.

<img src="/api-integrations/opencage/dashboard_geocoding_tab.png" alt="Geocoding API tab in the OpenCage dashboard"/>

3. Under **Your API Keys**, click the copy button next to your key to copy it.

<img src="/api-integrations/opencage/copy_api_key.png" alt="Copy button next to the API key under Your API Keys in the OpenCage dashboard"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with OpenCage.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/opencage/form.png" alt="OpenCage connection form in Nango's Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to OpenCage.
