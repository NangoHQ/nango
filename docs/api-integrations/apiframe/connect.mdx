## Overview

To authenticate with Apiframe, you need:

1. **API Key** — an Apiframe API key. It starts with `afk_`.

This guide will show you how to get it.

### Prerequisites

- An Apiframe account. You can [sign up](https://console.apiframe.ai/signup) yourself. New teams can unlock 100 starter credits after a phone check or a one-time $1 payment.

### Step 1: Create an API key

1. Log in to the [Apiframe dashboard](https://console.apiframe.ai). In the sidebar, under **Manage**, click **API Keys**.

<img src="/api-integrations/apiframe/dashboard_api_keys_nav.png" alt="Apiframe dashboard sidebar with API Keys under Manage"/>

2. Click **Create API Key**, enter a name for the key, then click **Create**.

<img src="/api-integrations/apiframe/create_api_key_dialog.png" alt="Apiframe Create API Key dialog with a name for the key"/>

3. Click **Copy** to copy the new key, then click **Done**. The key is shown only once.

<img src="/api-integrations/apiframe/api_key_created.png" alt="Apiframe dialog showing the new API key with a Copy button"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Apiframe.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/apiframe/form.png" alt="Apiframe connection form in the Nango Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to Apiframe.
