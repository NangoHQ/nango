## 🚀 Quickstart

Connect to Envoice with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Envoice_.
    </Step>
    <Step id="authorize-envoice" title="Authorize Envoice">
    Go to **Connections** -> _Add Test Connection_, pick the **Environment** (`api.envoice.eu` for live, `demo-api.envoice.eu` for the sandbox), then _Authorize_, log in to Envoice and choose the company to connect. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-envoice-api" title="Call the Envoice API">
    Let's make your first request to the Envoice API to list the company's chart of accounts. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/v1/account" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/v1/account',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.

        To obtain your own production credentials, follow the setup guide linked below.
    </Step>
</Steps>

## 🚨 API gotchas

- Every request must name the Envoice company in the `Envoice-Tenant-Id` header. Envoice returns the company's `tenantId` with the authorization code, Nango stores it on the connection, and the proxy adds the header for you.
- Envoice only issues a refresh token when you request the `offline_access` scope. Nango requests it by default if you configure no scopes; if you set your own scopes, include `offline_access`.
- Envoice has no self-service developer portal. You request an OAuth app, with its redirect URIs, by email.
- Envoice has a live environment (`api.envoice.eu`) and a [sandbox](https://envoice.stoplight.io/docs/envoice-api/ZG9jOjMwODczMjQ0-sandbox) (`demo-api.envoice.eu`). Each connection picks one with the `environment` connection config; it defaults to live. The sandbox uses separate development credentials, so a sandbox connection needs an integration configured with sandbox keys.
- Envoice asks clients to retry `429` and `5xx` responses with truncated exponential backoff.
