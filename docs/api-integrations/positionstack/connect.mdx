## Overview

To authenticate with Positionstack, you need:

1. **API Access Key** — the API access key of your Positionstack account.

This guide will show you how to get it.

### Prerequisites

- A Positionstack account. Positionstack accounts are APILayer accounts: [sign up for free](https://positionstack.com/signup/free) if you don't have one. The Free plan includes 100 requests per month and is restricted to non-commercial use.

### Step 1: Get your API access key

1. Sign in to your APILayer dashboard and open the [Positionstack page](https://app.apilayer.com/api-details/positionstack).
2. If you are not subscribed to Positionstack yet, click **Subscribe to Free Plan** (or pick a paid plan), then confirm. Your key is only enabled once you subscribe.
3. In the **Your API Key** card, click **Copy Key**.

<img src="/api-integrations/positionstack/copy_api_key.png" alt="Positionstack page of the APILayer dashboard with the Copy Key button next to Your API Key"/>

If your key has been compromised, you can reset it from the same page and generate a new one.

### Step 2: Enter your API access key in the Connect UI

1. Open the form where you need to authenticate with Positionstack.
2. Paste the key you copied in Step 1 into the **API Access Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/positionstack/form.png" alt="Positionstack Connect UI form with the API Access Key field" style={{maxWidth: "450px" }}/>

You are now connected to Positionstack.
