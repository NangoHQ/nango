## 🚀 Quickstart

Connect to Cloudinary with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Cloudinary_.
    </Step>
    <Step id="authorize-cloudinary" title="Authorize Cloudinary">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then select your region and enter your cloud name, API Key and API Secret. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-cloudinary-api" title="Call the Cloudinary API">
    Let's make your first request to the Cloudinary Admin API (get your product environment usage). Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, connection ID, and the cloud name the connection was created with:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/v1_1/<CLOUD-NAME>/usage" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/v1_1/<CLOUD-NAME>/usage',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- Every Admin API path starts with `/v1_1/<cloud name>`. Nango stores the cloud name on the connection as `connection_config.cloudName`, so read it from the connection and put it in each endpoint.
