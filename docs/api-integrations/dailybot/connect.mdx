## Overview

To authenticate with Dailybot, you need:

1. **API Key** — a Dailybot API key generated in your organization settings.

This guide will show you how to get it.

### Prerequisites

- A Dailybot organization on a paid plan. API keys require a paid Dailybot plan.

### Step 1: Generate an API key

1. Sign in to the [Dailybot dashboard](https://app.dailybot.com).
2. Open **Settings** -> **API & Connections** -> **API Keys**, or go straight to the [API Keys page](https://app.dailybot.com/settings/integrations/api-keys).
3. Click **Generate API Key**.
4. Copy the key right away: it is shown only once.

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Dailybot.
2. In **API Key**, paste the key you copied in Step 1.
3. Submit the form. Nango checks the key with Dailybot before saving the connection.

<img src="/api-integrations/dailybot/form.png" alt="Dailybot Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Dailybot.
