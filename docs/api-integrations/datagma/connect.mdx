## Overview

To authenticate with Datagma, you need:

1. **API Key** — the secret API key from your Datagma account.

This guide will show you how to find it.

### Prerequisites

- A Datagma account. All plans include API access, including the free plan. If you don't have an account, [sign up for free](https://app.datagma.com/sign-up).

### Step 1: Copy your API key

1. Sign in to [Datagma](https://app.datagma.com/).
2. In the left sidebar, click **API**.

<img src="/api-integrations/datagma/sidebar_api_link.png" alt="Datagma app sidebar with the API link highlighted" />

3. In the **Secret key** card at the top of the page, click **Copy** to copy your API key.

<img src="/api-integrations/datagma/api_key_copy.png" alt="Datagma API page with the Copy button next to the secret key highlighted" />

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Datagma.
2. Enter your API key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/datagma/form.png" alt="Datagma Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Datagma.
