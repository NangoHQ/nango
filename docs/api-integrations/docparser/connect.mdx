## Overview

To authenticate with Docparser, you need:

1. **API Key** - The secret API key of your Docparser account.

This guide will show you where to find it.

### Prerequisites

- A Docparser account. If you don't have one, [sign up](https://app.docparser.com/account/signup).

### Step 1: Copy your secret API key

1. Log in to [Docparser](https://app.docparser.com/account/login).
2. Click **API** in the left sidebar to open the **REST API Credentials** page ([direct link](https://app.docparser.com/myaccount/api)).

<img src="/api-integrations/docparser/myaccount_api_menu.png" alt="Docparser sidebar with API selected, showing the REST API Credentials page"/>

3. Next to **Secret API Key**, click **Copy to clipboard**.

<img src="/api-integrations/docparser/copy_secret_api_key.png" alt="Docparser REST API Credentials page with the Copy to clipboard button next to the Secret API Key"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Docparser.
2. Paste your secret API key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/docparser/form.png" alt="Docparser Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Docparser.
