## Overview

To authenticate with Coinranking, you need:

1. **API Key** — a Coinranking API key.

This guide will show you how to get it.

### Prerequisites

- A Coinranking developer account. The Free plan includes API access; [sign up here](https://account.coinranking.com/create-developer-account).

### Step 1: Copy your API key

1. Sign in to your [Coinranking dashboard](https://account.coinranking.com/sign-developer-in).
2. In the sidebar, click **API Keys**. The Free plan comes with one API key, created automatically when you activate your account.
3. Under **Your API key**, click the copy button next to your key.

<img src="/api-integrations/coinranking/api_keys_page_copy_key.png" alt="Coinranking API Keys page with the copy button next to the API key highlighted"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Coinranking.
2. Enter your **API Key** in the designated field.
3. Click **Connect**.

<img src="/api-integrations/coinranking/form.png" alt="Nango Connect UI form for entering the Coinranking API key" style={{maxWidth: "450px" }}/>

You are now connected to Coinranking.
