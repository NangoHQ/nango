## Overview

To authenticate with Court Rules, you need:

1. **API Key** - the API key shown on your Court Rules console dashboard.

This guide shows you how to get it.

### Prerequisites

- A Court Rules account. You can sign in at [console.courtrules.app](https://console.courtrules.app) with Google or email.

### Step 1: Copy your API key

1. Sign in to the [Court Rules console](https://console.courtrules.app/login).
2. On the **Dashboard**, click **Copy key** on the **API Key** card. The key starts with `crm_`.

<img src="/api-integrations/court-rules/copy_api_key.png" alt="Court Rules console dashboard with the Copy key button on the API Key card"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Court Rules.
2. Enter your **API Key** in the designated field.
3. Click **Connect**. Nango checks the key with Court Rules and rejects it if it is wrong.

<img src="/api-integrations/court-rules/form.png" alt="Nango Connect UI form for entering the Court Rules API key" style={{maxWidth: "450px" }}/>

You are now connected to Court Rules.
