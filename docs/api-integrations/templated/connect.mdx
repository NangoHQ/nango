## Overview

To authenticate with Templated, you need:

1. **API Key** - Your Templated API key, which lets Nango call the Templated API on behalf of your account.

This guide will show you how to find it.

### Prerequisites

- A Templated account. You can [start a free trial](https://app.templated.io/signup) with no credit card required.

### Step 1: Copy your API key

1. Log in to [Templated](https://app.templated.io).
2. Click **API Key** in the left sidebar.

<img src="/api-integrations/templated/sidebar_api_key.png" alt="API Key item in the left sidebar of the Templated dashboard"/>

3. Click the copy button next to the API key field to copy your **API Key**.

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Templated.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/templated/form.png" alt="Templated connection form in Nango's Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to Templated.
