## Overview

To authenticate with Daily, you need:

1. **API Key** — the API key of your Daily domain.

This guide will show you how to get it.

### Prerequisites

- A Daily account. You can [sign up](https://dashboard.daily.co/u/signup); a new account's API key is available right away.
- The Admin role in your Daily account. Only Admins can view and regenerate the API key.

### Step 1: Copy your API key

1. Sign in to the [Daily dashboard](https://dashboard.daily.co/).
2. In the left sidebar, open **Developers**.
3. Under **API keys**, click the options menu (⋯) next to your key and choose **Copy key to clipboard**.

<img src="/api-integrations/daily/copy_api_key.png" alt="Daily dashboard Developers page with the Copy key to clipboard option of an API key"/>

If you use Pipecat Cloud, you can use its Daily (WebRTC) key instead: it has the same capabilities as a key from the Daily dashboard. Find it under **Settings** → **Daily (WebRTC)** in the [Pipecat Cloud dashboard](https://pipecat.daily.co/).

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Daily.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/daily/form.png" alt="Daily Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Daily.
