## Overview

To authenticate with Algodocs, you need:

1. **Secret API Key** — the Secret API key of your Algodocs account.

This guide will show you how to find it.

### Prerequisites

- An Algodocs account. If you don't have one, [sign up](https://app.algodocs.com/signup). API access is included on every plan, including Free.

### Step 1: Copy your Secret API key

1. Sign in to [Algodocs](https://app.algodocs.com/).
2. Go to **Integrations** > **Rest API** (or open the [Rest API page](https://app.algodocs.com/restapi) directly).
3. Click the copy button next to **Secret API Key**. To create a new key instead, click **Generate New API Key**.

<img src="/api-integrations/algodocs/restapi_secret_key.png" alt="Algodocs Rest API page with the Secret API Key field, its copy button and the Generate New API Key button"/>

### Step 2: Enter your Secret API key in the Connect UI

1. Open the form where you need to authenticate with Algodocs.
2. Enter your key in the **Secret API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/algodocs/form.png" alt="Algodocs Connect UI form with the Secret API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Algodocs.
