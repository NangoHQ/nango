## 🚀 Quickstart

Connect to Zenrows with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Zenrows_.
    </Step>
    <Step id="authorize-zenrows" title="Authorize Zenrows">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then enter your Zenrows API key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-zenrows-api" title="Call the Zenrows API">
    Let's make your first request to the Zenrows API to get your plan and usage. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/v1/subscriptions/self/details" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/v1/subscriptions/self/details',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- Batch calls go to `https://async.api.zenrows.com`: set `baseUrlOverride` to that host, and Nango keeps the connection's credentials and headers. See [Zenrows API Authentication](https://docs.zenrows.com/authentication).
- Nango sends the key as the `apikey` query parameter on every call. Calls that need it another way, such as the `X-API-Key` header Batch requires, can read it from the connection's credentials (`credentials.apiKey`) and set it there themselves.
