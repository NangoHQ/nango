## Overview

To connect Fuse in Nango, you need to provide:

1. **API Key** — A Fuse API key, which starts with `af_`.

This guide walks you through creating a key in the Fuse app.

### Prerequisites

- You need a Fuse account. Create one at [fuseai.com](https://fuseai.com).

### Step 1: Creating your API key

1. Open the Fuse app and go to **Settings** -> **API Cockpit**.
2. Click **Create New Key**.
3. Copy the key straight away. Fuse shows the full value only once; afterwards it displays a masked form such as `af_3de1c09...b9c0`.

<Note>
Treat the key like a password. If it leaks, revoke it in API Cockpit and create a new one; revocation takes effect immediately.
</Note>

### Step 2: Authorize in Nango

1. Open the Nango Connect form.
2. Enter your **API Key**.
3. Submit the form, and you should be successfully authenticated.

You are now connected to Fuse.
