## Overview

To authenticate with Moosend, you need:

1. **API Key** — your Moosend account's API key.

This guide will show you how to get it.

### Prerequisites

- A Moosend account. You can [start a free trial](https://moosend.com/pricing/) without a credit card.
- The account owner or admin role. Only account owners and admins can see the API key.

### Step 1: Copy your API key

1. Log in to [Moosend](https://identity.moosend.com/login/).
2. In the top menu bar, click **More**, then **Settings**.

<img src="/api-integrations/moosend/more_settings_menu.png" alt="Moosend More menu open with Settings highlighted"/>

3. On the Settings page, click **API key** in the left menu.

<img src="/api-integrations/moosend/settings_api_key_tab.png" alt="Moosend Settings page with API key selected in the left menu"/>

4. Under **Your API key**, click **Copy**. If the key is compromised, click **Generate new API Key** to replace it.

<img src="/api-integrations/moosend/api_key_copy.png" alt="Moosend API key page with the Copy button highlighted"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Moosend.
2. Paste the key you copied in Step 1 into the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/moosend/form.png" alt="Moosend Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Moosend.
