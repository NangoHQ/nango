## Overview

To authenticate with Minerstat, you need:

1. **API Key** — a Minerstat API key.

This guide will show you how to get it.

### Prerequisites

- A Minerstat developer account. The Free plan includes API access and needs no card; [sign up here](https://minerstat.com/developers).

### Step 1: Open the developer portal

1. Go to the [Minerstat developer portal](https://minerstat.com/developers) and sign in with your email or Google.
2. On your first sign-in, tick **I accept the API terms** and click **Activate the developer portal**.
3. In the sidebar, click **API keys**.

<img src="/api-integrations/minerstat/developer_portal_dashboard.png" alt="Minerstat developer portal dashboard with API keys highlighted in the sidebar"/>

### Step 2: Create an API key

1. Under **Create a key**, enter a label (optional), then click **Create key**.

<img src="/api-integrations/minerstat/create_api_key.png" alt="Minerstat API keys page with a label entered and the Create key button highlighted"/>

2. In the **Your new API key** panel, click the copy button. Minerstat shows the key only once, so store it before you continue.
3. Click **I saved my key**.

<img src="/api-integrations/minerstat/api_key_created.png" alt="Minerstat Your new API key panel with the copy button highlighted"/>

### Step 3: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Minerstat.
2. Enter your **API Key** in the designated field.
3. Click **Connect**.

<img src="/api-integrations/minerstat/form.png" alt="Nango Connect UI form for entering the Minerstat API key" style={{maxWidth: "450px" }}/>

You are now connected to Minerstat.
