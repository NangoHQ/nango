## Overview

To authenticate with API.Bible, you need:

1. **API Key** — the API key of your API.Bible app.

This guide will show you how to find it.

### Prerequisites

- An API.Bible account with an app. You can [sign up](https://api.bible/sign-up) for free on the Starter plan.

### Step 1: Find your API key

1. [Sign in](https://api.bible/sign-in) to API.Bible. You land on your dashboard; you can also open **API Product** -> **Dashboard**.
2. Select your app.
3. Your **API Key** is shown in the top right corner of the dashboard. Click the copy icon next to it.

<img
    src="/api-integrations/api-bible/api_key_dashboard.png"
    alt="API.Bible app dashboard with the copy icon next to the API Key highlighted in the top right"
/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with API.Bible.
2. Enter your **API Key** in the designated field.
3. Click **Connect**.

<img src="/api-integrations/api-bible/form.png" alt="Nango Connect UI form for entering the API.Bible API Key" style={{maxWidth: "450px" }}/>

You are now connected to API.Bible.
