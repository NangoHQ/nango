## Overview

To authenticate with iplicit, you need:

1. **Domain** — your iplicit environment domain, for example `sandbox.demo`.
2. **Username** — the name of the iplicit user account used for the API.
3. **API Key** — an API key created for that user account.

This guide will show you how to get them.

### Prerequisites

- An iplicit user account with an API license.

### Step 1: Get your API credentials

Contact iplicit support at [apisupport@iplicit.com](mailto:apisupport@iplicit.com) to request API credentials. iplicit provides your **domain** and the **user account name**.

To create an API key for that user account:

1. Open the user account in iplicit. Accounts with an API license have an **API keys** tab.
2. Select **New**.
3. Enter a description and how long the key is valid for. iplicit recommends rotating keys every 90 days.
4. Copy the API key that's created.

<Note>
API keys expire on the date you set. When a key expires, create a new one and update it in Nango, or the connection stops working.
</Note>

### Step 2: Enter your credentials in the Connect UI

1. Open the form where you need to authenticate with iplicit.
2. Enter your **Domain**, **Username**, and **API Key** in the designated fields.
3. Submit the form, and you should be successfully authenticated.

You are now connected to iplicit.
