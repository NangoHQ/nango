## 🚀 Quickstart

Connect to Deepgram with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Deepgram_.
    </Step>
    <Step id="authorize-deepgram" title="Authorize Deepgram">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then select your region and enter your Deepgram API key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-deepgram-api" title="Call the Deepgram API">
    Let's make your first request to the Deepgram API to get details about the connected API key. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/v1/auth/token" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/v1/auth/token',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- Think models (`/v1/agent/settings/think/models`) are served from `https://agent.deepgram.com`, not from the connection's region host. Call them with `baseUrlOverride` set to `https://agent.deepgram.com`; Nango keeps the connection's credentials and headers. See [Think Models](https://developers.deepgram.com/reference/voice-agent/think-models).
