## Overview

To authenticate with Apilio, you need:

1. **API Username** — the username in the **Api access key** section of your Apilio profile page.
2. **API Password** — the password in the same section.

These are different from the email and password you use to log in to the Apilio web app. This guide will show you where to find them.

### Prerequisites

- An [Apilio](https://app.apilio.com/) account. The 21-day free trial needs no credit card.

### Step 1: Copy your API username and password

1. Log in to the [Apilio web app](https://app.apilio.com/).
2. Open your [user profile page](https://app.apilio.com/user) and scroll to the **Api access key** section.
3. Click the copy icon next to **Username** to copy your API username.
4. Click the copy icon next to **Password** to copy your API password.

<img src="/api-integrations/apilio/api_access_key_section.png" alt="Apilio profile page with the Api access key section showing the Username and Password fields"/>

Your account has one API username and password. If they leak, click **Regenerate** in the same section to issue new ones.

### Step 2: Enter your credentials in the Connect UI

1. Open the form where you need to authenticate with Apilio.
2. Paste the username you copied in Step 1 into the **API Username** field.
3. Paste the password you copied in Step 1 into the **API Password** field.
4. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/apilio/form.png" alt="Apilio Connect UI form with the API Username and API Password fields" style={{maxWidth: "450px" }}/>

You are now connected to Apilio.
