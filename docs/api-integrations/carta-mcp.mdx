## 🚀 Quickstart

Connect to the Carta MCP server with Nango and call MCP tools in minutes. Carta MCP uses OAuth 2.0 with **dynamic client registration** (RFC 7591) and PKCE, so no app registration is required.

<Steps>
    <Step title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to [Integrations](https://app.nango.dev/dev/integrations) -> _Configure New Integration_ -> _Carta (MCP)_.
    </Step>
    <Step title="Authorize Carta">
    Go to [Connections](https://app.nango.dev/dev/connections) -> _Add Test Connection_ -> _Authorize_, then log in to Carta. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step title="Call a Carta MCP tool">
    Make your first MCP request (initialize handshake). Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), [integration ID](https://app.nango.dev/dev/integrations), and [connection ID](https://app.nango.dev/dev/connections):
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/mcp" \
              -X POST \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>" \
              -H "Content-Type: application/json" \
              -d '{
                "jsonrpc": "2.0",
                "id": 1,
                "method": "initialize",
                "params": {
                    "protocolVersion": "2024-11-05",
                    "capabilities": {},
                    "clientInfo": {
                        "name": "nango-client",
                        "version": "1.0.0"
                    }
                }
            }'
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.post({
            endpoint: '/mcp',
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>',
            body: {
                jsonrpc: '2.0',
                id: 1,
                method: 'initialize',
                params: {
                    protocolVersion: '2024-11-05',
                    capabilities: {},
                    clientInfo: {
                        name: 'nango-client',
                        version: '1.0.0'
                    }
                }
            }
        });

        console.log(res.data);
        ```
        </Tab>

    </Tabs>
    ✅ You're connected! Check the [Logs](https://app.nango.dev/dev/logs) tab in Nango to inspect requests.
    </Step>

    <Step title="Implement Nango in your app">
        Follow our [Auth implementation guide](/guides/primitives/auth) to integrate Nango in your app.
    </Step>
</Steps>

## 📚 Carta (MCP) guides

Nango uses **dynamic client registration** with Carta's MCP OAuth server. You do not need to register an MCP application.

The MCP endpoint is `https://mcp.app.carta.com/mcp`, so requests go through the Nango proxy at `/mcp`.

### Scopes

Carta's authorization server advertises the following scopes:

| Scope | Grants |
| --- | --- |
| `openid` | OpenID Connect sign-in |
| `cuid` | The authorizing user's Carta identifier |
| `read_mcp_firms` / `readwrite_mcp_firms` | Firm and fund data |
| `read_mcp_companies` / `readwrite_mcp_companies` | Company and cap table data |
| `read_mcp_crm` / `readwrite_mcp_crm` | CRM records (investors, companies, contacts, deals, notes) |

Nango requests the read-only set by default (`openid`, `cuid`, `read_mcp_firms`, `read_mcp_companies`, `read_mcp_crm`). Add the matching `readwrite_*` scopes on the integration to allow writes.

### Connection requirements

Carta only exposes data the authorizing Carta account is already permitted to view, and the MCP surface must be enabled for that account.

Official resources: [Carta MCP setup](https://docs.carta.com/api-platform/docs/claude-plugins-setup) · [Carta API Platform](https://docs.carta.com/api-platform/docs/introduction)
