## Overview

To authenticate with AnyDB, you need:

1. **API Key** — the API key of your AnyDB user.
2. **AnyDB Account Email** — the email address of the same AnyDB account.

This guide will show you how to find them.

### Prerequisites

- An AnyDB account. You can [sign up](https://app.anydb.com/auth/signup) for the Free plan.

### Step 1: Copy your API key

1. Log in to [AnyDB](https://app.anydb.com).
2. Click your user icon at the bottom of the left sidebar to open your profile.

<img src="/api-integrations/anydb/open_profile.png" alt="AnyDB workspace with the user icon highlighted at the bottom of the left sidebar"/>

3. In the profile dialog, open the **Integrations** tab.
4. Click **Show Key**, then **Copy Key**.

<img src="/api-integrations/anydb/copy_api_key.png" alt="AnyDB profile dialog on the Integrations tab with the Copy Key button highlighted"/>

### Step 2: Find your account email

Use the email address you log in to AnyDB with. It must belong to the same account as the API key from Step 1.

### Step 3: Enter your credentials in the Connect UI

1. Open the form where you need to authenticate with AnyDB.
2. Enter your API key in the **API Key** field and your email address in the **AnyDB Account Email** field.
3. Submit the form. Nango checks the key and email with AnyDB before saving the connection.

<img src="/api-integrations/anydb/form.png" alt="AnyDB Connect UI form with the API Key and AnyDB Account Email fields" style={{maxWidth: "450px" }}/>

You are now connected to AnyDB.
