## Overview

To authenticate with Okendo, you need:

1. **User ID** — your Okendo User ID.
2. **API Key** — the 32-character key that goes with it.

This guide will show you how to get them.

### Prerequisites

- An Okendo account with access to the Merchant API. Okendo offers it to enterprise customers.

### Step 1: Get your User ID and API Key

1. Log in to the Okendo app.
2. Open the **integration settings** section.
3. Copy your **User ID** and **API Key**.

### Step 2: Enter your credentials in the Connect UI

1. Open the form where you need to authenticate with Okendo.
2. Enter your **User ID** and **API Key** in the designated fields.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/okendo/form.png" alt="Okendo Connect UI form with the User ID and API Key fields" style={{maxWidth: "450px" }}/>

You are now connected to Okendo.
