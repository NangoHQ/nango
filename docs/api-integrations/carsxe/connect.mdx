## Overview

To authenticate with CarsXE, you need an **API Key**.

This guide walks you through locating your API key in CarsXE and connecting your account.

### Prerequisites

- A CarsXE account

### Instructions

#### Step 1: Finding your API key

1. Log in to the [CarsXE developer dashboard](https://carsxe.com/dashboard/developer), or [create an account](https://carsxe.com) if you do not have one yet.
2. Open the **Developer** section and copy your API key. You can also rotate keys from the same page.
3. Treat the key like a password. Store it in an environment variable and never commit it to source control.

#### Step 2: Enter your credentials in the Connect UI

1. Open the form where you need to authenticate with CarsXE.
2. Enter your **API Key**.
3. Submit the form, and you should be successfully authenticated.

You are now connected to CarsXE.
