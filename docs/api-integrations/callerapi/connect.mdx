## Overview

To authenticate with CallerAPI, you need:

1. **API Key** — the API key from your CallerAPI dashboard.

This guide will show you how to find it.

### Prerequisites

- A CallerAPI account. CallerAPI uses Google sign-in.

### Step 1: Copy your API key

1. Go to the [CallerAPI dashboard](https://callerapi.com/dashboard) and sign in with Google.
2. If a **Special Offer** pop-up opens, close it with the **X** button in its top-right corner.

<img src="/api-integrations/callerapi/dashboard_api_key.png" alt="CallerAPI dashboard with the Special Offer pop-up open over the API key card"/>

3. In the **API key** card on the **Dashboard**, click **Copy key**. Click **Show key** if you want to see it first.

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with CallerAPI.
2. Enter your API key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/callerapi/form.png" alt="CallerAPI Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to CallerAPI.
