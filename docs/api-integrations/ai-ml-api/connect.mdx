## Overview

To authenticate with AI/ML API, you need:

1. **API Key** — your AI/ML API key.

This guide will show you how to get it.

### Prerequisites

- An AI/ML API account. You can [sign up here](https://aimlapi.com/app/sign-up).

### Step 1: Create an API key

1. Log in to [AI/ML API](https://aimlapi.com/app).
2. In the sidebar, click **API keys**, then click **Create key** on the **API keys** tab.

<img src="/api-integrations/ai-ml-api/api_keys_page.png" alt="API keys page in the AI/ML API dashboard with the Create key button"/>

3. Enter a descriptive name for the key and click **Create API key**.

<img src="/api-integrations/ai-ml-api/create_api_key_dialog.png" alt="Create API key dialog with a key name entered"/>

4. Click **Copy key** and store the key securely. It is not shown again.

<img src="/api-integrations/ai-ml-api/api_key_created.png" alt="Save your API key dialog with the Copy key button"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with AI/ML API.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/ai-ml-api/form.png" alt="AI/ML API connection form in the Nango Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to AI/ML API.
