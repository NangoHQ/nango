# Overview

To authenticate with iFax, you need an **API Key**. Nango sends the key in the `accessToken` header on API requests.

### Prerequisites

- An iFax account with API access

### Instructions

#### Step 1: Find your API key

Sign in to iFax and copy the API key for your account. If you cannot locate or generate a key, contact iFax support to enable API access.

<Warning>Store the API key securely. Do not expose it in client-side code.</Warning>

#### Step 2: Enter the API key in the Connect UI

1. Open the form where you need to authenticate with iFax.
2. Paste the value into the **API Key** field.
3. Submit the form to connect the account.

You are now connected to iFax.

For authentication details, see the [iFax API documentation](https://www.ifaxapp.com/docs/api/v1#authentication).
