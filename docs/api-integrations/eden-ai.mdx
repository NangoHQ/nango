## 🚀 Quickstart

Connect to Eden AI with Nango and see data flow in 2 minutes.

<Steps>
    <Step id="create-integration" title="Create the integration">
    In Nango ([free signup](https://app.nango.dev)), go to **Integrations** -> _Configure New Integration_ -> _Eden AI_.
    </Step>
    <Step id="authorize-eden-ai" title="Authorize Eden AI">
    Go to **Connections** -> _Add Test Connection_ -> _Authorize_, then choose your region and enter your Eden AI API key. Later, you'll let your users do the same directly from your app.
    </Step>
    <Step id="call-eden-ai-api" title="Call the Eden AI API">
    Let's make your first request to the Eden AI API to list your routing policies. Replace the placeholders below with your [Environment API key](/reference/backend/http-api/api-keys), integration ID, and connection ID:
    <Tabs>
        <Tab title="cURL">

            ```bash
            curl "https://api.nango.dev/proxy/v3/manage/routing-policies/?limit=1" \
              -H "Authorization: Bearer <NANGO-API-KEY>" \
              -H "Provider-Config-Key: <INTEGRATION-ID>" \
              -H "Connection-Id: <CONNECTION-ID>"
            ```

        </Tab>

        <Tab title="Node">

        Install Nango's backend SDK with `npm i @nangohq/node`. Then run:

        ```typescript
        import { Nango } from '@nangohq/node';

        const nango = new Nango({ apiKey: '<NANGO-API-KEY>' });

        const res = await nango.get({
            endpoint: '/v3/manage/routing-policies/',
            params: { limit: 1 },
            providerConfigKey: '<INTEGRATION-ID>',
            connectionId: '<CONNECTION-ID>'
        });

        console.log(res.data);
        ```
        </Tab>
    </Tabs>

    Or fetch credentials with the [Node SDK](/reference/backend/backend-sdk/node#get-a-connection-with-credentials) or [API](/reference/backend/http-api/connections/get).

    ✅ You're connected! Check the **Logs** tab in Nango to inspect requests.
    </Step>

    <Step id="implement-in-app" title="Implement Nango in your app">
        Follow our [quickstart](/getting-started/quickstart) to integrate Nango in your app.
    </Step>
</Steps>

## API gotchas

- The hosted MCP server is on `https://mcp.edenai.run` (endpoint `/mcp`), not on the connection's base URL. Call it with `baseUrlOverride` set to `https://mcp.edenai.run`; Nango keeps the connection's credentials and headers. See [MCP Server](https://www.edenai.co/docs/v3/expert-models/mcp-server).
