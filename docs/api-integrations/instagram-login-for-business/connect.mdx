## Overview

To authenticate with Instagram (Facebook Login for Business), you may need:
1. **Configuration ID** - only if it hasn't already been configured on the integration.

This guide walks you through finding your Configuration ID, in case you're asked to provide it.

### Instructions

#### Step 1: Find your Configuration ID

The Configuration ID is usually the same for every connection made through this integration, so whoever set up Instagram (Facebook Login for Business) in Nango has usually already preconfigured it. Only fill this in if you're explicitly asked to.

1. Go to the [Meta Developer Dashboard](https://developers.facebook.com/apps/) and open your app.
2. In the left sidebar, go to **Facebook Login for Business** > **Configurations**.
3. Copy the **Configuration ID** of the configuration you want to log in with (e.g., `1234567890123456`).

#### Step 2: Enter your connection details

1. Open the form where you need to authenticate with Instagram (Facebook Login for Business).
2. Only fill in **Configuration ID** if the connection form asks you for it.
3. Submit the form and log in to Facebook.

You are now connected to Instagram (Facebook Login for Business).
