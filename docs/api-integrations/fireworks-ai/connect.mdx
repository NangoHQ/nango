## Overview

To connect with Fireworks AI, you need:

1. **API Key** – A Fireworks AI API key, sent as a Bearer token.

This guide walks you through creating one.

### Prerequisites

- A [Fireworks AI](https://fireworks.ai) account.

### Instructions

#### Step 1: Create an API key

1. Log in to Fireworks AI and open the [Fireworks AI dashboard](https://app.fireworks.ai/settings/users/api-keys).
2. Create a new API key.
3. Give it a name that identifies this integration, so you can revoke it later without affecting your other keys.
4. Confirm, then copy the value. It is only shown once.

<Tip>Keep your API key secret. Anyone holding it can call the Fireworks AI API and spend your account's credits.</Tip>

#### Step 2: Authorize in Nango

1. Open the Nango Connect form.
2. Enter your **API Key** in the field provided.
3. Submit the form, and you should be successfully authenticated.

You are now connected to Fireworks AI.
