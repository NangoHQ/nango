## Overview

To authenticate with Fireworks AI, you need:

1. **API Key** — a Fireworks AI API key.

This guide will show you how to get it.

### Prerequisites

- A Fireworks AI account. You can sign up at [app.fireworks.ai/signup](https://app.fireworks.ai/signup).

### Step 1: Create an API key

1. Sign in at [app.fireworks.ai](https://app.fireworks.ai/login), then go to **Settings** -> **API Keys**, or open [app.fireworks.ai/settings/users/api-keys](https://app.fireworks.ai/settings/users/api-keys).
2. Click **Create API Key**.

<img src="/api-integrations/fireworks-ai/api_keys_page.png" alt="Fireworks AI API Keys settings page with the Create API Key button"/>

3. Enter a name for the key, optionally choose an **Expiration** (keys expire at most 1 year after creation), then click **Generate Key**.

<img src="/api-integrations/fireworks-ai/create_api_key_dialog.png" alt="Fireworks AI Create API Key dialog with the API Key Name and Expiration fields and the Generate Key button"/>

4. Copy the API key. It is only shown once, when it is created.

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Fireworks AI.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/fireworks-ai/form.png" alt="Fireworks AI connection form in the Nango Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to Fireworks AI.
