## Overview

To authenticate with ApexVerify, you need:

1. **API Key** — an ApexVerify API key.

This guide will show you how to get it.

### Prerequisites

- An ApexVerify account. You can [sign up for free](https://app.apexverify.com).

### Step 1: Create an API key

1. Sign in to the [ApexVerify dashboard](https://app.apexverify.com) and click **API Access** in the left sidebar.

<img src="/api-integrations/apexverify/dashboard_api_access_nav.png" alt="ApexVerify dashboard with API Access in the left sidebar"/>

2. Click **ADD API KEY**. A new key appears in the list.

<img src="/api-integrations/apexverify/add_api_key_button.png" alt="ADD API KEY button on the ApexVerify API Access page"/>

3. Optionally, rename the key (e.g. `nango-integration`) by clicking its name, typing a new one and pressing Enter.
4. Make sure the key's **Enabled** toggle is on, then click the copy icon to copy the API key.

<img src="/api-integrations/apexverify/copy_api_key.png" alt="Renamed ApexVerify API key with its Enabled toggle and copy icon"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with ApexVerify.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/apexverify/form.png" alt="ApexVerify connection form in the Nango Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to ApexVerify.
