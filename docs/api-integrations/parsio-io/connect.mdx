## Overview

To authenticate with Parsio, you need:

1. **API Key** — the API key of your Parsio account.

This guide will show you how to find it.

### Prerequisites

- A Parsio account. API access is included in the free plan. If you don't have an account, [sign up](https://app.parsio.io/signup).

### Step 1: Copy your API key

1. Log in to [Parsio](https://app.parsio.io).
2. Click your name in the top right, then open **Account & API**.
3. Under **Account Information**, click the copy icon next to the **API key** field.

<img src="/api-integrations/parsio-io/account_api_key.png" alt="Parsio Account & API page with the API key field and its copy icon"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with Parsio.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/parsio-io/form.png" alt="Parsio Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to Parsio.
