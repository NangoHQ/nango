## Overview

To authenticate with EODHD APIs, you need:

1. **API Token** — the API token of your EODHD account.

This guide will show you how to get it.

### Prerequisites

- An EODHD account. The free plan includes 20 API calls per day; [sign up here](https://eodhd.com/register).

### Step 1: Copy your API token

1. Sign in to [EODHD](https://eodhd.com/login) and open your [Dashboard](https://eodhd.com/cp/dashboard).
2. In the **API token** section, click the copy icon next to the token.

<img src="/api-integrations/eodhd-apis/dashboard_api_token.png" alt="EODHD Dashboard with the copy icon next to the API token highlighted"/>

### Step 2: Enter your API token in the Connect UI

1. Open the form where you need to authenticate with EODHD APIs.
2. Enter your **API Token** in the designated field.
3. Click **Connect**.

<img src="/api-integrations/eodhd-apis/form.png" alt="Nango Connect UI form for entering the EODHD API token" style={{maxWidth: "450px" }}/>

You are now connected to EODHD APIs.
