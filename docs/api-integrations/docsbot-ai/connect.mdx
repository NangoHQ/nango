## Overview

To authenticate with DocsBot AI, you need:

1. **API Key** — your DocsBot user API key.

This guide will show you how to generate it.

### Prerequisites

- A DocsBot account. If you don't have one, [sign up](https://docsbot.ai/register). The free plan needs no credit card.

### Step 1: Generate your API key

1. Sign in to [DocsBot](https://docsbot.ai/login).
2. In the left sidebar, open [API/Integrations](https://docsbot.ai/app/api).
3. Under **DocsBot API Key**, click **Change** to generate a new key.

<img src="/api-integrations/docsbot-ai/api_page_change_key.png" alt="DocsBot API/Integrations page with the Change button under DocsBot API Key" />

4. Click the copy button next to the new key and store it somewhere safe. DocsBot shows the key only once.

<img src="/api-integrations/docsbot-ai/api_key_created.png" alt="DocsBot API Key section with the new key and its copy button" />

<Note>
The API key belongs to your user account and works for every team you have a role in. There is one key per user: clicking **Change** again replaces it, and the old key stops working.
</Note>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with DocsBot AI.
2. Enter your API key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/docsbot-ai/form.png" alt="DocsBot AI Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to DocsBot AI.
