## Overview

To authenticate with Smarfle, you need:

1. **API Key** - A key the owner of a Smarfle business creates in Company Settings.

This guide shows you how to create the key and connect it.

### Step 1: Create an API key

1. Sign in to [Smarfle](https://www.smarfle.com) as the owner of the business.
2. Go to **Company Settings** -> **Integrations** -> **API keys** and click **Create API key**.
3. Pick **Read** to only read customers, jobs, invoices and services, or **Read and write** to also create and update records.
4. Copy the key. It starts with `smk_` and is shown only once.

### Step 2: Enter the key in the Connect UI

Paste the API key into the **API Key** field and click **Connect**.

<Note>Each key belongs to one Smarfle business and only reads or changes that business's data. Reads are free; each write is billed to the business's Smarfle plan.</Note>
