## Overview

To authenticate with APIpie AI, you need:

1. **API Key** — an APIpie API key.

This guide will show you how to get it.

### Prerequisites

- An APIpie account. You can [register here](https://apipie.ai/profile/auth/register).
- Credits on your account. After logging in, add credits on the [subscription page](https://apipie.ai/profile/subscribe) to enable API access.

### Step 1: Create an API key

1. Log in to [APIpie](https://apipie.ai/profile/auth/login).
2. Open the [API keys page](https://apipie.ai/profile/api-keys).
3. Create a new API key and copy it.

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with APIpie AI.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/apipie-ai/form.png" alt="APIpie AI connection form in the Nango Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to APIpie AI.
