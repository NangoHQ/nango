## Overview

To authenticate with SalesCaptain, you need:

1. **API Key** — a key created in your SalesCaptain account.

This guide will walk you through creating your API key in SalesCaptain.

### Prerequisites

- A [SalesCaptain account](https://app.salescaptain.com/).

### Step 1: Fetching an API key

1. Log in to your [SalesCaptain account](https://app.salescaptain.com/login).
2. Click **Settings** in the side navigation.
3. Click **API & Webhooks** in the settings.
4. Click **Copy** in API key section.

<img src="/api-integrations/salescaptain/copy_key.png" />

### Step 2: Enter your API key in the Connect UI

Once you have your API key:

1. Open the form where you need to authenticate with SalesCaptain.
2. Enter your **API Key** in the designated field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/salescaptain/form.png" style={{ maxWidth: '450px' }} />

You are now connected to SalesCaptain.
