## Overview

To authenticate with faktoora, you need:

1. **Environment** — the faktoora API host your account is on.
2. **API Key** — a faktoora API key.

This guide will show you how to get them.

### Prerequisites

- A faktoora account with API access. See [faktoora pricing](https://faktoora.com/en/preise) for the plans that include an API connection.

### Step 1: Choose your environment

faktoora has three API hosts. Select the one you want to connect to:

| Environment | Value to select |
|-------------|-----------------|
| Production | `api.faktoora.com` |
| Demo | `api.demo.faktoora.com` |
| Sandbox | `api.sandbox.faktoora.com` |

Use `api.faktoora.com` for your live faktoora account. faktoora provides a sandbox environment [on request](https://faktoora.com/en/api).

### Step 2: Create an API key

1. Sign in to your [faktoora account](https://app.faktoora.com).
2. Click the down arrow next to your profile picture.
3. Click **API Access**.
4. Create a new API key and copy it.

### Step 3: Enter your credentials in the Connect UI

1. Open the form where you need to authenticate with faktoora.
2. Select your **Environment** and enter your **API Key** in the designated fields.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/faktoora/form.png" alt="faktoora connection form in the Nango Connect UI" style={{maxWidth: "450px" }}/>

You are now connected to faktoora.
