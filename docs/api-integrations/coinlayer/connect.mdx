## Overview

To authenticate with Coinlayer, you need:

1. **API Access Key** — the API access key from your Coinlayer dashboard.

This guide will show you how to get it.

### Prerequisites

- A Coinlayer account on any plan. The Free plan includes 100 API requests per month; [sign up here](https://coinlayer.com/signup/free) or pick a paid plan on the [pricing page](https://coinlayer.com/pricing).

### Step 1: Copy your API access key

1. Log in at [coinlayer.com/login](https://coinlayer.com/login) and open the [dashboard](https://coinlayer.com/dashboard).
2. Under **Your API Key** at the top of the dashboard, click the copy icon to copy your API access key.

<img src="/api-integrations/coinlayer/dashboard_api_key.png" alt="Coinlayer dashboard with the copy icon highlighted in the Your API Key field"/>

### Step 2: Enter your API access key in the Connect UI

1. Open the form where you need to authenticate with Coinlayer.
2. Paste the key you copied in Step 1 into the **API Access Key** field.
3. Click **Connect**.

<img src="/api-integrations/coinlayer/form.png" alt="Coinlayer Connect UI form with the API Access Key field" style={{maxWidth: "450px" }}/>

You are now connected to Coinlayer.
