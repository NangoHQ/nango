## Overview

To authenticate with WebScraping.AI, you need:

1. **API Key** — the API key from your WebScraping.AI dashboard.

This guide will show you how to get it.

### Prerequisites

- A WebScraping.AI account. [Sign up](https://webscraping.ai/auth/sign_up) if you don't have one: the free plan includes 2,000 API credits per month and needs no credit card.

### Step 1: Copy your API key

1. Sign in to WebScraping.AI and open the [Dashboard](https://webscraping.ai/dashboard).
2. Find the **Your API key** panel and click **Copy** to copy your key.

<img src="/api-integrations/webscraping-ai/dashboard_api_key.png" alt="WebScraping.AI Dashboard with the Copy button in the Your API key panel highlighted"/>

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with WebScraping.AI.
2. Enter your key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/webscraping-ai/form.png" alt="WebScraping.AI Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to WebScraping.AI.
