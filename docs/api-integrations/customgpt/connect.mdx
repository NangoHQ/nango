## Overview

To authenticate with CustomGPT.ai, you need:

1. **API Key** — an API key from the API tab of your CustomGPT.ai profile.

This guide will show you how to create it.

### Prerequisites

- A CustomGPT.ai account. If you don't have one, [sign up](https://app.customgpt.ai/register) with a company email address (personal addresses such as Gmail are not accepted). Every plan starts with a 7-day free trial, which needs a credit card.

### Step 1: Create an API key

1. [Log in](https://app.customgpt.ai/login) to CustomGPT.ai.
2. Open [My Profile](https://app.customgpt.ai/profile), then open the [API](https://app.customgpt.ai/profile#api) tab.
3. Click **Create an API Key**.

<img src="/api-integrations/customgpt/api_tab_create_key.png" alt="CustomGPT.ai My Profile page on the API tab with the Create an API Key button" />

4. On the **API Key Ready** screen, click the copy icon next to **Copy your key** to copy the API key.

<img src="/api-integrations/customgpt/api_key_created.png" alt="CustomGPT.ai API Key Ready screen with the copy icon next to Copy your key" />

### Step 2: Enter your API key in the Connect UI

1. Open the form where you need to authenticate with CustomGPT.ai.
2. Enter your API key in the **API Key** field.
3. Submit the form, and you should be successfully authenticated.

<img src="/api-integrations/customgpt/form.png" alt="CustomGPT.ai Connect UI form with the API Key field" style={{maxWidth: "450px" }}/>

You are now connected to CustomGPT.ai.
