## Overview

To authenticate with Litmos, you will need:

1. **API Domain** - The Litmos API domain for your account's region.
2. **API Key** - A key that grants Nango permission to call the Litmos API on your behalf.

This guide explains how to obtain both.

### Prerequisites

- An Account Owner or Administrator login on a paid Litmos account. Litmos does not enable the API on trial accounts.

### Instructions

<a id="step-1-find-your-api-domain"></a>
#### Step 1: Find your API domain

Pick the API domain that matches the region your Litmos account is hosted in:

| Region | API domain |
| --- | --- |
| United States | `api.litmos.com` |
| Europe | `api.litmoseu.com` |
| Australia | `api.litmos.com.au` |

<a id="step-2-find-your-api-key"></a>
#### Step 2: Find your API key

1. Log in to Litmos as an Account Owner or Administrator.
2. Open **My Profile & Settings**.
3. Go to the **API Key** section and copy the key.

Treat the key like a password: it can read and change data across your whole Litmos account.

#### Step 3: Enter credentials in the Connect UI

1. Open the form where you need to authenticate with Litmos.
2. Select your **API Domain**.
3. Enter your **API Key**.
4. Submit the form to complete authentication.

<img src="/api-integrations/litmos/form.png" style={{maxWidth: "450px" }}/>

You are now connected to Litmos.
